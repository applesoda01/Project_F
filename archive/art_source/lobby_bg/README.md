## 게임 적용 내역 (2026-10-26 적용 완료)

게임용 2장은 `prototype/assets/lobby/`에 복사했고, 아래 값은 코드에 반영했습니다. 리나 발밑(`FEET`) 470→414, 말풍선 y 200→144도 같은 비율(−56)로 옮겼습니다.

- 카운터 위치: `COUNTER_Y` 428 → **372** (`prototype/js/lobby.js`)
- 의뢰서 칸: 게시판 안쪽이 x 356~1566, y 50~328 입니다. 지금 `BOARD`(x0 285, x1 1650, rows 68·210)는 판 밖으로 나가므로 예: x0 370, x1 1550, rows 64·204 로 줄여야 합니다.
- 칠판 안에는 글자·그림이 없습니다. 의뢰서는 코드가 그립니다.
- wall 레이어의 가려진 부분은 근사 채움이라 게시판·카운터를 움직이는 연출에는 쓰지 마세요.
