# 앉은 자세 제작 참고

| 파일 | 용도 |
| --- | --- |
| `chair_lv1·lv2_front·back.png` | 게임에 쓰는 의자 원본 (@2x, 192×256). 화면에서는 96×128 |
| `sit_chair_front·back_cell512.png` | 의자를 **걷기 시트와 같은 축척**으로 512 셀 안에 놓은 투명 PNG. 이 위에 앉은 캐릭터를 그리면 됨 |
| `sit_guide_front·back.png` | 위 셀 + 서 있는 전사(반투명) + 기준선. 크기 비교용 |

## 규칙

- 셀 512×512, 걷기 시트와 같은 축척 (화면 1px = 셀 1.728px)
- **의자 발밑 = 셀 기준점** (가로 가운데, y=488). 게임에서 의자와 캐릭터를 같은 점에 놓음
- 엉덩이는 초록 선(좌석 면 중심) 높이
- 앞모습(front) = 앞을 보고 앉음, 의자 앞모습 위. 뒷모습(back) = 등을 보이고 앉음, 의자 등받이가 캐릭터 앞에 그려짐
- **완성본에는 의자를 넣지 않음** (의자는 코드가 따로 그림, 레벨에 따라 바뀜)
- 파일 이름: `chr_<직업>_<성별>_sit.png` — 가로 2칸 [front, back]. 숨쉬기 등 프레임을 넣으면 행을 늘림
