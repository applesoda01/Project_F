# 리나 눈 깜빡임 합성 도구

전신 일러스트(1684×2528) 표정 6종에 눈 깜빡임 3칸(뜬 눈·반쯤·감음)을 만든 방법. 결과물은 `art_source/receptionist_blink/`.

## 흐름

1. **대머리 6종** (`art_source/receptionist_workfiles/bald_6/`) 에 **머리카락 전체 레이어** (`hair_layer/hair_전체_레이어.png`, RGBA 800×720, 캔버스 오프셋 (450,40)) 를 얹음. 분리 4부위(`parts/`)는 윤곽이 빠져서 쓰지 않음. 귀는 진지 원본(`in1_진지_원본.png`) 영역 (925,285,1110,470) 을 가우시안 5로 번지게 덮음. → 각 표정의 `open` 칸.
2. **눈 깜빡임 영상**: ComfyUI LTX-2.5 이미지→영상. 눈 주변을 460→768로 잘라(원본 x610~1070, y150~610) 1초(25프레임) 생성. 웃음은 이미 감은 눈이라 건너뜀(3칸 동일). 고른 시드 폴더가 `frames/f_<표정번호>_<시드>/f01~f25.png`.
3. **합성** (`comp3.py`, `proc2.py`):
   - `proc2.load2(표정번호, 시드)` → 영상 프레임을 SIFT로 대머리 베이스에 정렬.
   - `comp3.half(base, 프레임)` · `comp3.closed(base, 프레임)`. 눈썹·눈꺼풀 주름은 `open` 칸 그대로 두고, 눈 안쪽(속눈썹 윤곽+흰자위, 볼록 껍질)만 피부색으로 채운 뒤 영상의 속눈썹만 올림.
4. 눈 영역(y281~401, x707~937) 밖 픽셀은 `open` 칸과 최대 차이 0 인지 확인.
5. `build_idle_sheet.py` 로 기본 표정 3칸 시트 생성.

## 알아둘 점

- 스크립트에 경로가 박혀 있음: 영상 프레임 `/tmp/lina/bb/f_<표정>_<시드>/`, 대머리 `/mnt/user-data/outputs/bald_final/bald_<이름>.png`, 머리 레이어 `/mnt/user-data/outputs/hair2_inputs/hair_전체_레이어.png`, 합성 결과 `/mnt/user-data/outputs/hair_blink_fix/`. 새 PC에서는 `frames/`, `bald_6/`, `hair_layer/` 로 경로를 바꿔서 쓸 것.
- 눈 영상 프레임 전체(25장×시드)를 넣어 둔 것은 고른 시드 5개뿐. 다른 시드는 ComfyUI로 새로 생성.
- 눈 영상을 만든 ComfyUI 워크플로우 파일은 이 폴더에 없음.
- 영상 프레임의 눈썹·주름까지 가져오면 눈썹이 겹쳐 번지므로, 눈썹·주름은 반드시 `open` 칸에서 가져올 것.
- 흰자위(밝고 무채색) 영역을 베이스 눈 마스크에 포함해야 큰 눈(놀람·기본)이 깨끗이 지워짐 (`base_eye`).
