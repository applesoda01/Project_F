# 대화씬 편집기

프롤로그·대화씬·메인 퀘스트의 대사를 만들고 씬(JSON)으로 저장하는 단일 HTML 도구입니다.
`index.html` 을 크롬/엣지에서 열면 됩니다 (서버 불필요, 외부 통신 없음).

## 시작하기
1. `tools/dialogue_editor/index.html` 을 엽니다.
2. **폴더 열기** → Project_F 루트를 고릅니다. `data/dialogue/` 가 있으면 읽고, 없으면 저장할 때 만들어집니다.
3. 왼쪽에서 씬을 고르거나 **+ 새 씬**. 가운데 미리보기, 오른쪽 대화 로그에서 편집합니다.
4. **저장** (Ctrl+S). 폴더를 연결하지 않은 브라우저는 **내보내기/가져오기** 로 JSON 한 파일을 주고받습니다.
5. 작업 내용은 브라우저에 자동 보관되어, 저장 전에 창을 닫아도 다시 열면 복원됩니다.

## 저장 구조
```
data/dialogue/
  characters.json     화자 목록 (이름, 초상화 경로, 표정)
  scene_index.json    씬 호출 조건표
  scenes/<씬ID>.json  씬 한 개당 파일 하나
```
키 순서와 들여쓰기가 고정이라 Git diff 에 바뀐 대사만 나타납니다. 예시는 `sample/` 에 있습니다.

## 단계(step) 종류
| type | 내용 |
|---|---|
| say | 화자, 표정, 대사, 박스 효과 |
| background | 배경 파일, 전환(페이드/즉시) |
| bgm | 재생(파일) / 정지 |

모든 단계에 `id` 가 있어 나중에 번역표에서 그대로 쓸 수 있습니다. 파일 경로는 `prototype/assets/` 기준입니다.

## 박스 효과
흔들림(shake), 글자 떨림(tremble), 느린 타이핑(slow_type), 효과음 재생(se, 파일 지정), 화면 번쩍임(flash).

## 점검
없는 화자·표정·파일, 90자/3줄 초과, 빈 대사, 효과음 파일 누락을 씬 목록과 상단에 표시합니다. 오류가 있어도 저장은 할 수 있습니다.

## 빠르게 쓰기
- **키보드**: 대사 칸에서 Enter = 다음 대사 추가(같은 화자·표정), Shift+Enter = 줄바꿈, 빈 칸에서 Backspace = 단계 삭제. Alt+숫자 = 화자, Alt+Shift+숫자 = 표정, Ctrl+↑↓ = 단계 이동 선택, Alt+↑↓ = 순서 변경, Ctrl+Enter = 재생. 전체 목록은 상단 "단축키".
- **무대에서 직접 수정**: 이름 클릭 = 화자, 초상화 클릭 = 표정, 대사 클릭 = 글자 수정, 배경 단계에서 무대 클릭 = 파일 고르기.
- **대본 붙여넣기**: `리나(웃음): 대사 [흔들림] [번쩍임]`, `@배경 파일 컷`, `@BGM 파일`, `@BGM 정지` 형식의 텍스트를 한 번에 단계로 변환. 현재 씬을 대본으로 되돌려 볼 수도 있음.
- **파일 고르기**: 폴더를 연결하면 `prototype/assets` 의 이미지·소리를 목록(배경은 썸네일)에서 고르고 검색 가능. 입력 칸 자동 완성도 같은 목록을 씀.

## 기타 기능
- **dialog.csv 가져오기**: `data/dialog.csv` 의 장면을 `lina_<장면>` 씬으로 변환 (이미 있는 ID는 건너뜀, `{변수}` 는 그대로 유지).
- **화자 목록**: 화자 추가·표정·초상화 경로 수정 (없는 표정은 `default` 로 대체).
- **씬 호출 조건표**: 어떤 상황에 어떤 씬을 부를지 (`new_game`, `visit`, `mainquest_start`, `manual`).
- 단계 복제·위아래 이동·드래그 순서 변경, 선택 단계 뒤에 삽입, 실행 취소/다시 실행 (Ctrl+Z / Ctrl+Y).
- 재생: 선택한 단계부터. 클릭·Space·Enter 로 다음, Esc 로 정지.

## 이번 범위에서 제외
다국어 번역, 선택지·분기, 이벤트 호출, 이벤트 CG, 보이스, 오토/스킵, 모험가 다중 표정·다중 초상화.
게임(prototype)에서 씬 JSON 을 읽어 재생하는 연결은 아직 붙이지 않았습니다.
