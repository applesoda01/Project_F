# 소재 편집기

소재·음식·장비·물약을 정의하는 단일 HTML 도구입니다. 설치 없이 `index.html`을 Chrome으로 열면 됩니다(인터넷이 없으면 글꼴만 기본 글꼴로 보입니다).

## 하는 일

| 탭 | 내용 |
| --- | --- |
| 소재 | 코어 35종(5계열 × F~S)은 이름·아이콘·설명만 수정, 삭제 불가. 추가 소재는 등급·계열 변경과 삭제 가능. 조합법에서 쓰는 소재는 삭제가 막힘 |
| 퀘스트 | 의뢰 유형 × 등급 35칸(삭제 불가)과 직접 추가하는 메인·서브·승급·리소스 퀘스트. 오른쪽 상세는 하위 탭 4개로 나뉨(아래 표). 소재 상세에는 "얻는 퀘스트"가 표시됨 |
| 음식·장비·물약 | 이름, 등급, 효과 설명, 아이콘, 조합법(소재 최대 3종 × 수량) |

- 처음 열면 `docs/data/materials_v0.1.md`의 코어 35종, 복원 재료 2종, 음식 14종, 의뢰 35칸(주 소재 100%, 한 단계 아래 다른 계열 소재 7.5%씩 합계 30%, F~C는 수선 숫돌 5%. 모두 가안)(재료는 식재료 12종을 추가 소재로 만들어 연결)이 들어 있습니다. 식재료 소재는 가안이니 필요 없으면 삭제하세요.
- 추가 소재는 정렬(추가한 순·이름·등급·계열·쓰이는 곳 수, 오름·내림차순)을 고를 수 있고, 고른 정렬은 이 브라우저에 기억됩니다.
- 작업 내용은 이 브라우저에 자동 저장됩니다(다른 PC로 옮기려면 백업을 쓰세요).
- 아이콘은 긴 변 512px 이하로 줄여 보관합니다. 게임용 크기는 정해지면 내보낼 때 맞춥니다.

### 퀘스트 상세 하위 탭 (하나씩 만드는 중)

| 탭 | 상태 | 항목 |
| --- | --- | --- |
| 1. 기본 정보 | 완료 (2026-11-02) | 이름, 분류·유형·등급(기본 35칸은 고정), 의뢰인(쓴 적 있는 이름 자동 완성), 의뢰서 문구(글자 수 표시), 기획 메모(게임에 안 나옴) |
| 2. 미니 뷰 연출 | 완료 (2026-11-02) | 배경 지역(비우면 유형별 기본), 소요 기간(기본 기간 대비 변화), 적 목록 최대 3줄(이름·기본 수·보스·그림 파일). 고른 기간의 보상·판정 기준치·사망률·몬스터 수를 자동 계산해 보여 줌 |
| 3. 판정·보상 | 완료 (2026-11-02) | 요구 능력치(자동=게임 규칙: 유형 대표 + 등급 기본 개수까지 무작위 / 직접 지정), 보스급(기준치 ×1.15), 판정 기준치·사망률·보상 금액·명성 성공/실패·신뢰도 성공/실패(자동값 옆에 직접 입력, 비우면 자동, ↺로 되돌림), 보상 소재 |
| 4. 등장 조건·대사 | 준비 중 | 길드 등급·선행 퀘스트, 수락·성공·실패 때 리나 대사 |

### 기간 규칙 계수 (퀘스트 탭 맨 위)

기본 기간보다 1주 늘거나 줄 때 적용하는 계수입니다. 바꾸면 아래 표와 모든 퀘스트의 자동 계산이 바로 바뀝니다.

| 계수 | 기본값 [가안] |
| --- | --- |
| 보상 배수 (주마다) | ×2 |
| 몬스터 수 배수 (주마다, 보스 제외, 반올림) | ×1.5 |
| 판정 기준치 (주마다) | +5% |
| 기간 범위 | −1주 ~ +2주 (1주 미만 불가) |
| 주당 보상 상한 | 켬: 한 등급 위 기본 주당 보상까지 |

- 판정·보상 탭에서 직접 입력한 값은 계수보다 우선합니다(✎ 표시). 계수를 바꿔도 직접 입력한 값은 그대로입니다.
- 사망률은 기간에만 비례합니다: 1 − (1 − 등급 사망률)^(기간 ÷ 기본 기간).
- 등급 기본값(보상·기간·기준치·사망률)은 `data/balance.csv`의 quest 항목을 옮겨 적은 것입니다. balance.csv를 바꾸면 편집기 코드의 `BAL`도 맞춰야 합니다(게임 연결 단계에서 자동으로 읽게 바꿀 예정).
- 시뮬레이션 표: 등급 7 × 기간 변화별로 보상·주당 보상·몬스터 수·기준치·사망률 중 하나를 골라 봅니다. 주황 글자는 상한에 걸린 값입니다.

- 고른 하위 탭은 이 브라우저에 기억됩니다. 예전 작업(브라우저 저장·`backup.json`)을 열면 새 항목은 빈 값으로 채워집니다.

## 저장 방법

1. **폴더에 저장**: `Project_F/data` 폴더를 고르면 `materials.csv`, `items.csv`, `backup.json`, `icons/*.png`를 바로 씁니다.
2. **zip 내보내기**: 같은 파일을 zip 하나로 내려받습니다.
3. **백업 불러오기**: `backup.json`을 읽어 이어서 작업합니다.

## 출력 형식

- `materials.csv`: id, 이름, 등급, 계열, 구분(코어/추가), 설명, 아이콘
- `quests.csv`: id, 이름, 분류, 등급, 유형, 의뢰인, 의뢰서 문구, 기획 메모, 배경, 소요 주, 기간 변화, 요구 능력치, 보스급, 판정 기준치, 사망률(%), 보상 금액, 명성 성공, 명성 실패, 신뢰도 성공, 신뢰도 실패, 직접 입력 항목, 소재id, 소재이름, 구분, 확률(%) (보상 1개당 1행)
- `quest_enemies.csv`: 퀘스트id, 순서, 이름, 기본 수, 보스, 그림
- `quest_rules.csv`: 기간 규칙 계수 (항목, 값, 설명)
- `items.csv`: id, 종류, 이름, 등급, 설명, 재료1·수량1, 재료2·수량2, 재료3·수량3, 아이콘
- id는 `mat_<계열>_<등급>`(코어), `mat_xNNN`(추가), `food_NN` / `gear_NN` / `pot_NN`.

게임 데이터(`data_build.py`)에는 아직 연결하지 않았습니다. 요리하기 규칙(소재 소모, 14종 고정, 영구 해금)이 확정되면 연결합니다.
