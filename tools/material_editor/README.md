# 소재 편집기

소재·음식·장비·물약을 정의하는 단일 HTML 도구입니다. 설치 없이 `index.html`을 Chrome으로 열면 됩니다(인터넷이 없으면 글꼴만 기본 글꼴로 보입니다).

## 하는 일

| 탭 | 내용 |
| --- | --- |
| 소재 | 코어 35종(5계열 × F~S)은 이름·아이콘·설명만 수정, 삭제 불가. 추가 소재는 등급·계열 변경과 삭제 가능. 조합법에서 쓰는 소재는 삭제가 막힘 |
| 퀘스트 | 의뢰 유형 × 등급 35칸(삭제 불가, 이름만 수정)과 직접 추가하는 메인·서브·승급·리소스 퀘스트. 퀘스트마다 보상 소재(소재·구분 주/부/복원/기타·확률%)를 연결. 소재 상세에는 "얻는 퀘스트"가 표시됨 |
| 음식·장비·물약 | 이름, 등급, 효과 설명, 아이콘, 조합법(소재 최대 3종 × 수량) |

- 처음 열면 `docs/data/materials_v0.1.md`의 코어 35종, 복원 재료 2종, 음식 14종, 의뢰 35칸(주 소재 100%, 한 단계 아래 다른 계열 소재 7.5%씩 합계 30%, F~C는 수선 숫돌 5%. 모두 가안)(재료는 식재료 12종을 추가 소재로 만들어 연결)이 들어 있습니다. 식재료 소재는 가안이니 필요 없으면 삭제하세요.
- 추가 소재는 정렬(추가한 순·이름·등급·계열·쓰이는 곳 수, 오름·내림차순)을 고를 수 있고, 고른 정렬은 이 브라우저에 기억됩니다.
- 작업 내용은 이 브라우저에 자동 저장됩니다(다른 PC로 옮기려면 백업을 쓰세요).
- 아이콘은 긴 변 512px 이하로 줄여 보관합니다. 게임용 크기는 정해지면 내보낼 때 맞춥니다.

## 저장 방법

1. **폴더에 저장**: `Project_F/data` 폴더를 고르면 `materials.csv`, `items.csv`, `backup.json`, `icons/*.png`를 바로 씁니다.
2. **zip 내보내기**: 같은 파일을 zip 하나로 내려받습니다.
3. **백업 불러오기**: `backup.json`을 읽어 이어서 작업합니다.

## 출력 형식

- `materials.csv`: id, 이름, 등급, 계열, 구분(코어/추가), 설명, 아이콘
- `quests.csv`: id, 이름, 분류, 등급, 계열, 설명, 소재id, 소재이름, 구분, 확률(%) (보상 1개당 1행)
- `items.csv`: id, 종류, 이름, 등급, 설명, 재료1·수량1, 재료2·수량2, 재료3·수량3, 아이콘
- id는 `mat_<계열>_<등급>`(코어), `mat_xNNN`(추가), `food_NN` / `gear_NN` / `pot_NN`.

게임 데이터(`data_build.py`)에는 아직 연결하지 않았습니다. 요리하기 규칙(소재 소모, 14종 고정, 영구 해금)이 확정되면 연결합니다.
