# 아침 보고 (2026-11-21) — 던전 3단계 화면 구현

작성: Claude · 2026-11-21 · 자세히: [design/proposal_dungeon_v1.md](design/proposal_dungeon_v1.md) 12장 · 캡처 `design/mockups/dungeon_1120/applied/`

## 0. 요약

- **던전이 게임에서 처음부터 끝까지 됩니다:** 12주 열림 대화 → 리퀘스트 장에서 파티 고르기 · 보내기 → 원정 중 미니 뷰에서 갈림길 · 계속/귀환 고르기(6초) → 귀환 정산 → 50% 대장간 세트 → 100% 왕국 사자 · 편지 카드.
- **검사:** 관문 1 게임 388G · 시뮬 383G ✅ · 경제 계약 16/16 ✅ · 1280 · 1920 화면 오류 0.
- 수치 · 세부 규칙은 사용자 말씀대로 손대지 않았습니다(전부 [임시]).

## 1. 해 보시는 법

1. 새 게임 → 12주가 되면 바르톨 · 리나 대화 → 책이 리퀘스트 장으로 열림.
2. 던전 칸 → 아래 표에서 2~3명 → 「보내기」(원정 중인 사람도 예약 가능).
3. 다음 주 출발 → 오른쪽 「원정 중」에 고블린 굴이 뜨고, 진행 중 미니 뷰가 열리며 갈림길을 물어봄(6초 동안 시계 멈춤).

## 2. 정하실 것 (급하지 않음)

- 갈림길을 고르면 미니 뷰가 잠깐 닫혔다 새 방 싸움으로 다시 열립니다. 그대로 둘지.
- 던전 미니 뷰 배경이 풀밭입니다(동굴 배경 그림 필요 — 제미나이로 만들지).
- 보스는 고블린 그림을 1.3배로 키운 [임시]입니다. 보스 움직임 시트(공격 · 쓰러짐)를 만들지.
