# 진행 설계 v1 (튜토리얼 → F급 → 첫 전직)

> 2026-11-09 사용자와 논의해 확정한 **가안**. 프로토타입 안에서 튜토리얼부터 첫 2차 전직까지 한 흐름으로 보여 주는 것이 목표. 세부 수치는 나중에 다듬음.
> **아직 게임·시뮬레이터 코드에 반영하지 않음.** 메인 퀘스트·튜토리얼 구현 때 한꺼번에 넣고 관문 1 기준을 새로 잡음.

## 0. 요약

| 목표 | 결과 (시험용 게임, 30~40판) |
| --- | --- |
| 첫 2차 전직 제안 = 튜토리얼 뒤 약 1년 | **중앙값 48주** (하위 20% 40주 ~ 상위 20% 60주) |
| 1년 뒤 모험가 8명 | **약 8명** |
| 첫 전직 = 의뢰 약 15건 성공 | 15건 성공 시점 평균 **Lv 14.9 · 주 능력치 50.3** |
| 첫해 경제 | 월 순이익 약 545G (관문 1 기준 300~600G 안) |

## 1. 왜 바꿨나 (원인 분석)

| 원인 | 내용 |
| --- | --- |
| 길드 승급이 게임에 없음 | 시뮬레이터에만 승급(보스급 의뢰 → 침공) 규칙. 게임은 개발 버튼으로만 → F급 고정 → 관리소(E급 시설) 못 지음 → 전직 제안 0건 (400주) |
| 의뢰 유입 단위 실수 | `quest,perMonth` = 10(월)인데, 월 1회 생성하면서 다시 ÷4 → 실제 월 약 3건, 1년 36건 고정 |
| 성장량 | 의뢰 경험치 80, 의뢰 능력치 +0.2(이미 있었음, 효과 미미) → 1년 최고 Lv 7, 주 능력치 30 |
| 모험가 | 시작 5명 + 월 0.8명 무작위 → 1년 15명이 36건을 나눠 가짐 |

## 2. 결정 사항

### 2-1. 의뢰 공급과 신뢰도

| 항목 | 값 |
| --- | --- |
| 기본량 | **한 달 10건** (설정값대로 바로잡음) |
| 게시 | **매주 나눠 게시** (한 달 10건 ÷ 4주 × 퀄리티). 월초에 몰아 게시하면 게시판 6칸에 막혀 신뢰도 차이가 안 보임 |
| 신뢰도 | 0~100 (넘지 않음), **시작 50** |
| 신뢰도 역할 | **의뢰 발생량·보상·경험치**에만 영향 (모험가 등장에서는 뺌) |

**신뢰도 5단계 (퀄리티)** — 단계마다 범위 안에서 무작위. 보상·경험치는 의뢰가 붙을 때 의뢰마다 정하고 둘은 같은 비율

| 단계 | 신뢰도 | 표정 (HUD, 나중) | 의뢰 수 | 보상·경험치 | 능력치 상승 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0~19 | 화남 | 30~50% | 80~90% | 고정 |
| 2 | 20~39 | 불만 | 45~65% | 85~95% | 고정 |
| 3 | 40~59 | 보통 | 65~85% | 95~105% | 고정 |
| 4 | 60~79 | 만족 | 80~100% | 105~115% | 고정 |
| 5 | 80~100 | 아주 만족 | 100~120% | 110~120% | 고정 |

- 1단계를 유지하면 수입·성장이 보통의 약 60%, 5단계면 약 2.25배.
- 매주 게시 + 1단계 고정 1년 46건(빈 주 20%) / 5단계 고정 70건(빈 주 1%).

### 2-2. 모험가

| 항목 | 값 |
| --- | --- |
| 시작 | **2명** (튜토리얼 T1 · T4) |
| 등장 | **명성 10마다 1명** (10·20·30…). 플레이어가 HUD 명성으로 바로 알 수 있게 (확률 공식 없음) |
| 길드 등급별 상한 | F 8 · E 12 · D 16 · C 20 · B 24 · A 28 · S 32 |
| 명성 (F급 의뢰) | 성공 **+2** / 실패 **−1.5** (지금 +0.4 / −0.6) |
| 승급 시 명성 보너스 | **0** (메인 퀘스트 보상으로 따로) |

### 2-3. 성장

| 항목 | 값 | 지금 |
| --- | --- | --- |
| 의뢰 경험치 (성공) | **F급 240**, 등급마다 2배 (E 480) | 80 |
| 필요 경험치 | **14 × Lv^1.55** | 20 × Lv^1.55 |
| 의뢰 성공 시 대표 능력치 | **+2.0** (유형: 토벌 힘 · 사냥·채집 민첩 · 조사 지력 · 호위·구호 정신 · 탐사 기교) | +0.2 |
| 의뢰 실패 시 능력치 | 없음 (경험치만 30%) | 같음 |
| 1차 레벨 상한 | **20** | 30 |
| 2차 레벨 상한 | 미정 (30 / 종결 40 검토) | 40 / 50 |

### 2-4. 길드 승급과 F급 메인 퀘스트

| 항목 | 값 |
| --- | --- |
| 퀘스트 분류 | **메인 · 서브 · 리소스 3종** (승급 퀘스트 분류 없앰. 보스급 의뢰·침공 같은 내용은 필요하면 서브로) |
| 길드 승급 | **메인 퀘스트를 깨면** 다음 등급 |
| F급 메인 퀘스트 | 1개. **모험가 관리소 해금 + E급 승급** |
| 등장 조건 | **첫 모험가가 2차 전직 조건을 채우면** (시험 중앙값 약 41주) |
| 관리소 | 클리어 뒤 **2,000G로 직접 건설** (그때 금고는 보통 5,000G 이상) |
| 지명 | 플레이어가 고름. **아무나, 최대 5명, 대열 순서도 플레이어가 정함**. 퀘스트 지명 튜토리얼을 겸함 (고르기 · 예상 성공률 · 출발 확인) |
| 기간 | **1주** |
| 적 | **늑대 4 + 보스 1 (체력 2,000 · 공격력 100)**, 보스는 맨 뒤. 보스 이름·그림 미정 |
| 사망 | **없음** (쓰러지면 부상만). 후퇴 없이 승리 또는 전멸 |
| 실패 | 재도전 가능 |
| 보상 | **1,000G · 명성 10 · 소재 없음** (명성 10 = 모험가 1명 추가, E급 상한 12) |
| 대사 | 스크립트 설계 때 |

**지명 구성별 성공률** (등장 시점 길드, 직업 순 자동 대열, 20판 × 300전투)

| 파티 | 성공률 | 쓰러지는 평균 인원 |
| --- | --- | --- |
| 에이스 1명 | 21% | 0.8 |
| 상위 3명 | 70% | 1.3 |
| 상위 5명 | 91% | 0.9 |
| 에이스 + 약한 2명 | 63% | 1.5 |
| 상위 3명 + 약한 2명 | 95% | 0.7 |

### 2-5. 첫 전직까지의 흐름

```
튜토리얼(시간 멈춤, 모험가 2명)
 → F급 운영: 매주 의뢰 게시 · 명성 10마다 모험가 · 의뢰마다 경험치 240 + 대표 능력치 +2
 → 첫 모험가가 2차 조건(예: 주 능력치 50) 충족 (약 41주)
 → F급 메인 퀘스트 등장 · 지명 튜토리얼 · 1주 전투 (약 4주 안에 클리어 가정)
 → E급 승급 + 관리소 해금 → 2,000G로 건설
 → 다음 달 초 전직 제안 (약 48주)
```
