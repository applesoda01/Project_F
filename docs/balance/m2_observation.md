# 관문 2 중간 점검 — 로비 관찰 (2026-10-21)

게임 안 20주(1배속 10분 분량)를 4배속으로 돌리며 1초마다 화면 상태를 기록.

| 항목 | 결과 | 판단 |
| --- | --- | --- |
| 의뢰 흐름 (출발·식사·귀환·결산) | 로그 20건 모두 화면 행동으로 나타남 | 읽힘 |
| 말풍선이 떠 있는 시간 | 38% | 적당 |
| 무언가 움직이는 시간 | 52% → 한가할 때 행동 추가 후 59% | 개선 |
| 로비에 아무도 없는 시간 | 17% | 규칙 문제 |
| 로비 평균 인원 | 2.0명 (자리 4~8) | 적음 |
| 게시판 평균 쪽지 | 2.1장 (칸 6) | 적음 |

**결정:** 규칙은 그대로 둠. 관문 2 플레이테스트에서 다시 확인.
