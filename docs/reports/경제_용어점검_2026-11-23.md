## 1. 먹을 소재 이름 다섯 가지

같은 물건(소금 · 멧돼지 고기 · 향신료 등)이 화면마다 다른 이름으로 나옵니다.

| 이름 | 나오는 곳 |
| --- | --- |
| 음식 소재 | 소재 관리 장 분류 탭 「음식 소재 · 그 밖의 소재」 |
| 상시 재료 | 소재 관리 장 소재 설명 꼬리표 (예: 소금) |
| 식당 재료 | 소재 관리 장 「최근 매입」 출처 · 장부 「식당 재료 (시장 구매)」 |
| 요리 재료 | 상단 장 「좋아하는 물건 · 요리 재료」 |
| 식재료 | 상단 대사 (마르타 「귀한 식재료 좀 가져왔어요」) |

- 대사 속 「식재료」는 사람 말투라 그대로 두어도 자연스럽습니다.
- 화면 표시(탭 · 꼬리표 · 장부 · 상단 칸)는 하나로 맞추는 것을 권합니다. 예: 「음식 소재」로 통일, 장부는 「음식 소재 (시장)」.

## 2. 「매입」과 「구매」

| 표시 | 나오는 곳 |
| --- | --- |
| 소재 매입 | 장부 지출 · 소재 관리 장 「소재 매입」 칸 |
| 식당 재료 (시장 구매) | 장부 지출 |
| 사기 | 상단 장 「농산 상단에게서 사기」 |

- 장부 한 표 안에서 「매입」과 「구매」가 나란히 나옵니다.
- 「매입」은 모험가에게서 사는 것, 「구매」는 시장에서 사는 것으로 나눈 의도일 수 있습니다. 의도라면 「모험가 매입 · 시장 매입」처럼 앞말로 나누는 편이 덜 헷갈립니다.

## 3. 「시세 13G · 시장 14」

- 소재 관리 장 목록의 한 줄입니다. 「시장 14」는 마을 시장 **재고 14개**인데, 바로 앞이 값(13G)이라 값처럼 읽힙니다.
- 아래 상세 칸에는 「마을 시장 재고 14개 · 보통 15개」로 제대로 나옵니다.
- 예: 「시세 13G · 재고 14」 또는 「시세 13G · 시장 14개」.
