# 원정 미니 뷰 개선 점검 (2026-11-15 밤사이 작업 J)

> 작성: Claude · 상태: **점검 · 제안 (게임 코드는 바꾸지 않음)**. 시험판은 작업 공간 `miniview/`에만 있음.
> 대상: `prototype/js/expedition.js` 미니 뷰(480×203). 실제 게임 사본을 크롬으로 돌려 전투 의뢰 미니 뷰를 열고 확인함.

## 요약
- **SD 그림으로 바꿀 수 있습니다.** 시험판을 만들어 돌려 봤고 오류는 0건이었습니다. 키는 예전 도트와 같은 84px입니다. 달리기(10직업) · 서 있기(10직업) · 공격(확정 3종)을 쓰고, 없는 동작은 가까운 동작으로 대신했습니다. 비교 그림은 `miniview/miniview_px_vs_sd.jpg`, 영상은 `miniview_sd_trial.mp4`에 있습니다.
- **SD로 바꾸려면 그림 두 가지가 더 필요합니다.** 하나는 남은 7직업 공격으로, 오늘 밤 A 작업에서 만들고 있습니다. 다른 하나는 10직업 **쓰러짐**입니다. 쓰러짐은 지금 서 있기 그림을 눕혀서 대신합니다.
- **그 밖에 고칠 곳은 5가지입니다.** 위쪽이 투명해 로비가 비치는 문제, 산적 그림이 도적 그림과 같은 문제, 배경이 늘 숲인 문제, 비전투 의뢰의 수행 장면이 빈약한 문제, 작은 성능 문제입니다.

## 2. SD 시험판 (작업 공간 `miniview/`)

| 동작 | 쓰는 그림 | 없는 경우 |
| --- | --- | --- |
| 달리기 (결과: 성공 · 후퇴) | 타이틀용 SD 달리기 시트 `run_<직업>.webp` (10직업) | — |
| 걷기 (이동 · 조우) | 같은 달리기 시트를 **14fps로 천천히** | SD 걷기(옆모습)는 아직 없음 |
| 서 있기 (비전투 수행) | 로비 대기 시트 `lobby_iso/chr/<직업>_idle.webp` (10직업, 오른쪽 3/4) | — |
| 공격 | 확정 3종 `atk_game/<직업>_attack_*.webp` | 7직업은 서 있기로 대신 → A 결과로 채움 |
| 쓰러짐 | 서 있기 그림을 0.35초 동안 뒤로 눕히고 어둡게 | **SD 쓰러짐 10종 필요** |

- 맞으면 붉게, 회복하면 초록, 회피하면 뒤로 비키는 연출은 도트 때와 같은 방식으로 SD에도 적용했습니다.
- 발 위치(SURF − 1)와 키(84px)가 예전과 같아서, 막대 · 숫자 · 말풍선 위치는 그대로 맞습니다.
- 주소 끝에 `?px=1`을 붙이면 예전 도트로 볼 수 있습니다(시험판 비교용).
- 반영할 때는 `expedition.js`의 `drawActorSD` 부분과 그림 13장(`assets/expedition_sd/`)을 넣습니다. 시험용으로 넣은 연결(`X.__s` · `X.__open`)은 지웁니다.

## 3. 정할 것
1. 미니 뷰를 SD로 바꿀지, 바꾼다면 쓰러짐 10종이 생길 때까지 기다릴지 지금 대신 그림으로 바꿀지.
2. 위쪽 투명(로비가 비침)이 원래 설계인지 → 아니면 배경판(2번).
3. 산적 도트(3번) · 의뢰 종류별 배경(4번) · 수행 아이콘(5번)을 할지.
