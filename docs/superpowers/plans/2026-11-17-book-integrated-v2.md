# v2 본문 개정과 화면 예시

## 승인된 요청

별도 첨부 개선안 장을 없애고 기존 관련 목차의 본문 규칙을 실제로 개정한다. 수정 부분의 붉은 표시·클릭 요약은 유지한다. 긴 설명 대신 표·짧은 문구·기존 책 UI 리소스를 활용한 화면 예시를 넣는다. 새 게임 규칙과 수치는 제안/검증용, 게임 구현은 미반영으로 구분한다.

## 편집 기준

- 계약 → 모험가 합류·파티·계승, 발주 → 의뢰 게시판, 소유권 → 물약과 소재. 중복 신설 페이지도 기존 페이지로 통합.
- ‘v2 변경’ 머리말 + ‘v1에서 이어받은 설명’을 병치하지 않고 해당 규칙·표를 직접 수정한다.
- 원문은 `docs/references/guild-economy-contracts-2026-11-16/original.html`에만 보관. 책에는 독립 제안서 장이나 분리된 전문을 게시하지 않는다.
- 근거 지도는 기존 부록 D에 간결한 대응표로 남긴다. 검증·단계는 기존 범위/장부/미결에 통합.
- 실제 1600×879 펼침면, 장별 책갈피 색, 목록/상세 좌우 구성, 금화·등급·인물 리소스를 재사용한 정적 UI 예시를 제작한다. 실행 화면이 아닌 기획 시안이며 수치는 검증용이다.
- 이미지 단독 문단도 변경 표시에서 누락되지 않도록 비교기를 수정한다.
