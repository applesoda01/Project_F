# 안내서 버전 메뉴와 변경 요약

사용자 요청: 우측 상단 V1/V2 드롭다운, 우측 버전 이력 메뉴, 변경된 목차/본문의 붉은 표시와 클릭 요약, 기능 관리 버튼 제거.

## 구현 기준

- v1 원고와 첨부 원본은 유지한다. 생성 HTML의 도구 모음만 개편한다.
- 변경 표시는 v2 기준이다. v1과 동일한 본문과 공통 출처 안내는 붉게 만들지 않는다.
- 생성된 본문의 문단·표·목록 단위로 v1과 비교한다. 연속 변경은 하나의 영역으로 묶는다.
- 요약은 기존 변경 비교표의 이전/이후/상태에서 가져오고 해당 항목이 없는 문서 추가는 문서 변경으로 설명한다.
- 붉은 목차 제목은 요약 창을 열며, 창의 문서 열기로 이동한다. Ctrl/Command 클릭은 원래 링크를 유지한다.
- 붉은 본문은 클릭으로 요약을 열고, 별도 요약 버튼으로 키보드 접근도 제공한다. 기존 본문 링크는 유지한다.
- 네이티브 select와 dialog를 사용한다. 닫기 버튼·Escape·배경 클릭과 포커스 복귀를 제공한다.
- 기능 관리 자료 자체는 유지하되 도구 모음과 목차의 메뉴 진입점은 제거한다. 버전 이력은 우측 메뉴에만 둔다.

## 작업

- [x] 실제 HTML의 드롭다운·변경 영역·변경 없는 장·목차 메뉴 테스트를 먼저 작성하고 실패 확인.
- [x] 본문 비교 모듈, 메뉴 스타일/스크립트, 빌드 연결 구현.
- [x] 실제 mdBook 빌드·링크·원문 보존 검증, 독립 검토, 새 미리보기 제공.

## 검증 기록

- `node --test docs/tools/book-changes.test.mjs docs/tools/build-books.test.mjs`: 5개 통과. 원본 불변, 동일 문단 제외, 신규/삭제 변경, 중첩 표, 메뉴 제거, 버전 이동, 로컬 링크·자산 검사.
- `node --check docs/tools/book-ui.js`: 통과.
- 독립 검토에서 mdBook 기본 헤딩/선택 목차 색의 CSS 우선순위 문제 발견. 구체적인 링크/선택 상태 선택자로 보정.
- UI 스크립트는 외부 의존성 없이 로컬 HTML에서 작동하도록 작성. 실제 브라우저 렌더링·조작 검증은 도구의 로컬 접근 제한으로 수행하지 못함.
- 기능 관리 문서와 원본 v1은 보존. 공개 배포·게임 변경 없음.

공개 배포는 하지 않는다. 기존 미리보기 경로는 남기고 새 폴더에 빌드해 결과를 전달한다.
