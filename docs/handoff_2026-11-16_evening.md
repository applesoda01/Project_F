- **data_build.py는 `data/icons` → `assets/icons`를 덮어씀**(54개 다름). 저장소에서 돌렸으면 `git checkout -- prototype/assets/icons`. 작업 공간 사본에서는 백업 후 복원.
- CSV는 BOM 붙은 UTF-8. 고칠 때 `encoding='utf-8-sig'`, 줄바꿈 형식 유지(`newline=''`).
- 같은 규칙을 게임(`game_core.js`)과 시뮬레이터(`sim_engine.js`)에 둘 다 넣고 관문 1(`node prototype/tools/gate1_check.js`)을 돌릴 것. 오늘 관문이 깨졌던 원인은 "주 진행 순서(귀환 → 지명 → 출발)와 판단 시점이 어긋난 것"이었음.
- 저장 파일에는 그때의 밸런스 값이 들어 있어, **이어하기는 예전 수치로 불러옴.** 새 수치를 보려면 새 게임.
- 웹 배포: main에 푸시하면 GitHub Actions(`.github/workflows/main.yml`)가 `prototype/`을 Pages로 올림. 주소 `https://applesoda01.github.io/Project_F/` (개발용 `?dev=1`). 공개 주소임.
- 로컬 파일로 열면 브라우저가 JSON · 소리 읽기를 막음 → JSON이 필요한 값은 JS 안에 적어 둠(예: NPC 눈 위치).
- headless 시험: `/usr/bin/google-chrome` + `--allow-file-access-from-files`, 대화창은 `UI.advance()`로 넘김. 침공 시험은 저장 칸에 상태를 넣고 `#mLoad` → `#dWeek` 클릭.
