## 프롬프트 구성

공통: 첨부 스크린샷의 펼친 양피지 책·좌측 7개 책갈피·한국어 서체·기존 목록/상세 구성을 유지하는 전체 화면 UI 시안. 우측 세로 하위 탭 추가. 하단에 ‘기획 시안 · 게임 미구현 · 수치 예시’ 표시.

- **계약:** 명부·경력·전직제안 다음에 계약제안 탭. 다넬 선택. 기간 12주 드롭다운, 월 보수 40G 증감, 길드 몫 30% 드롭다운, 지원 한도 20G 증감, 업무 4주 중 2주 선택. 기본값 제공·조건 직접 선택, 기본값 복원, 이 조건으로 제안. 8주 120G, 가용 300→180G.
- **의뢰 관리:** 자동 게시판 목록 유지. 우측 게시판·의뢰 관리. 기본 중개 요율 10%, 검증용 10/15/20% 선택. 100G→길드10G/모험가90G. 새 의뢰부터 적용, 진행·정식 계약 조건 유지. 발주·외부 의뢰는 리퀘스트에서 관리.
- **리퀘스트:** 우측 리퀘스트·길드 발주·외부 의뢰. 길드 발주 선택. 약초 납품 1묶음, 길드 지급 200G, 예산 200G 예약, 가용300→100G. 중계료 없음·보조금 실적 제외. 예산 예약 후 게시.
- **매입:** 기존 경영 소재 격자·상세 유지. 우측 장부·소재판매·매입·위탁·도감·기록. 다넬 소유 소금 1개, 매입4G·기준판매6G·예상차익2G, 가용300→296G. 매입 확정 후 길드 소유.
- **위탁:** 동일 경영 탭에서 위탁 선택. 다넬 소금10개, 예정판매60G·수수료10%(6G)·소유자지급54G. 접수 버튼. 판매 전 개인 소유, 요리·납품 사용 금지, 판매 후 정산.

시안 내 인물 상태·수치는 배치 설명용이다. 계약 제출 가능 여부는 본문의 길드 등급·관리소·후보·가용 조건으로 검증한다. 생성 이미지를 육안 확인했으며 실제 브라우저 조작이나 게임 경제 실험을 의미하지 않는다.
