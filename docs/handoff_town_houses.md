## 4. 격자 기준 (측정값)

- 쿼터뷰, 그리드 N=20, S=0.9, 단계명 `['개척촌','마을','읍','도시','성채 도시']`
- 1×1 스프라이트: 벽 밑선 기울기 **0.545**, 앞 모서리가 몸체 폭의 **약 50%**
- 1×2 길이: 1×1 길이에 한 칸 분량 **310px**(스프라이트 원본 기준)을 끼워 넣음 → 벽 밑선 기울기 0.52, 점유 칸 두 개에 맞음
- 점유 칸 기준: 앞 모서리를 앞 칸의 아래 꼭짓점에 놓고, 긴 벽이 용마루 방향(오른쪽 위)으로 두 칸을 따라감
- 1×2는 gx 방향이 아닌 **gy가 줄어드는 방향(오른쪽 위)**으로 길어짐. 반대 방향이 필요하면 좌우 반전

## 5. 1×2 제작 방법 (재현용)

스크립트는 `tools/art/house_stretch/`에 있고, 경로가 클라우드 작업 환경(`/tmp/hs`, `/mnt/user-data/outputs`)에 고정되어 있어 새 환경에서는 경로를 고쳐야 합니다.

1. `stretch3.py` — 핵심. 1×1 스프라이트를 세로 경계선(`c`)에서 자르고, 용마루 방향으로 `L=310px` 만큼 한 칸을 끼움. 끼우는 구간은 장식 없는 띠(`bL`~`c`)를 반복해 채우고, 경계는 가로 7px 크로스페이드. 기울기 `SL=0.52`.
   - 굴뚝·지붕창이 띠에 걸리면 폴리곤을 지우고 용마루 축 방향 이웃 픽셀로 메운 뒤 가운데에 다시 붙임 (3단계·2단계)
   - 가운데 창문은 원본 창문 폴리곤을 `wdx`만큼 축 방향으로 복사해 붙임
2. `region.py` — 지붕·벽·층을 따로 늘리는 `stretch_regions`, `stretch_multi`. 5단계처럼 장식이 많을 때 사용. 층 경계는 기울기 0.52 직선으로 가름
3. `run5b.py` — 5단계 2층 실행 예 (색별 발 위치 차이를 `footpt`로 보정)
4. `key4.py` — Gemini 마젠타 배경 크로마키 처리

## 6. 실패한 방법 (반복 금지)

- **Gemini에 "같은 시점으로 길게" 요청**: 벽 밑선 기울기 0.40~0.45로 낮아지고 앞 모서리가 몸체 폭의 26~30%에 놓임. 점유 칸을 벗어남.
- **와이어프레임 설계도 첨부**(`guide.py`로 제작): 새 창에서 두 번 시도했으나 형태를 따르지 못함(기울기 0.40).
- **Gemini 이미지 읽기 제약**: 페이지를 새로 고치면 채팅 속 이미지(lh3 주소)는 캔버스로 읽을 수 없어 첨부가 막힘. 방금 생성된 blob 이미지는 가능.

## 7. 작업 환경 메모

- 작업 순서: `AskUserQuestion`(모호할 때) → 작업 → 2분마다 상태 보고 → 결과는 파일로 전달

- Gemini(내장 브라우저, 탭 `seed`, 대화 `d16c81d6fc6d0634`)를 쓸 때: 입력은 `ql-editor`에 `execCommand('insertText')`, 전송은 aria-label "메시지 보내기" 클릭, 다운로드는 "원본 크기 이미지 다운로드" 클릭 후 `~/Downloads`의 `.tmp`/PNG 확인(15~30초)
- 컨텍스트가 약 20만 토큰에 가까우면 새 세션 제안
