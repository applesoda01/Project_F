# 리나 메뉴 명패 5종 — 번호와 사용 현황

갱신: 2026-10-26. 그림은 `prototype/assets/ui/lina_menu/`, 이미지로 보는 표는 [plaque_numbers.png](plaque_numbers.png).

| 번호 | 파일 | 역할 | 현황 | 쓰이는 곳 |
| --- | --- | --- | --- | --- |
| ① | `btn_normal.png` (a) | 일반 | **사용 중** | 이야기하기, 요리하기, 음식 설정하기, 마을로 가기, 전직 제안(제안이 있을 때) |
| ② | `btn_hover.png` (b) | 마우스 오버 | **사용 중** | 마우스를 올린 명패(잠김 제외), 115%로 커짐 |
| ③ | `btn_selected.png` (c) | 선택 | **미사용** | 시뮬레이터에서만 클릭 시 선택 표시. 게임에는 아직 연결 안 됨 (코드에 이미지 경로만 정의됨) |
| ④ | `btn_locked.png` (d) | 잠김 | **사용 중** | 메인 퀘스트(지금은 항상 잠김), 전직 제안(제안이 없을 때) |
| ⑤ | `btn_mainquest.png` (e) | 메인 퀘스트 전용 강조 | **대기 중** | 메인 퀘스트가 열릴 때 사용. 지금은 잠겨 있어 화면에 나오지 않음 |

미사용 ③은 쓰임새를 정하거나(예: 선택해 둔 항목 표시) 정리할 수 있다.
