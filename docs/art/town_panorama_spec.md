# 마을 화면 구성안 (원경 파노라마) v0.1

> 작성: 2026-10-27 · 상태: 초안 · 함께 보는 파일: `docs/tools/town_layout_mockup.html` (단계·건물을 켜고 끄며 배치를 확인하는 목업)

## 요약

마을 화면은 **1920×1080 한 장 원경 파노라마**로 구성합니다. 길드 본관이 정중앙에 서고, 앞으로 뻗은 대로와 가로길을 따라 건물이 **세 줄(뒷줄·중간줄·앞줄)** 로 앉습니다. 인구 5단계에 따라 민가·상점·성벽·성이 단계적으로 늘고, 핵심 건물 12종은 특별 퀘스트를 달성할 때 지정 슬롯에 나타납니다.
- 일러스트는 **배경 5장(단계별) + 건물 개별 이미지 약 33장**으로 나눠 만들면 됩니다. 건물은 발밑 가운데를 기준점(ax 0.5, ay 1)으로 두며, 로비 가구와 같은 규칙입니다.
- 건물 하나는 크기·위치(슬롯)가 고정되어 있어, 그림만 바꿔 끼우면 코드 수정 없이 교체됩니다.
- UI가 가리는 영역(상단 HUD, 하단 메뉴, 기록창, 대화창)은 중요한 그림을 두지 않는 **안전 영역**으로 정했습니다.

## 5. 연출

**소문 말풍선 (무작위로 뜸, 설계 10.1)** — 아래 8곳 중 임의 자리에 `…` 말풍선이 뜨고 누르면 소문을 얻습니다.

| 번호 | x | y |
|---|---|---|
| 1 | 430 | 700 |
| 2 | 980 | 830 |
| 3 | 1280 | 690 |
| 4 | 700 | 860 |
| 5 | 1560 | 690 |
| 6 | 180 | 860 |
| 7 | 1650 | 880 |
| 8 | 960 | 720 |

**거주 모험가 동선** — 애착도 100이 되어 거주하는 모험가가 대로와 가로길을 오가며 걷습니다. 입·퇴장은 화면 아래(x 960)이며, 길드 입구는 (960, 700)입니다. 걷기 시트는 기존 로비의 것을 그대로 씁니다.

**침공 (시간이 흐르는 유일한 마을 상태)** — 마을 화면이 붉게 물들고, 몬스터가 양쪽 지평선(x 100·1840, y 560)에서 대로 방향으로 몰려옵니다. 아래 사항은 전투 규칙이 정해지면 다시 다듬습니다.

- 몬스터 이동선: 왼쪽 (100,560)→(420,640)→(780,720), 오른쪽 (1840,570)→(1500,640)→(1150,720)
- 망루가 있으면 침공 예고가 더 일찍 뜨고(천문대도 같음), 방어 보너스가 있음 (설계 10.3)
- 침공 중에는 소문 말풍선을 숨기고, 주민은 건물 안으로 들어가는 연출을 제안합니다.

## 7. 일러스트 프롬프트 (이미지 생성용)

**공통 지시** (모든 건물 이미지의 앞에 붙임)

> 판타지 마을 건물 하나, 정면에서 약간 위에서 본 시점. 크림색·연한 베이지 벽과 푸른색·붉은색 지붕, 갈색(#5a3a22) 외곽선 3px의 깔끔한 애니메이션풍. 로비 배경과 같은 밝고 따뜻한 색조, 부드러운 그림자는 건물 아래 타원 하나만. 투명 배경, 건물만 단독으로, 건물 아래 가운데가 이미지 아래쪽 가운데에 오도록. 글자나 로고 금지.

**건물별 한 줄 묘사**

| 건물 | 묘사 |
|---|---|
| 길드 본관 | 마을의 중심. 크림색 벽, 푸른 지붕, 가운데 탑과 금색 깃발. 로비 그림과 같은 색조 |
| 성당 | 석조 예배당, 푸른 지붕 종탑과 금색 십자가 |
| 대성당 | 성당의 상위. 쌍탑과 큰 중앙 지붕, 스테인드글라스 원형창 |
| 마법 학원 | 보라색 지붕과 돔 탑, 금색 첨탑. 마법진 문양 |
| 마탑 | 높은 석탑과 보라색 뾰족 지붕, 꼭대기에 푸른 구슬(밤에 빛남) |
| 천문대 | 푸른 돔에 열린 틈과 망원경. 석조 원통 몸체 |
| 극장 | 붉은 박공 지붕, 흰 기둥 6개, 자주색 커튼 정면 |
| 대도서관 | 청록 지붕, 흰 기둥이 늘어선 큰 석조 건물. 전설의 건물이라 가장 고풍스럽게 |
| 투기장 | 원형 석조 경기장, 양쪽 깃발(붉은색·푸른색) |
| 수련원 | 겹지붕의 낮은 동양풍 건물, 붉은 현판 |
| 사냥꾼 조합 | 통나무 오두막, 지붕 위 사슴뿔, 입구 옆 사냥 간판 |
| 연금 공방 | 청록 지붕과 굴뚝, 초록 연기, 문 옆 초록 플라스크 |
| 망루 | 목재 비계 망루, 꼭대기 붉은 지붕 감시대 |
| 여관 | 2층 붉은 지붕, 간판 걸린 따뜻한 느낌 |
| 물약 상점 | 작은 청록 지붕, 분홍 포션 병 간판 |
| 무기점 | 목재 벽, 푸른 지붕, 검 간판 |
| 대장간 | 회색 석벽 + 갈색 지붕, 굴뚝 연기, 열린 화덕 |

**배경 (단계별)** — 같은 구도를 유지한 채 단계만 바꿉니다. 단계 0은 푸른 하늘과 두 겹의 산, 풀밭과 흙길, 나무와 나무 울타리입니다. 단계 2는 돌길과 광장, 낮은 석벽으로 바꾸고, 단계 4는 지평선 전체에 성벽과 모서리 탑, 중앙 뒤에 큰 성을 추가합니다. 건물이 놓일 자리는 **비워 둡니다**(건물은 개별 이미지로 얹습니다).

## 8. 확인이 필요한 사항

1. **시점** — 설계서(10.1)에는 '탑뷰'로 적혀 있으나, 이번 구성은 로비와 맞춘 **정면 원경 파노라마**입니다. 설계서의 '탑뷰' 표기를 바꿀지 확인이 필요합니다.
2. **단계 이름** — 개척촌·마을·읍·도시·성채 도시는 설계서의 표기이며 [가안]입니다.
3. **시간대·계절** — 하늘색 변화(낮/저녁)나 계절 장식은 이번 범위에서 제외했습니다. 필요하면 배경만 단계×시간대로 늘리면 됩니다.
4. **침공 연출** — 방어선(성벽 위 궁수 등)을 그림으로 보여 줄지, 마을 화면에서 직접 지휘할지 정해야 합니다.
5. **건물 클릭** — 건물을 누르면 무엇이 열리는지(상점, 스킬 구매 등)는 UI 설계 후 슬롯에 연결합니다.
