# SD 스프라이트 파일 종류와 모션 목록

> 기준일: 2026-11-10. 모험가 10종(전사·궁수·마법사·성직자·도적 × 남·여)과 접수원 리나의 SD 스프라이트 현황입니다.
> 제작 방식과 규격 상세는 [art_source/sd_sprites/README.md](../../art_source/sd_sprites/README.md)를 보세요.

## 요약
- 완료: 모험가 걷기·앉기·서 있기(idle) 3종 × 10명
- 진행 중: 접수원 리나 5모션, 달리기(시험 단계)
- 미생성: 공격, 쓰러짐, 먹기, 피격, 수행 동작, 정면·뒷면 방향 등 (아래 3절)

## 1. 파일 종류

| 종류 | 위치 | 형식 | 용도 |
| --- | --- | --- | --- |
| 게임용 시트 | `prototype/assets/chr/` | PNG + JSON (80개) | 게임이 읽는 시트. 걷기 `walk`, 앉기 `sit_front`·`sit_side`, 정지 `front`·`back` |
| SD 원본 프레임 | `art_source/sd_sprites/<모션>/<캐릭터>/` | 투명 PNG (프레임별) | 모션별 프레임 원본. 걷기 `walk_NN.png`, 서 있기 `idle_NN.png`, 앉기 `sit_NN.png` |
| 미리보기 | 같은 폴더 | GIF | 확인용. 걷기 `walk.gif`, 서 있기 `idle.gif`, 앉기 `sitdown.gif` |
| 앉기 정렬 자료 | `art_source/sd_sprites/sit/aligned/`, `sit/sit_chair_placement.json` | PNG, JSON | 앉은 최종 자세와 종별 의자 위치(cx, by) |
| 도트 원본 | `art_source/pixel_chr/<캐릭터>/` | PNG + JSON + GIF | 도트 시험판: 걷기·달리기·공격·쓰러짐. 캐릭터별 `README.md`에 규격 |
| 128 걷기 시트 | `art_source/walk_sheets_128/` | PNG | 도트 변환용 걷기 시트 |
| 접수원(리나) | `art_source/receptionist_128/`, `receptionist_blink/` | PNG + JSON | 기존 접수원 시트(대기·인사·안내·독서). 새 SD 5모션은 제작 중 |

### SD 원본 프레임 규격

| 모션 | 프레임 | 크기 | 정렬 기준 | 비고 |
| --- | --- | --- | --- | --- |
| 걷기 | 24 (1주기, 30fps 기준 0.8초) | 640×800 | 키 516px, 바닥 y=787 | 반복 |
| 앉기 | 앉는 구간 + 안정화 6 | 720×700 | 의자 중심 x=360, 바닥 y=620 | 일어서기는 역재생 |
| 서 있기(idle) | 72 | 640×800 | 키 약 516px, 바닥 y≈787(직접 측정) | 반복. 미리보기 GIF는 프레임당 40ms |

## 4. 접수원 리나 (SD)

| 모션 | 상태 | 비고 |
| --- | --- | --- |
| 대기(idle) | 제작 중 | 72프레임, 24fps. 녹색 배경으로 재생성 중 |
| 인사(greet) | 제작 중 | 같음 |
| 안내(guide) | 제작 중 | 같음 |
| 의뢰서 전달(paper) | 제작 중 | 같음 |
| 감사(thanks) | 제작 중 | 같음 |

- 규격: 셀 256×256, 발끝 y=244, 캐릭터 높이 약 214px.
- 흰 배경 버전은 흰 블라우스와 배경이 섞여 투명 처리에 한계가 있어, 녹색 배경(0,177,64)으로 다시 만들고 있습니다. 확정 전까지 저장소에는 넣지 않습니다.
