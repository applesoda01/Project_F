## 2. 건물 형태 규격

1. **투영:** 쿼터뷰 약 35°. 타일 100×58px, 배율 ×0.944, 원점 (0,0) 꼭짓점이 화면 (960,185).
2. **앵커:** 건물의 앞(아래) 꼭짓점 (gx+w, gy+d)에 스프라이트 하단 중앙을 맞춥니다.
   - 화면 좌표: `sx = 960 + (gx−gy)×50×0.944`, `sy = 185 + (gx+gy)×29×0.944` (앵커 꼭짓점 기준이므로 gx+w, gy+d를 대입)
3. **보이는 면:** 왼쪽(+gy)면과 오른쪽(+gx)면. 바닥 발자국은 정사각형.
4. **깊이 정렬:** `gx+w+gy+d` 값이 큰 건물을 앞에 그립니다.
5. **폭 기준:** 점유 w×d 타일의 폭 = (w+d)×47px, 지붕 돌출 +15%까지 허용. 2×2는 약 190~215px.
6. **높이:** 30° 기준 목업 값보다 약 8% 크게 봅니다.
7. **후처리:** 흰 배경 제거(가장자리에서 flood fill) → 열기·구멍 채우기 → 알파 가장자리 블러 → bbox 자르기. 현재 처리 스크립트는 세션 로컬(`/tmp/town/sp/proc.py`)에만 있으니 필요하면 다시 요청해야 합니다.

## 3. 화풍 규칙

- 방향: 옥토패스 트래블러 계열 분위기, 손그림 구아슈 질감, 가는 따뜻한 갈색 선, 테라코타 지붕.
- 개척촌 건물은 크림색 회벽 + 갈색 목골 + 돌 기단이 기본이고, 건물마다 **지붕 색·재질·실루엣**으로 구분합니다.
- 사용한 공통 프롬프트와 건물별 설명: `docs/art/town_building_prompts.md`, 화풍 문장: `town_ref/town_gemini_prompts.md`.

## 4. 알려진 문제와 해결 제안

1. **슬롯 겹침 (최우선):** 슬롯이 2칸 간격이라 건물 높이(150~200px)가 앞 슬롯 건물을 가립니다. 물약 상점이 길드 하단을 가리고, 대장간·무기점 지붕이 겹칩니다.
   - 제안 A: 슬롯 사이에 빈 1칸을 두고 길 폭을 넓혀 16×16 격자에 2×2 건물 10~12채를 배치. (권장)
   - 제안 B: 간격은 두고 건물 높이를 약 30% 낮춰 재생성. (납작해질 위험)
   - 어느 쪽이든 지면판의 길 배치와 `data/town_slots.csv` 좌표를 함께 고쳐야 합니다.
2. **크기 불일치:** Gemini가 "길드보다 약간 작게" 지시를 무시하고 비슷하거나 더 크게 그립니다. 후처리에서 폭을 강제로 맞추는 방식으로 해결했습니다.
3. **실루엣 중복:** 여관·물약·길드가 같은 주황 박공 지붕입니다. 프롬프트에 "clearly different silhouette"와 지붕 재질·색을 명시하면 해소됩니다(무기점·대장간이 이 방식으로 성공).
4. **Gemini 한도:** 2026-10-27 기준 이미지 생성 한도에 도달했습니다. 초기화 후 같은 대화(길드 이미지 첨부 상태)에서 이어서 생성하면 화풍이 유지됩니다.

## 5. 다음 작업 순서

1. 슬롯 간격 방안(A/B) 결정 → 지면판 길·슬롯 좌표 수정.
2. 여관(이끼 초록 지붕, 2층 돌출) · 물약 상점(둥근 보라 지붕) 재생성.
3. 개척촌·마을 단계 핵심 건물 6종: 성당, 마법 학원, 사냥꾼 조합, 투기장, 수련원, 망루(1×1).
4. 읍 이상 4종(천문대, 극장, 대도서관, 연금 공방)과 업그레이드 2종(대성당, 마탑).
5. 영주의 성 5단계, 민가 변형(지붕색 4 × 1·2층).
6. 건물이 확정되면 HD-2D 후처리(틸트시프트, 블룸, 빛줄기, 따뜻한 보정)와 ComfyUI 단계로 이동.

## 6. Gemini 작업 절차 (재현용)

1. 같은 대화에 길드 본관 이미지를 첨부한 상태에서 프롬프트를 입력합니다. 공통 문장은 "same style, camera angle and scale as the first attached guild hall" 형식입니다.
2. 생성에 약 40~60초 걸립니다. 완료 후 이미지 위에 마우스를 올리면 나타나는 다운로드 아이콘으로 원본 크기를 받습니다. 한 번에 여러 건을 누르면 일부가 누락되니, 받을 때마다 다운로드 폴더에서 파일 수를 확인합니다.
3. 파일은 `Downloads\Gemini_Generated_Image_*.png`로 저장되며(2400×1792), 후처리 후 `sprites/{id}_v1.png`로 보관합니다.
