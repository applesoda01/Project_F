# 리소스 규칙 (프로토타입 실제 구현 기준)

계획 단계의 전체 리소스 목록과 규격은 [plan/phase2_M2-M3_plan.md](../plan/phase2_M2-M3_plan.md)의 '리소스 제작 목록과 규격'을 보세요. 이 문서는 **지금 코드가 실제로 읽는 이름과 규격**입니다. 둘이 다르면 이 문서가 기준이며, 계획 문서는 다음 정리 때 맞춥니다.

## 바꿔 넣는 방법

1. `prototype/assets/<폴더>/<이름>.png`에 같은 이름으로 덮어씁니다.
2. 브라우저를 새로 고칩니다. 파일이 없거나 읽지 못하면 같은 크기의 이름표 달린 임시 그래픽이 나옵니다.
3. 개발 패널의 "임시 그래픽 보기"로 모든 그림을 임시로 바꿔 구조를 확인할 수 있습니다.

전체 목록·크기·기준점은 `prototype/js/manifest.js`에 있습니다. 좌표와 크기는 화면 1920×1080 기준이고, 그림은 @2x로 넣어도 됩니다(그릴 때 크기를 맞춤).

## 공통 규칙

- 그림 안에 글자를 넣지 않습니다 (등급 글자, 제목 등은 코드가 씀)
- 기준점은 인물·가구 모두 **발밑 가운데**
- 바닥 그림자는 코드가 그림 (그림에 넣지 않음)
- 배경 투명 PNG, sRGB

## 레이어 순서 (뒤 → 앞)

벽 → 바닥 → 게시판 → 의뢰서 → 리나 → 카운터 → 소품 → 모험가·가구(발 위치 y로 정렬) → 말풍선·효과 → 조명 → 화면 UI

좌석: 뒷자리는 의자(앞모습) → 사람 → 테이블, 앞자리는 테이블 → 사람 → 의자(뒷모습).

## 걷기 시트

| 항목 | 값 |
| --- | --- |
| 배치 | 가로 24프레임 × 세로 4행 (아래·왼쪽·오른쪽·위) |
| 셀 | 128px 원본 또는 256px 업스케일본 (코드가 그림 높이로 알아냄). 최종은 512px 권장 |
| 재생 | 24프레임 = 두 걸음. 프레임은 **이동 거리**로 넘김(발 미끄러짐 방지) |
| 기준점 | 가로 가운데, 발밑 y = 셀의 122/128 |
| 오른쪽 행 | 시트 안에서 이미 반전됨. 코드에서 뒤집지 않음 |
| 정지·앉기 | 지금은 0번 프레임으로 대신함 → **새 디자인의 서 있는 자세·앉은 자세(앞·뒤) 필요** |
| 업스케일 | [tools/upscale](../../tools/upscale) — 시트 1장 약 3분 (CPU) |

## 접수원 (리나)

| 항목 | 값 |
| --- | --- |
| 위치 | 카운터 가운데 x=960 **고정** (걷지 않음). 발밑 y=470, 화면 키 250 (모험가와 같은 비율) |
