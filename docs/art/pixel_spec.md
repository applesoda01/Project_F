# 도트 규격 (2026-11-02)

타이틀 배경처럼 도트로 그리는 그림은 모두 이 규격을 따릅니다. 기준은 전사 도트 스프라이트(`art_source/pixel_chr/`, 브랜치 `art/pixel-warrior`)입니다.

## 1. 화면 배율
- 도트 1칸 = 화면 2px. 화면 1600×900 = 도트 800×450.
- 확대는 정수배만, 보간 없이(가장 가까운 픽셀). 움직임도 도트 1칸 단위.

## 2. 캐릭터 기준
| 항목 | 값 |
|---|---|
| 키 | 84도트 (3등신) |
| 폭 | 53~71도트 (동작에 따라) |
| 칸 | 128×96 (쓰러짐 160×104) |
| 바닥선 | 칸 위에서 92번째 줄 (발 기준점) |
| 방향 | 오른쪽 기본, 왼쪽은 좌우 반전 |

## 3. 블록
- **블록 1칸 = 32×32도트** (화면 64×64px). 캐릭터 키 약 2.6칸, 폭 약 2칸. 화면 가로 25칸.
- 테라리아처럼 블록을 쌓아 땅을 만듭니다. 맨 위 줄은 **풀 블록**, 그 아래는 **흙 블록**.
- 블록은 상하좌우 어느 쪽으로 붙여도 이어지게 그립니다(테두리 선 없음).
- 같은 블록에 2종 이상 변형을 두고 섞어 배치해 반복이 드러나지 않게 합니다.

| 블록 | 그림 크기 | 내용 | 파일 |
|---|---|---|---|
| 풀 블록 (3종) | **32×44** | 아래 32줄이 블록, 위 12줄은 블록 위로 솟는 풀잎(투명 배경). 풀 덮개가 블록의 절반 정도를 덮음 | `grass_a·b·c.png` |
| 흙 블록 (5종) | 32×32 | A 얼룩+돌 / B 큰 얼룩+돌 많음 / C 얼룩만 / D 작은 돌 / E 무난한 흙 | `dirt_a~e.png` |

- 풀 블록은 그림 아래쪽을 블록 칸에 맞춰 놓습니다(그림 y = 블록 y − 12).
- **지면선 = 풀 블록 그림의 8번째 줄(y=8)**. 캐릭터 발(바닥선 92)을 여기에 맞춥니다. B는 풀 덮개가 2줄 더 높지만(y=6) 풀의 들쭉날쭉함으로 봅니다.
- 블록은 Gemini로 만든 그림(`art_source/pixel_bg/blocks_gemini_sheet.png`)을 `tools/art/gem_blocks.py`로 정리한 것입니다: 테두리·모서리 음영 제거 → 32칸으로 줄이며 칸마다 가장 많은 색 선택 → 네 블록 공통 13색.
- 추가분(풀 C, 흙 C·D·E)은 `blocks_gemini_sheet2.png`를 `tools/art/gem_blocks_more.py`로 정리. 기존 13색에 맞추고, 흙 바탕색을 하나(135,82,55)로 통일, 블록 가장자리 2줄의 밝은 테두리 흔적 제거.
- **배치 규칙**: 흙은 가중치 A2·B1·C3·D2·E3로 고르고, 좌우·위아래에 같은 블록이 오지 않게 함. 풀은 A·B·C를 좌우 같은 것 없이.
- 처음 코드로 찍은 시안(`tools/art/make_blocks.py`)은 쓰지 않습니다.

## 3-1. 지역 (타이틀 배경 순환: 마을 → 풀밭 → 숲 → 사막 → 마을)
윗줄 블록은 모두 32×44(지면 y=8), 아랫줄 블록은 32×32.

| 지역 | 윗줄 | 아랫줄 |
|---|---|---|
| 마을 돌길 | `town_a·b·c` (c는 돌 사이 풀) | 흙 `dirt_a~e` |
| 풀밭 | `grass_a·b·c` | 흙 `dirt_a~e` |
| 숲 | `forest_a`(이끼·낙엽), `forest_b`(버섯) | 숲 흙 `fdirt_a`(뿌리)·`fdirt_b` |
| 사막 | `sand_a`(마른 풀)·`sand_b`(돌) | 위 2줄 `sand_c`, 아래 2줄 `sandstone`(층) |

| 경계 (왼쪽 → 오른쪽) | 윗줄 | 아랫줄 |
|---|---|---|
| 마을 → 풀밭 | `town_to_grass` | 흙 그대로 |
| 풀밭 → 숲 | `grass_to_forest` | `dirt_to_fdirt` |
| 숲 → 사막 | `forest_to_sand` | `fdirt_to_sand` |
| 사막 → 마을 | `sand_to_town` | `sand_to_dirt` |

- 지역 길이: 기본 단위 마을 10칸, 풀밭·숲·사막 각 12칸 × **배율 30** (타이틀 기본값). 달리기 속도 280, 보폭 13, 지면 높이 400.
- 원본: `art_source/pixel_bg/sheet_*.png`. 정리 도구 `tools/art/gem_sheet.py`(시트 → 블록), 배치 시안 `tools/art/route.py`.
- 알려진 손질거리: 경계 블록은 Gemini가 정사각형보다 넓게 그려 가로로 눌렀음. 사막 경계 열의 아래 2줄은 사암 층이 끊김.

## 3-2. 장식 오브젝트 (`art_source/pixel_obj/`)
옆모습, 아래가 지면선에 닿게 세움(그림 아래 = 지면선 +2, 윗줄 풀잎이 밑동을 살짝 덮음). 높이는 도트 칸(캐릭터 84 기준).

| 지역 | 오브젝트 (높이) | 배치 가중치 |
|---|---|---|
| 마을 | 집 110, 가로등 72, 울타리 26, 술통 28, 표지판 42 | 2·3·3·2·1 |
| 풀밭 | 나무 120, 덤불 14, 들꽃 20, 이끼 바위 26, 그루터기 24 | 3·3·3·2·1 |
| 숲 | 침엽수 136, 활엽수 124, 버섯 24, 고사리 24, 통나무 24 | 4·3·2·3·1 |
| 사막 | 큰 선인장 84, 작은 선인장 30, 바위 36, 뼈 20, 마른 덤불 24 | 3·3·2·1·2 |

- 간격: 오브젝트 폭 + (24~174도트) ÷ 밀도. 지역 경계 앞뒤 2칸에는 두지 않음.
- 정리 도구 `tools/art/gem_objects.py` (시트 → 높이 지정 축소, 칸마다 최다 색, 작은 잡티 제거는 별도 단계).

## 3-3. 전경과 생물
- **원칙: 생물이 아닌 지형지물은 스스로 움직이지 않고 지면에 붙어 있음** (2026-11-02 결정). 땅과 같은 속도로만 흐름.
- **전경**(캐릭터 앞에 그리는 지형지물): 원래 크기·색, 아래 끝 = 지면선 +2. 카메라 기준 1,800~5,000도트마다 1개.
  - 마을: 울타리·술통 / 풀밭: 덤불·들꽃·그루터기 / 숲: 고사리·버섯 / 사막: 작은 선인장·뼈·마른 덤불
- **생물**(5~12초마다, 지금 지역에 맞춰): 풀밭 나비(날갯짓 2장, 위아래로 오르내림), 마을 닭(걷기 2장, 왼쪽으로 걸어감).
- **예외: 사막의 마른 덤불은 바람에 굴러감**(회전하며 통통 튀어 캐릭터 쪽으로). 사막에서 5~12초마다.
- 쓰지 않음: 떨어지는 낙엽, 위쪽 나뭇가지(그림 `leaf_a·b`, `branch`는 보관만).
- 그림: `butterfly_a·b`, `chicken_a·b` (`sheet_anim.png`, `sheet_chicken.png`).

## 4. 색과 그리기 규칙
- 배경 팔레트 16색 이내(현재 블록 4종 공통 13색). 캐릭터 팔레트(32색)와 따로 관리.
- 흐린 경계·반투명 금지(알파는 0 또는 255).
- 배경은 캐릭터보다 외곽선을 약하게 해 캐릭터가 돋보이게 합니다.

## 5. 남은 일
- 캐릭터 발 위치가 동작마다 88~94줄로 흔들림 → 92로 맞추는 손질 필요.
- 전사 여 색 수 확인(움짤 기준 44색, 문서상 32색).

## 6. Gemini로 블록 만들 때
- 참고 그림을 코드로 붙여 넣으면 거절됨(2026-11-02). 첨부 없이 글로만 요청하거나, 첨부는 직접 끌어다 넣기.
- 요청 예: "픽셀아트 게임 타일 이미지를 만들어줘. 테라리아 같은 2D 횡스크롤 게임의 땅 블록 4개를 가로로 나란히 놓은 타일 시트 … 배경은 순수한 흰색 단색, 안티앨리어싱 없음, 글자 없음"
- Gemini는 32칸을 지키지 않음(약 47칸). 정리 도구로 32칸에 맞춤.
