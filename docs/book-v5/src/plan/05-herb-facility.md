## 1. 물약을 길드에서도 팝니다

| | 지금 | 바뀌면 |
| --- | --- | --- |
| 모험가가 사는 물약 | 마을 물약 상점에서만. 돈은 마을로 | 길드 약초 시설에서도 팜. 견줘서 길드에서 사면 돈이 길드로 |
| 구급 주머니 | 없음 | 길드 약초 시설에서 팜 |

- **이미 쓰고 있는 돈입니다.** 새 행동을 가르칠 필요 없이 그 돈의 갈 곳만 바뀝니다.
- **규칙이 하나로 맞춰집니다.** 밥은 식당과 여관, 손질은 정비대와 대장간, 점은 길드와 천막입니다. 물약만 「마을에서만 산다」이면 혼자 예외가 됩니다.
- **플레이어가 물약에 손을 댈 수 있게 됩니다.** 값을 매기고, 약초 퀘스트를 밀고, 「신입이 물약 사느라 밥을 못 먹는다」([18](18-purchase-judgment.md))를 직접 풉니다.
- **재고가 떨어져도 위험하지 않습니다.** 길드에 물약이 없으면 모험가는 마을 상점에서 삽니다. 물약 없이 떠나는 일은 생기지 않고, 길드가 덜 벌 뿐입니다.

### 파는 길과 선물하는 길은 따로 갑니다

| | 누가 | 어디서 | 어떻게 |
| --- | --- | --- | --- |
| 모험가가 사는 물약 | 모험가 | 길드 약초 시설 (또는 마을 물약 상점) | 제 돈으로 삼 |
| 플레이어가 선물하는 물약 | 플레이어 | 마을 물약 상점 | 소재를 조합해 완성품을 만들고, 그것을 줌 |
| 플레이어가 선물하는 장비 | 플레이어 | 마을 대장간 | 소재를 조합해 완성품을 만들고, 그것을 줌 |

- 길드 시설(약초 시설 · 정비대)은 모험가에게 파는 곳입니다. 팔 때 소재를 쓰므로 미리 쌓아 둔 물건이 없습니다.
- 선물은 마을 가게에서 조합한 완성품으로 합니다. 물약도 장비도 같습니다(사용자: 「무기점과 같아」).
- 따라서 조합법은 필요합니다. 장비 조합법은 [04](04-maintenance.md)에서 한 바퀴 뒤로 넘긴 대로 정합니다.

## 2. 구급 주머니는 보험입니다

| | 물약 | 구급 주머니 |
| --- | --- | --- |
| 언제 듣나 | 싸우는 중 | 쓰러진 뒤 |
| 하는 일 | 쓰러지지 않게 도움 | 쓰러져도 부상 없이 돌아옴 |
| 승산 | 올림 | 올리지 않음 |

- 지금은 전사가 보스와 싸우다 쓰러지면 2주 동안 쉽니다. 구급 주머니가 있으면 쓰러져도 쉬지 않고 돌아옵니다.
- 주머니는 써서 없어지고, 귀환 보고에 「구급 주머니 덕에 버텼다」가 남습니다.
- 부상은 싸우다 쓰러진 사람에게만 생기므로, 싸움이 있는 퀘스트에서만 쓸모가 있습니다.
- 효과는 「부상을 한 번 막음」[임시]입니다.
- 재료가 뼈와 뿔이라 「구급 주머니」라는 이름이 어색할 수 있습니다(「보약」 같은 이름). 어젯밤 정한 이름이라 그대로 두고 [임시]로 둡니다.

## 3. 열리는 순서 — 대장장이 · 점술가와 같은 세 단계

| 단계 | 일어나는 일 | 물약 값이 가는 곳 |
| :---: | --- | --- |
| 1 | 그레타의 리퀘스트를 끝냄 → 마을에 물약 상점 | 마을로 |
| 2 | 약초와 뼈를 건넴 → 길드에 약초 시설 | **길드로** |
| 3 | 둘째 묶음의 소재(귀한 약초 · 멧돼지 엄니)를 건넴 → 윗급 물약 · 윗급 구급 주머니 | 길드로 |

- 그레타의 리퀘스트가 끝나는 때는 대장장이 · 점술가의 리퀘스트와 함께 10 · 15에서 맞춥니다.

## 4. 소재

| 파는 것 | 쓰는 소재 | 나오는 곳 |
| --- | --- | --- |
| 회복 물약 | 약초 1개 | 세실리아 |
| 마력 물약 | 약초 1개 | 세실리아 |
| 구급 주머니 | 짐승 뼛조각 1개 | 굼바 |

- **물약은 둘 다 팝니다.** 처음에는 회복 물약만 팔려 했다가 거두었습니다. 마력 물약을 길드에서 안 팔면 마법사의 물약 값이 계속 마을로 갑니다.
- **둘 다 약초 1개입니다.** 지금 마력 물약은 약초와 마석으로 만들지만, 마석은 점술가만 쓰도록 건드리지 않습니다(사용자 안).
- **약초를 어디에 쓸지는 플레이어가 정합니다.** 약초 시설의 메뉴에서 「회복 물약 팔기」 「마력 물약 팔기」를 켜고 끕니다. 약초가 3개 남았고 다음 주에 전사들이 보스에 가면, 마력 물약을 꺼 두어 남은 약초가 모두 회복 물약으로 나가게 합니다.
- 토벌에서 많이 싸우면 다치고, 거기서 나온 뼈와 뿔이 구급 주머니가 됩니다.

### 약초가 빨리 닳는 걱정 — 종류가 아니라 양으로 풉니다

약초의 쓸 곳은 셋(회복 · 마력 · 단계 올리기)입니다. 소재의 종류를 더 늘릴 자리는 없지만, 들어오는 양은 우리가 정하는 숫자입니다.

| 손잡이 | 내용 |
| --- | --- |
| 줄마다 나오는 개수를 다르게 | 약초나 나뭇가지처럼 흔한 것은 한 번에 많이, 마석이나 광석처럼 귀한 것은 적게 |
| 소재 1개로 여러 번분 | 약초 1개에 물약 두 병분. 식당에서 재료 하나가 여러 그릇분이 되는 것과 같은 모양 |
| 퀘스트를 더 돎 | Lv 3이 된 약초 퀘스트를 다시 돎 ([17](17-quest-material-map.md)) |
| 떨어져도 위험하지 않음 | 모험가는 마을 상점에서 삼 |

지금 「줄마다 한 묶음에 9개」는 임시로 둔 값입니다. 숫자는 한 바퀴 뒤 소재를 한 표로 셈할 때 맞춥니다(임시 값 57번).

## 5. 마을 사람도 사고 싶은 것을 삽니다

식당에서 마을 사람은 요리를 가리지 않습니다. 약초 시설도 같습니다(사용자: 「요리처럼 사고싶은걸 사게」).

| | 모험가 | 마을 사람 |
| --- | --- | --- |
| 사는 것 | 회복 물약 · 마력 물약 · 구급 주머니 · 윗급 | 가리지 않음 |
| 판단 | 주머니 · 필요 · 견줌 ([18](18-purchase-judgment.md)) | 마을 형편(여관 값의 2배까지) · 견줌 ([06](06-town-customers.md)) |
| 견줄 곳 | 마을 물약 상점 | 같음 |
| 차례 | 먼저 | 남은 재료로 |

- 세실리아 수녀가 고아원 아이의 약을 사러 옵니다. 구급 주머니는 집에 두는 상비약이 됩니다.
- **품목마다 「마을 사람에게 팔기」를 끌 수 있습니다.** 귀한 소재로 만드는 윗급을 마을 사람이 먼저 사 가면 보스를 앞둔 모험가가 못 살 수 있기 때문입니다.
- 이 규칙은 정비대와 점술가에도 같이 넣었습니다. 처음에는 「마을 사람은 날 세우기만」 「기본 점만」으로 막아 두었다가 바꿨습니다.
- 마을 사람도 이용객 누적에 들어갑니다.

## 아직 모르는 것

1. 약초가 들어오는 양과 닳는 양. 물약은 싸우는 모험가 대부분이 사는 것이라 가장 빨리 닳을 수 있습니다
2. 구급 주머니가 팔리는지. 지금은 쓰러지는 일이 한 해 3 ~ 4번뿐이라, 보스 같은 위험한 일 앞에서만 팔릴 것입니다
3. 「부상을 한 번 막음」이 의무실 · 벽난로(부상 기간을 줄임)와 겹치는지
4. 마을 사람이 물약과 주머니를 얼마나 사는지(필요의 크기)
5. 챙길 재고가 요리 재료 · 손질 소재 · 약초로 늘어나는 것이 손에 부치는지
6. 선물용 물약을 조합하는 데 드는 소재와 공임, 그리고 길드가 파는 물약(약초 1개)과의 차이

## 한석님과 논의할 것

1. 물약을 길드에서도 파는 것, 그리고 길드의 마력 물약을 약초만으로 만드는 것
2. 구급 주머니의 효과(부상을 한 번 막음)와 의무실 · 벽난로의 관계
3. 달이기 · 나눠 주기를 「마을 가게에서 조합한 완성품을 선물」로 정리하는 것
4. 그레타에게 신뢰 단계를 붙이는 것
