## 1. 고비의 보너스 — 능력치를 나눠 줍니다

2026-11-24 카드에는 「레벨 고비마다 특성을 둘 중 하나 고른다」로 적혀 있었습니다. 더 단순하게 바꿨습니다(사용자 15:20: 「뭔가를 더 추가하는 게 아니라, 보너스 능력치를 줘서 키우는 맛을」).

| | 정한 것 [임시] |
| --- | --- |
| 받는 것 | 보너스 5점 |
| 주는 모양 | 다섯 능력치에 마음대로 나눠 줌 (3 + 2 · 5 + 0 · 1씩 다섯) |
| 되돌리기 | 한 번 주면 되돌리지 못함 |
| 새 규칙 | 더하지 않음 (하는 짓 · 스킬 같은 것 없음) |

**고비 레벨 — 간격이 점점 벌어집니다 (사용자 15:25)**

| 고비 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 레벨 [예시] | 3 | 6 | 9 | 15 | 24 | 39 | 63 |

- 앞의 두 수를 더한 것이 다음 수입니다. 처음에는 자주(배우는 때), 뒤로 갈수록 드물게(무게가 실리는 때) 옵니다.
- 너무 자주 나오면 피곤합니다. 「세 레벨마다 끝없이」는 Lv 50까지 열여섯 번이라 뺐습니다.
- 전직마다의 레벨 상한(1차 Lv 30 · 2차 Lv 40 · 3차 Lv 50)은 그대로 둡니다. 이대로면 닿는 고비는 39까지 여섯 번입니다. 수열은 예시이므로 상한이 정해질 때 맞춥니다.
- F급 안에서는 Lv 3 · 6 · 9입니다. 옛 규칙으로 창립 멤버는 Lv 6에 14주쯤, Lv 9에 32주쯤 닿습니다.

**[수행](09-training.md)과 겹쳐도 괜찮은 까닭**

| | 드는 것 | 크기 | 고민 |
| --- | --- | --- | --- |
| 수행 | 돈과 한 주 | 조금씩 자주 (+2) | 작은 고민 |
| 고비의 보너스 | 공짜 | 드물게 크게 (5점) | 큰 고민 |

- 둘이 같은 쪽을 밀면 「이 사람을 이쪽으로 키웠다」가 더 뚜렷해집니다.
- 능력치는 승산 · 퀘스트의 최소 조건 · **2차 전직의 조건**(예: 광전사는 힘 50 · 레인저는 힘 35와 민첩 35)에 닿습니다. 어디에 주느냐가 뒤의 전직 갈래로 이어집니다.
- 지금 게임에서는 승급하면 능력치 다섯에 저절로 +3씩 붙을 뿐, 플레이어가 고르는 것이 없습니다.

**높은 레벨로 온 신입 ([12](12-newcomers.md))**

| 온 사람 | 지나온 고비 | 앞으로의 고비 |
| --- | --- | --- |
| 풋내기 (Lv 1) | 없음 | 모두 플레이어가 나눔 |
| 경험자 (예: Lv 7) | Lv 3 · 6의 몫은 그 직업의 주력 쪽으로 이미 붙어서 옴 | Lv 9부터 플레이어가 나눔 |

- 풋내기는 내가 방향을 정하는 재목이고, 경험자는 방향이 정해져 온 바로 쓸 사람입니다. Lv 1부터 키울 까닭이 남습니다.

## 2. 승급 시험

| | 지금 | 새 설계 |
| --- | --- | --- |
| 조건(레벨 · 실적)이 차면 | 저절로 승급 | 「승급 시험」이 리퀘스트로 뜸 |
| 플레이어가 하는 것 | 없음 | 언제 보낼지 고름 (수행을 한 번 더 시킬까, 밥을 먹여 보낼까) |
| 결과 | 늘 오름 | 통과하면 오름. 떨어질 수도 있음 |

| | 정한 것 |
| --- | --- |
| 당사자 | 반드시 수락 (지금 게임의 「리퀘스트를 낸 본인은 늘 수락」과 같음) |
| 인원 | 높은 시험일수록 많음 — 아래 표 |
| 함께 가는 사람 | 등급을 가리지 않음. 수락은 [11](11-attachment.md)의 식(바탕 + 애착의 보탬) |
| 떨어지면 | 벌 없음. 1주 뒤에 다시 볼 수 있음. 애착 · 명성은 내리지 않음 |
| 죽음 | 시험에서는 죽지 않음. 부상은 보통 리퀘스트처럼 날 수 있음 |

| 승급 시험 | 필요한 인원 [임시] |
| --- | :---: |
| E급 | 1명 (본인 혼자) |
| D급 | 2명 |
| C급 | 3명 |
| B급 | 4명 |
| A급 · S급 | 5명 (파티의 최대) |

- 「높은 고비는 혼자 못 넘는다」. 한 사람만 키워서는 승급을 못 하므로 고르게 키울 까닭이 생깁니다.
- 떨어졌으면 더 좋은 동료를 붙이거나 수행을 시켜서 보내야 합니다. 다시 붙는 길은 시간이 아니라 준비입니다(사용자 15:32). 그래서 기다리는 기간을 길게 두지 않았습니다.
- 모험가의 등급은 길드 등급 + 1까지만 오릅니다. 프로토타입(F급 길드)에서 겪는 것은 혼자 가는 E급 시험 하나입니다.
- 시험의 내용은 10 · 15에서 리퀘스트를 지을 때 정합니다. 방향: 오를 등급 수준의 일 하나 · 그 직업의 주력 능력치에 맞는 종류.

## 3. 모험가의 바람

[11](11-attachment.md)에서 애착 60의 보상으로 「바람을 털어놓고, 그 사람만의 리퀘스트가 열린다」를 정했습니다.

| | 정한 것 |
| --- | --- |
| 나오는 때 | 애착 60 |
| 모양 | 그 모험가가 내는 개인 리퀘스트. 본인이 가고 반드시 수락 |
| 어떤 바람인가 | 그 사람의 성향에서 나옴 |
| 이루면 | 중급 아이템 하나 |

- 지금 게임에 본보기가 둘 있습니다: 「○○의 고향 편지」(애착이 높고 차분한 사람) · 「옛 동료와의 결판」(무모하거나 독불장군인 사람). 새 틀을 만들지 않고 이 자리를 씁니다.
- 「이루면 애착이 크게 오른다」(2026-11-24의 처음 말)와 「그 사람만의 칭호」는 넣지 않았습니다. 리퀘스트에 성공했을 때 보통 오르는 애착만 오릅니다.

**보상의 층**

| 어디서 | 받는 물건 |
| --- | --- |
| 보통 리퀘스트 | 낮은 등급 |
| 바람 | 중급 |
| 보스 ([17](17-quest-material-map.md)) | 레어 |

- 어떤 물건인지는 「아이템의 전체 틀」에서, 바람의 가짓수와 내용은 10 · 15에서 정합니다.

## 4. 큰 물건 — 넘겼습니다

| 넘어온 것 | |
| --- | --- |
| 강화 | 재료는 숫돌. 무엇이고 어디서 하는지 |
| 마법학원의 스킬 | 스킬을 더하는 방식 ([09](09-training.md) 5절) |
| 레어 장비 | 보스의 보상 |
| 모험가가 모을 큰 물건 | 지금 F급은 장비 세 칸뿐 ([18](18-purchase-judgment.md)의 「모으는 것」) |
| 장비 값이 모두 마을로 가는 것 | 길드가 몫을 얻는 길을 둘지 |

- 다섯 모두 「어떤 물건이 있고, 어디서 얻고, 값이 얼마인가」의 물음입니다. **아이템의 전체 틀**을 디자인할 때 함께 다룹니다. 따로 날을 잡아 하는 큰 작업입니다(사용자 15:36).

넷 모두 프로토타입(F급 48주쯤)에는 나오지 않습니다. 앞의 셋은 설계가 이미 있어, 오늘까지 정한 것과 맞춰 볼 곳만 적습니다.

| 은퇴 | **어느 문서에도 없음** | 없음 |

## 아직 모르는 것

1. 보너스 「5점」이 레벨업으로 저절로 붙는 성장에 견줘 큰지 작은지 — 재지 않았습니다
2. 늘 주력 능력치에 다 모는 것이 정답이 되는지. 퀘스트와 전직의 조건이 다른 능력치를 바라야 고민이 됩니다 (10 · 15)
3. 뒤의 고비일수록 점수를 더 줄지
4. 보너스를 나눠 주는 화면 — 시안을 만들지 않았습니다
5. 혼자 보는 E급 시험은 준비 없이 매주 다시 보내도 언젠가 붙을 수 있습니다. 시험의 세기를 「준비 없이는 팽팽」([18](18-purchase-judgment.md))에 맞춰야 합니다
6. 승급 조건이 찼는데 시험을 안 보낸 채 잊는 것 — [16](16-blocked-list.md)의 목록에 넣을지
7. 바람의 가짓수 (지금 본보기는 둘)
