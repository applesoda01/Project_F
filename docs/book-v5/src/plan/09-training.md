# 09 수행

> **상태: 초안 (2026-11-26) · 한석님 논의 전 / 게임: 미반영 · 이름과 숫자는 모두 [임시]**
>
> 「모험가가 어느 쪽으로 클지는 내가 정한다」([01 원칙 다섯](01-principles.md)의 육성)를 맡는 장치입니다. 길드가 돈을 내고 모험가를 한 주 동안 수행에 보내면, 고른 능력치가 오릅니다. 이 쪽을 쓰면서 새로 잰 것은 없습니다. 성장 수치는 한석님 안건입니다.
>
> 대화 기록: 저장소의 `docs/design/세부기획_대화_2026-11-25.md` (「09-1」 ~ 「09-5」 · 2026-11-26 00:01 ~ 11:20)

<div class="pf-key">

**이 쪽의 세 줄**

- 길드가 돈을 내고 모험가를 한 주 수행에 보내면, 고른 능력치가 오릅니다 (한 번에 +2 · 30G).
- 수행은 능력치마다 하나씩 다섯입니다. 여러 번 보내면 리퀘스트를 거쳐 윗단계로 자랍니다.
- 모험가는 수행을 거절하지 않습니다. 「쓰면 오르는 스킬 숙련」은 넣지 않습니다.

</div>

| 3 받아들임 | 모험가는 수행을 거절하지 않음. 다녀오면 애착이 조금 오름 |

## 1. 수행의 틀 — 능력치마다 하나씩 다섯

수행은 「능력치 +2」라는 단추가 아니라 **이름이 있는 훈련**입니다.

| 능력치 | 수행의 이름 [예시] | 윗단계의 이름 [예시] |
| --- | --- | --- |
| 힘 | 웨이트 트레이닝 | 근지구력 훈련 |
| 민첩 | 독함정 피하기 | (뒤에 정함) |
| 지력 | (뒤에 정함) | (뒤에 정함) |
| 정신 | (뒤에 정함) | (뒤에 정함) |
| 기교 | (뒤에 정함) | (뒤에 정함) |

- 위 이름은 사용자가 든 예시입니다. 다섯 수행의 이름은 10 · 15 의뢰에서 리퀘스트와 함께 정합니다.

| | 정한 것 |
| --- | --- |
| 여는 것 | 훈련 허수아비를 놓으면 수행이 열림 (2026-11-24에 정한 그대로) |
| 보내는 법 | 모험가를 눌러 수행을 고름 |
| 걸리는 때 | 한 번에 한 주. 그 주에는 의뢰를 가지 못함 |
| 돈 | 길드가 냄 |
| 누구를 | 쉬는 모험가도, 주력 모험가도 보낼 수 있음 |

- 쉬는 모험가를 보내면 잃는 것이 없습니다. 주력을 보내면 그 주의 의뢰를 못 갑니다. 그래서 「이번 주에 벌까, 키울까」를 고르게 됩니다.
- 기교는 [08](08-grow-with-use.md)에서 오르는 길이 밥 하나뿐이었습니다. 수행 다섯 가운데 하나가 기교라, 길이 하나 더 생깁니다.

## 3. 모험가는 거절하지 않는다

| | 정한 것 |
| --- | --- |
| 수락 | 수행은 모험가가 거절하지 않음 |
| 다녀오면 | 애착 +1 [임시] |
| 바뀌는 것 | 지금 게임의 「부탁은 애착에 따라 거절당함」에서 수행은 뺌 |

- 수행이 가장 필요한 사람은 새로 온 모험가인데, 그 사람의 애착이 가장 낮습니다. 애착이 낮다고 거절하면 가장 필요한 사람에게 가장 안 듣는 장치가 됩니다.
- [16 막힘 알림](16-blocked-list.md)에서 「같이 갈 사람이 없어요」를 누르면 수행으로 갑니다. 거절당하면 그 풀 길이 막힙니다.
- 약점: 돈만 있으면 얼마든지 보낼 수 있습니다. 막는 것은 돈과 「그 주에 의뢰를 못 감」 둘뿐입니다.

## 4. 맡겨 두기는 뒤 등급의 보상

| 때 | 수행을 보내는 법 |
| --- | --- |
| 처음 (F급) | 보낼 때마다 직접 고름 |
| 뒤 등급 | 「쉬는 주마다 이 수행」으로 맡겨 둘 수 있음 — 등급의 보상 ([08](08-grow-with-use.md) 5절의 목록에 더함) |

- 「누구를 무엇으로 키울까」를 고르는 것이 육성의 손맛이라, 처음에는 직접 하게 둡니다. 모험가가 늘어 손이 많이 갈 때쯤 맡겨 두기가 열립니다.
- F급의 모험가는 열 명 안쪽이라 직접 골라도 번거롭지 않다고 봅니다.

## 5. 스킬 — 숙련은 넣지 않는다

처음에는 「스킬도 열 번 쓰면 레벨이 오른다(숙련)」를 넣으려 했습니다. 게임성으로 다시 보고 뺐습니다(2026-11-26 11:15 ~ 11:20).

| 때 | 스킬이 달라지는 길 |
| --- | --- |
| F급 | **보스의 비전서 하나** ([17](17-quest-material-map.md) — 스킬 하나를 더함) |
| 그 뒤 | 마법학원 (스킬을 더함) · 전직 (스킬의 진화) |

**숙련을 뺀 까닭**

| 까닭 | 내용 |
| --- | --- |
| 고르는 것이 없음 | 싸우다 저절로 오름. 「방향을 내가 정했다」에 닿지 않음 |
| 숙제가 되거나 묻힘 | 눈금을 보이면 「채우고 싶은데 방법은 싸움에 더 보내는 것뿐」. 안 보이면 있는 줄도 모름 |
| 알림이 너무 잦아짐 | [08](08-grow-with-use.md)에서 밥 · 손질 · 점 · 물약 · 구급 주머니에 이미 「열 번」이 붙어 있음 |
| 차이를 벌림 | 많이 싸운 사람만 오름. 지금도 48주에 창립 멤버 Lv 10.7 · 나중에 온 모험가 Lv 5.9 |

- 스킬은 그 모험가의 얼굴 같은 것입니다. 드물게, 그리고 플레이어가 고른 순간(「이 비전서를 누구에게 줄까」)에 달라져야 사건이 됩니다.
- 지금 게임: 모험가는 직업 스킬 하나를 갖고 옵니다(전사 더블 스윙 · 궁수 연사 · 마법사 파이어볼 · 도적 급소 찌르기 · 성직자는 치유). 스킬이 달라지는 때는 2차 전직뿐이라, F급에서는 한 번도 달라지지 않습니다.

## 6. 수행과 시설의 「쌓이는 몫」 나누기

[08](08-grow-with-use.md)에서 넘어온 것입니다. 시설을 열 번 쓰면 능력치가 조금 남는데, 수행도 능력치를 올려서 둘이 겹칩니다. 이렇게 나눕니다.

| | 수행 | 시설의 쌓이는 몫 (08) |
| --- | --- | --- |
| 누가 정하나 | 플레이어가 고름 | 모험가가 쓰다 보면 저절로 |
| 드는 것 | 길드 돈 + 한 주 | 따로 없음 (모험가가 낸 값 안에) |
| 크기 [임시] | 한 번에 +2 | 열 번에 +1 |
| 맡은 일 | 방향을 정함 | 쓴 만큼 조금 따라옴 |

- **수행은 돈을 내고 크게, 시설은 저절로 조금.** 방향을 정하는 것은 수행입니다.
- 이 나눔과 크기는 재지 않았습니다. 한 바퀴 뒤에 [임시] 값과 함께 봅니다.

## 아직 모르는 것

1. **처음에는 수행을 자주 못 보냅니다.** 보조금을 10%로 낮춘 초반 12주의 순수입은 한 달 63G쯤입니다(결과 29). 30G짜리 수행은 한 달에 한두 번입니다. [01](01-principles.md)에 적은 「거의 매주」와 다릅니다
2. 「10번」을 다섯 수행에 나눠 채우면 F급 안에 윗단계가 하나도 안 열릴 수 있습니다 (사용자: 꼭 닿지 않아도 됨)
3. 모험가가 수행으로 빨리 세지면 준비물이 덜 팔릴 수 있습니다 ([08](08-grow-with-use.md)의 걱정과 같음)
4. 수행을 고르는 화면의 모양 — 시안을 만들지 않았습니다
5. 수행을 마친 모험가의 말. [01](01-principles.md)에 예시 여섯 줄이 있고, 실제 대사는 아직 쓰지 않았습니다. 처음의 수행 다섯은 능력치를 하나씩 올리지만, **능력치가 둘 이상 오르는 수행도 나중에 더할 예정**이라(사용자 2026-11-26 11:25) 「둘 이상 올랐을 때」의 대사는 그대로 둡니다
6. 둘째 묶음 퀘스트의 최소 조건을 「수행 한두 번으로 닿을 높이」에 두는 것 — 높이를 정하지 않았습니다
