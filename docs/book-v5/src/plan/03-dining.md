## 왜 고치나

| 진단 | 숫자 |
| --- | --- |
| 식당이 거의 벌지 못함 | 식당의 값이 한 달 +38G (2026-11-24 측정) |
| 만든 것이 안 팔림 | 만든 그릇의 61%가 안 팔림 |
| 재료와 퀘스트가 이어지지 않음 | F급 요리 재료를 모두 시장에서 삼. 모험가가 무엇을 잡아 오든 메뉴가 같음 |
| 밥이 결과를 바꾸지 못함 | 밥을 먹는 사람이 65명이든 47명이든 퀘스트 성공률이 90%로 같음 (2026-11-25 1차 측정) |
| 길드에서 먹는 사람이 적음 | 떠난 모험가 122명 가운데 47명 (같은 측정) |

## 1. 재료가 오는 길

| | 정한 것 | 지금 게임에서 바뀌는 곳 |
| --- | --- | --- |
| 주재료 (고기 · 버섯 · 생선) | 모험가가 잡아 온 것으로만 만듦 | 창고에 없으면 시장에서 사 쓰던 것을 뺌 |
| 양념 (소금 · 향신료 · 물 · 밀가루) | 플레이어가 시장에서 직접 삼. 떨어지면 그때그때 | 식당이 알아서 사던 것을 수동으로 되돌림 |
| 없을 때 | 그 요리는 품절이고 경고 카드에 뜸 | 양념은 카드를 누르면 바로 살 수 있게, 주재료는 「굼바의 일에서 나와요」처럼 풀 길이 보이게 |
| 장보기 기능 | 한 번에 쌓아 두기 · 맡기기는 뒤 등급에서 보상으로 엶 | 프로토타입(F급)에는 들어가지 않음 |

- **주재료를 시장에서 사면 퀘스트를 할 까닭이 줄어듭니다.** 17에서 「경영에서 급한 것이 퀘스트를 이끈다」로 정했습니다. 식재료만 시장에서 살 수 있으면 줄 10개 가운데 3개(고기 · 버섯·열매 · 생선)가 그 이음에서 빠집니다.
- 식재료가 나오는 사람이 셋(굼바 · 헤르만 · 탐험가)이라 길이 하나뿐인 것은 아닙니다. 식재료가 안 나오는 두 사람(사냥꾼 · 세실리아)만 밀면 식당이 비는데, 이것은 막지 않고 경고 카드에 보이게 둡니다.
- **양념을 직접 사는 것은 경영의 손맛입니다.** 모든 손길을 게임이 가져가면 경영하는 느낌이 사라집니다. 처음에는 직접 하고, 피로가 쌓일 즈음 장을 봐 두는 기능을 보상으로 엽니다([01](01-principles.md)의 「손이 가는 일은 처음에는 직접」).
- 양념 값은 그것으로 만드는 그릇 값의 10%쯤으로 둡니다(예: 20G짜리 2그릇이 나오는 양념 하나 = 4G). 지금 12G는 옛 규칙의 부산물입니다.

## 2. 만드는 때

| | 지금 게임 | 정한 것 |
| --- | --- | --- |
| 만드는 때 | 매주 출발 전에 요리마다 정해 둔 수(0 ~ 10그릇)만큼 미리 만듦 | 모험가가 주문할 때 재료를 씀 |
| 플레이어의 손 | 요리마다 준비할 그릇 수를 정함 | 없음 |
| 재료 한 세트 | 2 ~ 3그릇 | 그대로 |
| 남은 그릇분 | 한 주 뒤에 버리거나 할인 · 무료로 줌 | **상하지 않음.** 다음 주문 때 나감 |
| 재고 표시 | 재료 개수 | 「멧돼지 스테이크 5그릇분」처럼 그릇 수로 |

- 그릇 수 정하기는 손이 가는 일이지만 경영의 손맛이 아닙니다. 맞히면 본전이고 틀리면 버리기만 하는 「틀리면 손해만 보는 관리」입니다. 그 손은 「누구의 일을 밀까」와 「양념 사기」가 대신합니다.
- 버리는 일이 없어집니다. 따라서 「마감 할인」과 「무료 식사」도 없어집니다. 무료 식사의 애착 +1을 다른 모양으로 살릴지는 11 애착에서 다룹니다.

## 3. 값

값은 플레이어가 요리마다 숫자로 매깁니다. 사는 쪽의 규칙은 [18](18-purchase-judgment.md)에 있습니다.

```
멧돼지 스테이크      ◀  20G  ▶     적당하다     여관에서는 20G
```

- 1G 단위입니다. 한 번 매기면 바꿀 때까지 그대로 갑니다.
- 숫자 옆에 모험가가 그 값을 어떻게 느끼는지(싸다 · 적당하다 · 비싸다)와 여관 값이 함께 보입니다.
- 처음 값은 여관과 같은 값입니다. 지금의 「재료비 × 2 + 5G」로 계산하지 않습니다.
- 길드가 비싸거나 품절이면 모험가는 여관에서 먹고 떠납니다. 여관의 밥은 싸고 효과가 약합니다. 결산에 「여관에서 먹은 모험가 · 놓친 돈」이 보입니다.
- 마을이 커지면 여관 값이 오르고, 길드도 값을 올려 받을 수 있습니다.

## 4. 한 사람이 몇 그릇

따로 규칙을 두지 않습니다. 모험가는 준비물을 필요한 것부터 사고, 쓸 돈이 남으면 다음 것을 삽니다(18).

| 경우 | 사는 그릇 | 까닭 |
| --- | :---: | --- |
| 능력치 하나만 보는 퀘스트 (F급 대부분) | 한 그릇 | 둘째 요리는 그 퀘스트에 도움이 안 됨 |
| 능력치 둘을 보는 퀘스트 (D급부터) | 두 그릇까지 | 요리마다 올려 주는 능력치가 다름 |
| 보스 같은 큰일 | 두 그릇까지 | 지갑을 열어 쓸 돈이 넉넉함 |

- 서로 다른 요리여야 하고, 그 퀘스트에 도움이 되는 것만 삽니다. 같은 요리의 효과는 겹치지 않습니다. 상한은 두 그릇입니다.
- 요리를 여러 가지 갖춰 두면 한 사람이 더 삽니다. 요리를 늘릴 까닭이 생깁니다.

## 5. 요리의 계단

| 계단 | 값 | 효과 | 재료가 오는 곳 | 누가 사나 | 열리는 때 |
| --- | :---: | --- | --- | --- | --- |
| 여관의 밥 | 20G | 가장 약함 (모든 능력치 조금) | — | 길드에서 못 산 사람 | 처음부터 (마을) |
| 기본 요리 | 20G에서 시작 | 기본 | 첫 묶음 | 누구나 | 식당을 지으면 |
| **간판 메뉴** | 25G쯤 | 한 단계 위 | 첫 묶음 | 평소에도 잘 팔림 | 마르타의 2단계 |
| **고급 요리** | 40G 이상 | 두 단계 위 | 둘째 묶음 | 보스를 앞둔 사람 · 잘 버는 사람 | 마르타의 3단계 |
| 전설의 요리 | 미정 | 미정 | 특수 리퀘스트의 전설의 소재 | — | 프로토타입 밖 |

- 모험가는 살 수 있는 것 가운데 가장 좋은 것을 고릅니다. 모험가가 클수록, 큰일일수록 위 칸이 팔립니다.
- 효과의 크기는 「승산을 한 단계 올릴 만큼」을 기준으로, 측정(승산 훑기)이 오면 맞춥니다.

### 간판 메뉴 — 잘 팔리는 요리

기본 요리 가운데 하나를 골라 내거는 **우리 길드만의 요리**입니다. 기본 요리를 대신하지 않고, 메뉴에 한 줄이 더 생깁니다.

| | 기본 요리 | 간판 메뉴 |
| --- | --- | --- |
| 효과 | 기본 | 한 단계 위 |
| 값 | 여관에 견줌. 올리면 「여관보다 비싸요」 | 여관과 견주지 않음. 더 받을 수 있음 |
| 재료 | 한 세트 | 같음 |
| 개수 | — | 한 번에 하나. 바꾸는 것은 한 달에 한 번 |

- 값은 물약을 사고도 살 수 있는 25G쯤으로 둡니다. 평소에 밥에 쓸 수 있는 돈이 그쯤이기 때문입니다.
- **어느 요리를 걸지가 고민입니다.** 전사가 많으면 스테이크, 마법사가 많으면 버섯 수프가 맞습니다. 그리고 그 재료가 나오는 사람의 일을 꾸준히 밀어야 합니다.
- 「재료를 두 배로 쓰고 값도 두 배」는 검토했으나 쓰지 않습니다. 평소의 쓸 돈으로는 사기 어려워 「큰일 앞의 요리」가 되기 때문입니다. 그 자리는 고급 요리가 맡습니다.

### 고급 요리 — 큰일 앞의 요리

둘째 묶음의 식재료로 만드는 요리 셋입니다. 기본 요리 셋과 같은 능력치를 맡는 윗등급이라, 「고기는 힘, 버섯은 지력, 생선은 민첩」이 그대로 통합니다.

| 고급 요리 [이름 임시] | 주재료 | 재료가 나오는 곳 | 올려 주는 능력치 |
| --- | --- | --- | --- |
| 등심 스테이크 | 멧돼지 등심 | 굼바의 둘째 묶음 | 힘 · 기교 |
| 향버섯 볶음 | 향버섯 | 헤르만의 둘째 묶음 | 지력 · 정신 |
| 잉어 찜 | 큰 잉어 | 탐험가의 둘째 묶음 | 민첩 |

- 재료부터 여관에 없는 것이라 값을 여관과 견주지 않습니다.
- 「넘길까, 만들까」가 생깁니다. 처음 들어온 둘째 묶음 식재료는 마르타에게 넘겨 3단계를 열고, 그 뒤에 들어오는 것으로 요리를 만듭니다. 보스를 넘은 보람이 「새 재료 → 새 조리법 → 메뉴판의 새 줄」로 차례로 보입니다.
- 보스는 길드의 대목입니다(18). 보스를 앞두고 고급 재료를 쌓아 두는 것이 플레이어의 준비가 됩니다.

### 전설의 요리 다섯

지금 게임의 그리폰 알 오믈렛 · 와이번 꼬치구이 · 키메라 3종 모둠 · 불사조 수프 · 용 꼬리 스테이크는 버리지 않고 계단의 맨 위에 둡니다. 특수 리퀘스트에서 얻은 전설의 소재로만 만듭니다. 효과와 값은 특수 리퀘스트가 정해질 때(10 · 15) 함께 정합니다.

## 6. 마르타 — 떠돌이 농산 상단

| | 정한 것 |
| --- | --- |
| 넘기는 것 | 식재료. 12개에 한 단계 |
| 오는 때 | 떠돌이로 둠. 「마르타가 오는 주」가 작은 장날. 첫 방문과 간격은 지금(13 ~ 16주 · 5 ~ 8주마다)보다 당김 |
| 팔지 않는 것 | 첫 묶음의 주재료 · 한 등급 위의 식재료 |

마르타의 좌판은 신뢰에 따라 달라집니다.

| 마르타의 신뢰 | 파는 것 | 열리는 것 |
| --- | --- | --- |
| 1단계 | 양념 (시장보다 쌈) | — |
| 2단계 | 양념 + 가끔 귀한 식재료 한두 개 | 간판 메뉴 |
| 3단계 | 양념 + 귀한 식재료가 더 자주 | 고급 요리의 조리법 |

- **귀한 식재료는 둘째 묶음의 식재료이고, 길드가 이미 한 번 얻어 본 것만 팝니다.** 보스를 넘기 전에는 좌판에 오르지 않습니다. 값은 비쌉니다. 사기 전에 무엇인지 다 보입니다.
- 소재를 더 얻는 길이 셋이 됩니다: Lv 3이 된 퀘스트를 더 돈다 · 둘째 묶음으로 간다 · 마르타에게서 산다. 시간을 쓸지 돈을 쓸지를 고릅니다.
- A 그룹 넷 가운데 한스 · 대장장이 · 그레타는 늘 마을에 있고 마르타만 가끔 옵니다.

## 7. 요리 발견

새 요리는 지금처럼 **조리대에서 직접 만들어 봐야** 메뉴에 오릅니다. 식당에서 손맛이 가장 큰 일이라 그대로 둡니다.

| | 일어나는 일 |
| --- | --- |
| 마르타가 3단계가 되기 전 | 둘째 묶음의 식재료를 조리대에 올려도 「아직 다룰 줄 모르는 재료」 |
| 3단계가 되면 | 마르타가 조리법을 귀띔해 줌. 그 뒤 조리대에서 직접 만들어 보면 메뉴에 오름 |

- 마르타의 신뢰는 요리를 대신 넣어 주는 것이 아니라, 그 재료를 다룰 수 있게 해 주고 귀띔을 줍니다.
- 틀리면 넣은 재료가 사라지는 것은 그대로입니다. 귀띔을 듣고 만들면 틀리지 않습니다.
- 간판 메뉴는 새 요리가 아니라 이미 아는 요리를 내거는 것이라, 2단계가 되면 바로 걸 수 있습니다.

## 식당이 두 배로 버는 길은 손님 수입니다

값을 두 배로 올리면 평소의 쓸 돈(45G쯤, 싸우는 퀘스트에서는 물약 20G를 먼저 삼)으로는 사기 어렵습니다. 두 배는 먹는 사람 수에서 나옵니다.

| | 길드에서 먹는 사람 | 식당 수입 |
| --- | :---: | --- |
| 지금 (퀘스트가 쉬움) | 열에 넷 | 지금 수준 |
| 퀘스트가 팽팽해져 「꼭 필요하다」고 느끼면 | 더 많이 | 값을 올리지 않고도 늘어남 |

- 18에서 「퀘스트는 준비 없이 가면 팽팽하고, 준비하면 여유가 되게 설계한다」로 정했습니다. 식당의 벌이는 이 조건에 달려 있습니다.
- 얼마나 느는지는 재는 중입니다(승산 훑기).

## 1차 측정에서 식당에 대해 나온 것

「주문할 때 만든다 · 주재료는 잡아 온 것만」을 측정 도구 안에서 흉내 낸 결과입니다(100판 · 48주).

| | 지금 | 식당만 바꿈 |
| --- | :---: | :---: |
| 한 달 순수입 | 418G | 455G (+36 ± 17) |
| 한 달 식사 수입 | 119G | 99G |
| 재료 등 「그 밖」 지출 | −119G | −50G |
| 맞는 요리가 없어 못 먹은 사람 (한 판) | 9.4명 | 25.4명 |

- 식사 수입은 줄어도 버리는 재료가 없어져 순수입이 늡니다.
- 첫 24주에 재료가 모자랍니다. 처음 창고에 기본 재료를 넣어 둘지는 [임시] 값 목록에 올려 두었습니다.

## 지금 게임과 달라지는 곳

| 지금 | 바뀌면 |
| --- | --- |
| F급 주재료를 시장에서 사 씀 | 잡아 온 것으로만 |
| 양념을 식당이 알아서 삼 | 플레이어가 직접 삼 |
| 매주 미리 만듦 · 그릇 수를 정함 | 주문할 때 재료를 씀 |
| 남은 그릇은 버리거나 할인 · 무료 | 상하지 않음 |
| 값 = 재료비 × 2 + 5G에서 시작 | 여관과 같은 값에서 시작 |
| 한 파티에 요리 하나, 한 사람 한 그릇 | 사는 판단이 정함. 두 그릇까지 |
| 요리 17가지가 한 줄 | 여관 → 기본 → 간판 → 고급 → 전설의 계단 |
| 농산 상단이 한 등급 위의 식재료를 팖 | 양념, 그리고 이미 얻어 본 귀한 식재료 |
| 농산 상단과의 관계 = 거래 금액 | 넘긴 식재료의 개수 |

| 갈래 | 새로 만들 것 |
| --- | --- |

| 말 | 모험가가 안 산 까닭 · 경고 카드의 식당 줄(재료 없음 · 양념 없음 · 비싸서) · 결산의 「놓친 손님」 |

## 아직 모르는 것

1. 퀘스트가 팽팽해지면 길드에서 먹는 사람이 얼마나 느는지 (재는 중)
2. 요리의 효과가 얼마여야 승산을 한 단계 올리는지 (재는 중)
3. 주재료가 모자라는 초반을 어떻게 넘기는지 (처음 창고의 재료)
4. 요리 값에 「가장 남는 값」이 하나로 굳는지
5. 양념을 직접 사는 손이 귀찮음이 아니라 손맛이 되는지 (플레이해 봐야 앎)

## 한석님과 논의할 것

1. 주재료를 시장에서 사지 않는 것 · 양념을 직접 사게 되돌리는 것
2. 그릇 수 정하기와 마감 할인 · 무료 식사를 없애는 것
3. 요리 값의 출발을 여관에 맞추는 것 · 양념 값
4. 요리의 계단(간판 25G쯤 · 고급 40G 이상)과 효과의 크기
5. 농산 상단의 좌판과 오는 때를 바꾸는 것
6. 요리의 효과와 퀘스트의 세기를 「준비하면 승산이 한 단계 오른다」에 맞추는 것
