## 1. 마을 사람은 길드의 시설을 모두 이용합니다

18에서 길드 시설마다 견줄 마을 가게를 짝지어 두었습니다. 마을 사람도 그 짝을 그대로 씁니다.

| 길드의 시설 | 모험가의 쓸모 | 마을 사람의 쓸모 | 견줄 마을 가게 |
| --- | --- | --- | --- |
| 식당 | 퀘스트에 맞는 능력치 | 끼니 | 여관 |
| 주점 | 쉬는 날의 술 | 술 | 여관 |
| 정비대 (04) | 장비 손질 | 농기구와 연장 손질 | 대장간 |
| 약초 시설 (05) | 구급 주머니 | 다치거나 아플 때의 약 | 물약 상점 |

- 마을 사람도 모험가와 같이 「마을 가게보다 싸거나, 마을 가게에 없는 것이면 길드로 온다」로 판단합니다. 새 규칙이 없습니다.
- 능력치 효과는 마을 사람에게 쓸모가 없습니다. 그들을 부르는 것은 값과 「여관에 없는 것」입니다. 간판 메뉴와 고급 요리가 모험가에게는 더 센 밥이고, 마을 사람에게는 찾아올 까닭이 됩니다.
- 시설을 하나 지을 때마다 손님이 두 갈래로 늡니다. 시설마다의 마을 사람의 쓸모는 그 시설을 정할 때(04 · 05) 채웁니다.
- 굼바가 낫을 갈러 정비대에 오고, 세실리아가 고아원 아이의 약을 사러 오는 모습이 됩니다.

### 마을 사람의 주머니 — 마을 전체의 형편 하나 (사용자 19:22 · 19:23)

마을 사람이 「여관에 견줘 비싼가」만 보면, 고급 요리처럼 여관에 없는 것은 값이 얼마든 사게 됩니다. 마을 사람에게도 주머니가 필요합니다.

| --- | --- | --- |
| 소지금 없음 | 늘 살 돈이 있다고 봄 | 여관에 없는 요리는 값이 얼마든 팔림 |
| 한 사람씩 소지금 | 모험가처럼 저마다 지갑 | 수백 명이고 이름도 없음. 누가 왜 못 샀는지 읽을 수 없음 |

## 3. 모험가가 먼저

| | 모험가 | 마을 사람 |
| --- | --- | --- |
| 자리 | 먼저 앉음 | 남은 자리에 앉음 |
| 재료 | 먼저 먹음 | 남은 재료로 만든 것을 먹음 |
| 없으면 | 여관으로 감 | 여관으로 돌아감 |

- 길드는 모험가의 집입니다. 마을 사람 때문에 모험가가 밥을 못 먹고 떠나면 퀘스트가 흔들립니다.
- 돌아간 손님은 손해가 아니라 덜 버는 것입니다. 「자리가 없어 돌아간 마을 손님 3명」이 경고 카드에 뜨고, 테이블을 늘릴 까닭이 됩니다.

| 차례 | 일어나는 일 |
| :---: | --- |
| ① | 마을 손님을 받기 전에는 모험가만 먹음. 「시설에 빈자리가 있어요」 |
| ② | 마을 손님을 받으면 빈자리가 참 |
| ③ | 손님이 자리보다 많아짐. 「자리가 없어 돌아간 마을 손님 ○명」 |
| ④ | 테이블을 늘림 (한스) |

## 4. 열쇠는 촌장

| | 내용 |
| --- | --- |
| 누가 | 바르톨 촌장 |
| 조건 | B 그룹 다섯 사람의 첫 보스 가운데 셋을 해냄 |
| 일어나는 일 | 촌장이 찾아와 길드를 마을 사람들에게 엶. 그때부터 마을 손님이 옴 |

- B 그룹 다섯은 농부 · 사냥꾼 · 학자 · 수녀 · 탐험가, 곧 마을 사람들입니다. 그들의 큰일을 해내 주었으니 마을이 길드를 믿고 찾아옵니다.
- 보스를 넘은 보람이 「새 묶음 · 새 소재」에 더해 「마을 손님」으로도 돌아옵니다.
- 보스 셋은 한 사람씩 몰아서 밀면 15주쯤, 고르게 밀면 21주쯤입니다(계산값). 여러 사람의 일을 할 까닭이 하나 더 생깁니다.
- [02](02-timeline.md)에 남아 있던 「마을 손님 받기의 열쇠」가 이것으로 정해졌습니다.
