## 1. 마을 사람은 길드의 시설을 모두 이용합니다

18에서 길드 시설마다 견줄 마을 가게를 짝지어 두었습니다. 마을 사람도 그 짝을 그대로 씁니다.

| 길드의 시설 | 모험가의 쓸모 | 마을 사람의 쓸모 | 견줄 마을 가게 |
| --- | --- | --- | --- |
| 식당 | 퀘스트에 맞는 능력치 | 끼니 | 여관 |
| 주점 | 쉬는 날의 술 | 술 | 여관 |
| 정비대 (04) | 장비 손질 | 농기구와 연장 손질 | 대장간 |
| 약초 시설 (05) | 구급 주머니 | 다치거나 아플 때의 약 | 물약 상점 |

- 마을 사람도 모험가와 같이 「마을 가게보다 싸거나, 마을 가게에 없는 것이면 길드로 온다」로 판단합니다. 새 규칙이 없습니다.
- 능력치 효과는 마을 사람에게 쓸모가 없습니다. 그들을 부르는 것은 값과 「여관에 없는 것」입니다. 간판 메뉴와 고급 요리가 모험가에게는 더 센 밥이고, 마을 사람에게는 찾아올 까닭이 됩니다.
- 시설을 하나 지을 때마다 손님이 두 갈래로 늡니다. 시설마다의 마을 사람의 쓸모는 그 시설을 정할 때(04 · 05) 채웁니다.
- 굼바가 낫을 갈러 정비대에 오고, 세실리아가 고아원 아이의 약을 사러 오는 모습이 됩니다.

## 2. 얼마나 오나

| 차례 | 일어나는 일 |
| :---: | --- |
| ① | 인구에 따라, 이번 주에 밖에서 먹을 마을 사람의 수가 정해짐 |
| ② | 한 사람씩 길드와 여관을 견줌. 길드가 싸거나 여관에 없는 요리가 있으면 길드로 옴 |
| ③ | 길드에 빈자리가 있으면 먹고, 없으면 여관으로 돌아감 |

| 마을 | 인구 | 한 주에 밖에서 먹는 마을 사람 |
| --- | :---: | :---: |
| 시작 (개척촌) | 150명 | 3명쯤 |
| 마을 단계 | 300명 | 6명쯤 |
| 읍 단계 | 1,000명 | 20명쯤 |

- 인구 100명에 한 주 2명꼴입니다.
- 지금 한 주에 떠나는 모험가는 두세 명입니다. 시작할 때의 마을 사람 3명만 다 와도 손님이 두 배가 됩니다.
- 플레이어가 손님 수를 직접 정하지 않습니다. 길드가 여관보다 얼마나 나은가에 달려 있습니다.

## 3. 모험가가 먼저

| | 모험가 | 마을 사람 |
| --- | --- | --- |
| 자리 | 먼저 앉음 | 남은 자리에 앉음 |
| 재료 | 먼저 먹음 | 남은 재료로 만든 것을 먹음 |
| 없으면 | 여관으로 감 | 여관으로 돌아감 |

- 길드는 모험가의 집입니다. 마을 사람 때문에 모험가가 밥을 못 먹고 떠나면 퀘스트가 흔들립니다.
- 돌아간 손님은 손해가 아니라 덜 버는 것입니다. 「자리가 없어 돌아간 마을 손님 3명」이 경고 카드에 뜨고, 테이블을 늘릴 까닭이 됩니다.

| 차례 | 일어나는 일 |
| :---: | --- |
| ① | 마을 손님을 받기 전에는 모험가만 먹음. 「시설에 빈자리가 있어요」 |
| ② | 마을 손님을 받으면 빈자리가 참 |
| ③ | 손님이 자리보다 많아짐. 「자리가 없어 돌아간 마을 손님 ○명」 |
| ④ | 테이블을 늘림 (한스) |

## 4. 열쇠는 촌장

| | 내용 |
| --- | --- |
| 누가 | 바르톨 촌장 |
| 조건 | B 그룹 다섯 사람의 첫 보스 가운데 셋을 해냄 |
| 일어나는 일 | 촌장이 찾아와 길드를 마을 사람들에게 엶. 그때부터 마을 손님이 옴 |

- B 그룹 다섯은 농부 · 사냥꾼 · 학자 · 수녀 · 탐험가, 곧 마을 사람들입니다. 그들의 큰일을 해내 주었으니 마을이 길드를 믿고 찾아옵니다.
- 보스를 넘은 보람이 「새 묶음 · 새 소재」에 더해 「마을 손님」으로도 돌아옵니다.
- 보스 셋은 한 사람씩 몰아서 밀면 15주쯤, 고르게 밀면 21주쯤입니다(계산값). 여러 사람의 일을 할 까닭이 하나 더 생깁니다.
- [02](02-timeline.md)에 남아 있던 「마을 손님 받기의 열쇠」가 이것으로 정해졌습니다.

## 5. 마을 손님이 남기는 것

돈, 그리고 **게시판에 붙는 퀘스트**입니다. 길드에 다녀간 마을 사람이 많을수록 퀘스트가 더 붙습니다. 밥을 먹으러 온 사람이 부탁할 일을 남기고 가는 모양입니다.

| 차례 | 고리 |
| :---: | --- |
| ① | 퀘스트를 해냄 → 소재가 들어오고 마을이 큼 |
| ② | 식당을 잘 꾸림 → 마을 사람이 여관 대신 길드로 옴 |
| ③ | 마을 사람이 돈을 쓰고, 일을 남기고 감 |
| ④ | 게시판에 퀘스트가 더 붙음 → ①로 |

- 지금까지는 퀘스트가 소재를 주고 소재가 식당을 돌리는 한 방향이었습니다. 이것으로 고리가 양쪽으로 닫힙니다.
- 17의 숙제(F급 70건이 지금 박자로는 49주)에 길이 생깁니다. 퀘스트를 그냥 늘려 주지 않고, 마을 손님을 잘 받으면 늘어나게 합니다.
- 어젯밤의 「신뢰도가 조금 오른다」는 쓰지 않습니다. 플레이어가 느낄 수 없는 숫자 대신 게시판에서 바로 보이는 것으로 바꿨습니다.

## 6. 마을이 커지는 것과 길드

### 여관 값은 마을 단계마다 오릅니다

| 마을 단계 | 인구 | 여관의 밥 |
| --- | :---: | :---: |
| 개척촌 | 300 미만 | 20G |
| 마을 | 300 이상 | 30G |
| 읍 | 1,000 이상 | 45G |
| 도시 | 2,000 이상 | 70G |
| 성채 도시 | 3,500 이상 | 100G |

- **길드 등급과 마을 단계가 따로 큽니다.** 길드가 E급이 되어 모험가의 벌이는 늘었는데 마을이 아직 개척촌이면, 여관 밥은 여전히 20G입니다. 길드가 밥값을 올리면 「여관보다 비싸요」가 나옵니다.
- 마을을 키워야 값을 올려 받을 수 있습니다. 길드만 키워서는 안 되고 마을을 함께 키워야 합니다.

### 왕국 보조금은 퀘스트 보상의 10%

| | 지금 | 정한 것 |
| --- | :---: | :---: |
| 퀘스트 하나(보상 100G)에서 길드가 받는 돈 | 수수료 10G + 보조금 50G | 수수료 10G + 보조금 10G |

- 뿌리의 물음이 「길드는 어디서 돈을 버는가 → 모험가의 주머니에서」입니다. 벌이의 3분의 2가 왕국에서 오면 식당을 잘하든 못하든 길드가 굴러갑니다. 10%면 시설이 벌어 주지 않으면 길드가 크지 못합니다.
- 처음부터 10%이니 깎이는 순간이 없습니다. 「잘했더니 깎인다」가 생기지 않습니다.
- 지금 규칙에서 보조금만 10%로 바꾸면 첫 석 달의 한 달 순수입이 207G에서 46G쯤이 됩니다(계산값). 다만 이것은 정비대 · 약초 시설 · 마을 손님 · 팽팽한 퀘스트가 없는 지금 버전의 계산입니다. 시설들의 기획이 다 끝난 뒤에 한꺼번에 잽니다.

## 그림

- 마을 주민 남 · 여의 그림(걷기 · 서기 · 앉기 · 먹기 · 맥주)을 2026-11-25 새벽에 만들어 두었습니다. 걷기는 다시 만들기로 하고 대기 중입니다.
- 로비를 걸어 다니고 식당에 앉는 마을 사람이 보여야 합니다. 지금 로비에는 모험가만 오갑니다.

## 아직 모르는 것

2. 마을 손님이 남기는 퀘스트로 F급 70건이 40주 안에 들어오는지
