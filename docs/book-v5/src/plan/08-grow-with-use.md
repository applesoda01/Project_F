## 왜 필요한가

| 진단 | 근거 |
| --- | --- |
| 시설의 효과가 모두 「이번 원정만」 | 식사의 효과는 퀘스트가 끝나면 사라짐. 쌓이는 것은 퀘스트와 레벨 업에서만 나옴 |
| 효과를 키워도 수입이 늘지 않음 | 요리의 효과를 3배로 올려도 수입은 +6G (2026-11-24 측정) |
| 시설을 돈으로만 올림 | 업그레이드는 500 ~ 1,000G를 내고 한 번. 첫해에는 돈이 묶여 순수입 −5 ± 11G (정밀 분석) |

쌓이는 것은 두 곳에 생깁니다. 시설 쪽(레벨)과 모험가 쪽(몸에 남는 몫)입니다.

## 1. 시설의 레벨 — 네 시설에 같은 규칙

[04](04-maintenance.md)에서 정비대에 먼저 정한 규칙을 식당 · 점술가의 자리 · 약초 시설에도 똑같이 넣습니다.

| | 정한 것 |
| --- | --- |
| 오르는 길 | 이용객(모험가 + 마을 사람)이 쌓임. 한 레벨에 30명 [임시 예] |
| 오르면 | 모험가가 「적당하다」고 느끼는 값이 오름. 한 레벨에 +2G [임시 예]. 시설의 모습이 바뀜 |
| 요금 | 저절로 오르지 않음. 플레이어가 ◀ 숫자 ▶로 올림 |
| 치우면 | 창고에 들어가고 레벨은 그대로 ([07](07-placement.md)) |

사람의 단계와 시설의 레벨은 하는 일이 다릅니다.

| | 오르는 길 | 오르면 | 닿는 곳 |
| --- | --- | --- | --- |
| 사람의 단계 (마르타 · 대장장이 · 점술가 · 그레타) | 소재를 건넴 | 새것이 열림 (새 요리 · 새 손질 · 윗급) | 전투와 퀘스트 |
| 시설의 레벨 | 이용객이 쌓임 | 더 비싸게 받을 수 있음 · 모습이 바뀜 | 돈 |

값을 올리는 길은 둘이고, 겹치지 않게 둡니다.

| 값을 올리는 길 | 크기 |
| --- | --- |
| 마을 단계 (마을 가게의 값이 오름 · [06](06-town-customers.md)) | 큰 계단 (20G → 30G → 45G) |
| 시설의 레벨 (솜씨 값이 얹힘) | 작은 계단 (+2G씩) |

- 식당은 손님이 가장 많은 곳이라 레벨이 가장 먼저, 가장 자주 오릅니다.
- 「싸게 받아 손님을 늘려 빨리 키울까, 비싸게 받아 지금 벌까」가 네 시설 모두에 생깁니다.
- 지금의 「돈을 내고 한 번 하는 업그레이드」를 어떻게 할지는 아직 정하지 않았습니다.

## 2. 모험가가 조금씩 자라는 몫

> **그 원정 동안만 주던 것이, 열 번 쓰면 조금 몸에 남는다.** [임시: 열 번]

| 쓰는 것 | 그 원정 동안 | 열 번 쓰면 남는 것 [임시] |
| --- | --- | --- |
| 밥 | 능력치가 오름 | 그 요리의 능력치 +1 |
| 날 세우기 | 더 세게 때림 | 힘 +1 |
| 덧대기 | 덜 다침 | 민첩 +1 |
| 마석점 | 싸움이 없는 퀘스트의 승산 | 지력 +1 |
| 동전점 | 싸움이 없는 퀘스트의 승산 | 정신 +1 |
| 회복 물약 | 체력을 채움 | 최대 체력이 조금 |
| 마력 물약 | 마력을 채움 | 최대 마력이 조금 |
| 구급 주머니 | 부상을 막음 | 애착 +1 (들고 나간 횟수로 셈) |

- 전사가 멧돼지 스테이크를 열 번 먹으면 열 번째에 머리 위로 「힘 +1」이 뜹니다.
- **길드의 시설에서 쓴 것만 셉니다.** 여관에서 먹은 밥, 대장간에서 받은 정비는 세지 않습니다. 값이 같아도 길드에서 쓸 까닭이 하나 더 생깁니다.
- 모험가마다 길드에서 지낸 흔적이 남습니다. 「이 모험가는 정비대 단골이라 힘이 높다」.
- 메뉴가 육성에 닿습니다. 「전사가 많으니 스테이크를 간판으로 걸자」가 수입뿐 아니라 키우는 방향까지 정합니다.

**여기까지 온 길.** 처음에는 「밥에만 둔다」를 냈습니다. 어젯밤의 말씀은 「시설을 이용하면」이었으므로 모든 시설로 넓혔습니다(사용자 23:22). 손질은 「공격 · 방어」로 두었다가, 새 숫자를 만들지 않고 싸우는 쪽과 마법 쪽이 같은 모양이 되도록 「힘 · 민첩」으로 바꿨습니다(사용자 23:27). 점은 「지력 · 정신」(사용자 23:26), 구급 주머니는 「애착」(사용자 23:25)입니다.

- 구급 주머니가 실제로 쓰이는 때는 쓰러졌을 때뿐이라(지금 한 해 3 ~ 4번) 「쓰인 횟수」로 세면 차지 않습니다. 「들고 나간 횟수」로 셉니다. 실제로 부상을 막아 준 날에 애착이 따로 더 오르게 할지는 11에서 다룹니다.

### 기교는 지금 시설을 만들지 않습니다

능력치는 다섯인데 손질과 점이 올리는 것은 넷입니다. 기교가 남습니다.

| 길 | 내용 |
| --- | --- |
| 지금 | 기교는 밥(멧돼지 스테이크가 「힘 · 기교」를 함께 올림)과 수행(09)으로 오름 |
| 다음에 만들 시설의 첫 후보 | **지도 탁자** — 탐사를 떠나기 전에 들르는 곳. 의뢰의 성공 확률을 높이는 방안으로(사용자) |

- 덧대기를 민첩 대신 기교로 바꾸면 이번에는 민첩이 남습니다. 자리만 바뀔 뿐이라 고르지 않았습니다.
- 사용자의 새 생각(10 · 15로 넘김): **미니 뷰에 보물상자와 함정.** 기교가 닿는 곳입니다. 지금 기교는 전투에서 「때리는 빠르기」로만 쓰여 도적이 퀘스트 안에서 눈에 띄는 일이 없습니다.

## 3. 품삯 — 식당에는 두지 않습니다

| | 팔 때마다 드는 것 | 달마다 드는 것 |
| --- | --- | --- |
| 식당 | 주재료 + 양념(시장에서 삼) | 없음 |
| 정비대 · 점술가의 자리 · 약초 시설 | 소재 1개 | 품삯 (그 레벨의 기본 값 한 번) |

- 식당은 양념을 달마다 삽니다. 품삯은 양념이 없는 시설에서 그 자리를 채운 것이었습니다.
- 품삯은 「내가 골라 놓은 시설」에 붙는 돈입니다(2026-11-24 밤). 식당은 처음부터 있는 시설입니다.
- 보조금을 10%로 낮추면 첫 석 달의 순수입이 한 달 63G쯤입니다(2026-11-25 B세션 측정 · 100판). 처음부터 식당 품삯이 나가면 버티기 어렵습니다.
- 「식당은 양념, 나머지는 품삯」으로 외웁니다. 네 시설 가운데 식당만 다릅니다.

## 4. 장식 — 값이 아닌 것을 돕고, 짝이 있습니다

[07](07-placement.md)에서 장식을 「옆에 놓인 시설을 돕는 것」으로 정했습니다. 여기서는 레벨과 겹치지 않게 나누고, 짝을 더했습니다.

### 레벨은 값, 장식은 값이 아닌 것

| | 무엇을 돕나 | 예 [임시] |
| --- | --- | --- |
| 시설의 레벨 | 받을 수 있는 값 | Lv 2가 되면 +2G |
| 장식 | 값이 아닌 것 | 벤치: 그 시설의 자리 +1 |
| | | 화분: 그 시설에 마을 손님이 한 명 더 옴 |
| | | 사물함: 그 시설에서 소재가 가끔 닳지 않음 |

- 레벨은 한 사람에게서 더 받게 하고, 장식은 손님을 늘리거나 재료를 아끼게 합니다. 둘 다 놓을 이유가 있습니다.
- 자리가 모자란 식당에는 벤치를, 손님이 적은 점술가 옆에는 화분을 놓습니다.

### 속성과 짝

카이로소프트의 「주변 장식의 속성에 따라 벤치가 바뀐다」(사용자)를 우리 게임에 맞게 옮겼습니다.

| | 정한 것 |
| --- | --- |
| 속성 | 장식마다 하나 |
| 짝 | 붙여 놓으면 옆의 장식이 그 속성에 따라 바뀜. 이름과 모습이 달라지고 효과가 하나 더 붙음 |
| 찾기 | 어떤 짝이 있는지는 알려 주지 않음. 놓아 보며 찾음 |
| 좋아하는 사람 | 바뀐 장식마다 좋아하는 성향(신중 · 보통 · 무모)이 있음 |
| 좋아하면 | 그 옆 시설을 더 자주 씀(필요를 한 단계 높게 봄). 쓸 때 애착이 오름 |

예 [임시]: 벤치만 놓으면 그 시설의 자리가 +1 됩니다. 벤치 옆에 화분을 붙이면 「꽃그늘 벤치」로 바뀌어 마을 손님이 한 명 더 옵니다. 신중한 성향의 모험가는 이 자리를 좋아해서, 그 옆 식당에서 밥을 더 자주 먹고 애착이 조금씩 더 쌓입니다.

| 카이로소프트 | 우리 게임 |
| --- | --- |
| 더 자주 앉는다 | 좋아하는 모험가가 그 옆 시설을 더 자주 씀 |
| 만족도가 오른다 | 애착이 오름 |

- 「더 자주 쓴다」는 이미 있는 규칙입니다. [18](18-purchase-judgment.md)에서 대식가가 밥을 더 찾고, [19](19-fortune-teller.md)에서 미신가가 점을 더 찾는 것과 같습니다.
- **새 입맛은 만들지 않습니다.** 18에서 사는 판단에 입맛을 넣지 않기로 했습니다. 「누가 좋아하는가」는 이미 있는 성향으로 정합니다.
- 놓아 보며 찾는 재미는 [03](03-dining.md)에서 요리를 조리대에서 직접 만들어 보며 찾는 것과 같은 결입니다.
- 한스가 장식을 여러 개 만들 수 있게 한 것(07)의 쓸모가 여기서 생깁니다.

## 5. 뒤 등급에서 여는 보상

[01](01-principles.md)의 「손이 가는 일은 처음에는 직접, 맡기는 기능은 나중에 보상으로」에 따라 미뤄 둔 것들입니다. 모두 프로토타입이 끝나는 E급 승급보다 뒤의 일이라, 여는 때는 그 등급을 만들 때 정합니다.

| 미뤄 둔 것 | 나온 곳 |
| --- | --- |
| **지도 탁자** (기교 쪽 시설) — E급을 만들 때 가장 먼저 봄 | 이 쪽 2절 |
| 장보기 맡기기 (양념을 알아서 사 둠) | 03 · 「피로감이 쌓일 때쯤, 한 3년 이후」(사용자) |
| 남는 소재를 맡겨서 팔기 | 04 |
| 소재의 등급을 올리고 낮추는 시설 | 2026-11-25 18:04 (사용자) |
| 증축 (2층) | 07 |

지도 탁자만은 성격이 다릅니다. 기교의 빈자리를 채우는 시설이라 뒤로 미룰수록 도적이 덜 쓰입니다.

## 아직 모르는 것

1. **모험가가 빨리 세지면 준비물이 안 팔릴 수 있습니다.** 쌓이는 몫으로 모험가가 여러 갈래로 자라면 퀘스트가 쉬워지고, 승산이 「여유」이면 모험가는 준비물을 사지 않습니다(2026-11-25 B세션 1차 측정). 시설을 쓸수록 시설이 덜 팔리는 모양이 될 수 있습니다. 크기를 아주 작게 두고, 퀘스트의 세기를 10 · 15에서 함께 맞춰야 합니다
2. 「열 번에 +1」의 크기. 재지 않았습니다
3. 쌓이는 것이 거의 다 능력치라 수행(09)과 겹치는 것. 「수행은 돈을 내고 크게, 시설은 저절로 조금」으로 나눌 생각이나 09에서 맞춰야 합니다
4. 지력과 정신은 밥과 점 두 군데서, 힘과 민첩은 밥과 손질 두 군데서 오릅니다. 기교만 길이 하나 적습니다
5. 레벨의 문턱(30명)과 솜씨 값(+2G) · 레벨의 상한
6. 속성의 종류 · 짝의 목록 · 장식 8종 하나하나의 효과 · 짝마다 좋아하는 성향과 애착의 크기
7. 지금의 「돈을 내고 하는 업그레이드」(게시판 · 접수대 · 주점 · 판매 창구 · 관리소)를 남길지
