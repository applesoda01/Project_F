## 3. 이번에 끝낸 일

### 3-1. 의뢰 전투 (B 기반 C안) 1~4단계
- **규칙:** 적이 있는 의뢰는 전투 계산으로 성패(적 전멸 = 성공, 후퇴·전멸 = 실패), 비전투(조사·채집)는 능력치 판정 유지. 스킬 제외(성직자 회복만).
- **2단계 밸런스 확정(몬스터·직업 수치는 그대로):**
  - `combat,enemyVar` = **0.15** — 의뢰마다 적 전체 체력·공격력 0.85~1.15배. 모험가는 게시 정보로 판단 → 예측이 빗나가 실패 발생. 정보실 1단계마다 예측 오차 25% 감소.
  - `adv,departTh` = **0.95/0.85/0.65**, `adv,seekTh` = **0.50/0.70/0.85** (예전엔 코드에 고정값).
  - `combat,potionPrice` 추가.
  - 결과(100판 첫해): 성공률 92%(전투 97%·비전투 85%), 월 454G.
- **3단계 게임 연결:** 출발 때 물약 구매 + 전투 즉시 계산(기록을 `s.active[].fight`에 저장), 귀환 때 반영. 쓰러진 사람은 사망 판정 → 살면 부상(`state:'injured'`, F·E 2주, 의무실 −1주). **게임에 처음으로 의뢰 중 사망이 생김.**
- **관문 1:** 성공률 기준 65~85% → **80~95%**. 현재 게임 456G·93.1% / 시뮬 454G·92.0% → 통과.
- **비전투도 출발 때 결과를 정함**(`s.active[].ok`, 미니 뷰가 귀환 전에 결과 장면을 보여 주려고). 위험도 표시는 `rate`(출발 때 예상 성공률).
- 전투 기록 형식: `hit{by,to,hp,c}` · `miss{to}` · `hurt{to,hp}` · `heal{by,to,hp}` · `potion{to,hp}` · `down{to}`, `r`=라운드.

## 7. 작업 주의점 (꼭 지킬 것)

- **기기 저장(commit)은 조용히 실패하거나 옛 내용이 올라갈 수 있음.** 매번 `/mnt/user-data/outputs/fxNN/` **새 폴더**에 파일을 복사해 올리고(이번 세션은 fx18까지 사용), 저장 후 **다시 stage해서 `cmp`로 대조**. PNG는 전송 중 재압축되어 바이트가 다를 수 있으니 **픽셀 비교**로 확인.
- 기존 파일 덮어쓸 때 항상 `expectedMtimeMs`(직전 stage의 mtime) 지정. 한 번에 50개 제한.
- balance.csv는 **BOM(EF BB BF) 유지**. 고친 뒤 `python3 tools/data_build.py` → data_gen.js 재생성 → `node tools/gate1_check.js`.
- collegium_data.json은 `json.dumps(d, ensure_ascii=False, indent=2) + '\n'`이면 원래 서식과 같음.
- 클라우드 작업 사본(이번 세션): `/tmp/claude-0/-home-claude/69269ae0-.../scratchpad/proj` — **새 세션에서는 없으므로 기기에서 다시 stage해서 시작.**
- 게임 화면 검사: 기기 prototype 폴더를 stage해 임시 폴더에 모은 뒤 Playwright로 `file://` 열기(외부 글꼴 차단 경고는 무시). 개발 패널 `#dWeek`(다음 주), `#dGrade`(등급 올리기), `[data-speed="4"]`로 진행.

- 프롬프트에 **"real alpha transparency, NOT a drawn checkerboard, not grey"** 를 꼭 넣을 것. 그래도 가끔 체크무늬·회색 배경이 그려져 옴 → 진한 윤곽선이 있어 **가장자리 연결 영역 + 고리 안쪽 큰 덩어리 + 사슬 구멍 작은 조각** 제거로 처리 가능(scipy `ndimage.label`).
- 아이템이 칸 경계를 넘는 경우가 많음 → **칸 단위가 아니라 알파 덩어리 단위**(무게중심이 속한 칸)로 잘라야 끝이 안 잘림.
- 아이콘 후처리: 여백 7%씩 두고 정사각형 → 256px LANCZOS.
- 도트: GPT는 가짜 도트 → FFT로 격자 간격 추정 후 BOX 축소 + 팔레트 양자화(디더 없음) + 알파 임계값.
