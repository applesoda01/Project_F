`docs/design/popup_quality_todo.md`의 진행 표를 갱신해 보여 주고, 다음 팝업(⬜ 다음)을 안내합니다. 팝업을 하나 반영할 때마다 이 표도 함께 고칩니다.

## 2. 작업 흐름 (이 세션에서 굳어진 방식)

1. 사용자가 "○○ 보여줘" → **지금 화면을 캡처**해 보여 주고, 화면 문제 + **코드에서 확인한 실제 규칙과 어긋나는 점**을 표로 짚음 (예: 시설 8개가 효과 없이 돈만 나감, 식당 효과 문구가 실제와 다름).
2. 사용자가 두서없이 말함 → 한 항목씩 **받아 적고 번호를 매겨**(예: 성향 1·2·3…) 정리. 모호하면 선택지(AskUserQuestion)로 확인. 추천안이 있으면 표로 비교하고 추천 표시.
3. 사용자가 "시안 보여줘/진행해줘" → 작업 공간에서 고치고 **캡처로 시안**(오버 창·연출은 장면별로). **폴더에는 반영하지 않음.**
4. 사용자가 "반영해줘" → 폴더에 반영(장치 파일 수정 시각 확인), **다시 받아 cmp로 비교**, 규칙을 건드렸으면 **관문 1 실행**, 설계 문서·진행표 갱신, **한국어 커밋 메시지** 제공.

## 5. 미결 · 리마인드 (진행표 "남은 미결"과 같음)

- **[리마인드] 스킬 전투 계산**: 발동 확률·마력·재사용 대기 미정. 장착 5칸이면 발동률 1단계 41% · 2단계 63% · 3단계 81%. 사용자가 "나중에 꼭 리마인드"를 요청함 → 관련 작업 때 먼저 꺼낼 것.
- 성향 공개 규칙(설계서는 애착 단계별 공개, 팝업은 모두 보여 줌), 경력 기록 확장, 잠긴 물약 칸 🔒 임시.
- 시설 효과 1·2·3 개방(보류), 준비 중 시설의 효과 구현(F·E에서는 집무실), **후반 돈 과잉**(유지비 삭제로 커짐).
- 식사 효과 상한(16개 다 찾으면 +32%), **E급 요리 발견이 늦음**(숲 버섯 파이 2년에 절반 — 밀가루 확률 검토), 음식이 아닌 소재의 판매·장비 해금(지금은 보관만), 소재 판매 차익은 아직 자동 수입.
- 의뢰 게시판: 기한 지난 의뢰 자동 철회, 빈 칸 표시 여부.

## 6. 작업 주의점

- **장치 접근**: `device_bash` 없음 → `device_stage_files`(가져오기, 50개씩) / `device_commit_files`(쓰기, `expectedMtimeMs`로 사용자 수정 보호). 삭제 권한 없음.
- 반영할 파일은 `/mnt/user-data/outputs/fxNN/`에 모아 커밋(이 세션은 fx31까지 씀). 반영 후 **다시 받아 `cmp`**. PNG는 전송 중 다시 인코딩될 수 있어 픽셀로 비교.
- `data/collegium_data.json`은 `indent=2`로 저장(편집기 형식, `seq` 번호도 갱신). `data/meals.csv`·`balance.csv`는 **BOM 있음**. 데이터를 고치면 `python3 tools/data_build.py`.
- balance.csv에 항목을 추가하면 `tools/balance_schema.json`에도 추가.
- 게임과 시뮬레이터(`sim_engine.js`)는 **같은 규칙**이어야 함(관문 1이 둘을 비교). 규칙을 바꾸면 둘 다.
- 화면이 창 크기에 맞춰 축소·확대됨 → 좌표 계산은 배율 보정(`getBoundingClientRect` 폭 ÷ `offsetWidth`). 작은 창(1366×768)에서도 확인.
- 팝업을 다시 그리면(`renderPopup`) 애니메이션이 처음부터 재생됨 → 한 번만 재생할 효과는 상태로 막을 것(식당 `kFxAt`/`held` 참고).
- **GPT 그림**: 사용자의 ChatGPT가 Claude 내장 브라우저에 열려 있음. 프롬프트를 먼저 보여 주고 허락받은 뒤 보냄. "real alpha transparency, NOT a drawn checkerboard"를 넣고, 받은 뒤 JS로 투명 비율을 확인(회색 배경으로 오면 다시 요청). 사용자가 **다운로드 폴더에 저장** → 가져와서 자름. 원본 시트는 `art_source/`에 보관.

## 6-1. 소재 편집기 갱신 (2026-11-05 마지막 작업)

- 요리: 조합 수량 칸 삭제(소재 각 1개, 1~3종), 경고(같은 소재 두 칸·다른 요리와 조합 중복·퀘스트에서 못 얻는 소재), 효과 해석 미리보기.
- **요리 효과의 원본 = 편집기 요리 '효과'(items[].desc)**. 게임 `DISH`·시뮬레이터 모두 `it.desc || meals.csv 효과`. meals.csv는 메뉴 순서·등급 확인용.
- **오버 메모(`tip`)**: 음식·장비·물약·몬스터·퀘스트. data_gen.js까지 전달, 게임 표시는 아직 없음(나중에 오버 창에 쓸 자유 메모).
- `data_build.py`: 요리 규칙 검사(중복 재료·조합 중복은 오류, 퀘스트 없는 재료·해석 안 되는 효과는 경고). 지금 경고 8건은 D급 이상 재료 공급 퀘스트가 없어서 생김(그 등급 설계 때 해결).
- 편집기를 열면 **먼저 "불러오기"**(브라우저 임시 보관본이 새 소재·레시피를 덮어쓸 수 있음).
