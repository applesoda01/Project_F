## 4. 이번 기간 확정 내용

**대사창 (RPG 대화신 방식)**
- 방향: **우드 디자인**(파스텔은 아동용 느낌으로 폐기). 틀 두께 **18px 단일층**, 황동 모서리, 양피지 안쪽 창(투명도 조절), 먼지 장밋빛 이름표.
- 배치(1920×1080): 초상 x70 y90 h1240 / 박스 x60 y790 w1800 h250 / 이름 (151,760) 크기 30 / 본문 (159,848) 폭 1585 크기 33 줄간격 1.62 / 다음 표시 (1790,990) / 선택지 (1180,300) 폭 620. 값은 `docs/art/dialog/dialog_layout.json`.
- 제작: `tools/ui_wood/build_box.py`의 `build(W,H,T,bright,line,pbright,palpha)`로 프로그램 생성. 투명도 시안 55/70/85/100 비교본이 `docs/art/dialog/`에 있습니다.

**접수원 리나**
- 중앙(x=960) **고정**, 이동 없음. 대기 시트 3칸(깜빡임 순서 1→2→1→0), 동작 시트 5종(greet·guide a/b·read a/b, 12×6=72프레임 24fps)을 **1.5배속**으로 재생. 대기 6±2초마다 무작위 동작, 같은 그룹 연속 반복 없음.
- 모험가 줄은 리나 왼쪽 앞에 6칸 대기(`QSPOT`). 게시판 뒤 겹침은 허용.

**데이터 분리·협업**
- 밸런스·대사·말풍선·퀘스트 종류·이름·식사·스킬을 `data/*.csv`로 분리. `data_build.py`가 검증(파일·행·이유 표시) 후 `data_gen.js` 생성. 분리 후에도 관문 1 기준선 동일(436G/75.9%).
- 흐름: 작업자가 브랜치에서 CSV 수정 → PR → 자동 검사 → 병합 → 자동 재생성·빌드. 비공개 저장소 무료 플랜에서는 Pages 불가 → `최신빌드` 아티팩트를 사용합니다.

**로비 배경 v3 (주말 작업)**
- 밝은 낮, 석재+하늘색, 칠판 게시판. 합본 1920/3840, 레이어 4장, 게임용 2장 (`art_source/lobby_bg/`). 칠판에는 글자가 없고 의뢰서는 코드가 그립니다.

**리나 눈 깜빡임 (주말 작업)**
- 표정 6종 × 3칸(open·half·closed) = 18장 (`art_source/receptionist_blink/`, 1684×2528). 눈 영역 밖 픽셀은 원본과 동일. 웃음은 이미 감긴 눈이라 3칸 동일. 방법은 `tools/lina_blink/README.md`.
- 머리카락 4부위 분해(앞머리·오른쪽 옆머리·왼쪽 긴머리·나머지)와 대머리 6종 확정. 상반신 초상 파츠 분리 모션 계획은 `docs/plan/receptionist_parts_plan.md` (측정 완료, 제작 전). Live2D(Cubism 5.3 무료판) 제약 메모는 `작업규칙.md` 7항.
- 게임에는 아직 연결하지 않았습니다.

## 5. 현재 코드 상태

- 접수원: `prototype/js/lina.js`(X=960, FEET=470, H=250, MOTION_SPEED=1.5), 시트 규격은 `prototype/js/manifest.js`의 `RECEP`(셀 128, 12열 6행, 24fps). 시트 셀 크기는 이미지 높이에서 계산하므로 128/256/512 어느 쪽이든 동작합니다.
- 말풍선·대사: `speech.js`가 `GAME_DATA.speech`를 읽고, `UI.lines(id, vars)`가 대사 데이터를 가져옵니다. 대사의 `{변수}`는 허용 목록만 가능합니다.
- 데이터 우선순위: `baseDefaults()` 위에 `GAME_DATA.balance`를 덮습니다. 키·배열 길이는 `balance_schema.json`이 고정합니다.
- **실제 게임의 대사창은 아직 옛 디자인**입니다(우드 대사창은 시안·도구 단계).
