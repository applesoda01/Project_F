## 1. 프로젝트 한 줄 요약

게임 제목(가칭): **이세계 모험가 길드**

플레이어는 직접 싸우지 않는 **길드 마스터**(전직 B급 모험가)로서, 게시판·시설·마을을 키워 마왕을 무찌르는 모험가 파티가 나오게 만드는 **실시간 경영 시뮬레이션 + 육성** 게임입니다. 첫 엔딩까지 10~15시간(게임 내 약 15년).

## 3. 작업 방식 (가장 중요)

사용자(윤석, DRIMAGE 게임 기획자)와 합의한 방식입니다. 반드시 지켜 주세요.

1. **사용자의 아이디어가 기준입니다.** Claude가 먼저 설계를 짜서 밀어붙이지 않습니다. (초반에 그렇게 했다가 "스톱" 요청을 받았습니다.)
2. **피드백 모드:** 사용자가 아이디어를 주면 → 결론(동의/보완) → 근거 2~3개 → 보완점 → **질문은 한 번에 하나**, 선택지 표(A/B/C)와 추천안을 함께 제시합니다.
3. **아이디어는 두서없이 와도 됩니다.** 맥락을 이어서 이해하고, 미뤄 둔 질문은 나중에 다시 꺼냅니다.
4. **문서는 요청할 때만 만듭니다/반영합니다.** 결정이 충분히 쌓이면 "문서에 반영할까요?"라고 한 줄로 제안만 합니다.
5. **응답 스타일:** 격식체, 결론 먼저, 숫자·데이터 포함, 실행 가능한 제안 중심. 길어지면 요약 먼저.
6. **수치 표기:** 방향은 확정이고 수치는 검증 전이면 `[가안]`을 붙입니다. 수치는 나중에 **설정값을 바꿀 수 있는 시뮬레이터**로 검증하기로 했습니다 (사용자가 요청할 때만 제작).
7. **사용자가 거절한 방향은 다시 제안하지 않습니다.** 예: 화약(총사, 마탄), 전장 시인·기수·심판관, 취향 선물, 금전으로 성 강화, 힐러의 사망률 감소, 전투 결과 등급(대승/신승), 옛 동료가 간부로 귀환, 다회차 난이도 상승, 마스터의 이름.

## 4. 이번 세션에서 확정된 내용 (요약)

자세한 내용은 md의 **6.0 퀘스트 카테고리**, **12.1~12.2**, **12-1 스토리 뼈대(12-1.5 멀티엔딩, 12-1.6 메인 퀘스트, 12-1.7 접수원, 12-1.8 서브 스토리)**에 있습니다.

- **퀘스트 4분류:** 메인(서사) / 서브(마을 사람·모험가·히든) / 승급(길드 성장) / 리소스(금전·소재). 등급이 메인을 열지만 메인 없이도 승급할 수 있음. 히든은 소문 → 근접 → 발견.
- **마스터:** 전직 B급. 이 마을에서 옛 파티 전원이 사망했고, 기절했던 마스터만 동료들의 희생으로 생존. 원인은 미스터리로 시작해 마왕군 간부의 소행으로 밝혀짐. 진실은 메인 퀘스트로 등급별로 공개.
- **세계관:** 길드 연합(등급·승급) + 왕국(보조금). 마왕은 여러 부위로 나뉘어 봉인되었고, 이 마을이 마지막 남은 봉인. 영주의 성이 봉인의 핵이고, 인구가 봉인의 힘.
- **영주:** 봉인 수호 가문. 경계 → 동반자. 마을 단계를 따르되 서브 퀘스트로 앞당길 수 있음.
- **엔딩:** 마왕이 봉인을 덜 푼 채 무리하게 현신했다가 패배. 마왕 전투력은 마을 단계로 결정(100 / 85 / 70%).
- **간부:** 필수 3명(마지막이 원수) + 선택 1명(히든, 보상은 옛 용사의 방패). 방패는 첫 주인이 전위 역할 모험가이고, 이후 길드 소유로 마스터가 대여.
- **전투 결과:** 모든 전투는 승리/패배만 있음.
- **멀티엔딩 (플래그 누적형):** 1 토벌(메인, 프로토타입 목표. 마왕=마력의 근원이라 마력이 사라지고 혼란 속 새 시대) / 2 재봉인 / 3 계승(지친 마왕). 분기점 4곳.
- **메인 퀘스트:** F1·E1·D2·C2·B3·A3·S4 = 16개 초안 확정. 마스터가 직접 지명(애착 × 성향 수락 확률, 거절 이유 표시). 큰 이벤트는 탑뷰, 탐색형은 일러스트 + 모험가 1인칭 일지.
- **접수원:** 옛 파티 도적(오빠)의 여동생. 진상을 알고 싶어 지원했고 마스터와 서로 모른 채 시작. C급에서 정체 공개, B급에서 오빠의 일지 획득.
- **서브 스토리:** 핵심 건물 11종, 총 20개(기본 9 × 2 + 대성당·마탑 후속 각 1). 의뢰인 초안 확정.
- **이름 [가안]:** 마스터는 이름 없음(옛 궁수, 별명 "매의 눈"). 접수원 리나, 오빠 카일. 옛 파티 브람·셀린·토마스·카일. 영주 오스윈 하트웰. 원수 간부 모르바스, 마왕 녹투스 등 (md 12-1.9).
- **플랫폼:** 스팀(PC) 확정. 제목은 가칭 「이세계 모험가 길드」.
- **메인 세부:** 파티 최대 5인, 지명 인원(탐색형 F~C 1~3명·혼자 가능 / B~A 2~3명 / 큰 이벤트 3~5명), 실패 처리(대기 1·2개월, 부분 진행 +10%p), 보상(×2/×3, 고유 보상 7종), 일지 변형 66줄.
- **전생자:** 15년차에 마왕 미토벌이면 등장하는 구제용 합류 모험가(md 12-1.11). 이름 한도윤, 현대 지구 출신, 크런치로 쓰러진 게임 기획자(이스터에그), 신중·낭비·독불장군.
- **승급 세부:** N = 2/3/3/4/4/5(합계 21), N+2개 동시 공개, A→S는 S급 후보(A급·Lv45) 2명. S급 도달 시 명예의 전당 등재.
- **콘텐츠 목록 초안 완료:** 스킬 82, 장비 91, 소재 35 + 복원 재료, 시설 효과 44 (md 12-2, 별도 파일 4개). 마인 세부 확정(잠식도 → 엔딩 3 플래그, 2세가 없으면 8년차 말 이후 무너진 봉인 마을 출신 2세 자동 등장).
- **경제 수치 [가안]:** F급 의뢰 보상 100G 기준, 등급당 약 2배. 보조금 300~4,500/월, 건설비 2,000~30,000, 무기 150~30,000, 시작 자금 3,000 (md 5.5). 시뮬레이터로 조정.
- **요리·시작 모험가:** 시작 모험가 5명. 주점·식당에서 출발 전 식사 판매, 요리 14종을 식재료로 영구 해금(재료 소모 없음), 가격은 요리 등급 보상의 15%, 마진 60% (md 12-2.6). 주점 효과 3은 요리 효과 +50%.
- **프로토타입 = 스팀 데모:** 분리하지 않음. 본편 수치 그대로 F~D급, 약 2~3시간. 종료 지점은 D급 메인 「약초꾼의 기억」 + 첫 2차 전직. 개발 순서 M0~M6, 관문 3개.
- **개발 방식:** 프로토타입은 HTML, 본 개발은 유니티. 규칙(game_core.js)·데이터(JSON)·화면을 분리해 규칙은 C#으로 1:1 이식. 1차(M0~M1) 완료, 다음은 2차(M2~M3: 길드 단면도, 걸어 다니는 모험가, 육성·전직·장비).
- **다회차:** 데려올 영웅 수 = 본 엔딩 수(최대 3). 능력치·스킬 유지. 다회차는 더 쉽게 하는 것이 목적(난이도 상승 없음).
