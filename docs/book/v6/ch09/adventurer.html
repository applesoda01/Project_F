V2 추가·수정 규칙 — 제안·미반영

파티 전체가 아니라, 각자의 배분 기준액에 소속별 수수료를 적용합니다.

외부 일반 의뢰 — ECON-01 / 제안·미반영

순서규칙
① 기준액총 보상 R을 n명에게 균등 배분
② 길드 몫자유: 일반 수수료 / 계약 모험가: 계약 최종 수수료
③ 실수령개인 기준액 − 개인 길드 몫
④ 총액길드 몫 합 + 개인 실수령 합 = R
⑤ 잔액기준액 = ⌊R ÷ n⌋, 나머지는 대장부터 파티 순서로 1G씩. 개인 길드 몫 = ⌊기준액 × 수수료⌋(버림). 예: 101G · 3명 · 10% → 실수령 31 · 31 · 30G + 길드 9G = 101G [결정 2026-11-17]
⑥ 조건출발 때 참가자·수수료·계약을 저장. 귀환 시 변경 금지

계약 수수료는 일반 수수료를 포함합니다. 일반 10% 뒤 계약 20%(F급 기본, 결정 2026-11-17)를 다시 떼지 않습니다.

직접 기여 증가 = (계약 비율 − 일반 비율) × 월 개인 기준액 − 보수 − 실제 지원
