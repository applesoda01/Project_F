지명 퀘스트

지명은 마스터가 모험가를 직접 골라 보내는, 기존 자유 모험가에게 적용하는 "직접 지시"입니다. 리퀘스트와 메인 퀘스트가 이 틀을 씁니다.

flowchart LR
  A[리퀘스트 접수] --> B[지명: 1~5명 고르기<br/>섭외비 지불]
  B --> C{모험가 수락?}
  C -->|거절| B
  C -->|수락| D[수행 1~3주<br/>전투/판정]
  D --> E[보고 카드<br/>보상 · 애착 +3]
항목규칙
조건퀘스트마다 최소 능력치. 파티 중 1명만 채우면 됨
수락 확률전직과 같은 규칙: 애착 단계(40 / 65 / 90 / 100%) × 위험 보정, 정수 %로 표시
거절당하면다음 주에 바로 다시 지명 가능. 성향 말풍선 한 줄
섭외비모험가 등급별 F 20G · E 40G · D 80G · C 150G · B 250G · A 400G · S 600G. 거절당해도 나감
보상기존 보상·개인 몫 유지. 일반 외부 보상은 개인별 수수료, 길드 발주는 명시한 별도 지급 조건 [제안]
대열항상 자동(직업 순)
성공참가자 애착 +3
  • 지명 중인 모험가는 그 기간 게시판 의뢰를 받지 않습니다.
  • 섭외비는 연 약 1,400G(첫해 월 평균 62G)로, 처음 어림(550G)보다 컸지만 금액은 그대로 두기로 했습니다(2026-11-16).
