# 들어가며

**이 책은 Project_F(가칭 「이세계 모험가 길드」)를 처음 보는 사람이 한 시간 안에 게임의 뼈대를 파악하도록 만든 안내서입니다.**

플레이어는 길드 마스터가 되어 모험가를 직접 조작하지 않고, 의뢰 배분·시설 투자·지명 결정으로 길드를 키웁니다. 지금은 브라우저에서 바로 열리는 웹 프로토타입으로 첫해(48주)를 끝까지 플레이할 수 있습니다.

| 항목 | 값 |
| --- | --- |
| 장르 | 실시간 경영 시뮬레이션 + 육성 |
| 플랫폼 | 스팀(PC) 확정, 지금은 웹 프로토타입 |
| 프로토타입 범위 | F급 시작 → E급 승급, 게임 안 약 1년 |
| 첫해 월 운영 순이익 | 573G (게임 규칙 100판 평균) |
| 의뢰 성공률 | 94.9% (같은 측정) |
| 기준일 | 2026-11-16 |

## 누구를 위한 책인가

- **새로 합류한 기획자:** 1~2장 → 관심 있는 시스템 장 → 부록 C(결정 대기) 순서로 읽으시면 됩니다.
- **경제 구조 검토자:** 1장 → 2장 → 9장(경제)을 먼저 읽으시고, 9장에서 걸리는 시스템만 3~8장에서 찾아보시면 됩니다.
- **시연을 보는 동료:** 1장만 읽으셔도 충분합니다.

## 이 책과 원본 기획서의 관계

이 책은 **읽기용 요약본**입니다. 결정 이력, 출처 차이, 측정 근거까지 담은 원본은 저장소의 `docs/design/v2/`(문서 12개)에 있습니다. 숫자가 서로 다르면 원본과 `prototype/data/balance.csv`가 기준입니다. 원본 위치는 [부록 D](appendix/sources.md)에 정리했습니다.

> **경제 구조는 다시 짤 예정입니다.** 9장의 수치와 구조는 현재 프로토타입 기준이며, 시니어 기획자 검토 뒤 바뀝니다.
