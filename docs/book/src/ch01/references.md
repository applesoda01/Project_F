## 던전 마을과 다른 점

- **플레이어가 직접 지시할 수 있는 곳이 지명 하나뿐입니다.** 나머지는 배분 · 투자 · 승인으로만 움직입니다.
- **모험가가 죽고 2세가 이어받습니다.** 한 세대가 아니라 15년에 걸친 길드의 역사가 쌓입니다.
- **길드 등급이 이야기(마왕의 봉인)와 묶여 있습니다.** 마을 인구가 곧 봉인의 힘입니다.

## 분위기 참고

- 길드 로비는 "코노스바풍 밝은 낮" 분위기로 정했습니다(레퍼런스 비교 후 결정).
- 비주얼은 HD-2D 분위기의 배경 + SD 캐릭터입니다([10장](../ch10/README.md)).
