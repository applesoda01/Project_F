# 메인 퀘스트

**메인 퀘스트는 길드 등급마다 있고, 깨면 다음 등급으로 승급합니다.** 프로토타입에는 F급 메인 「다리를 지켜라」(침공) 하나가 있습니다.

| 등급 | 메인 수 [가안] |
| --- | --- |
| F | 1 |
| E | 1 |
| D · C | 각 2 |
| B · A | 각 3 |
| S | 4 |

## F급 메인 「다리를 지켜라」

| 항목 | 내용 |
| --- | --- |
| 등장 | 리퀘스트 8번 해결 → "영주의 전갈" → 리퀘스트 장 맨 위 붉은 카드 (마감 없음) |
| 받기 | 플레이어가 누름 → 2주 뒤 침공 |
| 준비 | 침공 1주 전부터 모든 의뢰 출발 금지 |
| 참가 | 지명 없이 살아 있는 모험가 전원 (의뢰 중 · 부상 중 제외) |
| 승리 | E급 승급 · 모험가 관리소 해금 · 1,000G · 명성 +10 |
| 패배 | 인구 −10% · 신뢰도 −5 · 4주 뒤 재도전 |
| 측정 (100판) | 등장 중앙 31주, 승급 중앙 39주 |

- 메인 퀘스트는 거절할 수 없고 보류만 됩니다.
- **"언제 받을지"가 첫 번째 결정**입니다. 받자마자 도전하면 절반쯤 지고, 몇 주 더 키우면 이길 확률이 오릅니다. 전투 규칙은 [5장 침공](../ch05/invasion.md)에 있습니다.
- 메인 퀘스트마다 옛 파티 전멸의 진실이 조금씩 드러납니다([11장](../ch11/README.md)).
