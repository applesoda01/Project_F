# 시간: 주 · 달 · 해

**1주는 현실 약 30초, 1년(48주)은 약 24분입니다(1배속).** 일시정지와 2배속 · 4배속이 있습니다.

| 단위 | 게임 안 | 현실 (1배속) |
| --- | --- | --- |
| 주 | 기본 단위 | 약 30초 |
| 달 | 4주 | 약 2분 |
| 해 | 12달 = 48주 | 약 24분 |

| 화면 | 시간 |
| --- | --- |
| 길드(로비) | 흐름 |
| 마을 | 멈춤 (침공 중에는 흐름) |
| 길드 업무 일지(책) | 멈춤 (HUD도 숨김) |

## 계절과 시간대

- 게임은 **3월(봄)** 에 시작합니다. 봄 · 여름 · 가을 · 겨울이 각 3달입니다.
- 한 달의 4주는 아침 · 낮 · 노을 · 저녁 배경에 대응합니다.
- 계절에 따라 길드 바깥 풍경과 마을 배경음악이 바뀌고, 계절 한정 리퀘스트가 나옵니다.
