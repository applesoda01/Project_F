# 모험가의 지갑

**모험가는 의뢰 보상의 90%를 받아 장비 · 물약 · 식사에 씁니다. 그런데 첫해 평균 지갑은 약 230G로, F급 장비 세트(450G)를 사기 어렵습니다.**

| 들어오는 돈 | 나가는 돈 |
| --- | --- |
| 의뢰 보상 − 중계료 (파티 인원으로 나눔) | 장비 (마을 상점) |
| 지명 퀘스트 보수 몫 | 물약 (출발 때) |
| | 식사 · 술 (길드) |

## 소비 성향이 정하는 것

| 성향 | 절약 | 보통 | 낭비 |
| --- | --- | --- | --- |
| 식당 이용 확률 | 30% | 60% | 90% |
| 물약 최대 | 1 | 2 | 3 |
| 장비 사기 전 남겨 두는 돈 | 장비값 × 2 | × 1 | × 0.3 |

## F급 모험가 한 명의 계산 (어림)

| 항목 | 값 |
| --- | --- |
| F급 의뢰 1건 (솔로) | 90G |
| 출발 때 식사 (F) | 25G |
| 출발 때 물약 (F, 보통 2개) | 40G |
| 남는 돈 | 약 25G |
| F급 장비 세트 (무기 150 × 3) | 450G |

이 계산이 첫해 F급 장비 보유율 10~20%의 원인입니다. 식사 · 물약 값이 한 번 나갈 때마다 의뢰 보상의 대부분을 가져갑니다.

> 위 표는 규칙 값으로 계산한 어림입니다. 파티로 가면 보상이 나뉘고, 모든 출발에서 식사 · 물약을 사지는 않습니다.
