# 합류 · 파티 · 사망과 계승

**모험가는 명성 10마다 1명씩 오고, 스스로 파티를 짜며, 죽으면 6개월 뒤 2세가 옵니다.** 길드 등급이 모험가 수의 상한을 정합니다.

## 합류와 상한

| 항목 | 값 |
| --- | --- |
| 시작 | 2명. 창립 멤버로 늘 길드에 있음 |
| 합류 | 명성 10 · 20 · 30 … 마다 1명 (확률 없음) |
| 길드 등급별 상한 | F 8 · E 12 · D 16 · C 20 · B 24 · A 28 · S 32 |

## 파티

| 항목 | 내용 |
| --- | --- |
| 결성 | 모험가가 스스로. 예상 성공률이 모자라면 주점에서 동료를 모음(최대 2주) |
| 최대 인원 | 5명 [가안] |
| 보상 분배 | 중계료를 뺀 보상을 인원수로 나눔 |
| 친밀도 0~49 | 임시 파티 (의뢰 뒤 해산) |
| 친밀도 50~99 | 단골 동료 |
| 친밀도 100 | 고정 파티 (이름이 생기고 함께 방문). 엔딩의 마왕 토벌 후보 |

## 사망과 계승

- 의뢰 실패나 전투 뒤 판정으로 사망할 수 있습니다. 실패 시 기본 사망 확률은 F · E급 1%, D · C급 3%, B · A급 5%, S급 8%이고, 성향으로 ×0.5~×1.5 됩니다.
- 사망 6개월(24주) 뒤 **"○○ 2세"** 가 Lv 1 · F급으로 옵니다. 부모의 1차 계열을 70% 확률로 잇고, 유품과 스킬 1개를 물려받습니다.
- 2세는 첫 1년 동안 애착과 관계없이 자주 방문합니다.
