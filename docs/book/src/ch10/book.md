# 길드 업무 일지(책 UI)

**모든 운영 팝업은 펼친 책 한 권에 담겨 있고, 왼쪽 책갈피 7장으로 넘깁니다(2026-11-13).**

| 책갈피 | 내용 |
| --- | --- |
| 의뢰 | 게시판, 등급별 의뢰 배분(막대 3개), 의뢰 카드 · 해골 위험도 |
| 리퀘스트 | 부탁 목록, 지명 창, 메인 퀘스트 카드, 아직 안 나온 부탁 힌트 |
| 모험가 | 명부(등급 배지 · 상태), 능력치 막대, 장비 · 물약 · 소지금, 전직 제안 |
| 시설 | 시설 카드(짓기 · 업그레이드), 장식 · 테이블 배치 |
| 음식 | 메뉴판(발견한 요리), 소재 보관함, 조리대 |
| 경영 | 장부(달별 수입 · 지출 · 그래프), 소재 판매, 도감, 길드 기록 |
| 설정 | 소리 · 화면 · 저장 |

- 공통 부품은 등급 배지 · 10칸 막대 · 아이콘 칸 · 마우스 오버 창입니다.
- 보이는 수치는 모두 정수입니다. 확률은 숫자 대신 문장으로 보여 주는 경우가 많습니다(예: 성향 "늘 신중하게 의뢰를 고릅니다").
