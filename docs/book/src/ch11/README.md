# 세계관과 이야기

**마왕의 마지막 봉인이 남은 마을에서, 옛 파티를 잃은 전직 모험가가 길드를 세웁니다.** 마을 사람들의 삶(인구)이 곧 봉인의 힘이라, 길드가 마을을 키우는 일이 이야기와 맞물립니다.

| 항목 | 내용 |
| --- | --- |
| 주인공 | 이름 없는 길드 마스터. 전직 B급 궁수. 옛 파티가 이 마을에서 전멸한 뒤 길드를 세움 |
| 세계 | 옛 용사 파티가 마왕을 여러 조각으로 나눠 여러 마을에 봉인. 15년 동안 다른 봉인이 깨지고 이 마을이 마지막 |
| 봉인의 힘 | 영주의 성이 봉인의 핵, 마을 인구가 봉인의 힘. 마왕군은 인구를 줄이려 침공함 |
| 접수원 리나 | 옛 파티 도적 카일의 여동생. C · B급 메인에서 정체와 오빠의 일지가 드러남 |
| 진실 | 옛 파티는 봉인이 약해지는 흔적을 알리려다 마왕군 간부에게 제거됨. 메인 퀘스트로 조금씩 공개 |
| 엔딩 | S급에서 전조 → 간부 3명(+선택 1명) → 고정 파티가 마왕 토벌. 실패하면 2세가 재도전 |
| 멀티엔딩 | 분기점 4곳의 선택으로 토벌 · 재봉인 · 계승 엔딩. 프로토타입 목표는 토벌 |
| 서브 스토리 | 마을 핵심 건물 11종에 의뢰인 이야기 20개 |

**경제와 닿는 곳:** 침공 패배의 "인구 −10%"는 이야기상 봉인이 약해지는 것이고, 게임상 의뢰 유입이 줄어드는 것입니다.
