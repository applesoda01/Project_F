# 마을과 인구

**마을 인구는 의뢰 유입량을 최대 2.5배까지 늘리는, 길드 밖의 성장 수치입니다.** 마을 화면은 로비와 별도의 탑뷰 화면이고, 들어가 있는 동안 시간이 멈춥니다(침공 제외).

## 인구가 느는 길

| 요인 | 증가 |
| --- | --- |
| 매달 기본 | +2 |
| 의뢰 성공 1건 | F +1 · E +2 · D +3 … S +8 |
| 정착 모험가(애착 65 이상) 1명 | 매달 +2 |
| 침공 패배 | −10% |

인구는 민가 수용 인원을 넘지 못합니다. 시작 인구는 150명입니다.

## 마을 단계

| 단계 | 인구 | 의뢰 유입 |
| --- | --- | --- |
| 개척촌 | ~299 | ×1.0 |
| 마을 | 300 | ×1.3 |
| 읍 | 1,000 | ×1.6 |
| 도시 | 2,000 | ×2.0 |
| 성채 도시 | 3,500 | ×2.5 |

## 민가

- 인구가 수용을 넘으면 초가(레벨 1)가 생기고, 매달 오래된 집부터 2채가 레벨업합니다.
- 1칸 수용: 초가 40 · 목조 45 · 회반죽 50 · 회반죽 2층 60 · 석조 75명.
- 집의 최고 레벨은 마을 단계가 정합니다.

## 마을 건물

핵심 건물 11종(퀘스트로 생김)과 일반 건물(인구 단계로 생김)이 있습니다. 전직 조건, 스킬 구매처, 마을 효과를 겸합니다. 프로토타입에서는 대장간 · 물약 상점이 리퀘스트로 생기며, F · E급 건물 효과는 아직 정하지 않았습니다.
