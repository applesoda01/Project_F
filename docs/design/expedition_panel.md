# 원정 현황 패널 (길드 화면 우측) 기획서 초안

> **요약:** 길드 화면 오른쪽 가장자리에 **원정 중인 모험가 목록**을 항상 띄웁니다. 평소에는 **반투명(불투명도 50%)** 으로 두어 길드 장면을 가리지 않고, **마우스를 올리면 100%** 로 선명해집니다. 한 줄에는 이름·등급·의뢰명·진행 바·위험도를 보여 주고, 귀환하면 목록에서 사라집니다. 코드 이름은 `hudExp`를 제안합니다.

## 0. 확정·가정

| 구분 | 내용 | 근거 |
| --- | --- | --- |
| 확정 | 패널은 우측에 **항상 표시**, 평소 반투명, 마우스를 올리면 선명 | 사용자 지시 |
| 가정 | 한 줄 정보 = 이름·등급·의뢰·**진행 바·위험도** | 질문 답변 "2번"을 모든 항목에 적용해 해석 |
| 가정 | 목록 = **현재 원정 중인 모험가만**(귀환하면 삭제), 이벤트 로그 없음 | 같은 해석 |
| 가정 | 이번 산출물 = **기획서만**(목업·구현 없음) | 같은 해석 |

가정이 다르면 알려 주십시오. 3·4·5장만 바꾸면 되도록 구조를 나눴습니다.

## 1. 목적과 위치

1. 길드 화면은 시간이 흐르고(기획서 2장), 모험가는 스스로 의뢰를 골라 길드 밖으로 나갑니다. 지금은 "누가 어디서 무엇을 하는지"를 볼 곳이 없습니다.
2. 기획서 6.4의 "마을에서 활동 중인 모험가 패널"과 **같은 계열**이지만, 이 패널은 **원정 중**인 모험가에 한정합니다. 6.4는 전체 모험가 필터형 목록이므로 역할이 겹치지 않게 별도 화면으로 둡니다.
3. 마스터가 확인할 질문은 세 가지입니다. 누가 나가 있는가, 언제 돌아오는가, 위험한가.

## 2. 화면 배치 (1920×1080 기준)

| 항목 | 값 [가안] |
| --- | --- |
| 위치 | 오른쪽 가장자리, 우측 여백 16px |
| 크기 | 폭 360px, 높이는 줄 수에 따라 늘어나며 최대 약 700px |
| 세로 범위 | 상단 y=96 ~ 하단 y=800 (상단 HUD 아래, 하단 HUD(`hudBR`) 위) |
| 겹침 | 오른쪽 위는 배속 바 이동 이후 비어 있고, 오른쪽 아래는 `hudBR`이 쓰므로 그 사이를 사용 |
| 레이어 | 길드 장면 위, 대사창(`dlg`)·팝업(`pop`) 아래 |

- 실제 프로토타입의 `hudTL`·`hudBR` 크기와 맞는지는 구현 전에 확인합니다.
- 반투명이어도 패널은 클릭을 받습니다. 뒤에 있는 길드 장면의 클릭 대상(모험가·시설)이 패널 영역과 겹치지 않도록 길드 화면 우측 여백을 확보해야 합니다.

## 3. 패널 구조

```
┌ 원정 중 (5)                        ┐   ← 머리줄: 제목 + 인원수
│ [D] 리나  고블린 소굴 토벌          │
│     ▓▓▓▓▓░░░░░  3주 남음   ▲ 위험  │
│ [E] 카일  약초 채집 (2인)           │
│     ▓▓▓░░░░░░░  1주 남음   ● 안전  │
│ ...                                │
└─────────────────────────────────────┘
```

- 머리줄은 `원정 중 (N)` 입니다. 인원이 0이면 패널 전체를 숨깁니다.
- 목록은 한 줄 높이 약 64px(2행 구성)이고, 화면에는 최대 8줄을 보여 준 뒤 스크롤합니다. 모험가 최대 99명 기준이지만 한 번에 원정 중인 수는 대부분 이보다 훨씬 적습니다.

## 4. 한 줄에 들어가는 정보

| 칸 | 내용 | 표시 규칙 |
| --- | --- | --- |
| 등급 배지 | 모험가 등급 F~S | 기존 등급 배지 에셋을 축소 사용 |
| 이름 | 모험가 이름 | 파티면 대표(파티장) 이름 + "외 N" |
| 의뢰명 | 수주한 의뢰 이름 | 긴 이름은 말줄임 |
| 진행 바 | 경과 기간 ÷ 전체 소요 기간 | 주 단위로 마디를 표시 |
| 남은 기간 | "N주 남음", 마지막 주는 "곧 귀환" | 월 = 4주 기준 |
| 위험도 | 안전 / 주의 / 위험 3단계 | 아이콘 + 글자 + 색을 함께 사용(색만으로 구분하지 않음) |

**위험도 산정 [가안]:** 기획서 6.6의 성공률을 그대로 사용합니다. 성공률 70% 이상 = 안전, 40~69% = 주의, 40% 미만 = 위험. 시뮬레이터에서 분포를 보고 구간을 조정합니다.

**파티 처리:** 같은 의뢰의 파티는 **한 줄로 묶고**, 구성원 수를 이름 옆에 표시합니다. 선택(클릭) 시 구성원이 펼쳐집니다.

## 5. 반투명과 호버 동작

| 상태 | 불투명도 | 전환 |
| --- | --- | --- |
| 평소 | 50% [조절기로 확정] | - |
| 마우스 진입 | 100% | 0.15초 |
| 마우스 이탈 | 50% | 0.3초 지연 후 0.3초 |
| 새 항목 발생·귀환 임박 | 해당 줄만 1초 강조 후 원래 투명도 | 호버 없이도 알림 |

- 반투명일 때도 글자는 읽혀야 하므로, **줄 배경은 어두운 나무 질감으로 채우고 전체를 반투명 처리**합니다(글자만 투명하게 하지 않습니다).
- 50%라는 값은 `dialog_tuner`와 같은 방식의 조절기로 정합니다. 대사창 시안(55/70/85/100)이 참고가 됩니다.

## 6. 목록 규칙

| 항목 | 내용 |
| --- | --- |
| 포함 | 의뢰를 수주해 길드 밖으로 나가 있는 모험가 |
| 제외 | 길드 안에 있거나 마을에 있는 모험가, 부상으로 쉬는 모험가 |
| 추가 시점 | 모험가가 출발하는 순간 맨 아래에 추가 |
| 삭제 시점 | 귀환해 접수대에 도착하면 해당 줄이 사라짐 (1초 강조 후) |
| 정렬 | 기본 = 남은 기간이 짧은 순. 위험도 "위험"이 있으면 그 줄을 위로 올리지 않음(순서가 흔들리지 않게) |
| 갱신 | 매주(주 단위 틱) 진행 바와 남은 기간 갱신 |

## 7. 상호작용

1. 줄에 마우스를 올리면 툴팁으로 의뢰 등급, 예상 성공률, 파티 구성을 보여 줍니다.
2. 줄을 클릭하면 모험가 상세 팝업을 엽니다(기존 `pop` 공통 틀 사용).
3. 패널에서 의뢰를 취소·소환하는 조작은 두지 않습니다. 모험가는 스스로 판단한다는 원칙(기획서 7.1)을 지키기 위해 **보기 전용**입니다.

## 8. 데이터

| 필드 | 설명 |
| --- | --- |
| `adventurer_ids` | 파티 구성원 |
| `quest_id`, `quest_name`, `quest_grade` | 의뢰 정보 |
| `start_week`, `duration_weeks` | 진행도 계산 |
| `success_rate` | 위험도 계산(출발 시점 값을 사용) |
| `leader_id` | 파티장(표시용 이름) |

- 의뢰 소요 기간의 실제 값(주 단위)은 기획서에 확정된 표가 없어 **[가안: 1~4주]** 로 가정했습니다. 정보꾼의 "지름길" 효과가 소요 기간을 줄이므로 남은 기간은 출발 시점에 고정하지 않고 매 틱 재계산합니다.

## 9. 미결·확인할 것

1. 의뢰별 소요 기간 표(주 단위)와 위험도 구간 기준.
2. 길드 화면 우측 영역에 이미 있는 클릭 대상이 있는지(겹침 확인).
3. 마을 화면에서도 이 패널을 보일지. 마을은 시간이 정지하므로 표시만 하고 갱신하지 않는 방안을 권합니다.
4. 6.4 "마을에서 활동 중인 모험가 패널"과 통합할지 여부. 이름 충돌을 피하려면 6.4를 "모험가 목록"으로 이름을 바꾸는 것을 권합니다.
5. 아이콘·나무 질감 패널의 아트는 기존 HUD 명패 ③ 스타일을 재사용합니다.
