## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 실시간 경영 시뮬레이션 + 육성 요소 |
| 플레이어 | 길드 마스터. 직접 싸우지 않고, 환경과 방침을 정해 간접적으로 운영 |
| 길드 | 플레이어가 시뮬레이션을 하는 공간 |
| 최종 목표 | 마왕을 무찌르는 모험가 파티가 등장하는 것 |
| 비주얼 | 일러스트풍 |
| 플레이 타임 | 첫 엔딩 10~15시간, 부가 요소 포함 25~40시간 |
| 게임 내 기간 | 첫 엔딩까지 약 15년 [가안] |
| 세계관 규칙 | 화약이 없는 세계. 무기는 검, 창, 활, 지팡이, 맨손 등 |

**설계 원칙**

- 육성은 경영의 일부입니다. 플레이어는 모험가를 직접 조작하지 않고, 투자와 방침으로 성장 환경을 만듭니다.
- 모험가는 스스로 판단합니다. 의뢰 선택, 장비 구매, 훈련 종목, 파티 결성은 모험가가 결정합니다.

## 3. 등장 인물과 용어

| 용어 | 정의 |
| --- | --- |
| 길드 마스터 | 플레이어 |
| 접수원 | 게시판 앞에서 모험가를 응대함. 한 명으로 고정된 비서 같은 캐릭터. 능력치는 없고, 연출과 정보 전달을 맡음 |
| 모험가 | 게시판에서 퀘스트를 수주하고 진행한 뒤 복귀하는 사람들 |

| 길드 | 플레이어가 운영하는 시뮬레이션 공간 |

| 의뢰서 | 게시판에 붙는 쪽지 한 장 |
| 길드 등급 | 길드의 공식 등급 F~S. 길드에는 '레벨' 없이 등급만 존재 |

## 5. 경제

### 5.1 길드 수입

| 수입원 | 내용 |
| --- | --- |
| 왕국 보조금 | 길드 등급에 따라 매달 지급 |
| 의뢰 중계료 | 의뢰 보상에서 일정 비율을 차감 |
| 시설 매출 | 식당, 소재 판매 |

### 5.2 중계료율

- 기본 중계료율은 모든 의뢰에 같습니다.
- **정보실**(가칭)의 효과(지도, 정보망 등)를 소재로 열수록 중계료율이 올라갑니다. 시설 레벨은 없습니다.

| 정보실 효과 개방 수 | 중계료율 [가안] |
| --- | --- |
| 없음 | 10% |
| 1 | 12% |
| 2 | 14% |
| 3 | 16% |
| 4 | 18% |
| 5 | 20% |

### 5.3 모험가 경제

- 모험가는 개인별 **소지금**을 가집니다.
- 수입: 의뢰 보상에서 중계료를 뺀 금액(파티는 인원수로 분배), 소재 판매
- 지출: 장비(마을 상점), 소모 아이템(마을 물약 상점), 식당 등
- **장비 구매 주체는 모험가**입니다. 장비는 마을 상점에서 사므로 길드 수입이 아닙니다.
- 물약 같은 소모 아이템도 모험가가 소지금으로 사서 의뢰에 가져갑니다.

### 5.4 길드 금전 사용처

| 사용처 | 내용 |
| --- | --- |
| 시설 건설, 유지비 | 길드 등급으로 열린 칸에 건설. 시설 성장은 금전이 아닌 소재로 |
| 소재 매입 | 소재 판매 창구에서 모험가의 소재를 삼 |
| 선물 | 대장간(무기·방어구), 스킬 상점(마법 학원·투기장 등), 물약 상점(포션). 애착도 상승. 기호품 선물은 없음 |
| 강화, 주문 제작 | 대장간, 금전 + 소재 |
| 길드 발주 의뢰 | 원하는 소재와 수량을 정해 길드 금전으로 보상을 걸고 게시. 상위 소재일수록 보상이 커야 모험가가 집어 감 |
| 정보 구매 | 정보실이나 정보꾼에게 돈을 내고 직업·레시피·시설 효과의 소문을 삼. 상위 정보일수록 비쌈 |

### 5.5 경제 수치 [가안]

기준은 F급 리소스 퀘스트 보상 100G이고, 등급이 하나 오를 때마다 약 2배입니다. 모든 수치는 시뮬레이터로 조정합니다.

| 등급 | 의뢰 보상 (의뢰인 지급) | 중계료 10%일 때 길드 몫 | 왕국 보조금 (월) | 시설 건설비 | 무기 상점가 |
| --- | --- | --- | --- | --- | --- |
| F | 100 | 10 | 300 | (기본 제공) | 150 |
| E | 200 | 20 | 500 | 2,000 | 400 |
| D | 400 | 40 | 800 | 4,000 | 1,000 |
| C | 800 | 80 | 1,200 | 8,000 | 2,500 |
| B | 1,500 | 150 | 2,000 | 15,000 | 6,000 |
| A | 3,000 | 300 | 3,000 | 30,000 | 14,000 |
| S | 6,000 | 600 | 4,500 | — | 30,000 |

| 항목 | 가안 |
| --- | --- |
| 시작 자금 | 3,000 |
| 시작 모험가 | 5명 |
| 수입 구성 | 초반은 보조금 중심, 후반은 중계료(최대 20%)와 소재 판매 비중 증가. 주점·식당과 소재 판매 마진은 월 수입의 약 20~30% 목표 |
| 시설 유지비 (월) | 건설비의 1.5% |
| 시설 효과 개방 | 소재 + 금전 (효과 1·2·3 = 해당 등급 건설비의 10% / 20% / 35%) |
| 장비 가격 | 방어구는 무기의 ×1.2, 장신구 ×0.8 |
| 대장간 제작비 | 상점가의 30% + 소재 |
| 강화 | 1회에 상점가의 10% + 소재 |
| 건물 스킬 | 건물 등급 무기 상점가의 1.5배 |
| 방어전 보상금 (1인) | 같은 등급 의뢰 보상의 50~150% (애착·성향에 따라) |
| 정보 구매 | 100~2,000 |
| 마인 정화 | 잠식도 10당 같은 등급 의뢰 보상 × 1 |

흐름 확인 (F급 초반): 월 수입 약 530(중계료 약 80 + 보조금 300 + 식당·판매 약 150) − 유지비 약 100 = 순이익 약 430. 약 1년이면 E급 시설 2개를 지을 수 있음. F급 모험가는 의뢰 2~3건으로 F급 무기를 살 수 있음.

## 6. 의뢰와 게시판

퀘스트는 목적에 따라 메인, 서브, 승급, 리소스의 네 가지로 나뉩니다. 지금까지 정한 일상 의뢰 규칙(유입, 필터, 성공 판정)은 리소스 퀘스트의 규칙입니다.

### 6.0 퀘스트 카테고리

| 구분 | 메인 | 서브 | 승급 | 리소스 |
| --- | --- | --- | --- | --- |
| 목적 | 마스터의 서사, 마왕 | 마을 사람·모험가의 이야기, 히든 | 길드 성장 | 금전, 소재 |
| 등장 경로 | 의뢰인이 집무실 방문 | 집무실 방문 또는 마을 말풍선 | 등급 조건 충족 시 접수원 보고 | 게시판 자동 등록 |
| 거절 | 불가 (보류만) | 가능 (일정 기간 뒤 재등장) | 불가 (보류만) | 게시판 철회 규칙 적용 |
| 반복 | 1회 | 1회 | 1회 | 반복 |
| 실패 시 | 재도전 가능 | 재도전 가능 | 재도전 가능 | 소멸 |
| 보상 | 서사, 명성 | 서사, 건물·전직 개방 | 등급 상승 | 금전, 소재 |

- **메인과 승급의 관계:** 길드 등급에 도달하면 그 등급의 메인 퀘스트가 열립니다. 메인을 하지 않아도 승급할 수 있습니다. 열린 메인은 사라지지 않고, 접수원이 월간 보고에서 상기시킵니다.
- **서브의 세 갈래:** 마을 사람(핵심 건물 11종 등), 모험가(애착·친밀도, 성향 변화 계기), 히든(조건이 있어야 열림).
- **히든 서브:** 전직 탐색과 같이 소문 → 근접(조건 일부 공개) → 발견 순서로 드러납니다.

**기존 의뢰의 배치**

| 기존 항목 | 카테고리 |
| --- | --- |
| 일상 의뢰 (토벌·사냥·채집·조사·호위·탐사), 복원 재료 특별 의뢰 | 리소스 |
| 보스급 의뢰, 승급 침공 | 승급 |
| 간부 퀘스트, 마왕성 | 메인 |
| 핵심 건물 11종 의뢰 | 서브 (마을 사람) |
| 3차 확장 의뢰, 용사의 검, 현자의 지팡이, 마인, 대도서관, 선택 간부 | 서브 (히든) |
| 소규모 습격 | 퀘스트가 아닌 방어 이벤트 |

### 6.1 의뢰 유입

| 구분 | 유입 방식 | 플레이어의 판단 |
| --- | --- | --- |
| 리소스 퀘스트 (일상 의뢰) | 신뢰도와 마을 인구에 따라 유입되고, 필터를 통과한 것만 자동 게시 | 필터 설정 |
| 메인·서브 퀘스트 | 의뢰인이 길드 마스터 집무실에 직접 방문 | 메인은 보류만, 서브는 수락·거절 |
| 승급 퀘스트 | 등급 조건 충족 시 접수원이 보고 | 보류 또는 진행 |

**월간 의뢰 유입량** = 기본량 × 신뢰도 보정 × 인구 단계 보정 [가안]

### 6.2 필터 (등급별 칸 배분)

- 게시판 칸을 **절대 등급(F~S)별로 배분**합니다.
- 필터 설정이 곧 길드의 **육성 전략**입니다. 예를 들어 고등급 위주로 배분하면 정예 집중, 저등급 칸을 남기면 신인과 2세 육성이 됩니다.

### 6.3 게시판 규칙

| 항목 | 내용 |
| --- | --- |
| 용량 | 길드 등급에 따라 다름 |
| 의뢰 기간 | 없음 |
| 수주 | 모험가가 취향에 맞는 의뢰서를 스스로 골라 수주 |
| 의뢰서 떼기 | '하지 않겠다'는 의사로 간주. 신뢰도 하락 + 금전 손실(등록비 + 위약금) |
| 장비 보상 | 퀘스트를 통해 장비를 얻을 수도 있음 |

### 6.4 UI

- **마을에서 활동 중인 모험가 패널**: 전체 모험가 리스트에 필터를 거는 방식

### 6.5 의뢰 유형

| 의뢰 유형 | 대표 능력치 | 내용 예시 | 잘 맞는 직업 |
| --- | --- | --- | --- |
| 토벌 | 힘 | 몬스터 퇴치 | 전사 |
| 사냥·채집 | 민첩 | 약초 채취, 짐승 사냥 | 궁수 |
| 조사 | 지력 | 유적 해독, 마법 현상 조사 | 마법사 |
| 호위·구호 | 정신 | 상인 호위, 부상자 구조, 언데드 정화 | 성직자 |
| 탐사 | 기교 | 던전 탐색, 함정 해제, 잠입 | 도적 |

**성장 규칙**

| 구분 | 오르는 능력치 |
| --- | --- |
| 레벨업 | 직업별 고정 성장치만큼 상승 (7.4-1 참고) |
| 의뢰 (서브) | 의뢰 유형의 대표 능력치가 능력치 경험치로 소폭 상승 |
| 수치 | 시뮬레이터로 결정 |

의뢰 필터로 특정 유형을 많이 배치하면 서브 능력치가 쌓여 전직 경로를 유도할 수 있습니다. 예: 마법사에게 토벌을 많이 맡기면 힘이 쌓여 마검사에 가까워짐.

### 6.6 성공 판정 (능력치 프로필)

의뢰마다 요구 능력치를 비율로 가지고, 파티 능력치 합이 이를 얼마나 채우는지로 성공을 판정합니다.

| 의뢰 등급 | 요구 능력치 수 |
| --- | --- |
| F~E | 1개 (솔로로 충분) |
| D~C | 2개 |
| B~A | 3개 |
| S | 4개 |

- 의뢰 유형의 대표 능력치가 가장 큰 비중을 차지합니다.
- 능력치별 충족률을 비중대로 평균 내고, 능력치별 충족률은 최대 150%까지 인정합니다. [가안]
- 성공률 = 0.55 + 1.1 × (종합 충족률 − 1), 최소 5% ~ 최대 97% [가안]
- 병목: 요구 능력치 중 하나라도 충족률이 50% 미만이면 성공률 절반 [가안]

## 7. 모험가

### 7.1 행동 구조

방문 → 퀘스트 수주 → 정비 → 퀘스트 실행 → 달성/실패 → 방문 후 보상

### 7.2 직업 (총 48개)

전직은 능력치 조합으로 정해지며, 같은 조합은 출신 직업과 관계없이 같은 직업으로 수렴합니다. 레퍼런스는 창세기전3이고, 살릴 재미는 '경로를 짜는 계획'과 '최종직에 도달하는 성취감'입니다.

| 단계 | 수 | 규칙 |

| 1차 (기본) | 5 | 전사, 궁수, 마법사, 성직자, 도적. 모두 전직 가능 |

| 2차 | 15 | 능력치 2개 조합. 물리 특화 3개는 2차 종결, 신비 특화 2개는 3차로 이어짐 |
| 3차 심화 | 12 | 2차의 두 능력치를 높이 올린 정점 |
| 3차 확장 | 10 | 능력치 3개 조합 (수렴) |
| 전설 | 3 | 전설의 물건을 얻으면 각성. 한 시대에 한 명 |

| --- | --- | --- | --- | --- | --- |

- 전설 직업은 마왕 토벌의 필수 조건이 아닙니다.

**모험가 등급**

모험가 등급(F~S)은 길드가 인정하는 공식 자격이며, 레벨(경험의 양)과 실적(도전의 질)을 모두 채워야 오릅니다. 직업 단계와는 별개입니다.

| 승급 | 최소 레벨 [가안] | 실적 조건 [가안] |
| --- | --- | --- |
| F → E | Lv 5 | E등급 의뢰 5회 성공 |
| E → D | Lv 10 | D등급 의뢰 5회 성공 |
| D → C | Lv 18 | C등급 의뢰 7회 성공 |
| C → B | Lv 26 | B등급 의뢰 7회 성공 |
| B → A | Lv 35 | A등급 의뢰 10회 성공 |
| A → S | Lv 45 | S등급 의뢰 10회 성공 |

| 항목 | 내용 |
| --- | --- |
| 레벨 상한 | 50 [가안] |
| 상한 (우리 길드 출신) | 길드 등급까지. 조건을 채워도 길드가 승급할 때까지 대기 |
| 상한 (외부에서 온 모험가) | 다른 길드가 인정한 등급 유지. 길드 등급 +2단계까지만 방문. 희귀하게 등장하고, 우리 길드에서의 추가 승급은 길드가 따라잡아야 가능 |
| 강등 | 없음 [가안] |
| 승급 처리 | 조건을 채우면 접수원이 알리고 자동 승급 [가안] |
| 2세 | Lv 1, F급부터 다시 시작 (8장 참고) |

| 구분 | 쌓이는 방식 | 역할 |
| --- | --- | --- |
| 레벨 | 의뢰 경험치 (모든 의뢰) | 생명력·방어력 기본값, 모험가 등급 조건 |
| 능력치 | 능력치 경험치 (코어·서브) | 의뢰 성공 판정, 전직 조건 |
| 모험가 등급 | 레벨 + 실적 | 공인 자격. 의뢰 선택 범위, 마왕 토벌 조건, 명성과 방문 |

### 7.4-1 레벨과 스킬

레벨은 성장의 엔진이고, 직업은 그 방향을 정합니다. 전직해야 레벨 상한이 풀리고, 가진 스킬이 새 직업의 형태로 진화합니다.

**레벨**

| 항목 | 내용 |
| --- | --- |
| 단계별 상한 | 1차 30, 2차 40, 2차 종결·3차·특수 직업 50 |
| 상한 도달 시 | 레벨 정지, 경험치는 쌓아 두었다가 전직 시 반영. 능력치는 의뢰·훈련장으로 계속 성장 |
| 경험치 곡선 [가안] | 완만하게 증가. 2차 무렵 Lv 18, 3차 무렵 Lv 30, 현역 말기 Lv 45~50 |
| 레벨업 성장 | 직업별 고정 성장치. 소수점은 내부 누적, 화면에는 정수. 전직·1차 복귀 시 새 직업의 성장치 적용 |
| 1차 복귀 | 레벨은 유지하지만 1차 상한(30)을 넘었다면 재전직 전까지 레벨업 정지 |

| 단계 | 레벨업 1회당 성장치 [가안] |
| --- | --- |
| 1차 | 주력 2.0, 나머지 합 1.6 |
| 2차 특화 | 주력 2.4, 나머지 합 2.1 |
| 2차 조합 | 두 능력치 각 1.8, 나머지 합 0.9 |
| 3차 심화 | 두 능력치 2.2·2.0 (특화는 주력 2.8), 나머지 합 1.3 |
| 3차 확장 | 세 능력치 각 1.5, 나머지 합 1.0 |
| 특수 직업 | 행운 중심, 전투 능력치는 낮게 |

**스킬**

| 항목 | 내용 |
| --- | --- |
| 새 스킬 | 1차 직업 5개에서 하나씩 (예: 마법사 파이어볼, 전사 더블 스윙), 마을 건물에서 구매 |
| 진화 | 2차·3차로 오를 때 새 스킬 없이, 바탕 능력치가 새 직업 조건에 들어 있는 스킬이 그 직업 고유의 형태로 진화. 형태는 (현재 직업, 바탕 능력치) 조합마다 하나 |
| 진화하지 않을 때 | 바탕 능력치가 없는 직업으로 옮기면 현재 형태로 멈춤 |
| 규모 | 기본 5 + 진화형 77 = 82개, 마을 건물 스킬 약 20개 (건물 스킬은 진화하지 않음, 제안) |
| 보유·장착 | 얻은 스킬은 모두 계속 보유, 장착 슬롯 5칸. 기본은 모험가가 스스로 장착, 길드 마스터가 직접 설정 가능 |
| 구매·선물 | 모험가가 소지금으로 구매 / 길드 마스터가 길드 금전으로 선물(애착도 상승) |
| 효과 분류 | 판정(충족률 상승), 생존, 파티, 경제, 침공 |

파이어볼 진화 예시(이름은 가칭): 마도사 플레임 버스트, 마검사 화염검, 마궁사 화염 화살, 대마도사 메테오. 어떤 1차를 거쳤느냐에 따라 가진 스킬이 달라져 출신 차이가 자연스럽게 생깁니다.

**전직 메리트**: 레벨 상한 해제, 성장치 증가(1차 합 약 3.6 → 2차 약 4.5 → 3차 약 5.5), 스킬 진화, 외형 변화

### 7.6-1 성향

성향은 축 3개 × 3단계 + 선호 의뢰 유형으로, 모험가가 스스로 내리는 판단(의뢰 선택, 소비, 파티 결성)을 정합니다. 수치는 모두 [가안]이며 시뮬레이터로 검증합니다.

| 축 | 단계 | 영향 |
| --- | --- | --- |
| 위험 | 신중 / 보통 / 무모 | 고르는 의뢰 등급(자기 등급 −1~0 / −1~+1 / 0~+2), 수주 기준(70% / 55% / 35%), 실패 시 사망 확률(×0.5 / ×1.0 / ×1.5) |
| 소비 | 절약 / 보통 / 낭비 | 예비금(장비 가격의 2배 / 1배 / 0.3배), 식당 이용(30% / 60% / 90%), 물약 구매량, 보상 가중치(×0.8 / ×1.0 / ×1.3) |
| 사교 | 독불장군 / 보통 / 사교적 | 파티 모집 기준(예상 성공률 30% / 50% / 70% 미만), 친밀도 상승(×0.5 / ×1.0 / ×1.5) |
| 선호 의뢰 | 5개 유형 중 1개 | 같은 조건이면 먼저 고름 |

**예상 성공률과 의뢰 선택**

- 예상 성공률 = 실제 성공률 × 인식 계수(신중 0.9 / 보통 1.0 / 무모 1.2) ± 오차 10%p (정보실 레벨당 2%p 감소)
- 판단 순서: 점수가 가장 높은 의뢰서 → 예상 성공률이 파티 모집 기준 미만이면 주점에서 모집(최대 2주) → 모집 실패 시 수주 기준 이상이면 솔로 수주 → 아니면 다른 의뢰나 휴식
- 실제 성공률의 등급 기준치: F 15, E 25, D 35, C 45, B 60, A 75, S 90 (요구 총량 = 기준치 × 요구 능력치 수 × 0.85~1.15)

**공개, 변화, 계승**

| 항목 | 내용 |
| --- | --- |
| 공개 | 방랑자: 선호 유형 / 길손: + 위험 / 동반자: + 소비·사교 / 마을의 수호자: 전부. 공개 전에도 행동과 말풍선으로 짐작 가능 |
| 변화 | 사건에 따라 한 단계씩, 같은 축은 1년에 한 번까지. 예: 동료 사망 → 신중 쪽, 고정 파티 결성 → 사교적 쪽, 거주 시작 → 절약 쪽. 접수원이 알림 |
| 2세 계승 | 축마다 50% 확률로 부모와 같음, 선호 유형은 60%. 부모가 무모하게 죽으면 신중 쪽, 마왕군에게 죽으면 무모 쪽으로 한 단계(50%). 부모의 성향을 알았다면 '부모를 닮았을지도'로 힌트 표시 |

- 길드 등급은 **시설을 짓거나 시설 레벨을 올릴 수 있는 범위를 해금**합니다.

| 항목 | 훈련장 | 도서관 |
| --- | --- | --- |

| 능력치 | 힘, 민첩, 기교 | 지력, 정신 |
| 훈련 아이템 예시 | 운동장, 허수아비, 자물쇠 연습대 | 서가, 마법진, 명상대, 제단 |

## 11. 승급과 침공

### 11.1 승급 흐름

1. 현재 등급보다 한 단계 위의 **보스급 의뢰**가 여러 개 등장 (예: F등급 길드에 E등급 의뢰)
2. 특정 수를 달성하면 **승급 이벤트** 발생
3. 승급 이벤트: **대규모 몬스터 침공**을 지금 있는 모험가들이 막음

| 승급 | 조건 | 증명하는 기능 |
| --- | --- | --- |
| F → E | 보스급 의뢰 2건 → 침공 방어 | — |
| E → D | 보스급 의뢰 3건 + 모험가 관리소 → 침공 방어 | 관리 |
| D → C | 보스급 의뢰 3건 + 훈련장 → 침공 방어 | 육성 |
| C → B | 보스급 의뢰 4건 + 의무실 → 침공 방어 | 생명 |
| B → A | 보스급 의뢰 4건 + 해체장 → 침공 방어 | 가공 (상위 장비) |
| A → S | 보스급 의뢰 5건 + 명예의 전당 + S급 후보 2명 → 침공 방어 | 명예 |

**보스급 의뢰 수 N은 합계 21건 [가안].** 정확한 소요 시간은 시뮬레이터로 검증합니다.

**보스급 의뢰 공개 방식 [가안]** — 여러 모험가를 함께 키우는 플레이를 위해 여러 개를 동시에 공개합니다.

| 항목 | 내용 |
| --- | --- |
| 동시 공개 수 | 등급마다 N + 2개를 동시에 게시 (예: E→D는 5개) |
| 승급 조건 | 공개된 것 중 아무거나 N개를 달성하면 승급 이벤트(침공) 발생 |
| 의뢰 구성 | 동시에 나오는 의뢰들의 요구 능력치 프로필을 서로 다르게 구성 |
| 보충 | 하나를 끝내면 1~2개월 뒤 새 의뢰가 채워져 항상 N + 2개 유지 |
| N 달성 후 | 남은 보스급 의뢰도 계속 수행 가능. 보상과 경험치는 그대로 |
| 승급 보류 | 마스터가 승급 이벤트를 보류하고 육성을 계속할 수 있음 |

**명예의 전당과 S급 후보**

| 항목 | 내용 |
| --- | --- |
| S급 후보 | A급이면서 레벨 45 이상인 모험가. 길드 등급 상한 때문에 S급에 오르지 못한 상태 |
| A→S 추가 조건 | S급 후보 2명 이상 (마왕전 고정 파티의 핵심 전력을 미리 확보) |
| 승급 순간 | 길드가 S급이 되면 후보들이 자동으로 S급이 되고, 그 자리에서 명예의 전당에 이름이 새겨짐 |
| 이후 등재 | S급에 도달한 모험가는 그때마다 등재. 사망한 S급 모험가도 이름이 남음 |

**다회차 (명예의 전당의 영웅)** — 다회차는 더 쉽게 플레이하며 다른 엔딩을 보게 하는 것이 목적입니다. 다회차 난이도 상승은 두지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 데려올 인원 | 지금까지 본 엔딩의 수 (최대 3명). 전생자가 참가한 토벌은 엔딩 1의 변형이라 따로 세지 않음. 프로토타입은 2회차에 1명 |
| 선택 | 회차 시작 시 명예의 전당에서 고름 |
| 상태 | 능력치와 스킬을 그대로 유지하고 초반에 등장. 모험가 등급은 길드 등급 상한에 맞춰짐. 애착 단계도 전 회차 그대로 유지 |
| 사망 | 그 회차에서는 다시 오지 않음 |


### 11.2 마을 방어 전투 (승급 침공, 소규모 습격)

승급 침공과 소규모 습격은 규모와 이름만 다른 '마을 방어 전투'입니다. 모든 전투(방어전, 간부전, 마왕전, 특별 퀘스트 전투)의 결과는 **승리와 패배** 두 가지뿐입니다.

| 항목 | 내용 |
| --- | --- |
| 화면 | 마을 탑뷰 한 화면, 화면 이동 없음, 지켜보기 |
| 구도 | 성문(적의 입구) → 마을 거리(전장) → 마을 중심의 성(지킬 대상). 길드에서 모험가가 출발 |
| 승리 / 패배 | 모든 적 제거 / 성 함락 (체력 0) |
| 시간 제한 | 없음 (보통 60~120초에 끝나도록 조정) |
| 웨이브 [가안] | 침공 3웨이브 + 보스 / 습격 1~2웨이브, 보스 없음 |
| 성 체력 | 마을 인구 단계에 따라 커짐 (개척촌 목책 요새 → 성채 도시 대성채). 금전으로 강화 불가 |
| 패배 시 | 인구 감소 (습격 −5%, 침공 −10% [가안]), 습격은 신뢰도 하락, 침공은 승급 실패. 이기면 인구 감소 없음 |
| 참가 | 거주민 자동. 그 외 마을에 있는 모험가는 애착도와 성향으로 정해진 '필요 보상금' 이상이면 참가. 의뢰 중·다른 마을·부상은 불참 |
| 대비 기간 | 침공 2개월, 습격 2주 전 예고 (천문대가 있으면 +1개월, +1주). 동반자 이상은 예고 후 장기 의뢰를 피함 |
| 준비 화면 | 참가 확정 목록 → 보상금 단계별 추가 합류 목록 미리 보기 → 아군 전력 vs 적 규모 → 확정 |
| 쓰러진 모험가 | 성당(없으면 의무실)으로 옮겨졌다가 일정 시간 뒤 복귀. 둘 다 없으면 복귀 없음. 대성당이 있으면 더 빨리 |
| 마력 회복 | 마법 학원(없으면 주점·식당, 그 전에는 자연 회복과 물약). 마탑이 있으면 더 빨리. 이동 기준: 신중 30% / 보통 15% / 무모는 가지 않음 |
| 사망 판정 | 전투 후, 쓰러진 횟수가 많을수록 확률 상승 |

**소규모 습격**

| 항목 | 내용 |
| --- | --- |
| 빈도 [가안] | 개척촌 8개월, 마을 6개월, 읍 5개월, 도시 4개월, 성채 도시 3개월에 한 번꼴 |
| 규모 | 길드 등급과 같은 등급의 몬스터, 1~2웨이브, 보스 없음 |
| 겹침 | 침공 대비 기간 중에는 발생하지 않음 |

### 11.2-1 자동 전투 규칙

| 역할 | 기준 능력치 | 자리와 표적 |
| --- | --- | --- |
| 전위 | 힘 | 성과 적 사이 가장 앞. 다가오는 적 |
| 사수 | 민첩 | 전위 뒤. 전위와 싸우는 적 |
| 마법 | 지력 | 전위 뒤. 적이 몰린 곳 |
| 지원 | 정신 | 전위 바로 뒤. 체력이 낮은 아군 |
| 유격 | 기교 | 전선 옆. 적의 원거리 공격수, 강한 적, 성에 가장 가까운 적 |

- 조합 직업은 더 높은 능력치의 역할을 맡고 다른 역할의 행동을 일부 섞습니다.
- 민첩은 이동·공격 속도와 회피, 기교는 치명타와 약점 공격에 쓰입니다.

| 성향 | 전투 중 행동 |
| --- | --- |
| 무모 | 전선보다 깊이 들어가고 체력이 낮아도 물러나지 않음 → 쓰러지는 횟수가 늘어 전투 후 사망 위험이 큼 |
| 신중 | 체력 30% 아래에서 성 쪽으로 물러나 회복을 기다림 |
| 사교적 | 친밀도가 높은 동료 근처에서 싸우고, 함께면 공격력 소폭 증가 |
| 독불장군 | 혼자 떨어져 싸우고, 혼자일 때 공격력 소폭 증가 |

**물약**: 모험가가 산(또는 선물받은) 물약을 들고 참가하고, 체력·마력이 일정 아래로 떨어지면 자동 사용. 지참량은 소비 성향, 사용 시점은 위험 성향을 따름.

**스킬 발동**

| 항목 | 내용 |
| --- | --- |
| 공격 스킬 | 기본 공격할 때마다 확률 판정 |
| 회복 스킬 (예외) | 근처 아군이 피해를 입을 때 판정 |
| 버프 스킬 (예외) | 전투 시작 시, 그리고 일정 시간마다 판정 |
| 발동 확률 [가안] | 스킬 단계에 따라 1단계 10%, 2단계 18%, 3단계 28% / 건물 스킬은 건물 등급에 따라 10~20% |
| 판정 순서 | 단계가 높은 스킬부터, 처음 성공한 하나만 발동 |
| 마력 | 마력이 모자란 스킬은 판정에서 제외 |
| 재사용 대기 | 같은 스킬의 연속 발동 방지 |

### 11.3 전투 수치와 전투 장면

체력, 마력, 방어력, 마법방어력은 능력치에서 계산되는 전투 수치로, **전투 장면에서만** 쓰입니다. 의뢰 성공 판정에는 쓰지 않습니다.

| 수치 | 계산 [가안] |
| --- | --- |
| 체력 | 직업 기본 + 레벨 × 직업 성장 + 힘 보정 + 방어구 |

## 12. 엔딩

| 단계 | 내용 |
| --- | --- |
| 1. 발생 | 길드 등급 S 달성 시 전조 단계 시작 (마을이 강해져 마지막 봉인이 단단해지자 마왕이 초조해짐) |
| 2. 전조 | 마왕군 간부 의뢰가 등장하고, 달성하면 마왕성 공략 의뢰가 열림 |
| 3. 자격 | 고정 파티 + 평균 A등급 이상만 수주 가능 (시스템 고정) |
| 4. 도전 | 조건을 갖춘 파티가 스스로 수주 |
| 5. 결과 | 성공하면 엔딩, 실패하면 사망과 계승 후 2세가 재도전 |

**마왕전 연출**: 고정 파티가 마왕성에서 싸우는 장면을 침공과 같은 방식(탑뷰, 지켜보기)으로 보여 줍니다. 마왕군 웨이브 → 마왕. 마왕 체력이 0이면 승리, 파티 전멸이면 패배이며 시간 제한은 없습니다. 전설 직업은 전용 스킬 연출을 가집니다.

### 12.1 마왕과 간부

| 항목 | 내용 |
| --- | --- |
| 마왕 현신 | 마왕이 봉인을 덜 푼 채 무리하게 나섬. 실패해도 마왕은 깊은 상처를 입고 물러나고, 2세가 재도전 |
| 마왕 전투력 [가안] | 마왕전 시점의 마을 단계로 결정: 읍 이하 100%, 도시 85%, 성채 도시 70% |
| 필수 간부 | 3명. 순서대로 등장하고, 마지막이 옛 파티를 죽인 원수 간부 (옛 동료와는 무관한 마왕군 간부) |
| 선택 간부 | 1명. 히든 서브로 개방. 토벌 보상은 옛 용사의 방패 |
| 마인 계보의 언데드 부모 간부 | 별도 이벤트이며 간부 수에 포함하지 않음 |

### 12.2 옛 용사의 방패 (전설급 방어구)

- 직업 제한 없음. 검·지팡이와 달리 스스로 주인을 고르지 않습니다.
- **최초 주인:** 선택 간부를 토벌한 파티의 전위 역할 모험가 (여럿이면 힘이 가장 높은 모험가). 스토리 연출로 지급하며 마스터가 회수할 수 없습니다.
- 첫 주인이 사망하거나 마을을 떠나면(애착 60 미만) 길드로 귀속됩니다.
- 이후에는 길드 창고에 보관하고 마스터가 원하는 모험가에게 빌려줍니다. 대여받은 모험가가 사망하거나 떠나면 다시 길드로 돌아옵니다.

### 12-1.4 영주

봉인을 대대로 비밀리에 지켜 온 가문입니다. 그래서 처음에는 외부인 길드를 경계하고, 태도가 '동반자'가 되면 봉인의 비밀을 털어놓습니다. 태도는 마을 단계를 따르고, 영주 서브 퀘스트를 완료하면 한 단계 앞당겨집니다. 태도별 혜택은 미정입니다.

| --- | --- |
| 개척촌 | 경계 |
| 마을 | 관망 (첫 방어전 승리 후 인정하기 시작) |
| 읍 | 협력 |
| 도시 | 신뢰 |
| 성채 도시 | 동반자 |

### 12-1.5 멀티엔딩

플래그 누적형입니다. 메인 16개의 큰 흐름은 같고, 분기점 4곳의 선택이 플래그로 쌓여 마왕전 이후 엔딩이 결정됩니다. 분량은 메인 16 + 변형 장면 약 10 + 엔딩 3 = 약 30개 단위입니다.
