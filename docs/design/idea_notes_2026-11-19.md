## 1. 모험가의 판매 판단

**문제:** 지금은 귀환 때 길드가 판매가 × 70%로 무조건 사들입니다. V4 제안도 「소재별 매입 켬/끔」을 **길드만** 정합니다. 모험가는 판단하지 않습니다.

**아이디어:** 모험가가 길드가 부른 값과 「자기가 직접 쓸 때의 가치」를 비교해서 고릅니다.

- 판다: 길드 매입가 ≥ 직접 쓸 때 가치 × 성향 배수
- 안 판다: 자기가 씀(또는 V4 3-7처럼 시장에 직접 팖)
- 성향 배수 예 [임시]: 짠돌이 1.2 · 보통 1.0 · 급전 0.8 (지갑이 비면 급전 쪽으로)

**플레이어 결정이 생기는 곳 — 매입가율**

| 매입가율 [임시] | 결과 |
| --- | --- |
| 낮게 (시세 × 60%) | 길드 몫은 크지만 모험가가 덜 팔아서 소재가 덜 들어옴 |
| 보통 (시세 × 70%) | 지금 비율 |
| 높게 (시세 × 85%) | 소재는 많이 들어오지만 남는 돈이 적음. 시세가 내리면 손해 |

**예시 [임시]:** 늑대 가죽 시세 10G · 매입가율 70% → 길드가 7G 제시. 모험가가 직접 쓸 가치를 8G로 보면 보통 성향은 안 팔고(7 < 8), 급전 성향은 팖(7 ≥ 8 × 0.8 = 6.4). 길드가 사 둔 가죽을 시세가 오른 뒤 팔면 이득, 한꺼번에 많이 팔아 시세가 내려가면 손해.

**걱정: 모험가에게 인벤토리가 필요한가? (사용자 23:18) → 즉시 처리안 (Claude 추천)**

길드에 팔지 않은 소재는 **귀환하는 그 자리에서 바로 쓰거나 바로 시장에 팜**. 들고 다니는 소재가 없으므로 인벤토리가 필요 없습니다.

| 안 판 소재가 가는 곳 | 바뀌는 값 (이미 있는 데이터) |
| --- | --- |
| 시장에 직접 팔기 (V4 3-7) | 지갑 `a.wallet` + |
| 물약 재료로 쓰기 | 물약 `a.pots` +1 |
| 장비 재료로 쓰기 | 장비 3칸 `a.eq` 업그레이드 쪽으로 쌓임 |

- 성향 배수는 장비를 살 때 쓰는 씀씀이 성향 `a.spend`를 그대로 씁니다(새 값 불필요).
- 화면에는 귀환 기록 한 줄로만 보입니다. 예: 「가죽 2장은 길드에 팔고, 1장은 장비 손질에 썼다」.

| 방식 | 새로 필요한 것 | 부담 |
| --- | --- | --- |
| **A. 즉시 처리 (추천)** | 없음. 「팔았다 / 썼다」 기록만 | 작음 |
| B. 소재 1~2칸 보관 | 모험가마다 작은 칸 · 명부 아이콘 | 중간 |
| C. 인벤토리 | 소지품 화면 · 저장 · 시뮬레이터 | 큼 (모험가 30명의 소지품을 플레이어가 볼 일이 거의 없음) |

**정할 것**
1. 「직접 쓸 때 가치」를 무엇으로 볼지 (장비 업그레이드 재료 · 물약 재료 · 시장 직접 판매가 중 무엇).
2. 매입가율을 길드 전체 하나로 할지, 소재별로 할지.
3. 성향 배수를 버릇 제안서([proposal_quirks_v1.md](proposal_quirks_v1.md))의 버릇과 묶을지.

## 2. 던전 (길드가 발주하는 리퀘스트)

**문제 (사용자 · 선배 진단):** 리퀘스트도 마을 사람이나 모험가에게서 받기 때문에, 근본적으로는 일반 의뢰와 비슷하게 느껴집니다. 길드가 소재를 모으는 기능(길드 발주, 결정 24~27)을 넣었지만 기대만큼 효과가 없었습니다. V4 1장 표도 「한 번 하고 끝, 다시 발주할 이유가 없음」으로 같은 문제를 적고 있습니다.

**아이디어:**
- 게임을 진행하다 보면 **던전**이 생깁니다.
- 던전은 **길드가 스스로 발주하는 리퀘스트**입니다. 누가 부탁해서가 아니라 길드가 목표를 정합니다.
- 파티를 한 번 보낼 때마다 **정복 수치**가 오르고, **100%가 되면 던전 클리어**입니다.

**다른 의뢰와 다른 점**

| | 게시판 의뢰 | 리퀘스트 | 던전 |
| --- | --- | --- | --- |
| 누가 내나 | 마을 사람 | 마을 사람 · 모험가 | **길드** |
| 한 번으로 끝나나 | 예 | 예 | **아니오 — 여러 번 보내서 쌓음** |
| 목표 | 보상 | 보상 · 관계 | **정복 100%** |

**정할 것 (Claude 의견은 괄호 안)**
1. **정복 수치가 오르는 양:** 성공만 오르고 실패는 그대로일지, 파티가 강할수록 더 오를지. (승산 칩과 이어 붙이면 마스터가 고르는 「팽팽」한 장면이 생겨, 버릇 제안서 3장에서 짚은 "장점이 안 보이는" 문제도 함께 풂)
2. **얻는 것:** 보낼 때마다 정해진 소재 · 클리어 보상 · 새 지역 열림 중 무엇. (보낼 때마다 그 던전 소재가 나오면 **길드가 원하는 소재를 원할 때 모으는 곳**이 되어, 길드 발주를 대신하거나 흡수할 수 있음)
3. **언제 열리나:** 보호 구간(튜토리얼 뒤 약 12주)이 끝나고 파티 사냥이 시작될 때와 맞출지. 침공(클리어목표주(48주))과는 어떤 관계로 둘지 — 침공 전 단계로 둘지, 따로 갈지.
4. **몇 개를 동시에:** 한 번에 하나만 열지, 여러 던전을 골라 공략할지.
5. **클리어 뒤:** 사라질지, 정복한 던전으로 남아 소재를 계속 줄지.

## 3. 요리 판매 때 재료 소모

**아이디어:** 요리를 만들어 팔 때마다 재료 소재가 사라집니다.

- V4 제안 「① 식당 재료 소모」와 같은 방향입니다. 그 제안에 따르면 소모를 넣으면 **양념(소금 · 향신료 · 물 · 밀가루)이 가장 먼저 모자랍니다**(희귀 뽑기로만 나옴). 잡화 상인(V4 3-1)이 이 병목을 풀도록 되어 있습니다.
- 아이디어 1 · 2와 이어지는 점: 식당이 재료를 쓰면 → 길드가 소재가 필요해짐 → 매입가율(1)이나 던전(2)으로 모으는 이유가 생깁니다.
