> 작성: Claude, 2026-11-14 밤사이 작업 9번 · 상태: **제안 (코드 반영 안 함)**
> 출발점: 재미 점검 레포트 1회차(`docs/reports/재미_점검_2026-11-14.md`) "긴장감 약함 — 성공률 94.6%, 적자 달 0번, 침공 없음"
> 근거: `design_v0.1.md` 11.2(마을 방어 전투) · `prototype/js/sim_engine.js`(`raidStep` · `invasionStep` · `battle` · `defenders`) · `todo.md` "시뮬레이터 E급 승급 정체"(결정됨: E급 승급 = F급 메인 퀘스트)

## 요약

- **프로토타입(F급 1년)에 넣을 것은 "소규모 습격"뿐입니다.** 침공은 승급 이벤트인데, E급 승급은 이미 "F급 메인 퀘스트 성공"으로 정해졌습니다(2026-11-13). 그래서 침공은 E→D 이후 몫으로 남기는 것을 제안합니다.
- **지금 규칙대로면 첫해 습격은 0.9번뿐입니다.** 개척촌은 8개월에 1번이라 8월에 한 번 오고 끝납니다(시뮬레이터 100판, 승률 91%). 긴장감을 주려면 **F급 첫해에 3번(4 · 8 · 12월)** 오게 바꾸고, 지는 비율을 **15~25%**로 맞추는 것을 제안합니다.
- **플레이어 결정 2개를 붙입니다.** ① 예고 2주 동안 "누구를 마을에 남길지"(긴 의뢰 보내기 vs 대기) ② 방어 보상금을 단계별로 얼마나 걸지. 결정 없이 결과만 나오면 장식이 됩니다.
- **돈 영향(어림값):** 보상금은 습격 1번에 평균 439G씩 나갑니다(시뮬레이터 측정). 서브 퀘스트 돈 내기(약 −2,300G)와 합치면 1년 차 금고는 약 8,400G에서 **약 4,800G**로 내려가 목표 범위(4,000~5,000G)에 들어옵니다. 대신 월 순이익이 300G 밑으로 떨어질 수 있어서, **"운영 순이익"에 습격 · 기부 지출을 넣을지** 정해야 합니다(5장 결정 1).

## 1. 지금 시뮬레이터 규칙 (그대로 옮길 대상)

| 항목 | 값 · 규칙 | 위치 |
| --- | --- | --- |
| 습격 주기 | 인구 단계별 `raidMonths` = 8 / 6 / 5 / 4 / 3개월 (개척촌 → 성채 도시) | `promo.raidMonths` |
| 첫 습격 | 8개월 차 (게임 시작부터 첫 주기) | `nextRaid` |
| 적 규모 | `raidScale 4 × typical(길드 등급) × 0.5`, typical = 5 × 의뢰 기준치 × 0.75 → F급 = 4 × 56 × 0.5 = **약 113** | `raidStep` |
| 아군 | 의뢰 중이 아닌 모험가 중 애착 100은 전원, 나머지는 60% 확률로 참가 | `defenders` |
| 보상금 | 애착 100 미만 참가자마다 의뢰 보상 × (애착 60 이상 0.5 / 미만 1.0) → F급 1명 50~100G | `defenders` |
| 승률 | 로지스틱: 1 / (1 + e^(−6 × (아군 전력 ÷ 적 − 1))) | `battle` |
| 사망 | 이기면 1%, 지면 3% × 성향(신중 0.5 · 보통 1 · 무모 1.5), 의무실 −15% | `battle` |
| 졌을 때 | 인구 −5%, 신뢰도 −5 | `raidStep` · `town.raidLoss` |
| 침공과 겹침 | 침공 대비 기간에는 습격 없음 | `invasionCooldown` |

**측정 (시뮬레이터 100판, 균형형, 시드 7000~7099):**

| 기간 | 습격 승 / 패 (판당) | 침공 승 / 패 |
| --- | ---: | ---: |
| 1년 | 0.91 / 0.09 | 0 / 0 |
| 2년 | 2.64 / 0.27 | 0 / 0.01 |
| 3년 | 4.38 / 0.37 | 0.05 / 0.54 |

- 침공으로 E급에 오른 판은 5년 안에 41판뿐이고, 중앙값은 49개월입니다. 이것이 `todo.md`의 "E급 승급 정체"이며, 이미 메인 퀘스트 방식으로 바꾸기로 결정돼 있습니다.

## 3. 플레이어 결정

| 시점 | 결정 | 화면 | 효과 |
| --- | --- | --- | --- |
| 예고 (2주 전) | 리나: "마스터, 성문 쪽에 들개 무리 발자국이 늘었대요. 2주 안에 올 것 같아요." | 일지 + 리나 말풍선 + 마을 화면 성문에 느낌표 | — |
| 예고 기간 | **누구를 남길지:** 긴 의뢰(2주 이상)를 보내면 그 모험가는 빠짐. 게시판 필터를 바꾸거나 출발을 보류 | 게시판 장에 "습격 대비" 표시, 모험가 카드에 "방어 참가 예정" | 수익 vs 방어 전력 |
| 습격 당일 | **보상금 단계:** 없음 / 낮음(의뢰 보상 × 0.5) / 보통(× 1.0) / 높음(× 1.5). 단계가 높을수록 애착 낮은 모험가도 참가 | 준비 창: 참가 확정 목록 → 단계별 추가 합류 → 아군 전력 vs 적 규모 막대 → 확정 (11.2 "준비 화면") | 돈 vs 승률 |

- 승률은 숫자 대신 막대 3칸(불리 · 비슷 · 유리)으로 보여 줍니다. 플레이어에게 보이는 수치는 정수 원칙(`working_rules.md` 4장).
- 애착 100(거주민)은 보상금 없이 자동 참가합니다. 그래서 "애착을 키우면 방어가 싸진다"는 연결이 생깁니다.

## 4. 연출

| 장면 | 내용 | 그림 |
| --- | --- | --- |
| 예고 | 마을 화면 성문 쪽에 느낌표, 로비 게시판에 "경계" 쪽지 1장 | 쪽지 1장 (기존 쪽지 그림 재사용) |
| 전투 | **마을 화면 탑뷰**: 성문에서 적 점(F급은 들개 · 도적 4종 아이콘)이 들어오고, 길드에서 모험가 점이 나감. 미니 뷰처럼 지켜보기, 60~90초 | 기존 미니 뷰 아이콘 · 말풍선 재사용 (`talk.csv` 전투 대사) |
| 결과 | 이김: 리나 "다들 무사해요!" + 명성 +1 / 짐: 민가 1~2채 연기, 인구 −5% 표시, 신뢰도 −5 | 연기 효과 1개 |

- 미니 뷰(원정 화면)는 그대로 두고, 습격만 마을 화면에서 보여 줍니다. 원정 중인 모험가는 미니 뷰에 "마을이 습격받는 중" 한 줄만 띄웁니다.

## 5. F급 첫해 값 제안과 영향 예측

| 항목 | 지금 (시뮬레이터) | 제안 |
| --- | --- | --- |
| 첫해 습격 횟수 | 0.9번 (8월) | **3번 (4 · 8 · 12월)**: 개척촌 주기 8 → 4개월, 첫 습격 4개월 차 |
| 패배 비율 | 9% | **15~25%** (`raidScale` 4 → 약 5, 구현 후 측정해 맞춤) |
| 졌을 때 | 인구 −5%, 신뢰도 −5 | 그대로 |
| 보상금 (판당) | **439G** (시뮬레이터 1년 100판 측정, 참가 평균 3.2명) | 보상금 단계 "보통" 기준 같음 |
| 첫해 습격 지출 | 약 400G | **약 1,300G** (3번) |

**1년 차 금고 어림 (게임 규칙 30판 8,384G에서 출발):**

| 더하는 것 | 금고 변화 | 1년 차 말 금고 |
| --- | ---: | ---: |
| 지금 | — | 8,384G |
| + 서브 퀘스트 돈 내기 · 금화 보상 (`sub_quest_F_v1.md` 2-2) | 약 −2,300G | 약 6,100G |
| + 습격 3번 보상금 | 약 −1,300G | **약 4,800G** (목표 4,000~5,000G 안) |

- **월 순이익:** 기부 · 보상금을 운영 순이익에 넣으면 482G → 약 180G로 목표(300~600G) 밑입니다. 넣지 않으면(건설비처럼 따로 셈) 482G 그대로입니다.
- **성공률(94.6%)은 습격으로 바뀌지 않습니다.** 의뢰 성공률은 8번 밸런스 탐색 레포트(`docs/reports/밸런스_탐색_2026-11-14.md`)에서 따로 다룹니다.
- 모든 숫자는 어림값입니다. 구현 후 관문 1과 재미 점검 지표로 다시 잽니다.

## 6. 침공 (E→D 이후, 프로토타입 밖)

- 규칙은 `design_v0.1.md` 11.1 · 11.2 그대로(보스급 의뢰 N건 → 침공 3웨이브 + 보스, 대비 2개월, 졌을 때 인구 −10% · 승급 실패)입니다.
- 습격을 먼저 넣으면 판정 · 준비 화면 · 마을 탑뷰 연출을 침공이 그대로 물려받습니다. 침공은 "웨이브 3 + 보스 + 대비 2개월"만 더하면 됩니다.
- 시뮬레이터는 E급 승급을 메인 퀘스트 규칙으로 바꿀 때(`todo.md`) F→E의 `invasionStep`을 끄고, E→D부터 침공을 씁니다.
