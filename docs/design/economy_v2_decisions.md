### 2-7a. 수락 복합식 (결정 5, 2026-11-17 15:18 · 보정값은 시험값)
> 수락: 계약 쪽 월수입 ≥ 자유 쪽 월수입 × **요구 비율**
> 요구 비율 = 1.00 − 애착 보정 + 성향 보정

| 요소 | 계산 | 범위 |
| --- | --- | --- |
| 자유 쪽 월수입 | 최근 8주 월 기준액 × (1 − 일반 수수료) | — |
| 계약 쪽 월수입 | 최근 8주 월 기준액 × (1 − 계약 수수료) + 보수 + 지원 한도 × 0.5 | — |
| 애착 보정 | 0.15 × (애착 − 30) ÷ 70 (연속값) | 30 = 0 → 100 = 0.15 |
| 소비 (`spend`) | 절약 −0.05 · 보통 0 · 낭비 +0.03 | −0.05 ~ +0.03 |
| 모험심 (`risk`) | 신중 −0.03 · 보통 0 · 무모 +0.05 | −0.03 ~ +0.05 |
| 사교 (`social`) | 사교적 −0.02 · 보통 0 · 독불장군 +0.05 | −0.02 ~ +0.05 |
| 요구 비율 전체 | | 0.75 ~ 1.13 |

- 같은 조건이면 늘 같은 답(재추첨 금지). 화면은 숫자 없이 3단계: 받아들일 것 같다 / 고민 중(필요액과 ±5% 안) / 거절할 것 같다.
- 예시(기준액 300G, 자유 270G, 기본 조건 계약 쪽 270G): 애착 40 · 보통 → 0.98 · 264G 수락 / 애착 40 · 무모 · 독불장군 → 1.08 · 291G 거절(보수 50G면 수락) / 애착 90 · 절약 · 신중 · 사교적 → 0.77 · 208G 수락(수수료 30%도 수락).
- 소수 비율은 내부 계산에만 씁니다. 금액은 정수 G로 비교합니다(내림).

**사용자가 고를 수 있는 범위 (추천):** 기간 · 수수료 · 보수 · 지원 한도 4가지(위험 단계는 결정 6으로 없어짐). 업무 상한(4주 중 2주) · 예산 전망(8주)은 고정.

| 수수료 지정 | 마스터가 게시판 의뢰마다(또는 등급 칸마다 — 화면 시안 때 정함) 10 · 15 · 20% 지정. 기본 10%. 해금 가안: 15% = 집무실, 20% = 게시판 업그레이드 |

| 계약 모험가 | 계약 수수료(결정 4)을 따르므로 의뢰별 수수료와 상관없음 |
