### 2-7a. 수락 복합식 (결정 5, 2026-11-17 15:18 · 보정값은 시험값)
> 수락: 계약 쪽 월수입 ≥ 자유 쪽 월수입 × **요구 비율**
> 요구 비율 = 1.00 − 애착 보정 + 성향 보정

| 요소 | 계산 | 범위 |
| --- | --- | --- |
| 자유 쪽 월수입 | 최근 8주 월 기준액 × (1 − 일반 요율) | — |
| 계약 쪽 월수입 | 최근 8주 월 기준액 × (1 − 계약 요율) + 보수 + 지원 한도 × 0.5 | — |
| 애착 보정 | 0.15 × (애착 − 30) ÷ 70 (연속값) | 30 = 0 → 100 = 0.15 |
| 소비 (`spend`) | 절약 −0.05 · 보통 0 · 낭비 +0.03 | −0.05 ~ +0.03 |
| 모험심 (`risk`) | 신중 −0.03 · 보통 0 · 무모 +0.05 | −0.03 ~ +0.05 |
| 사교 (`social`) | 사교적 −0.02 · 보통 0 · 독불장군 +0.05 | −0.02 ~ +0.05 |
| 요구 비율 전체 | | 0.75 ~ 1.13 |

- 같은 조건이면 늘 같은 답(재추첨 금지). 화면은 숫자 없이 3단계: 받아들일 것 같다 / 고민 중(필요액과 ±5% 안) / 거절할 것 같다.
- 예시(기준액 300G, 자유 270G, 기본 조건 계약 쪽 270G): 애착 40 · 보통 → 0.98 · 264G 수락 / 애착 40 · 무모 · 독불장군 → 1.08 · 291G 거절(보수 50G면 수락) / 애착 90 · 절약 · 신중 · 사교적 → 0.77 · 208G 수락(요율 30%도 수락).

| 효율 | 내 실수령 ÷ 걸리는 주. 내 실수령 = 보상 × (1 − 요율) ÷ 파티 인원 (정수 배분은 결정 8) |
| 모험가 선택 | 성공할 수 있는 의뢰(지금 출발 기준 그대로) 중에서 효율이 높은 순서로 고름 |
| 돈이 필요한 모험가 | 효율을 가장 크게 봄 — 지갑이 장비 구매선보다 적거나 낭비 성향 |
| 여유 있는 모험가 | 지금처럼 등급 · 성공 가능성 위주, 효율은 작게 반영 |
| 대가 | 고요율 의뢰는 늦게 팔림 → 기한이 지나면 사라지고 신뢰도 하락 (지금 규칙) |
| 계약 모험가 | 계약 요율(결정 4)을 따르므로 의뢰별 요율과 상관없음 |

- 지금 코드 사실: 모험가는 등급이 높은 의뢰부터 보고 성공할 것 같으면 바로 감(`departures`). 보상 · 실수령을 따지지 않아서 요율 20%가 손해 없이 이득만 났음(48주 측정 559G → 619G).
- 효율 가중치(돈이 필요한 정도에 따른 비중)는 5단계 구현 때 측정으로 맞춥니다.
