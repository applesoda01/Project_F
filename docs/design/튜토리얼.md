# 튜토리얼

작성: Claude · 2026-11-18 · 상태: **구현됨 (2026-11-18, 사용자 지시 "튜토리얼 전부 구현") · 대사는 초안 — 나중에 사용자가 따로 고침** · 좌측 상단 미션 표시는 보류(시안 뒤 결정)
흐름 원안: 사용자 2026-11-18 15:00~15:23 (부록 A에 말씀하신 그대로 보존) · 요리 · 상황별 안내 · FT0007 조건은 Claude 제안
관련: 결정 33(첫 모험가 = 전사) · 결정 7(금고 마이너스면 계약 · 건설 · 지명 막힘) · 동료 피드백 "초반에 뭘 해야 할지 모르겠음"(11-16) · 책 V3 3.5 합류

## 1. 요약
- **기본 튜토리얼 9개 (FT0001~FT0006 · FT0008 · FT0009):** 오프닝 영상 → 리나의 불평 → 첫 모험가(남자 전사) → 게시판 · 첫 원정 · 미니 뷰 → 식탁 설치 → 두 번째 모험가 → 첫 요리 → 첫 리퀘스트 · 집무실(리나가 1,000G 지원) → 강제 리퀘스트 진행으로 끝.
- **상황별 안내 13개 (FT0007 · FT0010~FT0021):** 그 일이 처음 생길 때 한 번만 나오는 짧은 대화. 필수 5개(FT0007 책상 업그레이드 · FT0010 월말 결산 · FT0011 모험가 상한 · FT0012 메인 퀘스트 · FT0021 첫 적자 500G).
- 리나의 지원은 세 번: 1,000G(FT0006) · 향신료(FT0008) · 비상금 500G(FT0021). 대사에서 "이번만"을 분명히 함.

## 2. 규칙
### 2-1. 대사 파일 번호 (사용자 결정)
- **(등급)(유형)(번호)** — 등급 = 길드 등급(그 등급에서 나오는 이벤트), 유형 = 리퀘스트의 메인 · 서브 · 튜토리얼, 번호 = 생성 순서 4자리.
- 예: **FT0001** = F등급 · 튜토리얼 · 첫 번째 대화 파일. 번호는 만든 순서이므로 재생 순서와 다를 수 있음(요리 FT0008 · FT0009는 FT0005와 FT0006 사이에 재생).
- 유형 글자: **T = 튜토리얼 · M = 메인 · S = 서브** (2026-11-18 17:05 사용자 확인). 예: FM0001 = F등급 메인 퀘스트 첫 대화, FS0001 = F등급 서브(리퀘스트) 첫 대화.
- 메인 퀘스트(침공)가 처음 나올 때의 짧은 안내는 튜토리얼(FT0012), 영주의 전갈 · 침공 장면 같은 이야기 대사는 FM으로 둠.

### 2-2. 진행 원칙
- 기본 튜토리얼: 대화와 안내가 나오는 동안 시간이 멈추고, 안내하는 버튼만 빛남. **원정을 떠났다가 돌아오는 동안은 시간이 흐름**(기존 기획의 "튜토리얼 동안 시간 멈춤"을 이렇게 바꿈 — 확인 필요).
- 시작 인원 0명 → FT0002에서 첫 모험가(남자 전사), FT0005에서 두 번째 모험가(전사 외 무작위). 결정 33과 같음.
- 상황별 안내: 처음 생길 때 한 번만, 3~6줄. 플레이를 막지 않고 해당 버튼만 빛남. 한 주에 하나만(겹치면 다음 주로).
- 설정에 "안내 다시 보기 / 끄기"(제안). 오프닝 영상은 언제든 스킵 가능.
- 표정: 리나는 게임에 있는 6종(smile · laugh · serious · surprised · worried · awkward). 모험가 · 대장장이는 이름표만.
