**흐름** (모험가 한 명씩)
1. 쓸 돈을 정합니다.
2. 준비물을 줄 세웁니다.
   - 물약: 지참 상한까지 남은 병 수만큼 한 병씩
   - 밥: 하나
   - 순서: 필요가 큰 것 먼저, 같으면 물약 먼저
3. 하나씩 「살까」(필요)를 봅니다.
   - 물약은 마을 값(지금 물약 값)으로 주머니만 봅니다.
   - 밥은 「길드에서 살까」(주머니 × 견줌, 1을 넘으면 1)를 봅니다. 맞는 요리가 없거나, 품절이거나, 자리가 없으면 0입니다.
   - 길드에서 안 사면 여관(주머니만)에서 삽니다.
4. 여관에 낸 돈은 길드 수입이 아닙니다.

## 2. 가정 (시안에 없어 정한 것)

| 가정 | 내용 |
| --- | --- |
| 큰일 | 승산이 「위험」인 퀘스트 + 싸우는 리퀘스트. **침공(메인 퀘스트)은 넣지 못했습니다.** 침공은 출발 처리(`launchParty`)를 거치지 않고 따로 물약을 삽니다. 시안 문서의 「보스 리퀘스트」는 지금 게임에 없어 「싸우는 리퀘스트」로 바꾸었습니다(지시문을 따름) |
| 모으는 중 | 대장간이 있고 다음에 살 장비 칸이 있을 때(`eqNext`). 그 밖은 모을 것 없음 |
| 승산 | 출발 때 넘겨받는 예상 성공률 `pp`를 밥 먹기 전의 값으로 씀. 게시판 의뢰는 대장의 「느낀 승산」(성향 배수 × 0.9 · 1.0 · 1.2 + 오차), 리퀘스트는 계산한 승산(`questP`). 지금 게임의 출발 처리가 그렇게 넘겨줌 |
| 받을 내 몫 | 그 퀘스트의 보상(× 2 의뢰면 2배, 보상 나누기면 × `q.party`)을 지금의 나누기(`econSplit`)로 나눈 순 몫 |
| 길드 의뢰 | 의뢰 카드의 `reward`가 있으면 그것, 없으면 0으로 봄(길드 의뢰의 보수는 따로 치름) |
| 여관 값 | 길드 등급 보상 × 0.2. 길드 요리 값은 요리 등급 보상 × 0.2(E급 요리 30G) |
| 양념 | 조건 3 · 4: 식당이 모자라면 시장에서 바로 삼(지금처럼). 지금 규칙의 미리 만들기(준비량)는 끔 |
| 「빠듯해서 아낌」 | 주머니가 0.5(값이 남은 돈 이하)인데 굴림에서 빠진 경우. 지시문의 못 먹은 까닭 목록에 없어 따로 셈 |
| 못 먹은 까닭 (돈) | 여관 값이 남은 돈보다 클 때: 지갑 < 값이면 「지갑이 빔」, 모으는 중이면 「모으는 중」, 아니면 「벌이가 적음」 |
| 「비쌈」 | 길드 값이 여관 값의 1.25배를 넘어 길드에서 안 산 경우. 이번 값(길드 = 여관)에서는 생기지 않음 |
| 물약 병 수 | 지참 상한(절약 1 · 보통 2 · 낭비 3)까지. 지금 규칙의 「50%는 1병 적게」는 새 판단에서 뺌 |
| 술 · 장비 | 지금 규칙 그대로 |
| 난수 | 새 판단의 굴림도 게임 난수(`s.R`)를 씀. 그래서 같은 시드라도 그 뒤 사건이 달라짐(짝 비교의 잡음) |

시안 문서와 지시문이 다른 곳: 「큰일」의 범위(보스 리퀘스트 → 싸우는 리퀘스트)뿐이고, 지시문을 따랐습니다.

## 8. 이 측정으로는 알 수 없는 것

- 보스(묶음의 큰일)가 식당의 대목이 되는 효과. 보스는 게임에 없고, 큰일은 「위험 · 싸우는 리퀘스트」로만 흉내 냈습니다. 한 판 12번쯤입니다.
- 침공 때 지갑을 여는 효과. 침공은 출발 처리를 거치지 않아 넣지 못했습니다.
- 플레이어가 메뉴 값 · 준비량을 고치는 효과. 봇은 값을 바꾸지 않고, 사는 판단에서는 길드 값을 20G로 고정했습니다.
- 플레이어가 양념을 직접 사거나 떨어뜨리는 효과. 양념은 식당이 시장에서 바로 산다고 보았습니다.
- 「모으는 중」 말이 보이거나 플레이어가 장비를 선물해 모을 것을 없애는 효과. 봇은 선물하지 않습니다.
- 여관 값이 마을 크기에 따라 오르는 효과. 여관 값은 길드 등급에만 묶었습니다.
- 모험가가 하는 말을 보고 플레이어가 퀘스트 · 요리를 바꾸는 효과.
- 정비 · 약초 주머니(올 준비물)가 순서에 끼는 효과. 지금 게임에 없습니다.
- 술 · 마을 손님. 이번 판단에 넣지 않았습니다.

## 9. 확인하지 못한 것
