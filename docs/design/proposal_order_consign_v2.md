## 0. 이 문서가 나온 경위 (2026-11-19 사용자와 논의)

| 사용자 의견 | 정리 |
| --- | --- |
| "길드 발주는 **의뢰를 발주**해야 하지 않을까?" | 발주 = 길드가 돈을 내고 게시판에 올리는 **길드 의뢰**. 지금의 '소재 목표 재고 + 게시판 · 뽑기 쏠림'은 보이지 않는 확률이라 없앰 |
| "소재는 **매입 단가**에 따라 모험가가 길드에 팔지 말지 결정하는 문제" | 길드는 소재별 **매입가**만 정하고, 모험가가 길드에 팔지 시장에 팔지 고름 |
| "위탁은 어디서 위탁받아서 파는 거야? 거래가 있어야" | 사 가는 사람이 없는 위탁은 없앰. 수요는 모두 **의뢰**(NPC 납품 · 길드 의뢰 · 나중에 상단)로 |
| 결정 49 · 50 · 51 | 상한 = 동시 건수 · 종류 = ①②③ 기본 + 나머지는 진행하며 해금 · 보상 = 플레이어가 정함 |

## 요약

- **길드의 역할은 '중개'와 '의뢰'로 정리합니다.** 모험가가 가져온 소재를 길드가 정한 매입가로 사들이고(살지 말지는 모험가가 고름), 필요한 일은 길드 예산으로 **길드 의뢰**를 냅니다.
- **길드 의뢰**는 게시판에 실제 카드로 올라옵니다. 동시에 걸 수 있는 수에 상한이 있고(등급별), 보상은 플레이어가 정합니다. 기본 종류는 ① 소재 납품 ② 토벌 ③ 정찰이고, ④ 순찰 · 경비 ⑤ 마을 일손 ⑥ 훈련 원정은 진행하면서 열립니다.
- **매입**은 소재별 매입가 하나로 줄입니다. 모험가는 "길드 매입가 vs 시장에 직접 팔 때"를 비교해 팝니다. 매입가가 '얼마나 모을지'의 손잡이가 됩니다.
- **위탁 · 안 받음 · 상시 발주 · 양념 발주는 없앱니다.** 소재마다 정할 것이 '매입 / 위탁 / 안 받음 × 50 · 70 · 90%'에서 '매입가 하나'로 줄어듭니다.

## 1. 길드 의뢰

### 1-1. 공통 규칙

| 항목 | 규칙 [임시] |
| --- | --- |
| 거는 곳 | 리퀘스트 장 → **길드 의뢰** 책갈피 (지금 '길드 발주' 자리). 집무실이 있어야 함 |
| 상한 (결정 49) | **동시 건수**: 길드 등급별 F 2 · E 3 · D 4 · C 5 …, 게시판 업그레이드 +1 |
| 보상 (결정 51) | **플레이어가 정함.** 종류마다 기준 보상(같은 등급 게시판 의뢰 보상)의 50 ~ 300%, 10G 단위. 거는 순간 금고에서 **예약**(빠져나가지는 않음), 끝나면 지급 |
| 모험가 | 다른 의뢰처럼 실수령 ÷ 기간 · 위험을 보고 맡음 → **보상이 높을수록 빨리 맡겨짐**. 길드 의뢰는 수수료가 없으므로 같은 보상이면 게시판 의뢰보다 실수령이 큼 |
| 게시판 | 게시판 칸을 차지하고 카드에 '길드 의뢰' 띠. 일반 의뢰를 밀어내므로 많이 걸수록 수수료 · 보조금 수입이 줄어드는 대가 |
| 기한 | 2 · 4 · 6주 중 선택. 지나면 사라지고 예약을 풂 (신뢰도 영향 없음 — 의뢰인이 길드 자신) |
| 수수료 · 보조금 | 없음 (의뢰인이 길드 자신, 책 V3 기획 그대로) |
| 중복 | 같은 종류 · 같은 대상은 동시에 1건 |

### 1-2. 기본 종류 (결정 50: ①②③)

| 종류 | 맡기는 일 | 정하는 것 | 결과 | 이어지는 시스템 |
| --- | --- | --- | --- | --- |
| **① 소재 납품** | "멧돼지 고기 N개 가져와 줘" | 소재 · 개수(1~20) · 보상 | 그 소재가 나오는 의뢰 틀로 원정. 가져온 그 소재는 **매입 판단 없이 모두 길드 창고로**(약속한 거래). 한 번에 다 못 채우면 **가져온 만큼 나눠 지급**하고 남은 개수로 다시 게시 | 식당 재료 · 납품 리퀘스트 · 대장간 |
| **② 토벌** | "늑대 굴 늑대를 줄여 줘" | 사냥터(몬스터 자원지) · 처치 수 · 보상 | 그 사냥터 전투 원정(적 수 = 처치 수). 이기면 개체수 −(처치 수 × 5). 떨어진 소재는 평소처럼 매입 판단 | 개체수 '많음' 피해 막기 (3단계) |
| **③ 정찰** | "이 사냥터 · 채집지 상황을 알아봐 줘" | 자원지 · 보상 | 1주 비전투 판정(탐색 능력치). 성공하면 4주 동안 그 자원지 **개체수를 숫자로 공개** · 그 자원지 의뢰의 **적 정보 오차 없앰**(의뢰 레벨이 막 오른 의뢰 포함) | 개체수 숨김 표시(결정 44) · 의뢰 레벨 정보 오차(결정 35) |

### 1-3. 해금 종류 (결정 50: 진행 상황에서 추가)

| 종류 | 열리는 때 [임시] | 맡기는 일 · 결과 |
| --- | --- | --- |
| ④ 순찰 · 경비 | F급 메인 퀘스트(침공) 전갈이 온 뒤 | 침공 전 마을 · 다리 순찰 → 침공 첫 차례 적 약화, 소규모 습격(보류) 확률 감소 |
| ⑤ 마을 일손 | 마을 인구 200 또는 민가 단계 2 | 비전투 일손 → 인구 증가 · 신뢰도 |
| ⑥ 훈련 원정 | 모험가 관리소 | 지명한 신입 + 선배가 쉬운 사냥 → 신입 경험치 · 능력치 · 친밀도 |
| (아이디어) 전직 시험 | — | 책 V4 부록 E. 아이디어 1 |

- 해금되면 리나가 알리고, 길드 의뢰 책갈피의 종류 목록이 늘어납니다(잠긴 종류는 흐리게 '○○하면 열림').

## 2. 매입: 모험가가 길드에 팔지 고른다

| 항목 | 규칙 [임시] |
| --- | --- |
| 길드가 정하는 것 | **소재별 매입가** = 시세의 50 ~ 120%, 5% 단위. 기본 85% |
| 모험가의 판단 | 돌아올 때 소재마다: 길드 매입가 ≥ 시세 × **판매 기준** 이면 길드에 팖, 아니면 **시장에 직접 팖**(모험가 지갑 +, 시장 재고 + → 시세 하락, 길드 몫 없음) |
| 판매 기준 | 성향: 절약 90% · 보통 85% · 낭비 75% / 애착 60 이상 −5%p, 90 이상 −10%p (정이 들면 조금 싸게도 넘김) |
| 금고 · 창고 | 금고가 매입가보다 적거나 창고 상한(30)이면 길드가 사지 못함 → 모험가가 시장에 팖 |
| 길드 의뢰 ①의 소재 | 매입 판단 없이 길드로 (약속한 거래, 보상으로 이미 값을 치름) |
| 판매 창구 | 길드 창고 소재를 **마을 상점**에 팖 — 거래 상대를 분명히. 팔수록 시세가 내려가는 규칙 그대로 |
| 화면 | 경영 → **매입** 책갈피(지금 '매입 · 위탁'): 소재마다 매입가 · 시세 그래프 · 지난 4주 '길드에 판 수 / 시장에 판 수' |

- 매입가를 시세보다 높게(100% 넘게) 잡으면 다 모이지만 돈이 많이 들고, 낮게 잡으면 시장으로 빠져 시세가 내려갑니다 → **"얼마나 모을지"와 "시세를 얼마나 누를지"가 한 손잡이**.
- 예전 "매입가를 낮추면 돈이 필요한 모험가가 그 의뢰를 거름"(결정 43)은 없앰 — 이제 모험가는 의뢰를 거르지 않고 판매처만 바꿈.

## 3. 없애는 것과 대신하는 것

| 없앰 | 대신 |
| --- | --- |
| 상시 발주 (목표 재고 · 게시판 쏠림 · 뽑기 쏠림 · 동시 6건) | 길드 의뢰 ① 소재 납품 |
| 양념 상시 발주 (결정 46) | 잡화 상인(유지) + 길드 의뢰 ① |
| 소재별 매입 / 위탁 / 안 받음, 매입 50 · 70 · 90% | 소재별 매입가 하나 + 모험가 판단 |
| 위탁 (월말 자동 판매 · 수수료) | 없음 — 수요는 NPC 납품 리퀘스트 · 길드 의뢰 · (나중에) 상단 구매 의뢰 |
| 연결 발주 (v1 제안) | 메뉴 재료가 떨어지면 "길드 의뢰를 낼까요?" 안내 단추만 |

유지: 소재 시세(결정 40) · 판매 창구 · 시세 그래프 · 식당 재료 소모 · 개체수 · 납품 리퀘스트 재료 남겨 두기.

## 7. 위탁 → 떠돌이 상단 (2026-11-19 사용자 결정 57~62)
