# 모험가 팝업 개편 설계

> 2026-11-05 사용자와 논의해 확정. 팝업 안쪽 내용 퀄업의 두 번째 대상(첫 번째는 `popup_board.md`). 공통 부품은 `prototype/css/ui_kit.css`.

## 0. 요약

| 영역 | 지금 | 바뀜 |
| --- | --- | --- |
| 능력치 | 오각형 그래프 | **10칸 막대** (상한 100, 한 칸 = 10점, 칸 안이 아래에서 차오름) |
| 장비 | 글자 목록 | **아이콘 3칸** (무기·방어구·장신구), 상세는 마우스 오버 |
| 물약 | 숫자 | **3칸** (가진 수만큼 채움, 소비 성향상 못 드는 칸은 잠금) |
| 전투 수치 | 없음 | 공격·방어·체력·마력 4칸 |
| 스킬·전직·성향·경력 | 한 화면에 모두 | 아래 **탭 4개**, 스킬 탭이 기본으로 펼쳐짐 |
| 소지금 | 없음 | 머리 오른쪽 금액 + **다음 장비까지 진행 바** |
| 목록 줄 | 이름·직업·Lv | 상태 색, **전직 제안 표시**, **마우스 오버 창** |

## 1. 화면 구성

- 왼쪽 = 모험가 목록 / 오른쪽 = 선택한 모험가 상세.
- 상세 순서: 머리(초상화·이름·등급·직업·상태·소지금 / Lv 바) → 왼쪽 장비·물약 + 오른쪽 능력치 막대·전투 수치 → 아래 탭.

## 2. 능력치 막대

| 항목 | 규칙 |
| --- | --- |
| 칸 | 10칸, 한 칸 10점, 상한 100. GPT로 그린 둥근 직사각형 칸(13×23px, 원본의 70%) |
| 색 | 금색 = 보통 / 주황 = 주 능력치 / 초록 줄무늬 = 장비 보너스 |
| 애니메이션 | 팝업을 열거나 다른 모험가를 고를 때 칸이 아래에서 차오름(칸·줄마다 조금씩 늦게) |
| 숫자 | 오른쪽에 값, 장비 보너스는 "+N" 초록 |

## 3. 장비·물약·소지금

- 장비: 아이콘만. 등급 테두리 색. 마우스 오버로 이름·수치.
- 물약: 3칸. 최대 소지 수 = 소비 성향(절약 1 · 보통 2 · 낭비 3). 초과 칸은 잠금(지금은 🔒 임시, GPT 아이콘 교체 검토).
- 소지금: 머리 오른쪽에 금화 + 금액. 식사·물약·장비 구매에 씀.
- 다음 장비 진행: 장비 제목 옆 "다음 장비(E급) 640/1,800G".
  - 기준 = 장비 구매 규칙과 같음: 세트 가격(무기 가격 × 3) × (1 + 소비 성향 여유분 × 0.5).
  - E급 예: 900G × 절약 2 · 보통 1.5 · 낭비 1.15 → 1,800 · 1,350 · 1,035G.
  - 길드 등급 때문에 더 살 장비가 없으면 "길드 등급 상한".

## 4. 목록 줄의 상태 표시

| 상태 | 점 | 줄 배경 |
| --- | --- | --- |
| 길드에 있음 | 초록 | 기본 |
| 의뢰 중 | 파랑 | 옅은 파랑 |
| 부상 회복 | 빨강 | 분홍 |
| 마을 밖 | 회색 | 기본 |

- 전직 제안이 있으면(A+D): 금색 빛이 줄 테두리를 4초에 한 바퀴 돌고, 초상화 왼쪽 위에 금색 ★ 배지.

## 5. 목록 줄 마우스 오버 창

- 0.2초 머물면 목록 오른쪽에 뜸. 아래쪽 줄은 팝업 밖으로 넘치지 않게 위로 붙음.

| 상태 | 내용 |
| --- | --- |
| 길드에 있음 | 의뢰를 고르는 중 · 다음 등급 승급까지 Lv·업적 |
| 의뢰 중 | 의뢰 이름 + 해골 위험도 · 동료 · 귀환까지 주 |
| 부상 회복 | 회복까지 주 · 다친 의뢰 |
| 마을 밖 | 애착 단계 · 마지막 방문 |
| 전직 제안 | 위 내용 + "★ 전직 제안: 직업 / 직업" |
| 공통 아랫줄 | 주 능력치 · 공격 · 체력 / 오른쪽 끝 소지금 |

- 새 기록: `a.injuredFrom`(다친 의뢰), `a.lastSeen`(마을에 있던 마지막 주). 예전 저장에는 없으므로 다음 일이 생길 때부터 표시.

## 6. 아래 탭 (2026-11-05 확정)

- 스킬 · 전직 · 성향 · 경력. 항상 하나가 펼쳐져 있고 기본은 **스킬**.

**스킬**

| 항목 | 규칙 |
| --- | --- |
| 장착 칸 | **5칸** (설계서 7.4-1). 가진 스킬은 아이콘 + 이름, 나머지는 "빈 칸"(오버 안내 없음) |
| 아이콘 | 1차 5 + 2차 25 = 30종 (`skill_<str·agi·int·spi·dex>_<0~5>.png`, 계열 안 순서 = 스킬 표 순서). 3차는 아직 없어 그 계열 1차 아이콘을 씀 |
| 칸 테두리 | 계열 색: 힘 빨강 · 민첩 초록 · 지력 파랑 · 정신 금색 · 기교 보라 |
| 오버 창 | 이름 · 계열·직업 · 효과 · 계열 능력치 / **진화**: 발견한 직업만 "직업 → 진화 스킬", 모르는 직업은 "? 아직 모르는 직업" 한 줄 (초반엔 이것만) |

**전직**

- 발견한 직업만 표시("아직 모르는 직업 N개" 줄 없음).
- 조건은 능력치와 같은 10칸 칸 막대 + **빨간 세로선 = 필요치**. 채우면 숫자 초록 + "조건 충족".

**성향**

| 순서 | 표시 |
| --- | --- |
| 애착 (맨 위) | 애착 [단계] + 진행 바 + 수치 + 다음 단계, 아래 한 줄 설명 |
| 모험심 · 소비 · 사교 | 항목 이름 + [값 박스] + 행동 문장. **수치는 화면에 보이지 않음** (내부 규칙만) |

- "위험" 축의 화면 이름 = **모험심** (내부 이름 risk는 그대로).
- 말투 줄 삭제 (모험심·사교에서 자동으로 정해지고 말풍선 분위기만 바꿈).
- 애착 단계 이름: 방랑자 → **신입**(예전 길손) → 동반자 → 마을의 수호자.

| 값 | 문장 |
| --- | --- |
| 모험심 신중 / 보통 / 무모 | 승산이 확실한 의뢰만 고르고, 조금만 다쳐도 물약을 꺼냅니다. / 자기 실력에 맞는 의뢰를 고르고, 위험하면 물러설 줄 압니다. / 실력보다 높은 의뢰에도 겁 없이 뛰어들고, 쓰러지기 직전까지 버팁니다. |
| 소비 절약 / 보통 / 낭비 | 돈을 아껴 식사는 자주 거르고, 장비는 넉넉히 모인 뒤에야 삽니다. / 먹을 땐 먹고, 필요한 만큼만 씁니다. / 번 돈은 바로 쓰는 편이라 식당 단골이고, 물약도 가득 챙깁니다. |
| 사교 독불장군 / 보통 / 사교적 | 웬만해선 혼자 떠나고, 정말 어려운 의뢰에만 동료를 찾습니다. / 버거운 의뢰라 싶으면 동료를 모읍니다. / 쉬운 의뢰에도 함께 갈 동료부터 찾습니다. |
| 애착 4단계 | 아직 길드에 마음을 두지 않았습니다. 언제든 떠날 수 있습니다. / 길드에 정이 들기 시작했습니다. / 길드를 믿고 오래 머무르려 합니다. / 이 마을과 길드를 자기 집처럼 여깁니다. |

**경력**: 제목 옆에 의뢰 성공 횟수. 기록 항목 확장은 미결.

## 6-1. 미결 (리마인드)

- **스킬 전투 계산**: 발동 확률·마력·재사용 대기 등 세부 규칙은 나중에 결정. 장착 5칸이면 발동률 1단계 41% · 2단계 63% · 3단계 81%(마력·재사용 대기 제외)라 그때 함께 확인.
- **스킬 아이콘 간격 조절 페이지**: 최종 작업 때 사용자가 요청하면 만듦.
- **성향 공개 규칙**: 설계서 7절은 애착 단계에 따라 성향을 공개(방랑자: 선호 유형 / 신입: + 모험심 / 동반자: + 소비·사교)한다고 되어 있으나, 지금 팝업은 모두 보여 줌. 적용 여부 결정 필요.
- 경력 기록 항목(부상·첫 상위 등급 의뢰 등) 확장.
- 잠긴 물약 칸 🔒 임시 표시 → GPT 아이콘 교체 검토.

## 8. 파티 색 (2026-11-12 추가)

> 사용자 요청: "팝업에서 파티원들끼리 같은 색으로 카드 색이 바뀌었으면 좋겠어." 로비 발밑 원·원정 중 패널과 같은 색을 씀.

| 항목 | 규칙 |
| --- | --- |
| 대상 | 의뢰 중인 모험가 전원 (1인 의뢰 포함) |
| 색 | 6색 순환: 청록 `#1D9E75` · 호박 `#EF9F27` · 파랑 `#378ADD` · 보라 `#7F77DD` · 분홍 `#D4537E` · 초록 `#639922`. 동시에 있는 파티끼리는 남은 색부터. 주황은 부상 줄과, 초록은 청록과 헷갈려 순서 조정 |
| 배정 | `Director.partyColor(의뢰 id)` 한 곳에서 배정 → 로비 발밑 원 · 모험가 목록 · 원정 중 패널이 같은 색. 불러오기 직후처럼 색이 없는 진행 의뢰는 처음 그릴 때 배정 |
| 목록 카드 | 옅은 파티 색 배경(17%) + 진한 테두리. 선택 줄은 금빛 고리 추가. 아래 글씨(직업 · 상태)도 파티 색 |
| 목록 순서 | 의뢰 중인 파티를 의뢰 순서대로 위에 묶음 → 나머지는 예전 순서(전직 단계 · Lv) |
| 원정 중 패널 | 줄 왼쪽 파티 색 세로 띠(5px) + 등급 배지 테두리 |
| 남은 0주 | 상세 머리 태그·오버 창: "의뢰 중 0주" → "의뢰 중 · 이번 주 귀환" |

- 표시만 바뀜. 관문 1 변화 없음 (게임 474G·94.8% / 시뮬 480G·94.1%).
- 남은 생각: 미니 뷰 안에도 파티 색을 쓸지, 상세 머리에 파티원 표시를 넣을지는 모험가 팝업 다음 개선 때.
