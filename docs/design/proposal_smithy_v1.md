## 요약
- **추천: 1단계는 "진열대(보기) + 마스터 선물" 두 가지만 만듭니다.** 길드 돈이 저절로 들어오거나 나가는 규칙이 없어 동결된 경제 수치(관문 1: 559G · 95.6%)를 건드리지 않고, 플레이어가 대장간에서 직접 할 일이 생깁니다.
- 이유 ① **지금 장비는 게임에 거의 영향이 없습니다.** 장비를 가진 모험가는 48주 차에 19%뿐이고, 장비값을 20~30% 깎거나 대장간 전 구매를 막아도 순이익 · 성공률 · 승급이 그대로였습니다(2장). 그래서 할인 · 구매 제한만으로는 대장간이 "있으나 마나"가 됩니다.
- 이유 ② **대장간이 너무 늦게 열립니다.** 100판 중 48주 안에 열린 판은 21판(중앙 59주)입니다. 조건(기술 42)을 낮춰도 23~28판이라 조건보다 납품(1차 소재 15개 → 2차 1,000G) 단계가 더 큰 벽입니다(3장).
- 이유 ③ 강화 · 소재 납품은 각각 "프로토타입 뒤로" 결정과 경제 검토(시니어 기획자)에 걸려 있어 2단계로 둡니다.
- **정하실 것 4가지:** ① 1단계 범위(추천 A+B) ② 선물 애착도 수치 ③ 해금 시점 앞당기기 여부 ④ 강화(C) · 납품(D)을 경제 검토 뒤로 미루는 것 동의 여부 (7장).

| 항목 | 지금 |

## 2. 장비 규칙만 바꿨을 때 (100판 · 48주)
| 안 | 순이익 | 성공률 | 장비 보유 24주 · 48주 | 승급 중앙 · 48주 안 |
| --- | ---: | ---: | --- | --- |
| 0 지금 | 559G | 95.6% | 22% · 19% | 40주 · 76판 |
| 대장간 생기면 장비 −20% | 559G | 95.5% | 22% · 19% | 40주 · 76판 |
| 대장간 처음부터 + −20% | 554G | 95.4% | 23% · 21% | 40주 · 74판 |
| 대장간 처음부터 + −30% | 558G | 95.4% | 24% · 23% | 39주 · 74판 |
| 대장간 없으면 F급까지만 | 559G | 95.6% | 22% · 19% | 40주 · 76판 |

- 결론: **할인 · 구매 제한은 숫자를 거의 안 움직입니다.** 모험가가 이길 의뢰만 고르기 때문에(늦장 실패 제안서 1장과 같은 이유) 장비가 성공률에 주는 차이도 작습니다.
- 장비가 의미 있어지려면 장비값 · 모험가 수입 쪽을 바꿔야 하고, 그건 **경제 검토(시니어 기획자) 범위**입니다.

## 3. 해금 시점 (100판 · 96주, 자동 플레이 기준)
| 조건 | 처음 맞는 주(중앙) | 48주 안 |
| --- | ---: | ---: |
| 인구 220 | 28주 | 93판 |
| 모험가 6명 | 21주 | 93판 |
| 명성 50 | 37주 | 85판 |
| **기술 42 이상 모험가** | **48주** | **51판** |
| 넷 다 | 50주 | 48판 |
| **실제 해금(납품 끝)** | **59주** | **21판** |

| 조건을 바꾸면 | 해금 중앙 | 48주 안 |
| --- | ---: | ---: |
| 지금 | 59주 | 21판 |
| 기술 42 → 38 | 56주 | 23판 |
| 기술 42 → 35 | 55주 | 28판 |
| 인구 180 · 명성 30 · 모험가 5 (기술 없음) | 51주 | 47판 |
| 조건 없음 | 49주 | 46판 |

- 조건을 다 없애도 48주 안 46판입니다. **자동 플레이는 조건이 맞은 뒤 소재 · 금을 모으는 데 오래 걸립니다.** 직접 하는 플레이어는 더 빠를 수 있어 이 숫자는 상한이 아니라 참고값입니다.
- 대장간을 1년 안에 대부분 보게 하려면 조건 완화 + 납품 소재 줄이기(예: 고철 10 → 5)를 같이 봐야 합니다. 2차 금액(1,000G)은 경제 수치라 그대로 둡니다.

## 4. 대장간이 할 일 후보
| 안 | 내용 | 경제 영향 | 기존 결정과 충돌 | 만들 양 |
| --- | --- | --- | --- | --- |
| **A 진열대** | 지금 살 수 있는 장비(등급 · 값)와 이번 달 누가 샀는지 보여 줌. 구매 규칙은 그대로 | 없음 | 없음 | 작음 |
| **B 마스터 선물** | 길드 금으로 장비를 사서 모험가에게 줌 → 장비 등급 +1, 애착도 상승(v2: F 1 · E 2, 같은 등급 0) | **있음 (플레이어가 고를 때만)** — 길드 금 사용처가 생김 | 없음 (v2 04 "선물" 규칙) | 중간 |
| C 강화 +1~+3 | 실패 없는 구간만. 비용 = 상점가 10% + 소재 | 있음 (금 + 소재 사용처) | **있음** — 11-16 "장비 묶음은 프로토타입 뒤로" | 큼 (장비가 지금 등급 숫자 하나뿐이라 강화 칸을 새로 만들어야 함) |
| D 소재 납품 → 진열 등급 | 길드가 소재를 대 주면 그 등급까지 진열 (v2 05 판매대 효과 2와 연결) | **있음** — 되팔기 수입(월 55G)과 경쟁 | 없음 | 중간 |

### 추천: 1단계 = A + B
- **A**는 대장간을 "들어가 볼 곳"으로 만들고, 장비가 왜 안 팔리는지(소지금 부족)도 화면에서 보이게 합니다.
- **B**는 플레이어가 직접 하는 일입니다. 연말 길드 금이 평균 3,409G로 쌓여 있어 쓸 곳이 생기는 효과도 있습니다. 쓰지 않으면 관문 1은 그대로입니다(자동 플레이는 선물하지 않게 둠).
- C · D는 경제 검토 결과를 받은 뒤 2단계로 정합니다.

## 5. 화면 스케치 (1단계)
마을 지도에서 대장간을 누르면 다른 시설 창과 같은 크기의 창이 뜹니다.

```
┌ 대장간 ───────────────────────────────────────── ✕ ┐
│ [대장장이 초상화]  "쇠는 거짓말을 안 하지. 뭘 보러 왔나?"  │
│ ─────────────────────────────────────────────── │
│  [진열대]  [선물]  [강화 🔒 준비 중]                    │
│                                                   │
│  진열대                                            │
│   F급 장비 한 벌   450G   ← 길드 등급까지만 진열        │
│   E급 장비 한 벌   900G   (길드 E급부터)              │
│                                                   │
│  이번 달 손님                                       │
│   · 레온  F급 구입                                   │
│   · 미아  "조금만 더 모으면…" (소지금 부족)             │
└───────────────────────────────────────────────────┘
```
```
│  선물  (길드 금 1,240G)                              │
│   모험가        지금 장비   선물하면     값      애착   │
│   레온 (전사)    F          E          900G    +2    │
│   미아 (궁수)    없음        F          450G    +1    │
│   [선물하기]  → 확인 → 대장장이 한마디 + 모험가 반응     │
```
- 정수 원칙: 확률 · 소수점은 보이지 않습니다. 애착 변화는 정수로만.
- 모험가 반응은 말투 5종 대사로(침공 대사와 같은 방식), 1단계는 종류별 1줄씩.
- 대장간이 없을 때는 지금처럼 "리퀘스트를 들어주면 지어집니다"만 보이고 창은 열리지 않습니다.

## 7. 정하실 것
1. **1단계 범위:** A+B (추천) / A만 / A+B+D
2. **선물 애착도:** v2 그대로(F 1 · E 2, 같은 등급 0) / 더 크게(F 3 · E 5)
   - v2 수치면 F급 450G에 애착 1이라 체감이 약할 수 있습니다.
3. **해금 시점:** 그대로 / 조건 완화(인구 180 · 명성 30 · 모험가 5, 기술 조건 없음) / 조건 완화 + 고철 10 → 5
   - 2차 금액 1,000G는 경제 수치라 바꾸지 않습니다.
4. **강화(C) · 납품(D)** 을 경제 검토 뒤 2단계로 미루는 데 동의하시는지

## 8. 경제 검토에 넘길 질문
- 모험가 소지금(평균 211~324G)이 F급 장비 구매선(518~900G)보다 낮아 장비 시스템이 거의 작동하지 않습니다. 장비값 · 모험가 수입 중 어느 쪽을 움직일지.
- 장비 구매 대금(한 판 1,881G)이 지금은 마을로 사라집니다. 대장간이 생기면 길드가 일부를 받을지(받으면 순이익이 오름).
- 소재 납품(D)이 되팔기(월 55G)를 대신할 때 길드가 얻는 보상을 무엇으로 줄지.
