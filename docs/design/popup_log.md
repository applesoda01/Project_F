## 0. 요약

| 영역 | 예전 | 바뀜 |
| --- | --- | --- |
| 모양 | 글 한 줄씩 쌓이는 목록, 날짜 "2/4/1" | **월 카드** (머리 = 그 달 결산) + 줄마다 [종류 아이콘] [주차] [글] |
| 종류 | 색 3가지 (성공·실패/경고·성장) | 아이콘 12종, 사망·부상·떠남·의뢰 철회를 따로 나눔 |
| 필터 | 없음 | 전체 · 의뢰 · 모험가 · 길드 · 중요 (칩마다 개수) |
| 글 | 퀘스트는 "F급 토벌 의뢰" | 편집기에서 지은 퀘스트 이름(파랑), 모험가 이름 굵게 |
| 정리 | 같은 주 레벨업 여러 줄, 건설비 부족·디버그 줄도 기록 | 레벨업 한 줄로 합침(Lv 1 → 3), 버튼 반응·디버그는 기록에서 숨김 |
| 보관 | 200개 (약 9개월), 화면 120개 | 600개 (약 2년), 전부 표시 |

## 1. 화면

| 영역 | 내용 |
| --- | --- |
| 필터 줄 | 위에 고정. 칩: 전체 · 의뢰 · 모험가 · 길드 · 중요. 고른 칩은 갈색 |
| 목록 | 필터 아래만 스크롤 (다시 그려도 위치 유지, 필터를 바꾸면 맨 위로) |
| 월 카드 머리 | "2년차 3월" · 순이익 ±nG(음수 빨강) · 의뢰 n건 · 성공 n건. 이번 달은 "진행 중" |
| 줄 | [아이콘 원] [n주] [글]. 모험가 이름 굵게, 퀘스트 이름 파랑 |

## 3. 기록 데이터

| 항목 | 내용 |
| --- | --- |
| `log(s, text, kind, extra)` | extra를 기록에 합침 |
| `who` | 기록에 나오는 모험가 이름 목록 → 화면에서 굵게 (예전 저장의 기록은 없음) |
| `lvAdv`·`lvFrom`·`lvTo` | 같은 주 같은 모험가의 레벨업을 한 줄로 합칠 때 씀 |
| `done` | 실제 전직 (중요 필터) |
| `net`·`nq`·`nok` | 월 결산 (순이익·의뢰 수·성공 수). 결산 기록의 주 − 1이 속한 달의 머리 |
| `qn(q)` | 퀘스트 이름: 편집기 이름이 있으면 `F급 「이름」`(「」는 화면에서 파랑), 기본 이름(○○ F급 의뢰)이면 `F급 토벌` |
