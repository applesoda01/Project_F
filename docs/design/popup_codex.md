## 0. 요약

| 영역 | 예전 | 바뀜 |
| --- | --- | --- |
| 내용 | 탭 5개만 있고 "0 / 0 · 아직 등록된 항목이 없습니다" | 탭마다 **모든 항목을 아이콘 칸으로** 배치 |
| 탭 | 몬스터 · 소재·아이템 · 모험가 · 요리 · 장비 | 몬스터 · 소재·아이템 · **직업** · 요리 · 장비 |
| 몬스터 | 만남 기록 없음 | `s.seenMons` 추가: 의뢰를 다녀오면(성공·실패) 그 의뢰의 몬스터 등록 + 길드 기록 "처음 보는 몬스터를 만났습니다" |

## 1. 화면

| 영역 | 내용 |
| --- | --- |
| 탭 | 위 고정 |
| 머리 | "○○ 도감" · n / 전체 발견 · 진행 막대 |
| 목록 | 등급 줄(F~S)마다 [등급 배지] + 아이콘 칸. 목록만 스크롤 |
| 칸 | 68px, 간격 12px (식당 보관함·스킬 칸과 같음). 칸 아래 이름 |
| 모르는 항목 | 실루엣 + ?, 이름 ???. 아이콘이 없는 항목은 ?만 (이름 앞 글자를 보여 주지 않음) |
| 아는 항목 | 마우스를 올리면 오버 창 (다른 팝업과 같은 창) |

## 2. 탭별

| 탭 | 칸 | 발견 기준 | 오버 창 |

| 몬스터 | 7종 (도트 그림) | 그 몬스터가 나오는 의뢰를 한 번 다녀오면 | 그림·종류·등급 / 체력·공격력 / 오버 메모 / 처음 만난 날 |
