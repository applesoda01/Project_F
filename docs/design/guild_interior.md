### 2-1. 업그레이드 (확정)

> 2026-11-12: 프로토타입에서는 업그레이드 없음(사서 놓으면 Lv1 효과). 레벨 대신 **교체 방식**을 검토 중 → 프로토타입 이후.

| 항목 | 내용 |
| --- | --- |
| 방식 | 장식(테이블 포함)을 클릭하면 **레벨 막대 + 업그레이드 버튼**. 그림은 바뀌지 않음 |
| 효과 | 레벨마다 Lv1 효과만큼 더함 (화분 Lv5 = 애착 +25%) |
| 비용 | Lv n → n+1 = 장식 가격 × n (Lv5까지 합계 = 가격 × 11) |
| 최대 레벨 | **길드 등급으로 제한**: F Lv2 · E Lv3 · D Lv4 · C 이상 Lv5 |
| 소재 | **Lv4 이상 업그레이드에만 소재 필요** (프로토타입 F·E는 최대 Lv3이라 영향 없음). 음식이 아닌 소재의 쓰임새 |

F·E 14종을 모두 Lv5까지 올리는 비용 약 84,000G → 후반 돈 과잉의 주된 소비처.

### 2-2. 2배 보상 의뢰 (확정 2026-11-10, 수치는 가안)

| 항목 | 내용 |
| --- | --- |
| 발생 | 의뢰가 게시될 때마다 확률로 "×2" 의뢰가 됨. 의뢰 카드에 ×2 표식 |
| 기본 확률 | **5%** |
| 올리는 방법 | **트로피 장식장** 레벨당 +3%p (장식 1종 = 효과 1개 원칙) |
| 상한 | **합계 20%** (트로피 Lv5 = 5 + 15 = 20%) |
| 등급별 | F Lv2 11% · E Lv3 14% · D Lv4 17% · C 이상 Lv5 20% |
| 적용 보상 | **골드만 2배** (명성·경험치는 그대로) |
| 이유 | 효과 하나로 상한까지 채워 단순하게, 명성까지 2배면 진행이 너무 빨라짐 |

- 이 변경으로 **트로피 장식장의 "의뢰 보상 +3%"는 의뢰인 대기 벤치로 옮김**. 벤치의 "게시 의뢰 수 +5%"는 없앰 (주당 0.125건이라 체감이 없고, 신뢰도가 이미 의뢰 수를 30~120%로 조절하며, 보조금과 얽혀 균형 변수만 늘어남).
- 경제 시뮬레이션에서 2배 보상의 기대 수입(11% 확률 = 기대 +11%)과 수치를 다시 확인할 것.

## 3. 테이블 세트

| 항목 | 가안 |
| --- | --- |
| 1세트 | 테이블 1 + 의자 2 = **2석** |
| 자리 | 1층 6칸 |
| 시작 | 2세트 (4석) |
| 추가 | 3·4번째 각 200G (F급부터) · 5·6번째 각 300G (E급부터) |
| 효과 | **업그레이드 막대**(2-1과 같은 규칙, 기준 가격 200G): 레벨마다 **음식 가격 +5%**, 모든 세트에 함께 적용 |
| 앉지 않은 모험가 | 서서 기다림. 불이익 없음, 주점 수입 그대로 |
| 음식 주문 | **앉은 모험가만** → 식사 수입·식사 효과는 좌석 수만큼 |

**필요 좌석 (1년 차 시뮬레이션 기준)**

| 시점 | 모험가 | 마을에 있는 인원 | 필요 |
| --- | --- | --- | --- |
| 시작 | 2명 | 1~2명 | 2세트 |
| 반년 | 4~5명 | 2~3명 | 2세트 |
| 1년 (F 상한) | 8명 | 4~5명 | 3세트 |
| E급 (상한 12) | 12명 | 6~8명 | 4~5세트 |

**보이는 흐름 (최종 목표)**: 빈자리에 앉기 → 주문 → 테이블에 요리가 놓임 → 먹는 모습 → 일어나 의뢰로 출발. 지금도 식사는 출발 전이라 흐름이 그대로 이어짐.
