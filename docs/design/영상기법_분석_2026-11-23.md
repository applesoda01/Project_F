# 참고 영상 기법 분석 — 일러스트 이야기 영상 (92초)

> 작성: Claude · 2026-11-23 · 사용자 요청 "이 영상 기법 분석해줘. 우리가 제작할 수 있는지도 고민이야"
> 방법: 1초 1장(92장) · 장면 전환 구간은 1초 6~8장으로 뽑아 봄. 원본 영상 · 장면 그림은 저장소에 올리지 않음(공개 저장소 · 저작권).

## 한 줄 요약

**움직이는 영상이 아니라, 세피아 톤 「한 장 그림」 약 8장을 레이어로 나눠 카메라가 천천히 밀고 들어가며(2.5D 패럴랙스) 불꽃 · 파편 · 빛 효과를 얹은 이야기 영상.** 캐릭터가 거의 움직이지 않아서 우리도 만들 수 있는 계열입니다.

## 쓰인 기법

| # | 기법 | 어디서 | 설명 |
| ---: | --- | --- | --- |
| 1 | **세피아 한 가지 톤** | 전체 | 모든 그림을 갈색 · 금색 한 계열로 → 다른 그림들도 한 권의 책처럼 묶임 |
| 2 | **잉크 선 + 수채 · 양피지 질감** | 전체 | 펜 선이 살아 있는 일러스트 위에 종이 얼룩 · 번짐을 곱해 겹침 |
| 3 | **2.5D 패럴랙스** | 파편 장면 · 인물 장면 | 그림을 배경 · 인물 · 앞쪽 파편으로 나눠, 카메라가 밀고 들어갈 때 앞 레이어가 더 빨리 움직임 → 깊이감 |
| 4 | **느린 밀어 넣기(줌) · 흐르기** | 모든 컷 | 컷마다 1~3% 정도 천천히 확대 · 이동. 정지 그림이 「살아 있는」 느낌 |
| 5 | **입자 효과** | 탑 장면 · 불꽃 인물 | 불티 · 불꽃 · 먼지 · 떠다니는 돌 조각이 그림 위에서 따로 움직임 |
| 6 | **흰 섬광 전환** | 7초 | 화면이 하얗게 터졌다가 다음 컷 — 사건(폭발)과 장면 전환을 겸함 |
| 7 | **선 그림 → 빛으로 드러남** | 44~47초 | 연한 선으로만 그려진 천사 날개가 금빛으로 타오르며 나타남 (마스크로 그려 넣는 연출) |
| 8 | **눈 빛남** | 68~76초 | 인물 그림은 그대로 두고 눈만 빛을 켬 — 적은 손으로 큰 인상 |
| 9 | **책장 넘김 전환 + 모션 블러** | 77~79초 | 손글씨 일지 페이지가 빠르게 넘어가며 흐려지고 검게 끝남 → 「이 이야기는 기록이다」 |
| 10 | **자막 + 낭독 + 음악** | 전체 | 한 문장씩 짧게, 그림이 바뀌기 전에 자막이 먼저 바뀌기도 함 |

## 우리가 만들 수 있나 — 결론: **만들 수 있음 (무료 도구만으로)**

| 필요한 것 | 우리 방법 | 난이도 |
| --- | --- | --- |
| 세피아 일러스트 8장 | ComfyUI(Illustrious) — 잉크 선 · 세피아 스타일로 생성. 레이어용으로 배경 · 인물 · 파편을 **따로** 생성하거나, 한 장을 생성해 배경 제거(rembg)로 나눔 | 중 (스타일 통일이 관건 — 같은 시드 · 같은 프롬프트 꼬리말 · 색은 후처리로 맞춤) |
| 패럴랙스 · 줌 · 섬광 · 입자 · 빛 드러남 · 책장 넘김 | **게임 안에서 직접 재생**(HTML 캔버스) — 그림 몇 장 + 움직임 표만 있으면 됨 | 중 (재생기 하나를 한 번 만들면 이후 컷은 표만 추가) |
| 질감 · 세피아 통일 | 양피지 질감 한 장을 곱하기로 겹치고, 색은 CSS 필터 · 캔버스로 통일 | 하 |
| 자막 | 지금 대화 시스템 글꼴 그대로 | 하 |
| 낭독 | 무료 TTS는 품질이 아쉬움 → **낭독 없이 자막 + 음악** 추천 | — |

**좋은 점**
- 지금 프롤로그는 동영상(63MB, 품질 점수 F 용량 −10의 원인). 같은 방식으로 게임 안에서 그림 + 움직임으로 재생하면 **그림 8장 ≈ 3~5MB**로 줄어듦.
- 한 번 재생기를 만들면 메인 퀘스트 · 던전 정복 · 계절 이야기 같은 장면을 그림만 바꿔 계속 쓸 수 있음.

**어려운 점**
- 8장의 그림 톤 · 선을 한 사람이 그린 것처럼 맞추는 것 (생성 뒤 손질 필요).
- 7번(선 → 빛으로 드러남)은 그림마다 「빛날 부분」 마스크를 따로 만들어야 함.

## 제작 순서 제안 (시험 1컷부터)

1. 시험 1컷(약 8초): 그림 1장을 3레이어로 나눠 줌 + 패럴랙스 + 불티 입자 + 양피지 질감 → 1280 · 1920으로 보여 드림
2. 괜찮으면 재생기를 정식으로 만들고 「움직임 표」 형식을 정함
3. 프롤로그 콘티(8컷) → 그림 생성 → 조립

ComfyUI 생성은 할 때마다 무엇을 · 어떻게 · 몇 분 걸리는지 먼저 알려 드리고 「진행해줘」를 받은 뒤 함.
