## 공통 (2026-11-09)

- **아이템 칸 숫자**: 개수 = 칸 **오른쪽 아래**(흰 글자 + 갈색 외곽선, 0개는 표시 안 함), 강화 = **오른쪽 위** `+n` 배지(+1~4 갈색 · +5~9 금색 · +10 이상 붉은색). 공통 부품 `ui_kit.css` `.ux-cnt`·`.ux-enh`, `ui.js` `cntBadge`·`enhBadge`. 쓰는 곳: 판매 창구·식당 보관함·모험가 장비 칸(강화는 `a.enh[장비 종류]`가 생기면 보임, 강화 시스템은 아직 없음).

- **오버 창**: 소재(식당 보관함·조리대·메뉴판 재료) = 소재 설명 · 장비/물약(모험가) · 요리(메뉴판) · 퀘스트(게시판 오버 창 메모 칸) = 편집기 '오버 메모'. 몬스터는 도감에서. 게시판의 소재는 이름만(A안).
