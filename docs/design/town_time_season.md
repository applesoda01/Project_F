# 마을 배경 시간대 · 계절 · 움직임 (시범, 2026-11-10)

> 한 줄 요약: 마을 지면판 **plate20(한 단계)** 에 계절 3종(가을·겨울·비)을 만들고, 시간대 색 보정·입자·구름/새·식물 흔들림·강물 흐름을 데모로 확정했습니다. 다른 성장 단계 판은 일반(여름) 판을 그대로 씁니다. 로비 코드 연동은 보류입니다.

## 1. 범위 결정

- 프로토타입이라 단계별(plate0, plate20, s1~s5) 계절 판 18장은 만들지 않고, **plate20 한 단계로 방식을 검증**했습니다. 같은 틀로 나중에 추가할 수 있습니다.
- plate20~s5의 외곽 풍경(산·나무·강·호수)은 거의 같아서, 이후 확장 시 같은 프롬프트와 흔들림 맵을 그대로 쓸 수 있습니다. plate0만 외곽이 달라 문구를 보강해야 합니다.

## 2. 계절 판 (Gemini 편집)

- 입력은 `plate20.jpg`, 16:9, 같은 구도 유지(도로·울타리·9개 잔디판·강·산 실루엣), 건물·사람·글자 금지.
- 계절 문구: 가을(황금빛 잔디·주황/적/노랑 잎·길 위 낙엽), 겨울(얇은 눈·앙상한 나무·가장자리 얼음·푸른 안개), 비(진한 초록·젖은 길과 웅덩이·흐린 하늘, 빗줄기는 그리지 않음).
- 정합 검사: 원본과 가장자리 상관으로 비교해 오프셋 **가을 0/-2px, 겨울 0/0px, 비 0/-2px** (1920×1080 기준).
- 워터마크(오른쪽 아래 별 모양)는 별 모양 마스크 + 주변 평균 채움 + 입자 노이즈로 제거했습니다.

## 3. 시간대 · 입자 · 하늘

- 시간대 색 보정은 길드와 같은 값: 아침 (0.99, 0.95, 0.84), 낮 원본, 노을 (1.00, 0.74, 0.60), 저녁 (0.46, 0.48, 0.74), 비는 ×0.9. 1달 = 4주, 1주 ≈ 30초.
- 입자(기본 40%): 가을 낙엽, 겨울 눈결정, 비 줄기 + 웅덩이 파문. **일반 배경에는 나뭇잎 없음.** 마을에는 실내가 없어 화면 전체에 뿌립니다.
- 구름·새: 게임 코드 `prototype/js/town.js`의 구름 4종과 비둘기 무리 동작을 그대로 사용하고, **일반 배경의 아침·낮·노을에만** 보입니다. 저녁으로 넘어갈 때 서서히 사라지고, 노을 색은 같이 곱합니다. 별은 넣지 않았습니다.

## 4. 식물 흔들림 · 강물 흐름

- 흔들림 맵 `sway_town_plate20.png`: R = 식물(나무·덤불, 줄기 아래는 고정하고 위로 갈수록 크게), G = 강, B = 강 중심선(한가운데 1, 기슭 0). 일반 판에서 색으로 자동 분리해 만들었고, 계절 4종이 같은 맵을 공유합니다.
- 식물: 길드와 같은 방식(3.5px, 속도 1.0). 겨울은 ×0.6, 비는 ×1.3.
- 강: 처음 만든 규칙적인 줄무늬는 컨베이어 벨트처럼 보여서, **노이즈 기반으로 길쭉하고 서서히 생겼다 사라지는 결**로 교체했습니다. 한가운데는 빠르게, 가장자리는 느리게 흐르고, 왼쪽 강은 오른쪽 아래로, 오른쪽 강은 왼쪽 아래로 흐릅니다. 겨울 ×0.35, 비 ×1.2.
- 건물은 별도 스프라이트 레이어입니다. 게임에서는 같은 색 보정을 건물에도 적용해야 하고, 굴뚝 연기·깃발 같은 건물 움직임은 건물 단계에서 정합니다.
