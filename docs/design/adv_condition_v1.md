# 모험가 몸 상태 설계 v1: 배고픔 · 피로도 (제안)

> 작성: Claude, 2026-11-13 · 상태: **제안 (결정 전, 코드 반영 안 함)** — 화면 자리만 책 조절 도구(`prototype/tools/book_layout_editor.html` 모험가 장)에 견본 값으로 잡아 둠
> 출발점: 사용자 요청 (2026-11-13) "배고픔과 피로도도 있어야 할 듯" · 지금 게임의 몸 상태는 **건강 / 부상(회복 N주)** 두 가지뿐

## 요약
- **배고픔:** 매주 조금씩 쌓이고, **주점에서 식사하면 크게 풀림**. 높으면 능력치가 조금 떨어짐 → 식당 운영 · 테이블 수(좌석)에 의미가 생김.
- **피로도:** **의뢰를 다녀오면 쌓이고, 길드 · 마을에서 쉬면 풀림**. 너무 높으면 의뢰를 고르지 않고 쉼 → 모험가를 무리하게 돌리지 못하게 함.
- 둘 다 0~100 정수, 3단계 (2026-11-13 결정). 화면은 명부 줄의 아이콘 + 단계 이름(배고픔 · 피로)과 성향 쪽지의 막대.
- 관문 1에 영향이 있으므로 숫자를 정한 뒤 게임 · 시뮬레이터 같이 넣고 다시 검증해야 함.

## 2. 배고픔 (0~100)

| 상황 | 변화 (매주) |
| --- | ---: |
| 의뢰 중 | +18 |
| 길드에 있음 · 마을 밖 | +8 |
| 부상 회복 중 | +6 |
| **주점 식사** (출발 전, 지금 규칙 그대로) | **−60** |
| 길드에 있을 때 식사 (새 규칙 선택: 같은 성향 확률, 같은 좌석 수) | −40 |

| 단계 | 범위 | 아이콘 | 효과 |
| --- | --- | --- | --- |
| 배부름 | 0~39 | 고기 + "배부름" | 없음 |
| 출출함 | 40~69 | 고기 + "출출함" | 능력치 −5% |
| 굶주림 | 70~100 | 고기 + "굶주림" | 능력치 −10% · 의뢰 성공 때 애착 증가 절반 |

- 절약 성향은 식사를 자주 걸러서 출출함 · 굶주림이 잦음 → 성향 문장("식사를 자주 거름")이 실제 효과로 보임.
- 좌석이 모자라면 먹지 못함 → **테이블 세트를 놓는 이유**가 생김.

## 3. 피로도 (0~100)

| 상황 | 변화 (매주) |
| --- | ---: |
| 의뢰 중 (비전투) | +15 |
| 의뢰 중 (전투) | +20 |
| 길드에 있음 | −20 |
| 마을 밖 | −12 |
| 부상 회복 중 | −15 |
| 술 1잔 (지금 규칙 그대로) | −10 |

| 단계 | 범위 | 아이콘 | 효과 |
| --- | --- | --- | --- |
| 활기 | 0~39 | 달 + "활기" | 없음 |
| 피곤함 | 40~69 | 달 + "피곤함" | 능력치 −5% |
| 지침 | 70~100 | 달 + "지침" | 능력치 −10% · **의뢰를 고르지 않고 쉼** (40 아래로 내려오면 다시 고름) |

- 예: 2주 전투 의뢰 = +40 → 피곤함. 돌아와서 마을 밖 2주 = −24 → 활기 근처. 쉬지 않고 연달아 나가면 지침.
- 나중에 숙소 · 휴게 시설이 생기면 "피로 회복 +N"으로 연결.

## 4. 화면 (2026-11-13 결정)
- **명부 줄:** `🌿  🍖 출출함  💤 피곤함` — 건강은 아이콘만(잎 = 건강 / 붕대 = 부상), **배고픔 · 피로는 아이콘 1개 + 단계 이름을 바로 표시**(애착처럼, 막대 없음). 단계 글자 색: 첫 단계 갈색 · 둘째 주황 · 셋째 붉은색.
- **아이콘 4개**(잎 · 붕대 · 뼈 붙은 고기 · 졸린 달)는 Gemini로 게임 아이콘 화풍에 맞춰 생성 (`archive/art_source/status_icons/`).
- **성향 쪽지:** 배고픔 · 피로 각각 아이콘 + 단계 이름 + 막대.
- **로비 (선택):** 굶주림 · 지침인 모험가 머리 위에 작은 말풍선 아이콘.
- 견본 화면은 조절 도구 모험가 장에서 확인 (값은 임의 견본).

## 5. 관문 1 영향 (어림)
- 의뢰 중 비율이 약 1/3이고 의뢰가 1~2주라, 대부분의 모험가는 활기 ~ 피곤함 사이를 오감. 능력치 −5%가 붙는 시간이 늘어 **성공률 −1 ~ −3%p** 정도로 예상 (지금 94.5%가 상한 95% 근처라 오히려 여유가 생김).
- 지침으로 쉬는 모험가가 생기면 처리하는 의뢰 수가 줄어 **수입이 조금 감소**할 수 있음 → 숫자를 정한 뒤 게임 · 시뮬레이터 같이 넣고 100판 측정.

## 6. 결정이 필요한 것
1. 배고픔 · 피로 변화 숫자 (2장 · 3장 표)
2. 단계 효과: 능력치 −5% / −10%, 지침 = 의뢰 쉼, 굶주림 = 애착 증가 절반
3. 길드에 있을 때도 식사하는 새 규칙을 넣을지 (2장 마지막 줄)
4. 로비 말풍선 아이콘을 넣을지
