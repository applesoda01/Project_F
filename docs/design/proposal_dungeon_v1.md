## 요약

- **던전 = 길드가 스스로 정하는 긴 목표.** 누가 부탁해서 가는 게시판 의뢰 · 리퀘스트와 달리, 길드가 발주하고 여러 번 보내 **정복 수치 100%** 를 채웁니다.
- **추천 조합 (정할 것 5가지):** ① 정복 수치는 **승산이 낮은 파티로 이길수록 많이** 오름 ② 보낼 때마다 **그 던전 소재**, 다 깨면 **해금 보상** ③ **보호 구간이 끝나는 12주**에 첫 던전 ④ 프로토타입은 **한 번에 하나** ⑤ 클리어 뒤 **정복지로 남아 소재를 계속** 줌.
- **사용자 결정 (11-20):** 보상은 **전부** 넣음 — 던전 소재 · **세트 장비 조합법** · **레어 장신구 1개**(죽거나 떠나면 잃음) · 요리 조합법 · 칭호. 원정 중 **갈림길**(안 고르면 대장 성향대로). 원정은 **후퇴선에 닿으면 귀환**, 방 3개 뒤 「계속 / 귀환」 갈림길. **모든 기능은 켬/끔 스위치로** (별로면 끔). → 6 · 7 · 8장
- **이 조합이 푸는 문제 3가지 (측정 근거 있음):**
  1. 길드 발주는 "한 번 하고 끝" (V4 소재 시장 1장 표) → 정복지가 **원할 때 원하는 소재를 모으는 곳**이 됩니다.
  2. 실제로 떠나는 원정의 **99%가 「여유」** (11-20 야간 0단계 측정) → 승산이 낮을수록 정복이 더 오르면, 마스터가 일부러 **「팽팽」 파티를 보낼 이유**가 생깁니다. 버릇 장점(공격 · 체력)도 그때 보입니다(「팽팽」에서 승산 +12%p, 제안서 3장).
  3. 리퀘스트가 일반 의뢰와 비슷하게 느껴짐 (사용자 · 선배 진단) → 던전은 **진행 막대가 있는 길드의 목표**라 성격이 다릅니다.

## 2. 정할 것 5가지 (Claude 추천은 ★)

### ① 정복 수치가 오르는 양

| 안 | 규칙 [임시] | 좋은 점 | 걱정 |
| --- | --- | --- | --- |
| A | 성공하면 +20%p (5번이면 클리어), 실패 0 | 가장 단순 | 센 파티만 보내면 끝 → 지금과 같은 「여유」 원정 |
| ★ B | 성공하면 **승산 칩에 따라** 여유 +15 · 팽팽 +30 · 위험 +45%p, 실패해도 +5(정찰) | 약한 파티로 이기면 빨리 깸 → 「팽팽」 장면이 생김 · 버릇 장점이 보임 | 부상 · 사망이 늘 수 있음 → 보호 구간 뒤에만 열기(③) |
| C | 처치한 적 수만큼 (적 1마리 = +4%p) | 전투 기록과 바로 이어짐 | 비전투(탐사) 층은 따로 정해야 함 |

- B는 이미 있는 승산 칩(여유 70% 이상 · 팽팽 40~69% · 위험 40% 미만)을 그대로 씁니다. 새 판정이 필요 없습니다.

### ② 얻는 것

| 안 | 내용 | 경제 영향 |
| --- | --- | --- |
| A | 보낼 때마다 **그 던전 소재** (예: 「고블린 굴」 = 고블린 소재 · 광석) | 소재 공급이 늘어남 → 시세(결정 36)와 함께 봐야 함 |
| B | 다 깨면 **해금 보상** (시설 · 새 리퀘스트 · 명성) | 한 번뿐이라 작음 |
| C | 다 깨면 **다음 던전(새 지역)** | 콘텐츠가 더 필요함 |
| ★ | **A + B** — 과정 보상은 소재, 끝 보상은 해금 | 소재 양은 선배님 경제 검토 뒤 (칸만 둠) |

- **→ 11-20 사용자 결정: 「전부 한다」.** 소재 + 세트 조합법(50%) + 레어 장신구 · 요리 조합법 · 칭호(클리어). 자세한 것은 6장.
- A가 있으면 **길드 발주를 대신하거나 흡수**할 수 있습니다: "발주(선지급) → 기다림" 대신 "정복지에 파티를 보냄 → 그 소재". 발주를 남길지 없앨지는 **정할 것**입니다.

### ③ 언제 열리나

| 안 | 때 | 이유 |
| --- | --- | --- |
| ★ A | **보호 구간이 끝나는 12주** (파티 사냥 시작 `quest.partyFrom` 12주와 같이) | 초반 2~3달은 어려우면 안 된다는 원칙(11-19)과 맞음. 파티 사냥을 배우는 곳 |
| B | 리퀘스트 n번 들어준 뒤 | 침공 조건(리퀘스트 10번)과 겹쳐 헷갈림 |
| C | 침공 클리어 뒤 | 1년 차에 볼 수 없음 → 프로토타입에서 안 보임 |

- **침공과의 관계 (정할 것):** ⓐ 따로 감 (추천 — 침공 클리어 중앙 48주가 흔들리지 않음) ⓑ 던전을 깨면 침공 적이 약해짐 (긴장감 연결, 대신 48주 다시 맞춰야 함).

## 6. 보상 (11-20 사용자 결정 반영)

| 정복 수치 | 보상 |
| --- | --- |
| 보낼 때마다 | **던전 소재** (그 던전만의 소재 + 가끔 희귀) — 양은 선배님 경제 검토 뒤 |
| 50% | **세트 장비 조합법** → 대장간 「만들기」에서 던전 소재 + 공임으로 제작 |
| 100% 클리어 | **레어 장신구 1개** · **요리 조합법**(던전 소재가 든 요리, 소문 힌트에는 안 나옴) · 참가자 **칭호** |
| 클리어 뒤 | **정복지**(⑤ B안)에서 소재를 모아 세트를 계속 만듦 |

**레어 장신구 (길드에 1개)** — 사용자 결정 ① 장신구 ③ 잃음
- 팔 수 없고 만들 수 없음. 같은 등급 최고 장신구보다 조금 셈 + 특수 효과 1개 (예: 체력 30% 아래에서도 겁먹지 않음 · 후퇴선 한 단계 ↓) [임시].
- **장착한 모험가가 죽거나 길드를 떠나면 사라짐** (예외 없음).
- 장신구라서 레어를 끼면 세트는 최대 2부위 → 「3세트」와 「레어 + 2세트」 중에 고름.

**세트 장비 (예: 「굴 사냥꾼 세트」 단검 · 가죽 갑옷 · 부적)** — 사용자 결정 ② 메리트를 더 키움
| 부위 수 | 효과 [임시] |
| --- | --- |
| 2부위 | 체력 +15 · 공격 +5 (어디서나) |
| 3부위 | 그 던전 몬스터 상대 공격 +25% · 어디서나 공격 +5% |
- 「어디서나」 효과가 침공 클리어 48주를 흔드는지 구현 때 측정합니다.

## 7. 원정 흐름 · 갈림길 (11-20 사용자: 쯔바이의 펫 탐험처럼, ⓐ 던전 원정 안에)

| 단계 | 내용 |
| --- | --- |
| 방 1 → 2 → 3 (최대 4) | 방마다 전투 또는 탐색. 방 사이에 **갈림길**: 위험한 길(소재 + · 정복 수치 + · 적 강함) / 안전한 길(적 약함 · 정복 수치 적게) / 가끔 특수(보물방 · 함정) |
| 방 3을 마친 뒤 | **「계속 / 귀환」 갈림길**. 계속 → 방 4 (보물 · 소재 많음, 적 강함) |
| 언제든 | 파티 체력이 **후퇴선**(대장 성향: 신중 50% · 보통 30% · 무모 10%) 아래면 **자동 귀환** — 정복 수치는 그때까지 얻은 만큼. 전멸까지 버티지 않음 (레어 장신구 · 에이스를 한 번에 잃지 않게) |
| 고르지 않으면 | 1배속 기준 약 10초 [임시] 뒤 **대장의 성향 · 버릇대로**: 무모 · 경쟁심 · 허세꾼 = 위험한 길 · 계속 / 신중 · 겁쟁이 = 안전한 길 · 귀환 / 보통 = 반반 |
| 시간 | 갈림길이 떠 있어도 게임 시계는 흐름 (쯔바이처럼 기다리지 않음) |

- 자동 진행 · 시뮬레이터는 「성향대로 고름」 하나로 같은 규칙을 씀.
- 화면(원정 미니 화면 위 갈림길 두 칸 · 남은 시간 막대)은 **시안 먼저**.
- 선택 사항: 「계속」을 고를 때 후퇴선을 한 단계 낮추는 **「강행」** (8장 스위치로 켬/끔).

## 8. 기능 켬 / 끔 (11-20 사용자: "별로면 빼 버리면 되니까")

모든 던전 기능을 `balance.csv` 의 `dungeon` 구분 스위치로 켜고 끕니다 (1 = 켬, 0 = 끔). 끄면 그 기능이 없던 때와 **똑같이** 돌아가야 합니다(난수도 쓰지 않음) — 버릇의 `quirk.rate 0` 과 같은 방식. 측정 때 켬/끔을 바꿔 가며 비교합니다.

| 스위치 [임시 이름] | 끄면 |
| --- | --- |
| `dungeon.on` | 던전 전체가 없음 (지금 게임 그대로) |
| `dungeon.branch` | 갈림길 없이 방 3개를 정해진 길로 |
| `dungeon.cont` | 「계속 / 귀환」 갈림길 없음 (방 3에서 귀환) |
| `dungeon.push` | 「강행」 없음 |
| `dungeon.set` | 세트 조합법 · 세트 효과 없음 |
| `dungeon.rare` | 레어 장신구 없음 |
| `dungeon.recipe` | 던전 요리 조합법 없음 |
| `dungeon.title` | 참가자 칭호 없음 |
| `dungeon.keep` | 정복지 없음 (클리어하면 사라짐) |

- 경제 계약 검사 G1(옛 설정 고정값)은 `dungeon.on = 0` 으로 돌려 그대로 유지.
