# 모험가 칭호 설계 v1 (제안)

> 작성: Claude, 2026-11-13 · 상태: **제안 (결정 전, 코드 반영 안 함)** — 화면 자리만 책 조절 도구(`prototype/tools/book_layout_editor.html` 모험가 장)에 견본으로 잡아 둠
> 출발점: 사용자 결정 4가지 (2026-11-13)

## 요약
- **조건을 달성한 칭호만 고를 수 있고, 플레이어가 모험가마다 1개를 붙인다.** 같은 칭호를 여러 모험가가 붙일 수 있다.
- **기본 칭호 "신입":** 처음부터 모두 가지고, 다른 칭호를 붙이지 않으면 신입 (2026-11-13 결정).
- **효과는 능력치 보조**(+1 ~ +3). 칭호 이름은 **4글자 이하**.
- 측정: 모든 모험가가 1년 내내 칭호를 붙였다고 쳐도(상한 가정) 관문 1 수입 **+0 ~ +4G**, 성공률 **+0.2 ~ +0.9%p** → 영향 작음. 단, 성공률이 이미 상한(95%) 근처라 주 능력치 +3을 모두에게 주면 95.4%로 기준을 살짝 넘음 → **주 능력치형은 +2까지** 추천.

## 1. 사용자 결정 (2026-11-13, 받아 적은 그대로)
1. 한 모험가가 붙이는 칭호는 **1개**
2. 칭호는 **플레이어가** 골라 붙임
3. 이름은 **최대 4글자**
4. 효과가 있으면 좋음 → 가능한지 확인 (→ 가능, 2장)
5. 얻는 방법: "의뢰 N회 성공, 대회 우승, 애착 단계" 같은 방식이 맞음 → 설계 필요 (→ 3장)
6. 여러 모험가가 같은 칭호를 쓸 수 있음. **습득 조건을 달성한 칭호만 선택 가능**
7. 효과는 **능력치 보조**
8. 시스템 설계는 문서로 따로, 화면은 견본 칭호로 자리만
9. **칭호가 없으면 모두 "신입"** (기본 칭호, 효과 없음. 다른 칭호를 떼면 다시 신입)
10. 애착 단계 이름이 칭호 "신입"과 겹치지 않게 **애착 이름 변경: 방랑자 · 새내기 · 동반자 · 토박이** (2단계 신입 → 새내기, 4단계 마을의 수호자 → 토박이). 게임 코드(`ATTACH_TITLE`)는 칭호를 게임에 넣을 때 함께 바꿈

## 2. 효과를 넣는 자리 (코드 확인)
- 게임 `game_core.js finalStat(s, a, i)` · 시뮬레이터 `sim_engine.js finalStat(a, i)` 두 곳이 모험가 최종 능력치를 계산한다. 지금은 장비 보너스만 더함 → **칭호 보너스를 같은 자리에서 더하면** 전투·비전투 판정·능력치 막대(초록 "+N")에 모두 반영된다.
- 두 곳을 똑같이 고치고 관문 1을 다시 돌린다 (규칙: 게임과 시뮬레이터 결과가 맞아야 함).

## 3. 얻는 방법 (조건 유형)

모험가 1명 기준 측정 (게임 규칙 20판, 모험가 8명):

| 시점 | 의뢰 성공 횟수 (중앙 · 최대) | 부상 (판 전체) | 애착 "마을의 수호자" |
| --- | --- | --- | --- |
| 1년 | 13 · 29 | 1.5회 | 0명 |
| 2년 | 28 · 75 | 1.8회 | 3.8명 |
| 3년 | 37 · 121 | 1.8회 | 4.4명 |

→ 의뢰 종류가 5가지라 **종류별 성공은 1년에 약 2~3회**. "종류별 10회"는 약 4년이라 너무 느림 → **종류별 5회**(약 2년)로 둠. 부상은 판 전체에서 1년에 1~2번뿐이라 "부상 3번"은 사실상 불가능 → **부상 1번 회복**.

| 유형 | 조건 예 | 대략 언제 | 기록할 값 (새로 필요) |
| --- | --- | --- | --- |
| 첫 경험 | 첫 의뢰 성공 | 첫 달 | 없음 (`a.done`) |
| 의뢰 횟수 | 의뢰 성공 30회 | 2~3년 | 없음 (`a.done`) |
| 의뢰 종류별 | 토벌 의뢰 5회 성공 등 5가지 | 약 2년 | 모험가별 종류별 성공 수 `a.qType[5]` |
| 고난 | 부상에서 1번 회복 | 운 | 모험가별 부상 횟수 `a.injN` |
| 애착 | 애착 "동반자" / "토박이" | 1~2년 | 없음 (`a.attach`) |
| 전직 | 2차 전직 | 2년 이후 | 없음 (`a.stage`) |
| 대회 | 대회 우승 | 대회 구현 후 | 대회 결과 |

## 4. 견본 칭호 12개 + 기본 칭호 (가안)

| 칭호 | 얻는 조건 | 효과 |
| --- | --- | --- |
| **신입** | **처음부터 (기본 칭호)** | **없음** |
| 첫걸음 | 첫 의뢰 성공 | 주 능력치 +1 |
| 괴력 | 토벌 의뢰 5회 성공 | 힘 +3 |
| 신속 | 사냥·채집 의뢰 5회 성공 | 민첩 +3 |
| 박식 | 조사 의뢰 5회 성공 | 지력 +3 |
| 수호 | 호위·구호 의뢰 5회 성공 | 정신 +3 |
| 손재주 | 탐사 의뢰 5회 성공 | 기교 +3 |
| 불굴 | 부상에서 1번 회복 | 정신 +2 · 힘 +1 |
| 개근 | 의뢰 성공 30회 | 모든 능력치 +1 |
| 단골 | 애착 "동반자" | 주 능력치 +2 |
| 터줏대감 | 애착 "토박이" | 모든 능력치 +2 |
| 각성 | 2차 전직 | 주 능력치 +2 |
| 우승자 | 대회 우승 (대회 구현 후) | 주 능력치 +2 · 모든 능력치 +1 |

- **이름 겹침 주의:** 칭호 이름은 애착 단계 이름(방랑자 · 새내기 · 동반자 · 토박이)과 겹치지 않게.
- 능력치 상한 100은 그대로 (칭호로 100을 넘지 않음).

## 5. 붙이기 · 바꾸기
- **어디서:** 모험가 장 → 붙인 쪽지 **"칭호"(5번째)** → 달성한 칭호를 누르면 바로 바꿔 붙임.
- **비용 · 제한 (선택):**
  - A. 제한 없음 (추천: 프로토타입 범위, 칭호 효과가 작음)
  - B. 바꾸면 그 모험가 애착 −2 (자주 바꾸면 손해)
  - C. 의뢰 중에는 못 바꿈
- 새 칭호를 얻으면 기록 한 줄 + 모험가 줄에 작은 "새 칭호" 표시 → 플레이어가 붙이러 감.

## 6. 화면 (조절 도구 견본으로 확인)
- 명부: 이름 앞 작은 금색 표시 `[불굴] 카야` (칭호를 안 붙였으면 `[신입]`)
- 상세 머리: 이름 위 작은 금색 글씨
- 칭호 쪽지: 지금 칭호와 효과 · 달성한 칭호(눌러서 바꾸기) · 아직 못 얻은 칭호(흐리게, 조건 표시)
