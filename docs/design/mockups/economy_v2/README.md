# 경제 V2 화면 시안 (E2-5, 2026-11-17 B 세션)

실제 게임 화면(책 → 모험가 → 명부)을 연 뒤 `overlay.js`를 덧씌워 찍은 사용자 확인용 시안입니다. 게임 코드에는 들어가지 않습니다.

| 파일 | 내용 | 근거 |
| --- | --- | --- |
| `e25_roster.png` | 명부: 애착 단계 이름 + 막대, 지역 기여(65+) · 상주(100 또는 창립) 아이콘, 계약 끝 주 · 진행 주, 오른쪽 상세에 계약 조건 | 결정 14 · 17 |
| `e25_offer_default.png` | 계약제안 탭: F급 기본값 그대로 (12주 · 20% · 25G · 10G) → "받아들일 것 같다" | 결정 4 · 5 · 16 |
| `e25_offer_think.png` | 수수료 30% · 보수 10G → "고민 중" | 결정 5 |
| `e25_offer_reject.png` | 수수료 30% · 보수 0G → "거절할 것 같다", 바꾼 칸에 "기본 ○G" 표시 | 결정 5 · 16 |

계약제안 3장의 반응은 **게임의 실제 수락 판단(`contractEval`, 72998d8)**으로 고른 것입니다. 시험 사본에서 20주를 진행한 뒤, 기본값이면 받아들이는 모험가를 골라 조건만 바꿨습니다(후보 조건 애착 30 · 성공 3이 안 되는 판은 시안용으로 맞춤). 판마다 시드가 달라 3장의 모험가는 서로 다릅니다.

## 화면 흐름 (결정 16)

1. 명부 오른쪽 책갈피 **계약제안** (전직제안 아래)
2. **기본값 양식**: 기간 12주 · 계약 수수료 20% · 월 보수 25G · 지원 한도 10G [임시]
3. **4가지 조정**: 기간 8 · 12주 / 계약 수수료 15 · 20 · 25 · 30% / 보수 0~60G(5G) / 지원 0~30G(5G). 지명 상한(4주에 2번)은 고정 줄로만 보임
4. **모험가 반응 3단계**: 거절할 것 같다 · 고민 중 · 받아들일 것 같다 (숫자는 보이지 않음) + 한 줄 대사
5. **제안하기** / **기본값 복원** (바꾼 칸이 없으면 흐리게)

## 시안의 가정 (확정 아님)

- 반응은 게임에 계약 규칙이 있으면 `contractEval`의 3단계(yes · maybe · no)를 그대로 쓰고, 없을 때만 시안용 단순식으로 대신합니다. 대사도 게임 `contractPropose`와 같은 문장입니다.
- 아이콘 모양(글자 칩)은 시안용입니다. 실제 아이콘 그림은 정해지지 않았습니다.
- 명부의 상태 아이콘 줄(건강 · 배고픔 · 피로)은 자리를 보이려고 이 시안에서만 숨겼습니다. 실제로는 함께 두거나 줄 높이를 늘려야 합니다.

## 다시 찍는 방법

시험 사본에서 책 → 모험가를 연 뒤 `overlay.js` 내용을 실행하고 `MOCK.roster()` 또는 `MOCK.offer({ rate: 30 })`를 부릅니다.
