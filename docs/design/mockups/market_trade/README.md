# 소재 거래 화면 시안 (2026-11-20)

사용자 요청: 경영의 **소재 판매**와 **매입**을 한 책갈피(소재 거래)에서 같이. 실제 게임 화면(책 → 경영 → 매입)을 연 뒤 `overlay.js`를 덧씌워 찍은 확인용 시안이며 게임 코드에는 들어가지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `trade_combined.jpg` | 30주 진행한 자동 플레이 판, 멧돼지 고기를 고른 상태 (매입가 10G로 직접 정함) |
| `overlay.js` | 시안 덧씌우기 — `MOCK.trade(state, 소재id, { filter: 'all' \| 'food' \| 'etc', weeks: 4 \| 12 \| 24 \| 48 })` |

## 화면 구성

- **오른쪽 책갈피:** 소재판매 · 매입 → **소재거래** 하나 (경영 책갈피 6 → 5개).
- **왼쪽 쪽 — 소재 목록:** 걸러보기(전체 · 음식 소재 · 그 밖의 소재). 줄마다 아이콘 밑 보유 수 · 이름 · 시세 · 추세(▲▼) · 작은 그래프 · 매입가(직접 정함 / 자동) · 지난 4주 길드 · 시장 수. 아래 줄: 이번 달 판매 · 매입 합계, "음식이 아닌 소재 모두 팔기".
- **오른쪽 쪽 — 고른 소재:** 이름 · 등급 · 상시 / 희귀 재료 표시 · 설명 → 시세 그래프(4 · 12 · 24 · 48주) → 두 상자
  - **팔기:** 창고 n/30 · 1개 값 · 전부 팔면 · 1개 팔기 / 전부 팔기
  - **사들이기:** 매입가 −5 · − · + · +5 · 자동으로 + **모험가 판단 미리보기**(절약 · 보통 · 낭비 중 누가 길드에 팔지)
  - 최근 매입 3줄

## 시안의 가정

- 모험가 판단 미리보기는 애착 할인을 빼고 성향 기준(90 · 85 · 75%)만으로 보여 줍니다.
- 기존 매입 화면 오른쪽의 '이번 달 매입 · 매입 기록(전체)'은 왼쪽 아래 합계 줄과 소재별 최근 매입으로 나눴습니다.
