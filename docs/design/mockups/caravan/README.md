## 호위 의뢰 (안)

- **언제:** 관계 2단계 이상인 상단이 머무는 동안, 떠나기 전에 부탁합니다(방문마다 [임시] 50%).
- **내용:** 전투 의뢰 · 2주 · 2~3명 권장. 다음 마을 가는 길의 몬스터(그 상단 등급 사냥 의뢰 틀을 빌림).
- **보상:** 상단이 냄 — 그 등급 의뢰 보상 × 1.2 [임시]. 길드는 평소처럼 수수료를 뗌(금고에서 맡기지 않음).
- **결과:**
  - 성공: 관계 +100, 다음 방문 1~2주 빨라짐, 다음 주문서 값 +0.1배.
  - 실패: 관계 −50, 다음 방문이 늦어짐.
  - 거절: 변화 없음.
- **화면:** 상단 책갈피의 부탁 상자에서 [게시판에 올리기] / [이번엔 거절]. 올리면 게시판에 '상단 호위' 띠 카드가 붙습니다.
