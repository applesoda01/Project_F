- **겹치지 않게:**

## 바뀐 곳 (`prototype/js/actors.js`)

1. `settle` 위에 추가
   - `STUCK`(까닭 → 감정 · 둘러보기)
   - `BOARD_AT`(게시판 앞 2자리)
   - `STUCK_SAY` 2.5 · `STUCK_EMO` 0.7
   - `stuckOf` · `boardDue` · `boardTry`(대본)
   - `D.boardTalk`(말 차례)
2. `settle`: 「막힘」이고 이번 주에 아직 안 했으면 `boardTry` 대본을 앞에 끼우고, 다시 `settle`합니다.
   - 새로 들어온 · 귀환한 · 술을 시킨 모험가는 모두 `settle`을 거치므로 함께 적용됩니다.
3. `onWeek` 4-2(새 단락): 지난주부터 앉아 있던 모험가도 「막힘」이면 0.8초 간격으로 일어나 다녀옵니다.
4. 그리기 `standDraw`: `ac.look === 'L'`이면 서 있기 그림을 좌우 반전합니다(게시판을 볼 때만).
5. `D.flush` · `D.reset`: 게시판 자리와 `look`을 비웁니다.

## 까닭 셋이 구분되는가 (판단)

- **구분되는 것**
  - 이름표: 동료 기다림 · 맞는 의뢰 없음 · 수수료 고민
  - 말풍선 대사: 까닭마다 다름
  - 둘러보기: mates만
- **약한 것: 감정 표시만으로는 셋이 잘 구분되지 않습니다.**
  - 세 그림 모두 흰 얼굴 말풍선(62px)이라 멀리서는 비슷합니다.
  - 식은땀과 「?!」는 작은 기호 하나만 다릅니다.
  - 「욱」은 붉은 기호가 있어 조금 더 눈에 띕니다.
  - 그래서 실제 구분은 **말풍선 대사와 이름표**가 맡습니다.
- **까닭과 감정의 짝이 어색할 수 있습니다.**
  - 수수료 고민에 「욱」은 셉니다. 대사는 「수수료가 좀 세군」 · 「지갑이 얇아서요, 헤헤」처럼 가벼운 것도 있습니다.
  - 「헤헤(smile)」나 식은땀이 더 맞을 수 있습니다. 대신 mates와 겹칩니다.
- 1280에서도 이름표 · 말풍선 글자는 읽힙니다. 감정 기호는 더 작아져 구분이 더 어렵습니다.
- **세 사람이 한 주에 모두 막히면** 게시판 앞 장면이 약 10초 이어집니다(한 사람 약 4초).
  - 셋째는 자리가 빌 때까지 테이블 옆에 서서 기다리며, 이때 이름표는 「휴식 중」입니다.

## 보면서 알게 된 것 (시안 범위 밖, 기록만)

- 지금 코드는 지난주부터 앉아 있던 모험가의 이름표를 새 주에 고치지 않습니다(`restLab`은 앉을 때만 정함).
  - 이 시안에서는 「막힘」인 사람만 일어나 다시 앉으므로 이름표가 새로 바뀝니다.
  - 「사정」인 사람(rest · rain 등)은 지금처럼 지난주 이름표가 남을 수 있습니다.
- 게시판 근처에는 「구경 중」 서성임 자리(`LOITER` P(3, 5.5))도 있어, 사람이 많으면 그 근처가 붐빕니다.
