# 타이틀 화면 설계

> 2026-11-02 사용자와 함께 정리. 미리보기: `prototype/tools/title_preview.html`, 도트 규격: `docs/art/pixel_spec.md`

## 1. 화면 순서

1. 하늘색 배경 아래로 도트 땅이 흐르고, 전사가 왼쪽 밖에서 달려 들어옴. 화면 가운데에 오면 카메라가 따라감.
2. 타이틀(마법진 + 문양 + COLLEGIUM)이 등장하고, PRESS ANY KEY가 반짝임(땅과 겹치는 위치).
3. 아무 키나 누르면 PRESS ANY KEY가 사라지고 메인 메뉴가 나타남.
4. 메인 메뉴: **새 게임 · 이어하기 · 옵션 · 종료**

| 메뉴 | 동작 |
|---|---|
| 새 게임 | **저장 칸 3개 층이 열림** (아래 3절) |
| 이어하기 | 저장 칸 3개 층이 열림. 저장된 칸을 고르면 시작 연출 후 저장 시점으로 |
| 옵션 | 빈 팝업(내용은 나중에) |
| 종료 | 보이기만 하고 지금은 반응 없음 |

### 1-1. 달리는 무리 (2026-11-02)
- 배경에 동시에 보이는 캐릭터는 **최대 5명**. 모험가 10종(직업 5 × 남녀) 중 겹치지 않게 고름. 동작은 **달리기만** 사용(쓰러짐 없음).
- 처음엔 전사 남 혼자 왼쪽에서 달려 들어옴. **카메라는 맨 앞 캐릭터**를 화면 가운데에 둠.
- **합류:** 1~4명이 함께 뒤(화면 왼쪽 밖)에서 빠르게 달려와(땅보다 최대 +150도트/초) 줄 끝에 붙음.
- **줄:** 합류하면 **한 줄로** 서서 앞 캐릭터를 따라감. 줄 간격 기본 62도트(조절 막대 "줄 간격").
- **이탈:** 가끔 한 명이 오른쪽으로 빠르게(+220) 달려 나가 사라짐 → 남은 캐릭터가 다시 한 줄로 정렬. **맨 앞이 빠지면 카메라는 다음 캐릭터로 부드럽게 넘어감.**
- 무리 사건은 7~15초마다 1번(5명 미만이면 합류 65%, 2명 이상이면 이탈 가능).
- 다리 동작은 각자 달린 거리로 넘어가므로, 빨리 달리는 캐릭터는 다리도 빠름.

### 1-2. PRESS ANY KEY → 메인 메뉴 (구현됨)
- 타이틀 등장(5.2초) 뒤 아무 키·클릭 → PRESS ANY KEY가 잠깐 빛나고 사라짐 → 같은 자리에 메뉴가 서서히 나타남.
- **메뉴는 가로 한 줄** (2026-11-02 변경, 세로 → 가로): PRESS ANY KEY 자리(y=818, 땅과 겹침), 화면 가운데 기준, 항목 간격 230, 글자 32. 타이틀 크기는 그대로(0.8).
- 고른 항목: 밝아지고 양옆 마름모 + 아래 밑줄. 좌우 화살표·마우스로 고르고 Enter·클릭으로 정함.
- 새 게임 → 저장 칸 층(새 게임), 이어하기 → 저장 칸 층(이어하기), 옵션 → "준비 중" 팝업, 종료 → 반응 없음.
- 층이 닫히면 메뉴로 돌아옴. 메인 메뉴에서 Esc·오른쪽은 반응 없음.

## 2. 공통 규칙
- 메뉴 표현: 은빛 글자만, 가로 한 줄. 고른 항목은 양옆 마름모·밑줄 + 밝게.
- 저장 기록이 하나도 없으면 **이어하기는 흐리게**, 고를 수 없음.
- **Esc·마우스 오른쪽 = 바로 전 화면.** 메인 메뉴에서는 반응 없음(PRESS ANY KEY로 돌아가지 않음).
- 층(저장 칸·옵션)이 열려도 뒤 화면(타이틀·배경·달리기)은 그대로. 층이 열려 있는 동안 PRESS ANY KEY 자리에 **"뒤로가기"** 글자.

## 3. 저장 칸 층

- 칸 3개. 칸마다 보여줄 것: **저장 날짜·시간, 길드 단계, 플레이 시간, 모험가 수, 소지금**. 칸마다 반투명 어두운 바탕.
- **모양: B 세로 카드 3장 (확정)**. 카드 330×570(화면 px), **카드 간격 140**(가운데 카드 기준 좌우 대칭), 위 125. 모서리 깎은 은빛 테두리 2겹 + 위쪽 눈금 + 아래쪽 가는 선·마름모, 바탕 짙은 남색 88%.
  - 위에서부터: 칸 번호 문양(눈금 있는 작은 마법진 안에 Cinzel Ⅰ·Ⅱ·Ⅲ, 고른 칸은 천천히 회전) → 길드 단계 → 저장 날짜·시간 → 구분선 → 플레이·모험가·소지금(금색)
  - 고른 칸: 테두리 발광 + 양옆 장식선·마름모. 한글은 고운바탕체.
  - 카드가 길어 가운데 카드가 달리는 캐릭터 머리를 가림(층이 열려 있는 동안만).
- 빈 칸은 **"비어 있음"** + 음영.

| 들어온 곳 | 빈 칸을 고르면 | 저장된 칸을 고르면 |
|---|---|---|
| 새 게임 | 그 칸에 새로 시작 → 시작 연출 → 프롤로그 | **경고: "덮어쓰겠습니까?"** (2026-11-02 변경) |
| 이어하기 | 고를 수 없음(음영) | 시작 연출 → 저장 시점으로 |

### 덮어쓰기 경고
- 문구(가안): "이 칸의 기록을 지우고 새로 시작할까요?" + 칸 요약(날짜·길드 단계)
- 선택: **예 / 아니오**, **처음 선택은 아니오**(실수 방지, 확정)
- 예 → 그 칸에 새로 시작(시작 연출 → 프롤로그). 아니오·Esc·오른쪽 → 저장 칸 층으로 돌아감.

## 4. 시작 연출 (새 게임·이어하기 공통)
타이틀·메뉴·저장 칸 층이 서서히 사라짐 → 카메라가 위로 올라가며 하늘이 점점 진해져 완전한 검정 → 다음 화면(프롤로그 또는 저장 시점).
