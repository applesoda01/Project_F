# 길드 바깥 배경: 시간대 · 계절 · 날씨 설계 (2026-11-10)

> 길드 1층 바깥 풍경을 시간과 계절에 따라 바꾸는 설계. 사용자와 논의해 정함. 시안(데모)에서 값을 확정함. **코드 미반영** (로비 코드는 리나 쿼터뷰 · 캐릭터 모션 완료 후).

## 0. 요약

| 항목 | 결정 |
| --- | --- |
| 방식 | **계절·날씨별 통째 배경 그림** + **흔들림 지도**(식물만 움직임) + 시간대는 **게임 안 색·밝기·불빛 덧씌우기** |
| 시간대 | 한 달 4주 = 아침 · 낮 · 노을 · 저녁 (월마다 반복) |
| 계절 | 3월 시작 기준. 3~8월 일반 · 9~11월 가을 · 12~2월 겨울 |
| 비 | 달의 시작(1주 아침)에 판정. **일반 계절의 달만, 10%**. 걸리면 그 달 내내 비 |
| 떠다니는 요소 | 낙엽 · 눈 · 비는 영상이 아니라 **엔진 입자 연출** |
| 모습 수 | 배경 4종(일반·가을·겨울·비) × 시간대 4 = 16가지 |
| 흔들림 값 | 세기 **3.5px** · 속도 **1.0** · 풀밭 **0.5** (1280×720 기준, 데모에서 확정) |

## 1. 시간대 (한 달 4주)

| 주차 | 시간대 | 바깥 색 | 밝기 | 불빛 | 월 흐름 |
| --- | --- | --- | --- | --- | --- |
| 1주 | 아침 | 따뜻한 연노랑 | 0.95 | 꺼짐 | 새 달 시작 |
| 2주 | 낮 | 원본 | 1.00 | 꺼짐 | 가장 밝음 |
| 3주 | 노을 | 주황 · 분홍 | 0.80 | 철제 랜턴 켜지기 시작 | 해 질 무렵 |
| 4주 | 저녁 | 남보라 | 0.50 | 철제 랜턴 켜짐 (건물 안은 그대로) | 월말 결산 (반기 보조금은 6·12월 말) |

- 1주 ≈ 현실 30초, 1달 ≈ 2분, 1년(48주) ≈ 24분. 배속하면 전환도 함께 빨라짐.
- 주가 바뀔 때 약 **4초** 동안 색·밝기를 부드럽게 섞음. 노을 → 저녁은 불빛이 서서히 켜짐.
- 4주 저녁의 어두운 정도는 **0.50으로 확정** (0.65안은 비교용으로만 데모에 남김).
- 저녁 하늘 색은 **현행(남보라) 유지로 확정**. 채도 -20% 안과 비교해 현행을 선택함.
- **적용 범위 (2026-11-10 결정)**: **건물 안은 원본 그대로**(창문·벽등은 **낮에도 항상 켜진 모습**으로 확정), **바깥 배경(하늘·풀밭·덤불·돌길·울타리·가로등 기둥)만** 시간대 색·밝기가 바뀜. 건물 윤곽을 따라 마스크(가장자리 약 1픽셀 흐림)로 나눔. 입구는 매트 바깥 테두리를 경계로, 돌계단 · 연석(밝은 윗면 띠 포함)은 바깥으로 처리. 철제 랜턴만 노을에 켜지기 시작해 저녁에 켜짐(유리 노란색 + 번짐).

## 2. 계절 (3월 시작)

| 달 | 계절 | 바깥 모습 | 엔진 연출 |
| --- | --- | --- | --- |
| 3~8월 (6달) | 일반 | 푸른 풀밭 · 초록 나무 | 없음 |
| 9~11월 (3달) | 가을 | 단풍 든 나무 · 누런 풀 | 낙엽 |
| 12~2월 (3달) | 겨울 | 눈 덮인 땅 · 잎 없는 나무 | 눈 |

- 계절이 바뀌는 달 1주 아침에 약 4초 동안 섞음.
- 3월 시작이면 가을은 첫 해 약 13분, 겨울은 약 18분 지점.

## 3. 비 오는 날

| 항목 | 내용 |
| --- | --- |
| 판정 시점 | 달의 시작 (1주 아침) |
| 대상 | **일반 계절**의 달만 (가을·겨울은 비 없음) |
| 확률 | **10%**. 당첨되면 그 달 4주 내내 비 |
| 연간 평균 | 6달 × 10% = 0.6달. 첫 해에 비를 못 볼 확률 약 53% |
| 모습 | 젖은 땅 · 어두운 구름, 빗줄기와 웅덩이 파문(엔진 입자) |
| 시간대 | 아침→낮→노을→저녁 그대로 돌고, 밝기를 약 0.1 더 낮춤 |

비가 너무 드물게 느껴지면 15%로 올리는 안을 검토.

## 4. 배경 제작 (방식 변경 이력)

| 시도 | 결과 |
| --- | --- |
| Gemini 영상으로 식물 흔들림 | 3회 모두 **하늘만 움직임** → 폐기 |
| 스프라이트(나무·덤불 따로) | AI가 정면 입면으로 그림. 타일 받침을 써도 식물 시점은 정면 → 폐기 |
| **통째 배경 + 흔들림 지도 (채택)** | 원본의 쿼터뷰를 그대로 유지, 울타리 · 가로등 · 건물은 지도에서 제외해 고정 |

**일반 낮 배경 (확정)**
- 원본 그림(나무 · 덤불 있음)을 기준으로, **꺼진 가로등만** ChatGPT가 다시 그린 버전(쇠색 틀 · 푸른 회색 유리)으로 합성함. 주변 풀 · 꽃은 원본 그대로.
- 흔들림 지도: 어두운 초록(나무 · 덤불)은 강하게, 밝은 초록(풀밭)은 약하게. 초록이 아닌 곳(건물 · 울타리 · 가로등 · 돌길)은 0.
- 재생: 식물만 사인파로 일렁이게 하는 셰이더. 건물 안쪽 변화 0픽셀 확인.

**계절 · 비 배경**
- 일반 배경을 기준으로 "바깥 풍경만 바꿔 줘"로 편집. 건물 · 울타리 · 가로등 · 돌길 · 구도는 그대로.
- 구도가 같으면 같은 흔들림 지도를 재사용(어긋나면 새로 만듦).

## 6. 코드에 바뀔 곳 (메모)

- `game_core.js`: 월 → 계절 표, 달 시작 때 비 판정(`s.rain`), 주차 → 시간대(`weekPhase`).
- 로비 렌더: 배경 + 흔들림 셰이더(`A=3.5, S=1.0, 풀밭=0.5`) + 시간대 색 보정 + 불빛 레이어 + 입자 레이어, 전환 섞기.
- 장부·기록: 비 오는 달 한 줄 (선택).

## 9. 입자 · 하늘 연출 (2026-11-10 확정)

데모(`time_season_demo.html`)에서 정한 값. 모든 입자와 하늘 연출은 **건물 안에는 보이지 않고** 바깥(하늘 · 풀밭 · 돌길)에만 그림.

| 계절 | 입자 | 모양 |
| --- | --- | --- |
| 일반 | 녹색 나뭇잎 | 뾰족한 잎 + 잎맥, 초록 5색, 회전하며 낙하 |
| 가을 | 낙엽 | 뾰족한 잎 · 물결 모양 잎, 주황 · 빨강 · 노랑 5색 |
| 겨울 | 눈 결정 | 6각 결정(가지 갈래) + 먼 곳은 작은 점 |
| 비 | 빗줄기 + 웅덩이 파문 + **유리 물방울** | 굴절(뒤 풍경이 뒤집혀 비침) · 방울마다 모양이 다름 · 서로 붙지 않게 맺힘(흘러내리는 방울만 합쳐짐) |

- **입자 수 기본 40%** (0~200% 조절). 일반 나뭇잎 68장 · 가을 낙엽 92장 · 눈 결정 190 + 점 110 · 빗줄기 460을 100%로 보고 비율로 줄임.
- 유리 물방울: 최대 30개(100% 기준), 큰 방울 30%(반지름 14~24px) · 작은 방울(4~10px), 맺힌 뒤 3~8초, 큰 방울의 절반은 흘러내림.
- **구름**: Gemini로 그린 구름 1덩어리(`cloud_sprite.png`)를 크기 · 높이 · 반전 · 속도만 바꿔 최대 6개 흘림(기본 3개, 8px/s). 시간대 색 × 계절 색(일반 흰색 · 가을 노을빛 · 겨울 청회색 · 비 어두운 회색)으로 물들임.
- **별**: 코드로 그림(그림 파일 없음). 원판 위에 별 2,800개(100%)를 흩뿌려 **시계 방향으로 천천히 회전**(기본 0.1바퀴/분), 크기 50%(0.35~2.2px), 별 수 100%. 별은 가끔 임의로 커졌다 작아져 반짝임. 노을 말기부터 서서히 나타나 저녁에 가장 선명(비 오는 날은 35%).
- **하늘 영역**은 마스크(`sky_mask_*.png`, 배경 4종)로 구분. 구름과 별은 이 마스크 안에서만 보임.
- 데모 슬라이더: 입자 수 · 별 수 · 별 크기 · 별 회전 · 구름 수 · 구름 속도.

참고: 마을 배경도 같은 방식(계절 4종 + 시간대 덧씌우기)으로 확장 예정.
