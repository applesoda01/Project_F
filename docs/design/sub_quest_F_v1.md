## 요약
- **F급 서브 퀘스트 28개**입니다. 의뢰인은 **모험가 4 · 마을 사람 16 · 외지인 8**입니다.
- **등장 조건은 카이로소프트 방식**입니다: 마을 인구 · 명성 · 신뢰도 · 금고 · 모험가 수 · **모험가 능력치(힘 · 민첩 · 지력 · 정신 · 기교 모두 2번 이상)** · 레벨 · 애착 · 성향 · 설비 · 소재 · 계절이 기준을 넘으면 등장합니다. 시간("N개월 차") 조건은 없습니다.
- **계절 퀘스트 9개** (봄 3 · 여름 2 · 가을 3 · 겨울 3, #6은 봄 · 가을 둘 다), 그중 **축제 3개는 매년 반복**합니다.
- 기준값은 게임 규칙 30판 측정에 맞췄습니다 → **첫해 약 24개 등장**, 한 달에 2개 안팎, 동시에 최대 4개.

- 모든 퀘스트에 의뢰 · 클리어 대사, 사람을 보내는 퀘스트에는 실패 대사, 그리고 리퀘스트 장에 보여 줄 **등장 조건 힌트 1줄**이 있습니다.

| 이 문서 | 데이터 열 |
| --- | --- |
| 의뢰인 3종 | `giver`: adventurer / resident / outsider (**outsider 새로 추가**, 기존 merchant · lord는 resident · outsider로 나눠 넣음) |
| 등장 조건 | `cond`: `pop>=200; fame>=40; stat.int>=30; season=winter; done=f_req_don01; mat.mat_x015>=3; tables>=2; gold>=1000; advs>=6; lv>=5*2; attach>=65; trait=social*2; dishes>=5; town>=1` 처럼 `;`로 이어 씀 (모두 만족) |
| 매년 반복 · 힌트 | `repeat`: once / yearly, `hint`: 2-3절 문장 |
| 종류 | `type`: hunt(전투) / search(탐색) / deliver(납품) / donate(돈 내기) / install(설치 요청) / town(건물 해금, 2단계) |
| 설비 해금 | `rw_unlock`: table / plant / boardDeco / locker / banner / bench / map / fireplace / trophy (`unlockReward` 호출) |

| 대사 | `text_req` · `text_ok` · `text_fail` (줄마다 `화자: 대사`, 여러 줄은 `/`로 구분). 2단계 묶음은 `text_req2` · `text_ok2` |
| 보스 | 전투 퀘스트의 보스 = F급 몬스터 강화본 (체력 약 3배 · 공격 1.3배): 큰 슬라임 · 도적 두목 · 외눈 멧돼지 |
