> 작성: Claude, 2026-11-13 · 상태: **② 로비 잡담 반영 (2026-11-13)** · ③~⑤ 대기
> 출발점: 사용자 요청 (2026-11-13) "캐릭터들끼리 대화를 나누면 좋겠다 — 로비 · 파티 · 마을 · 미니 뷰 전부, 관계 수치까지"

## 요약
- 지금 대사는 **한 사람의 혼잣말**뿐 (`speech.csv` 96줄, 말투 5가지 = 성향에서 자동). → **두 사람이 2~3줄 주고받는 대화**를 더함.
- 대사는 조합 수만큼 쓰지 않고 **"말 걸기 · 대답 · 맺음"을 말투별로 따로 써서 이어 붙임** → 상황 6 × 말투 5 × 역할 2~3 × 3줄 ≈ **180~270줄**로 말투 조합 25가지를 모두 만듦.
- 단계: ① 설계(이 문서) → ② 로비 잡담 → ③ 파티 대화 + 미니 뷰 대사 → ④ 마을 대화 → ⑤ 관계 수치. **②~④는 연출만**(게임 숫자 그대로), ⑤에서 처음으로 규칙에 영향 → 관문 1 다시 측정.

## 2. 대화가 생기는 곳 · 때

| # | 상황 (`talk.csv` 상황 이름) | 곳 | 누가 | 언제 | 빈도 (안) |
| --- | --- | --- | --- | --- | --- |
| 1 | `table` 식탁 잡담 | 로비 | 같은 테이블에 앉은 두 사람 | 식사 · 술 중 | 앉아 있는 동안 1번 |
| 2 | `board` 게시판 앞 | 로비 | 게시판 앞에 함께 선 두 사람 | 의뢰 고르는 중 | 25% |
| 3 | `idle` 로비 잡담 | 로비 | 할 일 없이 3칸 안에 있는 두 사람 | 혼잣말 판정 자리 | 혼잣말 대신 30% |
| 4 | `depart` 출발 전 | 로비 → 미니 뷰 | 같은 파티 2명 이상 | 파티가 출발할 때 | 파티마다 1번 |
| 5 | `return` 귀환 후 | 로비 | 같은 파티 | 보고 뒤 | 성공 / 실패 따로 |
| 6 | `battle` 전투 중 | 미니 뷰 | 같은 파티 | 전투 시작 · 동료 피격 · 치유 · 승리 · 패배 | 이벤트마다 30% (말풍선 1줄 + 짧은 대답) |
| 7 | `town` 마을 길 | 마을 | 거주 모험가 두 사람이 가까이 지날 때 | 마을 화면 | 40초에 1번 이하 |

- **시끄럽지 않게:** 로비 · 마을 · 미니 뷰 각각 **동시에 대화 1개**, 끝난 뒤 **20~40초 쉼**. 한 사람은 대화 뒤 60초 동안 다시 대화하지 않음.
- **줄 간격:** 한 줄 말풍선 1.8초, 다음 줄은 1.2초 뒤 (대답이 겹쳐 보이게 살짝 겹침). 대화 하나 = 약 4~6초.
- **손님이 많은 장면 우선순위:** 리나 응대 · 승급 · 레벨업 말풍선이 있으면 대화는 미룸.

## 3. 대사 표: `prototype/data/talk.csv` (새 표)

```
상황,역할,말투,관계,대사,메모
table,open,bold,,오늘 사냥감 봤어? 내가 다 잡을 거야!,
table,reply,careful,,…조심해. 저번에 다쳤잖아.,
table,close,any,,(둘 다 웃는다),맺음 (생략 가능)
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| 상황 | table · board · idle · depart · return_ok · return_fail · battle_start · battle_hit · battle_heal · battle_win · battle_lose · town | 2장 표 |
| 역할 | open(말 걸기) · reply(대답) · close(맺음, 선택) | 대화 = open + reply (+ close) |
| 말투 | bold · careful · friendly · loner · plain · any | 말하는 사람의 말투 |
| 관계 | 비움 · good · bad | ⑤ 관계 수치 단계. 비우면 모든 관계 |
| 대사 | `{a}` 말 건 사람 이름, `{b}` 대답하는 사람 이름, `{q}` 의뢰 이름 | |

- **조합 규칙:** open은 A의 말투에서, reply는 B의 말투에서 고름 → 호탕 A + 무뚝뚝 B면 "같이 가자!" / "…알아서 해." 처럼 말투 차이가 대화에서 드러남.
- **줄 수 (안):** 상황 12 × 말투 5 × open · reply 2 × 2~3줄 ≈ **240~360줄** 중 우선 로비 3상황(②)부터 **90줄**.
- **대사 쓰기:** Claude가 초안 → 사용자가 대사 편집 도구(`tools/dialogue_editor`)로 고침. 도구가 `talk.csv`도 열 수 있게 ②에서 함께 손봄.

## 4. 화면

- **로비 · 마을:** 두 사람 머리 위 말풍선이 차례로. 말 거는 사람이 상대 쪽을 봄(좌우 방향만).
- **채팅 기록:** 지금처럼 얼굴 · 이름 · 직업과 함께 한 줄씩. 대화 묶음은 왼쪽에 옅은 세로줄로 이어 표시.
- **미니 뷰:** 작은 말풍선 1줄 + 대답 1줄. 전투 대사는 1초 이하로 짧게.

## 5. ⑤ 관계 수치 (마지막 단계, 규칙 영향 있음)

> **2026-11-13 사용자 결정: 숨김 수치.** 친밀도 숫자 · 막대 · 단계 이름은 화면 어디에도 보이지 않음(명부 · 상세 · 툴팁 모두). 플레이어는 **대화 내용(단짝끼리 다정한 말 / 서먹한 사이의 퉁명스러운 말)과 파티 구성**으로만 관계를 짐작함. 개발 메뉴에서만 확인 가능.

| 항목 | 안 |
| --- | --- |
| 표시 | **없음 (숨김)** — 대사 고르기(good · bad)와 규칙에만 쓰임 |
| 값 | 모험가 두 사람마다 **친밀도 0~100** (처음 30), 저장 `s.rel["3-7"]` |
| 오름 | 같은 파티로 의뢰 성공 +3 · 대화 +1 (하루 한 번) · 같은 테이블 식사 +1 |
| 내림 | 같은 파티로 실패 −2 · (버릇 도입 후) 시비 −5 |
| 단계 | 0~29 서먹 (bad 대사) · 30~69 보통 · 70~100 단짝 (good 대사) |
| 효과 (안) | 단짝끼리 같은 파티면 성공률 +1%p · 파티를 짤 때 단짝을 먼저 고름 · 방출 대가 "같은 파티 동료 애착 −5"를 **단짝은 −10**으로 |
| 연결 | 긴장감 묶음의 **버릇**(시비 거는 모험가 → 다툼 대화 · 친밀도 −5) · **마스터 중재**(다툼이 나면 중재 / 방관 / 방출 선택) |
| 검증 | 효과를 넣은 뒤 게임 · 시뮬레이터 관문 1 100판 다시 측정 (성공률이 이미 94.6%라 +1%p는 상한 95% 근처 → 효과 크기 조정 필요할 수 있음) |
