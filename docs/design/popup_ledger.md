# 장부 팝업 개편 설계

> 2026-11-05 사용자와 논의해 확정. 팝업 안쪽 내용 퀄업의 다섯 번째 대상.

## 0. 요약

| 영역 | 예전 | 바뀜 |
| --- | --- | --- |
| 열 | 이번 달 (진행 중) \| 지난달 | **지난달 \| 이번 달** ("(진행 중)" 삭제) |
| 구성 | 항목 7줄 한 표 | **수입**(초록 띠) / **지출**(빨간 띠) + 합계 + 순이익 |
| 항목 | 시설 유지비 줄, "기타 (의뢰서 떼기 등)" | 유지비 줄 삭제(유지비 없음), "기타" |
| 시설 건설비 | 장부에 없음 (금고에서만 빠짐) | **지출**에 기록 |
| 순이익 | 운영 순이익 (건설비 제외) | 수입 − 지출 (**건설비 포함**) |
| 오버 내역 | 없음 | **모든 금액 칸** |
| 그래프 | 막대만 (값·월 안 보임, 손해도 위로) | 0 기준선 위 이익 / 아래 손해, 금액·월 표시, 건설한 달 ⚒, 오버 내역 |
| 배치 | 위쪽에 붙음 | 표·그래프 묶음을 팝업 가운데에 |

## 1. 표

| 구분 | 줄 |
| --- | --- |
| 수입 | 중계료 · 소재 판매 차익 · 식사 판매 · 주점 매출 · 왕국 보조금 → 수입 합계 |
| 지출 | 시설 건설비 · 기타 → 지출 합계 |
| 순이익 | 수입 − 지출 |

- 금액은 모두 "G", 지출은 "−" + 빨간 글씨.
- 이번 달의 **주점 매출 · 왕국 보조금**(월말 결산 때 한꺼번에 들어옴)이 아직 0이면 흐린 **"월말"**.
- 소재 판매 차익은 지금처럼 자동 수입(의뢰 보상의 8%). 실제 소재 판매가 생기면 다시 정리.

## 2. 오버 내역

| 칸 | 내용 |
| --- | --- |
| 중계료 | 성공한 의뢰 n건 · 보상의 n% (그달 중계료율) |
| 소재 판매 차익 | 성공한 의뢰 n건 · 보상의 8% |
| 식사 판매 | 요리별 판매 그릇 수 |
| 주점 매출 | 지난달: 길드에 머문 모험가 n명 기준 / 이번 달: 월말 결산 때 들어옵니다 (지난달 ○G) |
| 왕국 보조금 | ○급 길드 월 ○G |
| 시설 건설비 | 지은 시설과 금액 |
| 기타 | 의뢰서 떼기 건별 (의뢰 이름 · 금액) |
| 그래프 막대 | 그달 수입 · 지출 · 순이익, 지은 시설 |

- 예전 저장의 달에는 내역 기록이 없어 "내역 없음 (예전 기록)".

## 3. 그래프

- 최근 12개월 **순이익(건설비 포함)**. 0 기준선 위 초록 = 이익, 아래 빨강 = 손해. 위아래 18%는 금액 글자 자리.
- 막대 끝에 금액, 아래에 월, 건설한 달 ⚒.
- 제목 옆: 순이익 평균 · 의뢰 성공률.

## 4. 관문 1과의 관계

- 관문 1·시뮬레이터는 계속 **운영 순이익**(`m.net`, 건설비 제외)으로 계산. 장부 화면만 건설비를 포함한 순이익을 보여 줌.
- 새 기록은 화면용이라 결과 변화 없음 (게임 458G·93.7%).
