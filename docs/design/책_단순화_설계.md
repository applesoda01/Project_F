## 0. 요약

- **왜:** 사용자가 "책들이 너무 메뉴가 많고 복잡해 보인다"고 함. 세어 보니 들어가는 곳이 15곳(장 7 + 오른쪽 탭)이고, 아래 메뉴 펼침과 책 탭이 같은 화면으로 가는 입구를 두 벌 갖고 있었음.
- **어떻게:** 장 수는 거의 그대로 두고(메뉴 잠금 · 튜토리얼 안내가 장 단위로 짜여 있음), **장 안의 탭**과 **가끔 쓰는 입구**를 줄임.
- **결과:** 들어가는 곳이 15곳에서 **11곳**으로 줄어듦. 상단이 와 있을 때는 12곳.

## 2. 정하면서 나온 것

- **도감은 탭으로 남김** (사용자 17:05): 처음 시안은 도감도 작은 단추로 옮겼으나, 모으는 재미의 목표라 탭으로 둠.
- **아래 메뉴 펼침은 없애지 않음** (사용자 17:08 Claude 제안 수락):
  - 마우스를 올려야 보이는 지름길이라 평소 화면을 복잡하게 만들지 않음.
  - 대신 내용을 책 탭과 똑같이 맞춤.
  - 설정 펼침(설정 · 저장 · 불러오기 · 월간 보고)은 그대로 — 설정 장을 책에서 뺐으므로 이제 설정으로 가는 길은 이 펼침뿐임.
- **장은 합치지 않음:** 의뢰 · 리퀘스트를 합치는 안도 있었으나, 메뉴 잠금(칸마다 다른 때 열림)과 튜토리얼 안내를 크게 고쳐야 해서 뺌.
