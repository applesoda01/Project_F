## 요약

- 길드 등급은 F~S이고, 길드에는 레벨 없이 등급만 있습니다. 등급 공인과 승급 심사는 대륙 단위의 길드 연합(본부)이 맡습니다.
- **현재 규칙(2026-11-09 결정): 길드 승급은 그 등급의 메인 퀘스트를 깨면 다음 등급이 됩니다.** 퀘스트 분류는 메인·서브·리소스 3종이며, "승급 퀘스트" 분류는 폐지했습니다.
- F→E는 **F급 메인 퀘스트 1개**로 확정되었습니다. 첫 모험가가 2차 전직 조건을 채우면 등장하고(약 41주), 성공하면 E급 승급 + 모험가 관리소 해금입니다. 관리소는 클리어 뒤 2,000G로 직접 짓습니다.
- 설계서 원안(2026-10-20)의 승급 흐름은 "한 단계 위 **보스급 의뢰** N건 달성 → **대규모 몬스터 침공** 방어"였고, 등급마다 승급 시설(관리소·훈련장·의무실·해체장·명예의 전당)이 조건이었습니다. 이 원안은 E→D 이후에 어떻게 쓸지 아직 정하지 않았습니다(미결).
- 길드 등급이 오르면 보조금, 게시판 용량, 의뢰 난이도 상한, 공간·시설 해금, 시설 레벨 상한, 마을 안전, 모험가 수 상한, 모험가 등급 상한이 함께 바뀝니다.
- 명성·신뢰도는 현재 길드 승급의 직접 조건이 아닙니다. 명성은 메인 퀘스트 보상(F급 메인 명성 10)과 모험가 합류(명성 10마다 1명)로, 신뢰도는 의뢰 공급으로 승급 속도에 간접 영향을 줍니다.
- 이 프로젝트에서 "관문 1·관문 2"는 밸런스 검증 단계의 이름이며, 길드 승급의 관문이 아닙니다(5절).

## 1. 길드 등급과 승급이 바꾸는 것

| 항목 | 내용 |
| --- | --- |
| 길드 등급 | 길드의 공식 등급 F~S. 길드에는 '레벨' 없이 등급만 존재 |
| 공인 주체 | 대륙 단위의 길드 연합(본부)이 길드 등급 공인과 승급 심사를 맡고, 왕국은 계약에 따라 등급별 보조금을 지급. 다른 마을 길드도 같은 연합 소속 (→ [09_스토리_세계관.md](09_스토리_세계관.md)) |

**길드 등급의 역할 (핵심 수치)**

| 수치 | 범위 | 역할 |
| --- | --- | --- |
| 길드 등급 | 길드 | 보조금, 게시판 용량, 의뢰 난이도 상한, 공간·시설 해금, 시설 레벨 상한, 마을 안전 |

**등급에 묶인 값 (다른 분류 문서에 상세)**

| 항목 | 등급별 값 | 상세 |
| --- | --- | --- |
| 공간·시설 해금 | F 1층 로비 · E 1층 확장 · D 지하 1층 · C 2층 · B 지하 2층 · A 3층·옥상 | → [05_길드.md](05_길드.md) |
| 시설 건설비 | F 기본, E 2,000 · D 4,000 · C 8,000 · B 15,000 · A 30,000 | → [07_경제.md](07_경제.md) |
| 장식 최대 레벨 | F 2 / E 3 / D 4 / C 이상 5 | → [05_길드.md](05_길드.md) |
| 모험가 수 상한 | F 8 · E 12 · D 16 · C 20 · B 24 · A 28 · S 32 | → [01_모험가.md](01_모험가.md) |
| 모험가 등급 상한 | 길드 등급 + 1 (F급 길드에서도 E급까지, S급은 길드 S 승급 순간만) | → [01_모험가.md](01_모험가.md) |
| 보조금 | 반기 실적 비례(의뢰 등급별 건당 보조금). 예전 월 고정 등급별 금액은 폐지 | → [07_경제.md](07_경제.md) |

> ⚠️ 출처 차이: 모험가 등급 상한 — design_v0.1.md 모험가 등급 절의 표는 "우리 길드 출신은 길드 등급까지. 조건을 채워도 길드가 승급할 때까지 대기", 같은 절의 2026-11-12 추가 줄과 game_overview.md §3(2026-11-12)은 "모험가 등급 상한 = 길드 등급 + 1" → 최신인 "길드 등급 + 1"을 따름. (→ [01_모험가.md](01_모험가.md))

> ⚠️ 출처 차이: 보조금 — design_v0.1.md §4·§5.5는 길드 등급에 따른 월 보조금, game_overview.md §8(2026-11-09 확정)은 반기 실적 비례 → 최신을 따름. 등급은 건당 보조금이 의뢰 등급에 따라 오르는 방식으로만 반영됨. (→ [07_경제.md](07_경제.md))

## 2. 승급 흐름 (현재 규칙: 메인 퀘스트 = 승급)

의뢰는 목적에 따라 메인·서브·리소스 3종으로 나뉩니다(2026-11-09, 승급 퀘스트 분류는 폐지). 승급은 메인 퀘스트를 클리어하면 다음 등급이 되는 구조입니다.

| 항목 | 값 |
| --- | --- |
| 퀘스트 분류 | 메인 · 서브 · 리소스 3종 (승급 퀘스트 분류 없앰. 보스급 의뢰·침공 같은 내용은 필요하면 서브로) |
| 길드 승급 | 메인 퀘스트를 깨면 다음 등급 |
| 메인 퀘스트의 목적 | 마스터의 서사, 마왕, 길드 승급 |
| 메인 퀘스트의 보상 | 서사, 명성, 등급 상승 |
| 거절 | 불가 (보류만) |
| 실패 시 | 재도전 가능 |
| 서브 퀘스트 | 승급과 무관 |

메인 퀘스트의 전체 구성(등급별 수, 줄기, 지명 규칙)은 → [02_의뢰.md](02_의뢰.md)·[09_스토리_세계관.md](09_스토리_세계관.md).

> ⚠️ 출처 차이: design_v0.1.md §6.0·§6.1(2026-10-20)은 퀘스트를 메인·서브·**승급**·리소스 4종으로 나누고, "승급 퀘스트 = 등급 조건 충족 시 접수원이 보고, 보류 또는 진행, 보상은 등급 상승", "메인을 하지 않아도 승급할 수 있음"이라고 적음. game_overview.md §4(원본 progression_v1.md 2-4, 2026-11-09)는 승급 퀘스트 분류를 폐지하고 "메인 퀘스트 클리어 = 승급" → 최신인 game_overview.md를 따름. game_overview.md §11도 "설계서 반영"을 요구함.

### 2-1. F급 메인 퀘스트 (F → E 승급) [가안]

모험가 관리소 해금과 E급 승급을 연결합니다.

| 항목 | 값 |
| --- | --- |
| 수 | 1개. 모험가 관리소 해금 + E급 승급 |
| 등장 조건 | 첫 모험가가 2차 전직 조건을 채우면 (시험 중앙값 약 41주) |
| 관리소 | 클리어 뒤 2,000G로 직접 건설 (그때 금고는 보통 5,000G 이상) |
| 지명 | 플레이어가 고름. 아무나, 최대 5명, 대열 순서도 플레이어가 정함. 퀘스트 지명 튜토리얼을 겸함 |
| 기간 | 1주 |
| 적 | 늑대 4 + 보스 1 (체력 2,000 · 공격 100) |
| 사망 | 없음 |
| 보상 | 1,000G · 명성 10 |

| 지명 파티 | 성공률 | 쓰러지는 평균 인원 |
| --- | --- | --- |
| 에이스 1명 | 21% | 0.8 |
| 상위 3명 | 70% | 1.3 |
| 상위 5명 | 91% | 0.9 |
| 에이스 + 약한 2명 | 63% | 1.5 |
| 상위 3명 + 약한 2명 | 95% | 0.7 |

**진행 흐름 (새 게임 기준)**

1. 튜토리얼(시간 멈춤, 모험가 2명)
2. F급 운영: 매주 의뢰 게시, 명성 10마다 모험가 1명 합류
3. 첫 모험가가 2차 전직 조건 충족 (약 41주)
4. F급 메인 퀘스트 등장: 지명 튜토리얼, 1주 전투
5. E급 승급, 관리소 해금 후 2,000G로 건설
6. 다음 달 초 첫 전직 제안 (약 48주)

- 순서 제안 [제안]: 2개월 차 첫 기부 → 4개월 차 첫 토벌 지명(연습) → 첫 2차 전직 조건 도달 시 F급 메인 → E급. 첫 지명형 서브(f_hunt_01)가 메인보다 먼저 나오면 연습판 역할을 합니다. (원본: named_sub_quest_v1.md §3, 2026-11-13 제안)
- 현재 상태: F급 메인·서브 퀘스트는 프로토타입 범위이며 아직 코드에 없습니다. 시뮬레이터는 침공 승급 규칙을 쓰고 있어 "E급 승급 정체"(침공으로 E급에 오른 판은 5년 안에 41판뿐, 중앙값 49개월)가 있었고, 메인 퀘스트 구현 때 게임·시뮬레이터에 함께 반영하고 관문 1 기준을 새로 잡기로 했습니다(결정 끝, 미착수). (원본: `docs/todo.md` 2026-11-12·11-13, raid_invasion_v1.md §1)

> ⚠️ 출처 차이: 메인 퀘스트 지명 장소인 길드 마스터 집무실 — design_v0.1.md §9.1은 E급 시설, game_overview.md §7(2026-11-12)은 "E → F, 1,000G" → 최신인 F급을 따름. 그래서 F급 메인 퀘스트의 지명이 F급 길드에서 가능함. (→ [05_길드.md](05_길드.md))

> ⚠️ 출처 차이: 모험가 관리소 — design_v0.1.md §9.2는 "E → D 승급 조건, 2차 전직 조건", 현재 규칙(game_overview.md §2·§4)은 "F급 메인 퀘스트 클리어로 해금, E급 시설로 2,000G 건설, 짓지 않으면 2차 전직이 막힘" → 최신을 따름. E→D 조건으로 쓸지는 미결.

## 3. 설계서 원안의 승급 흐름 (보스급 의뢰 → 침공)

설계서 원안(2026-10-20)의 승급 흐름입니다. F→E는 2절의 메인 퀘스트 방식으로 바뀌었고, E→D 이후에 이 원안을 쓸지는 정하지 않았습니다. 습격·침공 이식 설계안(2026-11-14, [제안])은 침공을 E→D 이후 몫으로 남기자고 제안합니다.

1. 현재 등급보다 한 단계 위의 **보스급 의뢰**가 여러 개 등장 (예: F등급 길드에 E등급 의뢰)
2. 특정 수를 달성하면 **승급 이벤트** 발생
3. 승급 이벤트: **대규모 몬스터 침공**을 지금 있는 모험가들이 막음

| 승급 | 조건 | 증명하는 기능 |
| --- | --- | --- |
| F → E | 보스급 의뢰 2건 → 침공 방어 | — |
| E → D | 보스급 의뢰 3건 + 모험가 관리소 → 침공 방어 | 관리 |
| D → C | 보스급 의뢰 3건 + 훈련장 → 침공 방어 | 육성 |
| C → B | 보스급 의뢰 4건 + 의무실 → 침공 방어 | 생명 |
| B → A | 보스급 의뢰 4건 + 해체장 → 침공 방어 | 가공 (상위 장비) |
| A → S | 보스급 의뢰 5건 + 명예의 전당 + S급 후보 2명 → 침공 방어 | 명예 |

**보스급 의뢰 수 N은 합계 21건 [가안].** 정확한 소요 시간은 시뮬레이터로 검증합니다.

> ⚠️ 출처 차이: F → E 행은 game_overview.md §4·raid_invasion_v1.md(2026-11-13 결정 인용)에 따라 "F급 메인 퀘스트 성공"으로 대체됨 → 최신을 따름.

### 3-1. 보스급 의뢰 공개 방식 [가안]

여러 모험가를 함께 키우는 플레이를 위해 여러 개를 동시에 공개합니다.

| 항목 | 내용 |
| --- | --- |
| 동시 공개 수 | 등급마다 N + 2개를 동시에 게시 (예: E→D는 5개) |
| 승급 조건 | 공개된 것 중 아무거나 N개를 달성하면 승급 이벤트(침공) 발생 |
| 의뢰 구성 | 동시에 나오는 의뢰들의 요구 능력치 프로필을 서로 다르게 구성 |
| 보충 | 하나를 끝내면 1~2개월 뒤 새 의뢰가 채워져 항상 N + 2개 유지 |
| N 달성 후 | 남은 보스급 의뢰도 계속 수행 가능. 보상과 경험치는 그대로 |
| 승급 보류 | 마스터가 승급 이벤트를 보류하고 육성을 계속할 수 있음 |

### 3-2. 승급 시설

| 시설 | 개방 층 (길드 등급) | 승급 조건 (원안) | 다른 역할 |
| --- | --- | --- | --- |
| 모험가 관리소 | E | E → D | 2차 전직 조건 |
| 훈련장 | D | D → C | 힘·민첩·기교 훈련. 효과: 훈련 아이템 |
| 의무실 | C | C → B | 부상 회복. 효과: 약재 선반 (회복 단축, 사망 확률 감소) |
| 해체장 | B | B → A | B등급 이상 원재료를 가공해야 상위 레시피 해금과 상점 진열. 효과: 해체 도구 (가공 속도 증가) |
| 명예의 전당 | A | A → S | 3차 직업 모험가 기록. 효과: 트로피 (명성 상승) |

시설 자체의 규칙·효과는 → [05_길드.md](05_길드.md).

### 3-3. 승급 침공

- 승급 침공과 소규모 습격은 규모와 이름만 다른 '마을 방어 전투'입니다. 규칙(보스급 의뢰 N건 → 침공 3웨이브 + 보스, 대비 2개월)과 전투 수치는 → [03_전투.md](03_전투.md) (원본: design_v0.1.md §11.2·§11.2-1·§11.3).
- 침공에서 지면 인구 −10% [가안]과 **승급 실패**입니다. 이기면 인구 감소가 없습니다. 첫 엔딩까지 승급 침공은 6회입니다.
- 습격을 먼저 넣으면 판정·준비 화면·마을 탑뷰 연출을 침공이 그대로 물려받습니다. 침공은 "웨이브 3 + 보스 + 대비 2개월"만 더하면 됩니다. [제안]
- 시뮬레이터는 E급 승급을 메인 퀘스트 규칙으로 바꿀 때 F→E의 `invasionStep`을 끄고, E→D부터 침공을 씁니다. [제안]

## 4. 명예의 전당, S급 후보, 다회차

### 4-1. 명예의 전당과 S급 후보

| 항목 | 내용 |
| --- | --- |
| S급 후보 | A급이면서 레벨 45 이상인 모험가. 길드 등급 상한 때문에 S급에 오르지 못한 상태 |
| A→S 추가 조건 | S급 후보 2명 이상 (마왕전 고정 파티의 핵심 전력을 미리 확보) |
| 승급 순간 | 길드가 S급이 되면 후보들이 자동으로 S급이 되고, 그 자리에서 명예의 전당에 이름이 새겨짐 |
| 이후 등재 | S급에 도달한 모험가는 그때마다 등재. 사망한 S급 모험가도 이름이 남음 |

> ⚠️ 출처 차이: "S급 후보 = 길드 등급 상한 때문에 S급에 오르지 못한 상태"는 원안의 "모험가 등급 상한 = 길드 등급" 전제입니다. 2026-11-12 규칙(상한 = 길드 등급 + 1, 단 S급은 길드 S 승급 순간만)에서도 S급은 길드가 S가 되는 순간에만 오르므로 이 절의 내용은 그대로 유지됩니다.

### 4-2. 다회차 (명예의 전당의 영웅)

다회차는 더 쉽게 플레이하며 다른 엔딩을 보게 하는 것이 목적입니다. 다회차 난이도 상승은 두지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 데려올 인원 | 지금까지 본 엔딩의 수 (최대 3명). 전생자가 참가한 토벌은 엔딩 1의 변형이라 따로 세지 않음. 프로토타입은 2회차에 1명 |
| 선택 | 회차 시작 시 명예의 전당에서 고름 |
| 상태 | 능력치와 스킬을 그대로 유지하고 초반에 등장. 모험가 등급은 길드 등급 상한에 맞춰짐. 애착 단계도 전 회차 그대로 유지 |
| 사망 | 그 회차에서는 다시 오지 않음 |

(엔딩 구성은 → [09_스토리_세계관.md](09_스토리_세계관.md))

## 5. 명성·신뢰도와 승급, 그리고 "관문"이라는 이름

### 5-1. 명성·신뢰도는 승급의 직접 조건이 아님

현재 규칙에서 길드 승급 조건은 메인 퀘스트 클리어뿐이고, 명성·신뢰도 수치 문턱은 없습니다. 두 수치는 승급까지 걸리는 시간에 간접적으로 영향을 줍니다.

| 수치 | 승급과의 연결 | 상세 |
| --- | --- | --- |
| 명성 | 명성 10마다 모험가 1명 합류(길드 등급별 상한 안에서). F급 메인 퀘스트 보상 명성 10 = 모험가 1명 추가(E급 상한 12). 의뢰 성공·실패로 정수 변동 | → [01_모험가.md](01_모험가.md), [../../balance/fame.md](../../balance/fame.md) |
| 신뢰도 | 0~100, 시작 50. 5단계로 의뢰 수·보상·경험치에 영향 → 모험가 성장 속도와 메인 등장 시점(2차 전직 조건 도달)에 영향 | → [02_의뢰.md](02_의뢰.md) |
| 모험가 승급 시 명성 보너스 | 0 (메인 퀘스트 보상으로 따로) | [../../balance/progression_v1.md](../../balance/progression_v1.md) 2-2 |

- 명성·신뢰도가 예전보다 약 2.5~3배 빨리 움직이게 된 정수화(2026-11-12) 뒤에는 방문 수·의뢰 유입·승급 속도와 함께 관문 1 재검증이 필요합니다. (원본: balance/fame.md)

### 5-2. "관문"은 승급 조건이 아님

- 이 프로젝트의 **관문 1**은 게임 규칙과 시뮬레이터를 100판씩 1년 돌려 첫해 월 운영 순이익과 의뢰 성공률을 비교하는 **밸런스 검증 단계**입니다(`tools/gate1_check.js`). 장부와의 관계는 → [07_경제.md](07_경제.md) 6-2절, 기준과 이력은 → [../../balance/gate1.md](../../balance/gate1.md).
- **관문 2**는 플레이테스트 단계의 점검입니다(→ [../../balance/m2_observation.md](../../balance/m2_observation.md)).
- 길드 승급과 관련된 것은 F급 메인 퀘스트를 구현할 때 "관문 1 기준을 새로 잡는다"는 점뿐입니다(progression_v1.md 4장).
