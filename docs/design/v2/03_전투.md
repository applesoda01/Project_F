## 요약

- **전투가 있는 의뢰는 실제 전투 계산으로 성공·실패를 정하고, 그 전투에서 잃은 것(체력·물약·부상·사망)도 그대로 결과가 됩니다.** 비전투 의뢰(조사, 채집 등)는 능력치 판정을 그대로 씁니다(→ [02_의뢰.md](02_의뢰.md)). 미니 뷰는 전투 기록을 그대로 재생합니다(→ [10_UI.md](10_UI.md)).
- 전투는 라운드 방식의 자동 계산입니다. 2026-11-11 재작성으로 피해는 고정 차감, 회피·마법 방어는 폐지, 행동은 기교 기반 행동 게이지, 치명타는 민첩 기반으로 바뀌었습니다. 실제 엔진은 `prototype/js/combat.js`입니다.
- 대열은 아군·적 모두 한 줄이고 맨 앞끼리 맞붙습니다 [가안]. 스킬 발동 확률 20 / 35 / 50%는 설계서에서 확정했지만 지금 엔진은 20% 고정이라 통일이 필요합니다.
- 모험가는 예측 전투로 이길 여유를 보고 출발합니다. 출발 기준은 확정 0.95 / 0.85 / 0.65(신중 / 보통 / 무모)입니다.
- 밸런스 목표는 의뢰 성공률 80~95%, 첫해 월 운영 순이익 300~600G입니다. 2026-11-11 시험에서는 승률 100%로 너무 쉬워 몬스터 공격력 상향을 보류 중입니다.
- 마을 방어 전투(승급 침공·소규모 습격)는 마을 탑뷰 한 화면에서 지켜보는 자동 전투이고, 결과는 승리와 패배 두 가지뿐입니다.
- 습격·침공 이식 설계 v1 [제안]: 프로토타입(F급 1년)에는 소규모 습격만 넣고, 첫해 3번(4 · 8 · 12월), 패배 비율 15~25%, 플레이어 결정 2개(누구를 남길지 · 보상금 단계)를 붙입니다. 침공은 E→D 이후 몫입니다.
- 마인은 마왕군에게 죽은 모험가의 2세에게서 생기는 특수 전투 요소입니다 [가안].

## 1. 전투 의뢰와 비전투 의뢰

**전투가 있는 의뢰는 실제 전투 계산으로 성공·실패를 정하고(B), 그 전투에서 잃은 것(체력·물약·부상·사망)도 그대로 결과가 된다(C).** 비전투 의뢰(조사, 채집 등)는 지금의 능력치 판정을 그대로 쓴다. 미니 뷰는 전투 기록을 그대로 재생한다. [가안]

| 의뢰 | 성공을 정하는 것 | 잃는 것 |
| --- | --- | --- |
| 전투 의뢰 (적이 있는 의뢰) | **전투 계산** (적 전멸 = 성공, 후퇴·전멸 = 실패) | 체력, 물약, 부상, 사망 |
| 비전투 의뢰 (적이 없는 의뢰) | 능력치 판정 (지금과 같음) | 실패 시 빈손 귀환 |

### 1-1. 기획서(design_v0.1)와 달라지는 점

- 기획서 11.3 "체력·마력·방어력은 의뢰 성공 판정에 쓰지 않는다" → **전투 의뢰에서는 쓴다**로 바뀜.
- 기획서 6.6 성공 판정(능력치 프로필) → **비전투 의뢰에만** 적용. (6.6 판정식 → [02_의뢰.md](02_의뢰.md))
- 퀘스트의 "판정 기준치·요구 능력치"는 비전투 의뢰에만 의미가 있고, 전투 의뢰의 난이도는 **적 구성 × 기간**(몬스터 수 ×1.5/주, 이미 정한 규칙)이 정함.

## 4. 라운드 전투 계산

전투는 라운드 방식의 자동 계산이며, 계산 결과(기록)를 미니 뷰가 그대로 재생합니다. 전투 의뢰에서는 이 계산이 곧 의뢰의 성패입니다. 실제 엔진은 `prototype/js/combat.js`에 있습니다.

### 4-1. 기본 규칙 (2026-11-11 재작성 후, 지금 엔진)

| 항목 | 규칙 |
| --- | --- |
| 피해 | (공격 × 배율 × 흔들림[× 치명타]) − 방어, 0 미만이면 0 (고정 차감). 회피·마법 방어 폐지 |
| 배치 | 자동. 전사·도적(체력 높은 순) → 궁수·마법사 → 성직자 |
| 대상 | 적은 살아 있는 맨 앞 아군을, 아군은 맨 앞 적을 공격 (후열을 노리는 적은 프로토타입 이후) |
| 행동 게이지 | 기교 1당 +0.5%로 라운드마다 충전, 100이 차면 행동(한 라운드에 여러 번 가능). 적 속도는 1 |
| 치명타 | 민첩 1당 +0.5%, 피해 1.5배 |
| 능력치 환산 | 힘 1당 체력 3, 지력 1당 마력 3, 정신 1당 회복력 2 |
| 최대 라운드 | 30 (전체 합산, 넘으면 후퇴) |
| 후퇴 | 파티 전체 체력이 후퇴선(신중 50% / 보통 30% / 무모 10%) 아래면 실패 |
| 출발 판단 | 고정 씨앗 전투 30회의 승률을 예상 성공률로 사용 (0.02~0.98) |

> 출처: game_overview.md §5

### 4-2. 계산 순서 (2026-11-03 초안, 무작위 있음) [가안]

1. 라운드마다 민첩 순서로 행동. 모험가는 체력 낮은 적부터 집중 공격, 적은 앞줄(전사·도적 → 궁수 → 마법사·성직자)부터 공격.
2. 성직자는 체력이 낮은 아군이 있으면 공격 대신 회복(정신 비례, 마력 소모).
3. 체력이 물약 사용선 아래면 물약 사용. (물약 규칙 → [04_아이템.md](04_아이템.md) 2장)
4. **후퇴**: 파티 전체 체력이 후퇴선 아래로 내려가면 후퇴 = 실패. 후퇴선은 파티장의 위험 성향(신중 50% / 보통 30% / 무모 10%).
5. **성공**: 적 전멸. 도중에 체력 0이 된 사람은 부상(성공해도).
6. 무작위(피해 ±10%, 회피, 치명타)가 있어 같은 파티라도 결과가 달라짐 → 성공 확률이 자연스럽게 생김.
7. 기록: 라운드별 양쪽 체력·물약·쓰러짐 → 미니 뷰가 재생.

> ⚠️ 출처 차이: quest_combat.md §3(2026-11-03)은 "민첩 순서로 행동, 모험가는 체력 낮은 적부터 집중 공격, 적은 앞줄부터", quest_combat.md §11(2026-11-09)과 game_overview.md §5(2026-11-12)는 "한 줄 대열, 맨 앞 1명만 맞음, 기교 기반 행동 게이지" → 최신인 game_overview.md·§11을 따름. 회피는 폐지되어 6번의 "회피" 무작위는 지금 엔진에 없음.

> 출처: quest_combat.md §3

### 4-4. 웨이브와 스킬

- 한 그룹의 최대 마릿수는 F 2 / E 3(E는 확정 대기), D 이상은 임시값입니다. 그룹을 나눠 웨이브를 반복하며, 추가 이월은 체력·마력이 회복 없이 이어집니다. 보스는 마지막 웨이브에 단독 등장합니다.
- 스킬은 성직자를 제외하고 20% 확률로 발동합니다(지금 엔진 값). 더블 스윙·연사는 1배 두 번, 파이어볼은 대상과 바로 뒤 1명에게 1.5배, 급소 찌르기는 1.5배 한 번입니다. 마력 소모는 전사 20 / 궁수 20 / 마법사 30 / 도적 15입니다.
- 스킬 전투 계산 v1 설계서([../../balance/skill_combat_v1.md](../../balance/skill_combat_v1.md))는 발동 확률 20/35/50%(1·2·3차), 마력 10/20/30, 힐은 아군 체력 50% 이하에서 발동, 물약 회복량은 물약 등급 기준 30~70%로 정의합니다. 지금 엔진과 일부 수치가 다르므로, 정식 반영 시 통일이 필요합니다.
- 스킬 목록(82개)과 장착 규칙 → [01_모험가.md](01_모험가.md).

> ⚠️ 출처 차이 (스킬을 전투 계산에 넣을지): quest_combat.md §8·§9(2026-11-03)는 "스킬은 넣지 않음, 성직자 회복만 기본 행동", quest_combat.md §11(2026-11-09)은 "스킬 확정: 발동 20 / 35 / 50%", game_overview.md §5(2026-11-12)는 "지금 엔진은 성직자 제외 20% 고정, 설계서와 통일 필요" → 설계 기준은 최신 확정인 20 / 35 / 50%이고, 엔진 반영은 미결(game_overview.md §11 불일치 목록 "skill_combat_v1.md vs 현재 combat.js").

## 10. 마을 방어 전투 (승급 침공, 소규모 습격)

### 10-1. 기본 규칙

승급 침공과 소규모 습격은 규모와 이름만 다른 '마을 방어 전투'입니다. 모든 전투(방어전, 간부전, 마왕전, 특별 퀘스트 전투)의 결과는 **승리와 패배** 두 가지뿐입니다.

| 항목 | 내용 |
| --- | --- |
| 화면 | 마을 탑뷰 한 화면, 화면 이동 없음, 지켜보기 |
| 구도 | 성문(적의 입구) → 마을 거리(전장) → 마을 중심의 성(지킬 대상). 길드에서 모험가가 출발 |
| 승리 / 패배 | 모든 적 제거 / 성 함락 (체력 0) |
| 시간 제한 | 없음 (보통 60~120초에 끝나도록 조정) |
| 웨이브 [가안] | 침공 3웨이브 + 보스 / 습격 1~2웨이브, 보스 없음 |
| 성 체력 | 마을 인구 단계에 따라 커짐 (개척촌 목책 요새 → 성채 도시 대성채). 금전으로 강화 불가 |
| 패배 시 | 인구 감소 (습격 −5%, 침공 −10% [가안]), 습격은 신뢰도 하락, 침공은 승급 실패. 이기면 인구 감소 없음 |
| 참가 | 거주민 자동. 그 외 마을에 있는 모험가는 애착도와 성향으로 정해진 '필요 보상금' 이상이면 참가. 의뢰 중·다른 마을·부상은 불참 |
| 대비 기간 | 침공 2개월, 습격 2주 전 예고 (천문대가 있으면 +1개월, +1주). 동반자 이상은 예고 후 장기 의뢰를 피함 |
| 준비 화면 | 참가 확정 목록 → 보상금 단계별 추가 합류 목록 미리 보기 → 아군 전력 vs 적 규모 → 확정 |
| 쓰러진 모험가 | 성당(없으면 의무실)으로 옮겨졌다가 일정 시간 뒤 복귀. 둘 다 없으면 복귀 없음. 대성당이 있으면 더 빨리 |
| 마력 회복 | 마법 학원(없으면 주점·식당, 그 전에는 자연 회복과 물약). 마탑이 있으면 더 빨리. 이동 기준: 신중 30% / 보통 15% / 무모는 가지 않음 |
| 사망 판정 | 전투 후, 쓰러진 횟수가 많을수록 확률 상승 |

- 승급 흐름(보스급 의뢰 N건 → 침공)과 승급 조건 → [08_길드승급.md](08_길드승급.md).
- 마을 인구 단계·성 체력의 바탕이 되는 마을 규칙 → [06_마을.md](06_마을.md).

> ⚠️ 출처 차이 (참가·사망): design_v0.1.md §11.2는 "참가 = 애착도·성향으로 정해진 필요 보상금 이상이면 참가, 사망 = 쓰러진 횟수가 많을수록 상승", raid_invasion_v1.md §1(2026-11-14, 시뮬레이터 실제 규칙)은 "애착 100은 전원, 나머지는 60% 확률 참가, 사망 = 이기면 1% · 지면 3% × 성향(0.5 · 1 · 1.5), 의무실 −15%", raid_invasion_v1.md §3 [제안]은 "플레이어가 고른 보상금 단계로 참가" → 최신인 raid_invasion_v1.md를 따르되, 보상금 단계는 아직 [제안]이므로 12장에 둠.

### 12-3. 플레이어 결정

| 시점 | 결정 | 화면 | 효과 |
| --- | --- | --- | --- |
| 예고 (2주 전) | 리나: "마스터, 성문 쪽에 들개 무리 발자국이 늘었대요. 2주 안에 올 것 같아요." | 일지 + 리나 말풍선 + 마을 화면 성문에 느낌표 | — |
| 예고 기간 | **누구를 남길지:** 긴 의뢰(2주 이상)를 보내면 그 모험가는 빠짐. 게시판 필터를 바꾸거나 출발을 보류 | 게시판 장에 "습격 대비" 표시, 모험가 카드에 "방어 참가 예정" | 수익 vs 방어 전력 |
| 습격 당일 | **보상금 단계:** 없음 / 낮음(의뢰 보상 × 0.5) / 보통(× 1.0) / 높음(× 1.5). 단계가 높을수록 애착 낮은 모험가도 참가 | 준비 창: 참가 확정 목록 → 단계별 추가 합류 → 아군 전력 vs 적 규모 막대 → 확정 (11.2 "준비 화면") | 돈 vs 승률 |

- 승률은 숫자 대신 막대 3칸(불리 · 비슷 · 유리)으로 보여 줍니다. 플레이어에게 보이는 수치는 정수 원칙(`working_rules.md` 4장).
- 애착 100(거주민)은 보상금 없이 자동 참가합니다. 그래서 "애착을 키우면 방어가 싸진다"는 연결이 생깁니다.
- 준비 창의 화면 배치 → [10_UI.md](10_UI.md).

### 12-5. F급 첫해 값 제안과 영향 예측
