## 요약

- 주인공은 이름 없는 길드 마스터("마스터")입니다. 전직 B급 모험가(궁수)로, 옛 파티원이 이 마을에서 전멸한 뒤 길드를 세웠습니다. 옛 파티는 봉인이 약해지는 흔적을 알리려다 마왕군 간부에게 제거되었고, 그 진실은 메인 퀘스트로 길드 등급마다 조금씩 공개됩니다.
- 세계관: 옛 용사 파티가 마왕을 여러 부위로 나눠 여러 마을에 봉인했고, 15년 동안 다른 봉인이 깨져 이 마을이 마지막 봉인으로 남았습니다. 영주의 성이 봉인의 핵이고, 마을 사람들의 삶(인구)이 봉인의 힘입니다. 마왕군은 인구를 줄여 봉인을 약화시키려 합니다. 화약이 없는 세계입니다.
- 엔딩: 길드 등급 S에서 전조가 시작되고, 마왕군 간부 3명(+선택 간부 1명)을 거쳐 고정 파티가 마왕을 토벌하면 엔딩입니다. 실패하면 사망과 계승 후 2세가 재도전합니다.
- 멀티엔딩은 플래그 누적형입니다. 분기점 4곳의 선택으로 토벌(메인) · 재봉인 · 계승 엔딩이 갈리며, 프로토타입 목표는 1번 토벌입니다.
- 접수원 리나는 옛 파티 도적 카일의 여동생이며, C급·B급 메인에서 서로의 정체와 오빠의 일지가 드러납니다.
- 마을 핵심 건물 11종마다 의뢰인의 서브 스토리(총 20개)가 있고, 15년차까지 마왕을 토벌하지 못하면 구제용 전생자 "한도윤"이 합류합니다 [가안].
- 메인 퀘스트 16개의 세부(배치·지명·실패·보상·일지)는 (→ 02_의뢰.md), 플랫폼은 (→ 00_게임개요.md)에 있습니다.

## 1. 엔딩

| 단계 | 내용 |
| --- | --- |
| 1. 발생 | 길드 등급 S 달성 시 전조 단계 시작 (마을이 강해져 마지막 봉인이 단단해지자 마왕이 초조해짐) |
| 2. 전조 | 마왕군 간부 의뢰가 등장하고, 달성하면 마왕성 공략 의뢰가 열림 |
| 3. 자격 | 고정 파티 + 평균 A등급 이상만 수주 가능 (시스템 고정) |
| 4. 도전 | 조건을 갖춘 파티가 스스로 수주 |
| 5. 결과 | 성공하면 엔딩, 실패하면 사망과 계승 후 2세가 재도전 |

**마왕전 연출**: 고정 파티가 마왕성에서 싸우는 장면을 침공과 같은 방식(탑뷰, 지켜보기)으로 보여 줍니다. 마왕군 웨이브 → 마왕. 마왕 체력이 0이면 승리, 파티 전멸이면 패배이며 시간 제한은 없습니다. 전설 직업은 전용 스킬 연출을 가집니다.

- 고정 파티(친밀도 100) 규칙과 사망·계승은 (→ 01_모험가.md), 방어 전투와 같은 전투 표현은 (→ 03_전투.md · 08_길드승급.md).

> ⚠️ 출처 차이: 이 절(design_v0.1.md §12)은 "조건을 갖춘 파티가 스스로 수주"로 적었으나, 같은 문서 §12-1.6(메인 퀘스트)은 "메인만 마스터가 직접 지명 (간부·마왕성도 자격 조건을 갖춘 파티 중에서 지명)"으로 정함 → 더 구체적인 §12-1.6을 따름. 마왕성 공략도 자격을 갖춘 파티 중에서 마스터가 지명합니다. (→ 02_의뢰.md)

## 3. 옛 용사의 방패 (전설급 방어구)

- 직업 제한 없음. 검·지팡이와 달리 스스로 주인을 고르지 않습니다.
- **최초 주인:** 선택 간부를 토벌한 파티의 전위 역할 모험가 (여럿이면 힘이 가장 높은 모험가). 스토리 연출로 지급하며 마스터가 회수할 수 없습니다.
- 첫 주인이 사망하거나 마을을 떠나면(애착 60 미만) 길드로 귀속됩니다.
- 이후에는 길드 창고에 보관하고 마스터가 원하는 모험가에게 빌려줍니다. 대여받은 모험가가 사망하거나 떠나면 다시 길드로 돌아옵니다.

- 전설급 장비의 수치·장비 규칙은 (→ 04_아이템.md). 창고의 장비 보관대는 (→ 05_길드.md).

> 출처: design_v0.1.md §12.2

## 4. 길드 마스터 (주인공)

| 항목 | 내용 |
| --- | --- |
| 출신 | 전직 B급 모험가. 나이와 능력의 한계로 더 오르지 못하고 은퇴 |
| 설립 동기 | 개인 연고 + 왕국 허가·보조금. 길드가 없던 이 마을에서 옛 파티원 전원이 의뢰 중 사망 |
| 생존 이유 | 기절해 있다 홀로 깨어남 (기억 공백). 사실은 동료들이 쓰러진 마스터를 지키다 죽었음 |
| 사망 원인 | 처음에는 원인 불명의 사고로 알려짐. 실은 봉인이 약해지는 흔적을 발견하고 알리려던 옛 파티를 마왕군 간부가 제거한 것 |
| B급의 의미 | 길드가 B→A로 승급하는 순간이 '마스터가 닿지 못한 곳을 넘어서는' 감정 정점 |

- 플레이어 = 길드 마스터. 직접 싸우지 않고 환경과 방침으로 간접 운영합니다. (→ 00_게임개요.md)

## 5. 진실의 공개 [가안]

진실은 메인 퀘스트로만 공개합니다. 실제 수행은 모험가가 하고, 마스터는 집무실 결과 보고로 알게 됩니다.

| 길드 등급 | 원인 줄기 (누가) | 생존 줄기 (왜 나만) |
| --- | --- | --- |
| F~E | 사고로 알려짐 | 운이 좋았다고 믿음 |
| D~C | 흔적이 마물 습성과 맞지 않음 | 쓰러진 위치가 처음과 다름 (누군가 옮김) |
| B | 의도된 습격 | 동료들이 마스터를 지키다 죽었음을 확인 |
| A | 마왕군 간부의 정체 | 동료들의 마지막 행적이 완성됨 |
| S | 원수 간부 토벌 | 빚을 갚는 장면 |

- 등급별 메인 퀘스트 16개(제목·내용·연출·위험도)와 분기점 표, 지명 인원, 실패 처리, 보상, 일지 변형은 (→ 02_의뢰.md).

> 출처: design_v0.1.md §12-1.2 · §12-1.6

## 6. 세계관

| 항목 | 내용 |
| --- | --- |
| 세계관 규칙 | 화약이 없는 세계. 무기는 검, 창, 활, 지팡이, 맨손 등 |
| 조직 | 대륙 단위의 길드 연합(본부)이 길드 등급 공인과 승급 심사를 맡고, 왕국은 계약에 따라 등급별 보조금을 지급. 다른 마을 길드도 같은 연합 소속 |
| 마왕 | 과거 옛 용사 파티가 마왕을 여러 부위로 나누어 여러 마을에 봉인. 봉인 과정에서 흩어진 작은 조각이 '마왕의 파편'(마인 계보의 근원) |
| 이 마을 | 봉인 마을 중 하나. 15년 동안 다른 봉인들이 하나씩 깨져 이 마을이 마지막 봉인으로 남음. 소식은 월간 보고와 소문으로 전달 |
| 봉인의 원리 | 영주의 성이 봉인의 핵이고, 마을 사람들의 삶(인구)이 봉인의 힘 |
| 마왕군의 목적 | 약탈이 아니라 인구를 줄여 봉인을 약화시키는 것 (습격·침공, 패배 시 인구 감소, 성 함락 = 패배의 명분) |
| 전설의 검 | 봉인을 만든 옛 용사의 증표. 마왕에게 추가 피해를 주지만 엔딩 필수 조건은 아님. 검의 '원래 자리'는 봉인지 안의 제단 |

- 습격·침공의 전투 규칙과 인구 감소 수치는 (→ 08_길드승급.md), 인구 규칙은 (→ 06_마을.md), 보조금 수치는 (→ 07_경제.md).
- 화약 금지 규칙은 전생자의 메타 대사로 웃음으로 설명합니다 (13장).

## 7. 영주

봉인을 대대로 비밀리에 지켜 온 가문입니다. 그래서 처음에는 외부인 길드를 경계하고, 태도가 '동반자'가 되면 봉인의 비밀을 털어놓습니다. 태도는 마을 단계를 따르고, 영주 서브 퀘스트를 완료하면 한 단계 앞당겨집니다. 태도별 혜택은 미정입니다.

| 마을 단계 | 영주의 태도 |
| --- | --- |
| 개척촌 | 경계 |
| 마을 | 관망 (첫 방어전 승리 후 인정하기 시작) |
| 읍 | 협력 |
| 도시 | 신뢰 |
| 성채 도시 | 동반자 |

- 이름: 오스윈 하트웰 (Oswin Hartwell) [가안] (12장).
- 영주 태도를 올리는 다른 경로: C급 메인 「숲속의 석비」 분기①(영주에게 보고하면 태도 한 단계 상승), 영주 요청 서브 퀘스트 [제안]. (→ 02_의뢰.md)
- 메인 A급 「성 아래의 빛」에서 영주가 성이 봉인의 핵이라고 고백합니다. (→ 02_의뢰.md)

> 출처: design_v0.1.md §12-1.4 · §12-1.6 · §12-1.9

## 8. 멀티엔딩

플래그 누적형입니다. 메인 16개의 큰 흐름은 같고, 분기점 4곳의 선택이 플래그로 쌓여 마왕전 이후 엔딩이 결정됩니다. 분량은 메인 16 + 변형 장면 약 10 + 엔딩 3 = 약 30개 단위입니다.

| 엔딩 | 내용 | 범위 |
| --- | --- | --- |
| 1. 토벌 (메인) | 마왕 토벌. 마왕은 세상 마력의 근원이었으므로 마력이 사라지고, 세상은 다른 의미의 혼란 속에 새로운 시대로 들어섬 (에필로그) | 프로토타입 목표 |
| 2. 재봉인 | 마왕이 마력의 근원임을 알고, 세상이 너무 크게 바뀌는 것을 막기 위해 다시 봉인 | 이후 확장 |
| 3. 계승 | 일에 지친 마왕이 자리를 물려줌 (마왕은 물러나고 싶었고, 간부들이 독자적으로 움직였다는 방향) | 이후 확장 |

- **마력 복선:** A급 전후 메인에서 "다른 마을의 봉인이 깨질 때마다 그 지역의 마력이 들끓었다"는 소식을 흘림. 1번 루트에서는 복선, 2번 루트에서는 진실의 단서.
- 프로토타입에서 분기는 대사와 에필로그 문구만 바꾸고, 2·3번은 플래그에 조건을 붙여 확장합니다.
- 분기점과 엔딩의 연결 (분기가 일어나는 메인 퀘스트 내용은 → 02_의뢰.md):

| 분기 | 쌓이는 플래그 | 연결되는 엔딩 |
| --- | --- | --- |
| ① 석비 보고 | 영주와의 신뢰 | 2번 재봉인 |
| ② 정점 파견 | 생존자 기록 | 모든 엔딩의 에필로그 |
| ③ 마력 조사 | 마력의 진실 | 2번 재봉인 |
| ④ 간부의 말 | 마왕의 피로 | 3번 계승 |

- 전생자가 참가한 채 토벌하면 에필로그에 "이방인의 도움" 문구가 추가됩니다 (13장).

> 출처: design_v0.1.md §12-1.5 · §12-1.6 · §12-1.11

## 9. 메인 퀘스트 (링크)

메인 퀘스트(배치 F1 · E1 · D2 · C2 · B3 · A3 · S4 = 16개, 수행·수락 확률·연출, 16개 목록, 분기점, 지명 인원, 실패 처리, 보상, 일지 변형)는 의뢰 문서 담당입니다. (→ 02_의뢰.md)

이 문서와 맞물리는 이야기 요소만 적습니다.

- 메인은 진실의 공개(5장)를 원인 줄기 · 생존 줄기 두 갈래로 나르며, 정점(B급 「그날의 숲」)·전환(A급 「성 아래의 빛」)·간부 1~3·마왕전이 큰 이벤트입니다.
- 메인 고유 보상 중 이야기 연출: 옛 파티의 문장(길드 장식), 리나의 일러스트 교체(일지를 품음), 옛 파티의 유품 4점, 옛 용사의 방패(선택 간부).

> 출처: design_v0.1.md §12-1.6

## 10. 접수원

| 항목 | 내용 |
| --- | --- |
| 역할 | 게시판 앞에서 모험가를 응대함. 한 명으로 고정된 비서 같은 캐릭터. 능력치는 없고, 연출과 정보 전달을 맡음 |
| 정체 | 옛 파티 도적(정찰 담당)의 여동생. 오빠는 기절한 마스터를 동굴 입구로 옮겨 숨기고 망토를 덮어 준 뒤, 동료들에게 돌아가 싸우다 죽음 |

| 직업 | 전설 직업 "전생자" (고유). 다른 세계에서 온 사람 |

| 사망 | 다시 오지 않음. 2세도 없음 |
| 엔딩 | 전생자가 참가한 채 토벌하면 에필로그에 "이방인의 도움" 문구 추가 |

| 항목 | 내용 |
| --- | --- |
| 이름 | 한도윤. 이 세계 사람들은 발음을 어려워해 "도인"이라고 부르기도 함. 서양풍 이름들 사이에서 혼자 한국 이름이라 이방인임이 바로 드러남 |

| 성향 | 위험 신중, 소비 낭비, 사교 독불장군 |
| 메타 대사 | 드물게, 짧게. 예: "게시판에 필터까지 있네… 이거 누가 기획했지?" / "화약? 안 돼요. 그거 넣으면 이 세계 밸런스 다 무너져요." (화약 금지 규칙을 웃음으로 설명) |
