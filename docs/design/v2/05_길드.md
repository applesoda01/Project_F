## 요약

- 길드는 플레이어가 운영하는 시뮬레이션 공간입니다. 길드 등급(F~S)이 오르면 층이 열리고, 층마다 정해진 시설이 있습니다(총 15종).
- 시설에는 레벨이 없습니다. 원래 설계는 정해진 소재를 써서 시설마다 효과 3개(정보실 5개, 집무실 0개, 총 44개)를 하나씩 여는 방식입니다.
- 프로토타입(F·E급)은 2026-11-12 개편으로 효과 개방 대신 **업그레이드 1단계(금전만)**를 둡니다. 집무실은 E급 2,000G에서 **F급 1,000G**로 바뀌었고, 로비 안쪽 문 2개는 해당 시설을 지으면 열립니다. 시설 유지비는 2026-11-05에 삭제했습니다.
- 길드 내부(하우징)는 2:1 쿼터뷰이며 프로토타입은 1층만 있습니다. 시설 6종은 자리가 고정이고, 장식(F급 8종)과 테이블 세트는 **바닥 격자 자유 배치**(2026-11-12)입니다.
- 장식 효과는 정수로 바꿨고(2026-11-12), 프로토타입에는 장식 업그레이드가 없습니다. 테이블은 0세트에서 시작해 각 200G, 앉은 모험가만 음식을 주문합니다.
- 2026-11-13부터 설비 중 처음에는 테이블 2세트만 지을 수 있고, 테이블 3·4세트와 장식 8종은 서브 퀘스트(리퀘스트) 보상으로 열립니다.
- 훈련장(힘·민첩·기교, D급)과 도서관(지력·정신, C급)이 시설 훈련을 맡습니다.
- 주점·식당은 출발 전 식사와 술 판매로 수입을 냅니다. 요리 규칙 자체는 (→ 04_아이템.md)에 있습니다.

## 4. 시설 효과 (44개) [가안]

모든 이름과 수치는 [가안]입니다. 수치는 시뮬레이터로 검증합니다. 시설 효과의 재정리는 현재 스탯·전투·장비 개편 뒤 다시 하는 작업이 예정되어 있습니다.

> ⚠️ 출처 차이: 이 장(design_v0.1.md §12-2.5, 2026-10-20)의 효과 1·2·3 개방은 popup_fac.md §4·§6(2026-11-12)에서 **프로토타입에서 보류**되었고, 프로토타입 F·E 시설은 6장의 "업그레이드 1단계(금전만)"로 대신함 → 프로토타입은 6장을 따르고, 이 장은 D급 이후·정식 설계의 기준으로 남김.

## 6. F·E 시설 개편 (2026-11-12 확정, 프로토타입 · 업그레이드·집무실·문 구현됨)

프로토타입 범위(F·E)의 시설은 이 장이 기준입니다. 수치는 모두 프로토타입용 임시값이며 밸런스는 프로토타입 이후입니다. 원칙: 효과는 %가 아닌 바로 읽히는 정수로 적습니다 (`working_rules.md` 4장).

### 6-1. 시설별 1단계·업그레이드

- **문 열림:** 로비 안쪽 문 2개는 길드 등급이 아니라 **해당 시설을 지으면 열림** (왼쪽 = 집무실, 오른쪽 = 관리소). 지금 열린 문 배경은 두 문이 함께 열린 한 장이라 문별로 나눠 덧그려야 함 (6-2에서 구현).
- **술 판매는 규칙(`game_core.js`)과 시뮬레이터에서 판정**하고, 로비의 술 주문 장면은 그 결과를 보여 줍니다 (화면 배속·로비 표시 여부와 무관하게 수입이 같도록).
- **접수대 응대 속도는 로비 연출 값**이라 게임 수치(수입·성공률)에는 영향이 없습니다. 응대 시간(1.5초)은 화면에 숫자로 보이지 않으므로 정수 원칙의 예외.
- **관리소 수락 확률:** 지금 식(애착 단계 40·65·90·100% × 2차 1.2배, 상한 100%)을 그대로 쓰고 +10%p만 더함. 애착 60 이상은 이미 100%라 효과가 없음 → 계산식 재설계는 프로토타입 이후.
- **소재 자동 차익**(의뢰 성공 시 보상의 8%, `econ.resaleRate`)은 프로토타입에서 그대로 둠. `economy_v1.md`의 "없앰"과 다름 → 밸런스 때 정리. (→ 07_경제.md)
- **메인·서브 퀘스트**(F급)는 프로토타입 범위. 아직 코드에 없어 새로 구현해야 하며, 집무실이 지명 기능의 선행 조건. (→ 02_의뢰.md)

#### 8-2-1. 장식 업그레이드 (2026-11-09 확정 → 프로토타입에서 없음)

2026-11-12: 프로토타입에서는 업그레이드 없음(사서 놓으면 Lv1 효과). 레벨 대신 **교체 방식**을 검토 중 → 프로토타입 이후. 아래는 2026-11-09 확정안으로, 프로토타입 이후의 기준입니다.

| 항목 | 내용 |
| --- | --- |
| 방식 | 장식(테이블 포함)을 클릭하면 **레벨 막대 + 업그레이드 버튼**. 그림은 바뀌지 않음 |
| 효과 | 레벨마다 Lv1 효과만큼 더함 (화분 Lv5 = 애착 +25%) |
| 비용 | Lv n → n+1 = 장식 가격 × n (Lv5까지 합계 = 가격 × 11) |
| 최대 레벨 | **길드 등급으로 제한**: F Lv2 · E Lv3 · D Lv4 · C 이상 Lv5 |
| 소재 | **Lv4 이상 업그레이드에만 소재 필요** (프로토타입 F·E는 최대 Lv3이라 영향 없음). 음식이 아닌 소재의 쓰임새 |

#### 8-2-2. 2배 보상 의뢰 (확정 2026-11-10, 수치는 가안)

| 항목 | 내용 |
| --- | --- |
| 발생 | 의뢰가 게시될 때마다 확률로 "×2" 의뢰가 됨. 의뢰 카드에 ×2 표식 |
| 기본 확률 | **5%** |
| 올리는 방법 | **트로피 장식장** 레벨당 +3%p (장식 1종 = 효과 1개 원칙) |
| 상한 | **합계 20%** (트로피 Lv5 = 5 + 15 = 20%) |
| 등급별 | F Lv2 11% · E Lv3 14% · D Lv4 17% · C 이상 Lv5 20% |
| 적용 보상 | **골드만 2배** (명성·경험치는 그대로) |
| 이유 | 효과 하나로 상한까지 채워 단순하게, 명성까지 2배면 진행이 너무 빨라짐 |

- 이 변경으로 **트로피 장식장의 "의뢰 보상 +3%"는 의뢰인 대기 벤치로 옮김**. 벤치의 "게시 의뢰 수 +5%"는 없앰 (주당 0.125건이라 체감이 없고, 신뢰도가 이미 의뢰 수를 30~120%로 조절하며, 보조금과 얽혀 균형 변수만 늘어남).
- 경제 시뮬레이션에서 2배 보상의 기대 수입(11% 확률 = 기대 +11%)과 수치를 다시 확인할 것.
