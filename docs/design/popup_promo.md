# 전직 제안 팝업

> 2026-11-09 사용자와 논의해 확정. 팝업 퀄업 8번 (마지막).

## 0. 요약

| 영역 | 예전 | 바뀜 |
| --- | --- | --- |
| 배치 | 제안 받은 모험가가 세로로 쌓임 | 왼쪽 **제안 목록**(n명, 12명 넘으면 스크롤) / 오른쪽 고른 모험가 상세 |
| 모험가 머리 | 오각형 능력치 + 회색 이름표 | 모험가 팝업과 같은 초상화·이름·등급 배지·직업·Lv, **애착·수락 확률 막대**, 능력치 **네모 10칸** |
| 선택지 | 글로 된 조건·성장 ("힘 0.4→0.5 · …") | 카드: 조건 10칸 + 목표선 + ✓/✕, 성장 "지금 ▲ 바뀜"(초록/빨강), 스킬 진화 아이콘 |
| 버튼 | "마도사(으)로 전직 승인", 보류가 작고 위쪽 | 금색 큰 버튼 "마도사**로** 전직 승인"(조사 맞춤), 보류는 아래 보조 버튼 + 안내 |
| 예외 | 없음 | 조건 부족 선택지는 카드 옅게 + 회색 "조건 부족 · 전직 불가"(누를 수 없음) |

## 1. 제안 규칙 (코드 그대로, 바꾸지 않음)

| 조건 | 내용 |
| --- | --- |
| 능력치 | 조건 능력치를 모두 채운 직업만 선택지 |
| 시설 | 모험가 관리소가 있어야 2차 제안. 없으면 "새 직업의 길"만 발견 |
| 3차 | 마을 건물이 필요해서 프로토타입에서는 제안 없음 |
| 수락 | 애착 단계별 40·65·90·100% × (2차 1.2 / 3차 0.9). 거절·보류해도 벌칙 없이 3개월 뒤 다시 |

- 능력치가 내려가는 규칙이 없으므로 정상 진행에서는 조건 부족 선택지가 나오지 않음. 회색 버튼은 예전 저장·디버그 대비.

## 2. 화면

| 영역 | 내용 |
| --- | --- |
| 왼쪽 (300px, 모험가 팝업과 같음) | "제안 n명" + 줄: 얼굴·★·이름·"직업 · n차 제안"·Lv. 목록만 스크롤, 다시 그려도 위치 유지, 고른 모험가는 보이게 |
| 오른쪽 위 | 초상화 · 이름 · 배지 · "1차 마법사 · Lv 10" · "2차 전직 제안" / 애착 막대(수치·칭호) · 수락 확률 막대 / 오른쪽 끝 능력치 5줄 × 10칸 |
| 카드 3장 | 이름 / 태그(3차로 이어짐·2차 종결 + Lv 상한, 늘 이름 아래 줄) / 조건(2줄 높이 확보) / 레벨업 성장 5개(줄 높이 22px 고정) / 스킬 진화 / 버튼(카드 바닥에 맞춤) |
| 아래 | 보류 + "보류하거나 모험가가 거절해도 벌칙은 없고, 3개월 뒤 다시 제안합니다." |
