# 마을과 인구

**마을 인구는 의뢰 유입량을 최대 2.5배까지 늘리는, 길드 밖의 성장 수치입니다.** 마을 화면은 로비와 별도의 탑뷰 화면이고, 들어가 있는 동안 시간이 멈춥니다(침공 제외).

## 인구가 느는 길

| 요인 | 증가 |
| --- | --- |
| 매달 기본 | +2 |
| 의뢰 성공 1건 | F +1 · E +2 · D +3 … S +8 |
| 지역 활동 기여 모험가(애착 65 이상) 1명 | 매달 +2. 실제 거주·계약과 별도 |
| 침공 패배 | −10% |

인구는 민가 수용 인원을 넘지 못합니다. 시작 인구는 150명입니다.

## 거주와 지역 기여 — TOWN-01 / 제안·미반영

| 구분 | 규칙 |
| --- | --- |
| 실제 거주 | 기존 주거 판정 보존, 애착 구간 통일은 미결 |
| 지역 활동 기여 | 애착 65 이상 기존 인구 효과 유지 |
| 정식 계약 | 인구를 추가 생성하거나 같은 사람을 두 번 세지 않음 |
| 상점 수입 | 대장간·물약 상점의 독립 수입. 길드 매출에 합산 금지 |

## 민가

- 인구가 수용을 넘으면 초가(레벨 1)가 생기고, 매달 오래된 집부터 2채가 레벨업합니다.
- 1칸 수용: 초가 40 · 목조 45 · 회반죽 50 · 회반죽 2층 60 · 석조 75명.
- 집의 최고 레벨은 마을 단계가 정합니다.

## 마을 화면의 조작: 슬롯 하나, 팝업 하나

**마을의 모든 조작은 "건물 자리(슬롯)를 누르면 팝업" 한 가지입니다.**

| 슬롯 상태 | 보이는 모습 | 조건 |
| --- | --- | --- |
| 빈터 | 표지 말뚝 | 인구 단계 미달 |
| 잠김 | 반투명 윤곽 | 단계는 됐지만 퀘스트 미완료 |
| 해금 | 건물 | 퀘스트 완료 |
| 업그레이드 | 바뀐 건물 | 성당 → 대성당, 마법 학원 → 마탑 |

건물 팝업은 공통 틀입니다: 머리(이름 · 단계) → 본문(지금 효과 1~2줄, 이용 버튼) → 아래(업그레이드 비용 · 조건, 못 채운 것은 붉게).

## 마을 건물

| 구분 | 생기는 방식 | 예 |
| --- | --- | --- |
| 핵심 건물 11종 | 특별 퀘스트 달성 | 성당, 사냥꾼 조합 … |
| 일반 건물 | 인구 단계 | 여관 · 대장간 · 물약 상점 등 |

프로토타입에서는 대장간 · 물약 상점이 리퀘스트(#19 · #20)로 생기며, F · E급 건물 효과는 아직 정하지 않았습니다. 대장간이 없으면 장비 강화를 할 수 없습니다.

> **지금 게임 (2026-11-18):** 마을 지도에서 건물을 누르면 설명 팝업이 뜹니다. **길드 본관**은 설명 + 지금 상태(모험가 · 길드에 있는 인원 · 원정 중 · 금고)와 **'길드로 가기'** 버튼을 보여 줍니다. **대장간**(해금 뒤)은 누르면 대장간 창이 열립니다 — 진열대(길드 등급까지 무기 · 방어구 · 장신구를 1개씩, 최근 손님) · 마스터 선물(길드 금으로 1칸씩, 애착 F +1 · E +2 [임시]) · 강화(2단계, 잠김). 자세한 규칙은 [장비](../ch06/gear.md) · 결정 34.

## 핵심 건물 11종

**핵심 건물은 3차 직업의 전직 조건이자 마을 효과를 주는 곳입니다.** 건물마다 의뢰인의 서브 스토리가 있습니다.

| 건물 | 전직 대상 | 특별 퀘스트 예 | 등장 등급 | 마을 효과 |

| 마법 학원 | 마검성 · 마궁성 | 폭주한 실험체 제압 | C | 훈련장 마법진 해금 |
| 투기장 | 검무사 | 떠돌이 검투사단과 결투 | C | 명성 상승, 무술 대회 |
