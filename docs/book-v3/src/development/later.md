# 5. 후속 사업과 보류 범위

**0~8단계가 검증된 다음 후속 사업을 별도 설계·구현합니다.**

| 순서 | 범위 | 선행 조건 | 완료 기준 |
| --- | --- | --- | --- |
| 9 / P3 | 상단 호위·장기 계약 | 예약·실적·외부 예치·기존 발주 검증 | 수행 보수/관리비 분리, 실패 환급·배상, 침공 충돌 해결 |
| 10 / P4 | 도시·왕국 계약 | 장기 사업의 비용·효과 검증 | 기존 길드 성장과 연결, 수익·의무·기간·취소 책임 명시 |
| 11 / P4 | 투자 탐사·정보·가공 | 소유 지분·원가·거래 기반 | 투자·위험·권리 배분과 실제 경제 효과 검증 |

각 후속 기능은 **설계 확정 → 실패 사례 → 규칙/시뮬레이터 → UI → 경제 비교**로 별도 진행합니다. 최소판 일정에 자동 포함하지 않습니다.

## 이번 최소판에서 제외

| 제외 | 이유 |
| --- | --- |
| 전원 고용·F급 급여 강제 | 자유 운영·첫해 진행 보존 |
| 접수원 급여 소급·시설 유지비 부활 | 기존 경제 변경 원인 분리 |
| 광고·보험·공제 | 핵심 계약·거래보다 뒤에 검토 |
| 완전한 시세 경제·독점 탐사권 | 가격·권리·실패 책임 확장이 큼 |
| 대장간 등 별도 제안의 동시 편입 | 최신 main의 제안과 충돌·중복 여부부터 확인 |

기존 미결인 늦장 실패·마스터 중재·후반 보상표는 [결정 대기 목록](../appendix/pending.md)에서 계속 관리합니다. 이번 계획에서 빠졌다는 이유로 폐기하거나 완료 처리하지 않습니다. (부상 표시는 2026-11-17 구현 완료되어 목록에서 뺐습니다.)
