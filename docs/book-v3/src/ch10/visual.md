# 비주얼과 사운드

**비주얼은 HD-2D 분위기의 배경 + SD 캐릭터이고, 바깥 풍경은 계절 · 시간대 · 날씨에 따라 바뀝니다.** 영상이 아니라 "통째 배경 그림 + 색 덧씌우기 + 입자 연출"로 만듭니다.

| 화면 | 시점 |
| --- | --- |
| 길드 | 단면 · 쿼터뷰 내부 |
| 마을 | 탑뷰 |
| 모험가 초상 | 얼굴 위주 고정 |
| 모험가 · 몬스터 | SD 스프라이트 (직업 10종 × 남녀, 몬스터 8종) |

## 시간대 (한 달 4주)

| 주 | 시간대 | 바깥 색 | 밝기 | 불빛 |
| --- | --- | --- | --- | --- |
| 1주 | 아침 | 따뜻한 연노랑 | 0.95 | 꺼짐 |
| 2주 | 낮 | 원본 | 1.00 | 꺼짐 |
| 3주 | 노을 | 주황 · 분홍 | 0.80 | 랜턴 켜지기 시작 |
| 4주 | 저녁 | 남보라 | 0.50 | 랜턴 켜짐 (월말 결산) |

주가 바뀔 때 약 4초 동안 부드럽게 섞습니다. 건물 안은 시간대와 관계없이 원본 그대로입니다.

## 계절과 날씨

| 달 | 계절 | 모습 | 연출 |
| --- | --- | --- | --- |
| 3~8월 | 일반 | 푸른 풀밭 · 초록 나무 | 나뭇잎 |
| 9~11월 | 가을 | 단풍 · 누런 풀 | 낙엽 |
| 12~2월 | 겨울 | 눈 덮인 땅 | 눈 |
| 비 | 일반 계절의 달 시작에 10% 확률로 그 달 내내 | 비 그림 | 빗줄기 · 유리 물방울 · 웅덩이 파문 |

- 낙엽 · 눈 · 비 · 구름 · 새 · 별은 코드 연출입니다. 식물은 흔들림 지도로 줄기 위쪽만 흔들립니다.
- 마을 배경은 한 단계(plate20)로 같은 방식을 시범 확정했습니다. 나머지 성장 단계는 필요할 때 같은 틀로 만듭니다.

## 사운드: 마을 배경음악 4곡

| 곡 | 루프 길이 | 도입부 |
| --- | ---: | ---: |
| 일반 | 168.2초 | 7.0초 |
| 가을 | 169.7초 | 5.25초 |
| 겨울 | 178.8초 | 3.0초 |
| 비 | 181.0초 | 5.0초 |

- 도입부를 한 번 재생한 뒤 끊김 없이 반복하고, 배경이 바뀌면 2초 교차 페이드로 곡을 바꿉니다.
- 시간대(낮 · 노을 · 저녁)는 같은 곡을 유지합니다.
