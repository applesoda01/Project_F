## 버전 관리

| 작업 | 기록할 것 |
| --- | --- |
| 규칙 수정 | 해당 장 본문 + [변경 비교표](changes.md) |
| 기획 채택 | 결정 날짜·근거, 구현 여부와 별개 |
| 게임 구현 | 코드 커밋·검증 범위·결과 |
| 수치 확정 | 같은 조건의 측정 근거 |
| 이전 규칙 확인 | 우측 V1 선택. 개정 본문에 옛 규칙을 중복 적재하지 않음 |

원고는 v1 `docs/book/src/`, v2 `docs/book-v2/src/`이고, 열람용 HTML은 v1 `docs/book/v1/`, v2 `docs/book/v2/`입니다(`docs/tools/build-books.mjs`로 만듦). `docs/design/v2/`는 기존 재분류 묶음으로 별도 버전 체계입니다.

## 실제 화면 기준 보완

- 모험가: 전직제안 아래 계약제안 탭, 기본값·직접 선택.
- 의뢰: 자동 제공 게시판 유지, 우측 의뢰 관리에서 수수료 조정.
- 리퀘스트: 기존 부탁 유지, 길드 발주·외부 의뢰 탭 추가.
- 경영: 소재 판매 유지, 매입·위탁 탭 추가.
- V1 돈의 흐름과 알려진 문제 7개·열린 질문 복원. 추가 제안과 과거 수치 구분.

## 전체 원문 보존 점검

기존 61개 페이지와 목차 경로를 대조했습니다. 개선안과 무관한 설명·수치·UI 상세를 복원하고, 계약·소유권·정산에 필요한 교체만 유지했습니다. 표는 변경된 행, 목록은 변경된 항목만 붉게 표시합니다.

## 개발 순서 추가

[개발 순서와 완료 기준](development/README.md)을 독립 목차로 추가했습니다. 기반·계약·거래·발주·보조금·통합 검증·후속 사업을 선행 조건과 완료 기준으로 구분합니다. 신규 게임 기능의 상태는 계획·미구현을 유지합니다.
