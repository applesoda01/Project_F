# 요리

**요리는 식당 조리대에서 소재 1~3개를 조합해 "발견"하고, 발견한 요리가 많을수록 모든 모험가가 강해집니다.** 요리는 길드의 식사 판매 수입원이기도 합니다.

| 항목 | 규칙 |
| --- | --- |
| 발견 | 조리대에 소재를 넣어 맞히면 발견. 틀리면 소재가 사라지고 리나가 힌트를 줌 |
| 요리 수 | 16종, F · E 6종 확정 |
| 효과 ① | 발견한 요리 1개당 +2% (비전투 성공 확률, 전투 공격력) |
| 효과 ② | 먹은 요리의 능력치 보너스 (예: 힘 · 기교 +3%), 먹은 사람만 |
| 기준 가격 | 요리 등급 의뢰 보상의 25%(F 25G)를 출발점으로 검증. 결제·직접 원가 별도 |
| 먹는 확률 | 소비 성향: 절약 30% · 보통 60% · 낭비 90% |
| 좌석 | 테이블에 **앉은 모험가만** 주문 (테이블 1세트 = 2석) |

- 16개를 다 발견하면 효과 ①만 +32%입니다. 후반 상한은 아직 정하지 않았습니다.
- 월 평균 71G는 v1 과거 측정입니다. 새 결제·지원 정산의 결과가 아닙니다.

## V4 변경 — 재료 소모 · 메뉴 가격

> **V4 변경 · 결정 36 (2026-11-19) · 기획: 제안 / 게임: 미반영** — [소재 시장과 식당 순환](../ch09/market.md)

**V4에서는 요리를 발견한 뒤에도 팔 때마다 재료가 듭니다.** 발견은 메뉴에 올릴 권리이고, 실제 판매는 재료가 있어야 합니다.

| 항목 | V3 | V4 제안 [임시] |
| --- | --- | --- |
| 판매 | 발견 뒤 소재 없이 무한 | 레시피 재료 1세트 = **요리마다 정한 그릇 수** (결정 37: F 멧돼지 스테이크 정식 2 · 들버섯 수프 3 · 민물고기 구이 정식 2 / E 늑대 고기 스튜 3 · 산딸기 파이 4 · 숲 버섯 파이 4 [임시]). 재료가 없으면 품절 |
| 준비량 | 없음 | 요리별 하루 준비량 0~10그릇, 남은 그릇은 한 주 뒤 버림 |
| 가격 | 의뢰 보상 25% 고정 | **1G 단위로 직접 입력** (결정 39), 1G ~ 기준가 × 3 |
| 사 먹을 확률 | 소비 성향 30 · 60 · 90% | 소비 성향 × 가격 계수, 가격 계수 = 1 + 1.5 × (1 − 가격 ÷ 기준가), 0.1 ~ 1.6 (60% → 1.6 · 100% → 1.0 · 150% → 0.25), 상한 100% |
| 메뉴판 | 판매 수 | **원가(재료 시세 합 ÷ 그릇 수) · 판매가 · 마진** |
| 양념 | 의뢰 희귀 뽑기(15%)로만 | 창고에 없으면 식당이 시장에서 시세로 삼 (결정 38 → 65) |
| 발견 수 보너스 | 발견한 요리 수 × 2% | 품절 아닌 요리만 셈 |

> **V4 게임 반영 (2026-11-19) · 브랜치 `feature/market-stage1` · PR applesoda01/Project_F#9 (main 미병합)** — 측정 `docs/balance/market_v4_stage1.md`

- **게임 반영 (2026-11-20 결정 65):** 양념과 F급 식재료(상시 재료)는 창고에 없으면 식당이 마을 시장에서 시세로 사고, E급 이상 식재료(희귀 재료)는 모험가 매입 · 떠돌이 상단에서만 얻습니다. 요리 실험 때도 상시 재료는 시장에서 삽니다. (예전: 잡화 상인 · 상시 발주, 결정 46) 식당은 납품 리퀘스트를 위해 재료마다 2개는 남겨 둡니다. 메뉴판에 재고 · 1그릇 원가 · 가격 ±1 · ±5 · 마진 · 손님 배율 · 한 주 준비량이 보입니다.

예: 멧돼지 스테이크 정식(2그릇) = 멧돼지 고기 6G + 향신료 6G → 1그릇 원가 6G, 25G에 팔면 마진 19G. 들버섯 수프(3그릇)는 (6 + 6) ÷ 3 = 4G 원가. 싸게 팔면 많이 팔려 재료가 빨리 닳고 발주가 자주 켜집니다.

## 결제와 지원 — ECON-04 / 제안·미반영

| 항목 | 처리 |
| --- | --- |
| 구매 전 | 개인 잔액·지원 대상·약정 한도 확인 |
| 실제 결제 | 개인 부담 + 약정 지원을 가격과 대조 |
| 식당 운영 | 실제 외부 결제·직접 원가·지원 부담 구분 |
| 길드 자체 지원 | 내부 자금 이동을 추가 매출로 합산하지 않음 |
| 술 | 실제 잔액 차감 후 제공. 출처 없는 마진 가산 없음 |
| 요리 재료 | 길드 소유만 사용. 위탁품 사용 금지 |

계산 예시: 가격 25G 중 개인 20G·길드 지원 5G, 직접 원가 10G라면 길드의 실제 외부 수취는 20G, 직접비 차감 기여는 10G입니다. 지원 5G를 새 현금 수입으로 더하지 않습니다. 가격·원가는 검증용입니다.

## 모험가는 어떤 요리를 먹나

출발 전, 발견한 요리 중 **의뢰 등급 이하**에서 그 의뢰의 요구 능력치와 가장 많이 겹치는 것을 고릅니다. 같으면 높은 등급, 높은 수치 순입니다. 발견한 요리가 없으면 먹지 않습니다.

> **V4 변경 · 결정 72 (2026-11-20):** 메뉴 기준가는 재료 원가에 맞춥니다 — 1그릇 재료 원가 × 2 + 등급 가산(F 5 · E 15G) [임시]. 예: 들버섯 수프 17G · 멧돼지 스테이크 25G · 늑대 고기 스튜 38G. [소재 시장과 식당 순환](../ch09/market.md)
