# 물약과 소재

**물약은 모험가가 출발 전에 사서 들고 가고, 소재는 의뢰에서 얻어 소유자 동의에 따라 길드 창구에서 거래합니다 [제안].**

## 물약

| 항목 | 규칙 |
| --- | --- |
| 가격 | F 20 · E 30 · D 40 · C 80 · B 100 · A 130 · S 250G |
| 회복량 | 최대 체력의 30%(F) ~ 70%(S) |
| 들고 가는 수 | 소비 성향: 절약 1 · 보통 2 · 낭비 3 |
| 쓰는 때 | 체력이 후퇴선(신중 50% · 보통 30% · 무모 10%) 아래 |
| 순서 | 출발 때 식사 → 물약 구매 |

## 소재

| 항목 | 내용 |
| --- | --- |
| 종류 | 장비 제작용 35종(의뢰 등급 7 × 유형 5) + 복원 재료 + 음식 소재(F · E 9종) |
| 판매가 | F 6 · E 9 · D 12 · C 30 · B 36 · A 48 · S 90G |
| 쓰는 곳 | 소재 판매 창구에서 팖, 대장간 제작 · 강화, 리퀘스트 납품, 요리 |

> **지금 코드에는 "소재 자동 차익"(의뢰 성공 때 보상의 8%가 저절로 길드 수입)이 남아 있습니다.** 설계상으로는 없애고 직접 판매만 남기기로 했지만 아직 정리하지 않았습니다. 첫해 월 평균 55G로 운영 수입의 약 9%입니다([9장](../ch09/issues.md)).

## 의뢰에서 소재를 얻는 방법 — 결정 27 (2026-11-18, 게임 반영)

**의뢰에 성공하면 몬스터 1마리 · 탐색 포인트 1곳마다 그 의뢰의 보상표에서 1개씩 뽑습니다.** 예전에는 의뢰 하나에 보상표를 1번만 굴렸습니다.

| 항목 | 규칙 |
| --- | --- |
| 뽑는 횟수 | 전투 의뢰 = 몬스터 수, 몬스터 없는 의뢰 = 탐색 포인트 **2~3곳 [임시]** (`econ.drawPts`) |
| 무엇이 나오나 | 보상표의 주 소재(확률 30% 이상)에서 확률을 비율로 써서 1개 — 100 : 70이면 59% : 41% |
| 희귀 소재 | 확률 30% 미만은 지금처럼 **의뢰당 1번만** 굴림 |
| 길드 발주 중 | 보상표에 발주 소재가 있으면 뽑기마다 발주 소재 |
| 소재 값 | 그대로 |
| 몬스터 도감 | 몬스터별 '떨구는 소재' 목록은 쓰지 않음 — 도감 표기는 나중에 정리 |

**예시:** "고철이나 줍자"(보상표 고철 조각 · 무명천, 슬라임 2마리) → 평소에는 고철 · 무명천 중에서 2개, 고철 발주 중이면 고철 2개.

측정(100판 · 48주): 소재 한 달 12.5 → 16.2개 · 매입 49 → 65G · 판매 3 → 12G · 월 순이익 475 → 479G · 48주 안 E 승급 82 → 88판. 값을 낮추는 보정은 필요 없었습니다.

## 소재 소유·지원 추가 — ITEM-01 / 제안·미반영

물약 지원은 개인 잔액과 약정 한도를 확인해 실제 구입액만 분담합니다. 길드 소유 소재만 요리·제작·시설 개방·지원·납품에 쓸 수 있습니다. 실제 매입·판매·위탁 거래를 도입하면 해당 거래의 자동 차익 8%는 대체합니다. 가격·매입가·수수료·수량부터 검증하고 큰 시세 변동은 제외합니다.

| 획득 상황 | 소유자 / 제한 |
| --- | --- |
| 일반 전리품 | 개인 또는 파티 공동 소유 |
| 의뢰인 납품품 | 의뢰 조건에 따라 인도. 판매 불가 |
| 길드 발주 소재 | 가져온 파티에 1개 값 지급 후 길드 창고 (선지급한 돈에서) [결정 25] |
| 매입 / 자발적 기증 | 거래·기증 확정 후 길드 |
| 위탁품 | 판매 전까지 원소유자. 요리·제작·납품 사용 불가 |
| 길드 투자 탐사 | 출발 전 합의한 지분 |
| 기존 저장 재고 | 기존 길드 보유분 보존. 원가 미상은 별도 표시 |

## 기존 소재 판매 + 매입·위탁 우측 탭

![UI 04 — 소유자와 원가를 구분한 소재 거래](../assets/ui/purchase-tabs.png)

[큰 이미지 보기](../assets/ui/purchase-tabs.png) · **기획 시안 / 미구현 / 거래 금액 예시**

![우측 위탁 탭의 접수와 정산](../assets/ui/consignment-tabs.png)

기존 소재 판매의 격자 목록·선택 상세·1개 팔기·전부 팔기를 유지합니다. 우측 탭은 **장부 / 소재 판매 / 매입 / 위탁 / 도감 / 기록**. 매입은 후보 소유자·매입가, 위탁은 소유자·수량·수수료·지급 예정액을 표시합니다. 그림의 소금 4G→6G는 소액 거래 예시이며 아래 70G→100G는 별도 계산 예시입니다.

| 거래 예시 | 모험가 지급 | 길드 현금 | 길드 거래 이익 |
| --- | ---: | --- | ---: |
| 70G 매입 → 100G 판매 | 매입 때 70G | −70G → +100G | 30G |
| 100G 위탁, 10% 수수료 | 판매 때 90G | 수수료 10G만 귀속 | 10G |

- 매출 100G와 차익 30G를 둘 다 수입에 합치지 않습니다.
- 공동 전리품은 지분을 기록해 판매대금을 배분합니다.
- **결정 12 [결정 2026-11-17]:** 의뢰에 성공해 가져온 소재는 귀환 때 길드가 판매가의 **70% [임시]**(버림)로 **자동 매입**하고 돈은 모험가 지갑으로 갑니다. 길드가 팔 때는 100%. 길드 돈이 모자라면 매입 대신 **위탁(수수료 10% [임시])**. 소재 자동 차익 8%는 없앱니다. 70% · 10%는 임시 수치로 측정 뒤 바뀔 수 있습니다.
- 정식 계약의 금전 배분은 개인 전리품 소유권을 자동 이전하지 않습니다.

## V4 변경 — 소재 시세 · 매입 / 위탁 / 안 받음 · 개체수

> **V4 변경 · 결정 36 (2026-11-19) · 기획: 제안 / 게임: 미반영** — [소재 시장과 식당 순환](../ch09/market.md)

**V4는 등급별 고정가를 마을 시장 재고에 따른 시세로 바꿉니다.** 같은 소재를 계속 가져오면 값이 내려가고, 많이 잡아 사냥터가 비면 값이 오릅니다.

| 항목 | V3 | V4 제안 [임시] |
| --- | --- | --- |
| 값 | 등급별 고정 (F 6 · E 9 …) | 기준가 × 시세 배수(0.5 ~ 2.0). 배수 = 1 + 0.6 × (목표 재고 − 마을 시장 재고) ÷ 목표 재고 |
| 마을 소비 | 없음 | 매주 시장 재고 × 10% + 인구 ÷ 100개 — 마을이 클수록 값이 오름 |
| 소재 처리 (결정 43) | 판매가 70%로 무조건 자동 매입 | 소재마다 **매입 / 위탁 / 안 받음** 선택. 매입가는 시세의 50 · 70 · 90%(기본 70%), 창고 상한 30 |
| 판매 창구 | 고정가, 무제한 | 시세. 한 개 팔 때마다 시장 재고 +1 → 값이 내려감 ("N개 팔면 평균 ○G" 미리 보기) |
| 위탁 | 금고 부족 때 자동, 수수료 10% | **플레이어가 고르는 선택지.** 길드가 월말에 시장에 대신 시세로 팔고 수수료 10%, 요리 · 납품에 못 씀. 창고 상한을 넘거나 금고가 모자라면 자동 위탁 |
| 안 받음 | 없음 | 모험가가 시장에 직접 시세로 팖. 길드 몫 없음 |
| 매입률과 모험가 | — | 돈이 필요한 모험가는 매입률이 낮은 소재의 의뢰를 확률로 거름 (50%면 25%) |
| 개체수 (3단계) | 없음 | 자원지(멧돼지 숲 · 버섯 숲 · 강 · 늑대 굴 · 산딸기 덤불 …)마다 0~100. 1개 가져올 때 −3, 주마다 +4. 30 미만이면 그 의뢰 · 소재가 줄고, 80 넘으면 피해 리퀘스트 |
| 의뢰 레벨 (결정 35) | 3번 성공마다 Lv+1 | 개체수가 낮으면 레벨이 오르지 않음 |
| 표시 | 값만 | 시세 화살표(▲▼, 4주 대비) · 개체수 막대(많음 · 보통 · 적음, 숫자 숨김 — 결정 44) |
- 대장간·물약 상점은 독립 경제. 길드는 납품·별도 서비스 대가만 얻습니다.
