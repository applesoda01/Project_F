## 1. 전직 시험 의뢰

**전직을 "결과 통보"에서 "준비하고 통과하는 과정"으로 바꾸자는 생각입니다.**

### 지금 전직 (코드 확인, 2026-11-19)

1. 능력치 조건 + 모험가 관리소를 채우면 매달 리나가 전직을 제안합니다.
2. 마스터가 직업을 고르면 애착에 따른 확률(2차 기준 약 48~100%)로 **그 자리에서 바로** 전직합니다.
3. 거절당하면 3개월 뒤 다시 제안합니다. 비용 · 기간 · 시험이 없고, 플레이어가 확률을 올릴 방법은 관리소 업그레이드(+10%p)뿐입니다.

→ 성장이 의뢰에서 저절로 일어나고 전직은 누르면 끝나서, "이 모험가를 키운다"는 손맛이 약합니다.

### 아이디어

| 단계 | 내용 [임시] |
| --- | --- |
| ① 전직 자격 | 지금처럼 능력치 조건 + 관리소 → 리나가 "전직 시험을 볼 수 있습니다" |
| ② 전직 시험 의뢰 | 마스터가 **길드 의뢰로 시험을 발주**(해금형 의뢰 종류). 새 직업에 맞는 시험 — 전사 계열은 강적 토벌, 마법 계열은 조사 판정 등. 시험 비용(보상)은 길드가 냄 |
| ③ 준비 | 시험 전에 장비 선물 · 요리 · 함께 보낼 동료 지명으로 성공률을 올림 → 육성에 손대는 감각 |
| ④ 결과 | 성공 = 전직 + 축하 연출 / 실패 = 4주 뒤 재도전, 시험 경험치는 남음 |
| ⑤ 애착 | 지금의 "확률로 거절"은 없애고, 애착이 낮으면 시험 볼 의욕이 없어 대기가 김 |

- **좋은 점:** 전직이 길드 의뢰 구조 안으로 들어오고, 시험 · 준비 비용이 금고 쓸 곳이 되며, 장비 선물 · 요리 · 지명이 "육성"으로 묶입니다.
- **조심할 점:** 침공(F급 메인)과 장면이 비슷해 보일 수 있음 → 시험은 짧고 1~2명만. 전직이 늦어지면 E급 승급 · 관리소 일정에 영향 → 측정 필요.
- **먼저 확인할 것:** 육성 체감을 숫자로 — 1년에 전직이 몇 번 일어나는지, 플레이어 조작이 성장에 얼마나 영향을 주는지.

## 2. FM식 계약 협상

길드가 조건을 일방적으로 내미는 대신, 모험가가 요구 조건을 내놓고 몇 차례 주고받는 협상입니다.

- 다룰 거리 후보: 월 보수 · 계약금(서명할 때 한 번) · 기간 · 출전 보장(한 달 지명 횟수) · 성공 수당 · 해지 위약금 · 갱신 우선권.
- 성향(소비 · 모험심 · 사교)과 애착 · 최근 성적에 따라 요구가 다르고, 너무 깎으면 관계(친밀도 · 애착)가 상함.
- 결정 48(애착 할인 하한 · 등급별 최소 월 보수)을 넣은 뒤 계약 화면을 협상형으로 바꿀지 검토.

## 3. 다른 길드에서 스카우트

세계에는 여러 길드가 있으므로(길드 연합), 다른 길드의 계약 모험가를 스카우트해 오는 아이디어입니다(2026-11-17 사용자). 계약 시스템 · 세계관과 함께 다시 봅니다. 원문은 `docs/design/economy_v2_decisions.md` '아이디어'.
