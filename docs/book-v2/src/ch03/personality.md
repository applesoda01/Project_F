# 성향과 애착도

**성향은 모험가가 "무엇을 고르는가"를, 애착도는 "얼마나 자주 오고 오래 머무는가"를 정합니다.** 둘 다 플레이어가 직접 바꿀 수 없고, 환경으로 유도합니다.

## 성향: 3축 × 3단계 + 선호 의뢰

| 축 (화면 이름) | 낮음 / 보통 / 높음 | 영향 |
| --- | --- | --- |
| 위험 (모험심) | 신중 / 보통 / 무모 | 출발 기준 95% / 85% / 65%, 후퇴선 체력 50% / 30% / 10%, 실패 시 사망 ×0.5 / ×1.0 / ×1.5 |
| 소비 | 절약 / 보통 / 낭비 | 식당 이용 30% / 60% / 90%, 물약 최대 1 / 2 / 3개, 예비금 장비값의 2배 / 1배 / 0.3배 |
| 사교 | 독불장군 / 보통 / 사교적 | 동료 찾는 기준 예상 성공률 50% / 70% / 85% 미만, 친밀도 상승 ×0.5 / ×1.0 / ×1.5 |
| 선호 의뢰 | 5개 유형 중 1개 | 조건이 같으면 먼저 고름 |

- **경제와 이어지는 축은 "소비"입니다.** 낭비 성향이 많을수록 식당 · 주점 매출이 늘고, 장비를 늦게 삽니다.
- 무모한 모험가는 자기 실력을 1.2배로 봅니다. 실패의 대부분이 여기서 나옵니다([5장](../ch05/departure.md)).
- 화면에는 확률 숫자 대신 "늘 신중하게 의뢰를 고릅니다" 같은 문장으로 보여 줍니다.

## 애착도 (0~100)

### 계약·거주와 분리 — ADV-01 / 제안·미반영

| 구분 | 정하는 것 | 자동으로 정하지 않는 것 |
| --- | --- | --- |
| 애착 | 장기 관계·방문·영입/갱신 의향 | 고용·급여·주택 입주 |
| 계약 | 보수·지원·업무 범위 | 전투 등급·인격·개인 소유 |
| 생활·활동 | 방문/숙소/주택, 대기/원정/부상/예약 | 영구 소속 |
| 창립 이력 | 기존 상주 혜택·이야기 표식 | 무료 전속 의무 |

### 관계 구간의 미결

아래는 기존 기획 구간입니다. 수락 계산의 0~29/30~59/60~89/90+ 구간과 다르므로, 계약 추가 때 함께 바꾸지 않습니다.

| 애착 | 단계 | 뜻 |
| --- | --- | --- |
| 0~29 | 방랑자 | 언제든 떠날 수 있음 |
| 30~69 | 새내기 | 정이 들기 시작함 |
| 70~99 | 동반자 | 오래 머무르려 함 |
| 100 | 토박이 | 관계 단계 이름. 실제 거주는 별도 판정 |

| 애착이 오르는 일 | 변화 |
| --- | --- |
| 게시판 의뢰 성공 | +2 |
| 지명(리퀘스트) 성공 | +3 |
| 장식 "화분"이 있을 때 의뢰 성공 | +1 추가 |
| 마스터의 장비 선물 | 등급별 F +1, E +2 … |

- 방문 간격 = 기본 2주 × (1 + (100 − 애착) ÷ 50). 애착 0이면 6주, 100이면 2주마다 옵니다.
- **애착 65 이상은 지역 활동 기여로 인구를 매달 +2** 올립니다. 실제 주택 거주와 다르며 계약 체결로 중복 가산하지 않습니다.
- **용어 통일 [결정 2026-11-17](숫자는 그대로):** 애착 단계 0~29 방랑자 · 30~59 새내기 · 60~89 동반자 · 90~100 토박이 / **지역 기여** = 애착 65 이상(인구 +2) / **상주** = 애착 100 또는 창립 멤버 / **실제 거주** = 마을 집 배정 / 계약은 이 넷과 별개. 명부에는 단계 이름 + 막대 · 아이콘 2개 · 계약 기간을 표시합니다.
- 지원 부족·업무 초과는 설명 가능한 불만 사유로 표시합니다(급여는 금고가 마이너스여도 자동 지급되어 체납이 없음, 결정 2026-11-17). 새 충성도 막대는 추가하지 않습니다.
- 애착은 전직 수락 확률도 정합니다([전직](jobs.md)).
