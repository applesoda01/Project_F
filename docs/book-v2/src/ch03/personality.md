# 성향과 애착도

## v2 변경 — 애착·계약·거주 분리

> **ADV-01 · 기획: 제안(유지 사항 별도 명시) / 게임: 신규 규칙 미반영**

애착 단계·실제 거주·지역 활동 기여와 계약을 별도 축으로 표시합니다. 기존 애착 경계와 인구 기여 수치의 불일치는 미결이며 이번 계약 제안과 동시에 수치를 바꾸지 않습니다. 급여 체납·업무 초과 등 설명 가능한 사유를 남깁니다.

## v1에서 이어받은 설명

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**성향은 모험가가 "무엇을 고르는가"를, 애착도는 "얼마나 자주 오고 오래 머무는가"를 정합니다.** 둘 다 플레이어가 직접 바꿀 수 없고, 환경으로 유도합니다.

## 성향: 3축 × 3단계 + 선호 의뢰

| 축 (화면 이름) | 낮음 / 보통 / 높음 | 영향 |
| --- | --- | --- |
| 위험 (모험심) | 신중 / 보통 / 무모 | 출발 기준 95% / 85% / 65%, 후퇴선 체력 50% / 30% / 10%, 실패 시 사망 ×0.5 / ×1.0 / ×1.5 |
| 소비 | 절약 / 보통 / 낭비 | 식당 이용 30% / 60% / 90%, 물약 최대 1 / 2 / 3개, 예비금 장비값의 2배 / 1배 / 0.3배 |
| 사교 | 독불장군 / 보통 / 사교적 | 동료 찾는 기준 예상 성공률 50% / 70% / 85% 미만, 친밀도 상승 ×0.5 / ×1.0 / ×1.5 |
| 선호 의뢰 | 5개 유형 중 1개 | 조건이 같으면 먼저 고름 |

- **경제와 이어지는 축은 "소비"입니다.** 낭비 성향이 많을수록 식당 · 주점 매출이 늘고, 장비를 늦게 삽니다.
- 무모한 모험가는 자기 실력을 1.2배로 봅니다. 실패의 대부분이 여기서 나옵니다([5장](../ch05/departure.md)).
- 화면에는 확률 숫자 대신 "늘 신중하게 의뢰를 고릅니다" 같은 문장으로 보여 줍니다.

## 애착도 (0~100)

| 애착 | 단계 | 뜻 |
| --- | --- | --- |
| 0~29 | 방랑자 | 언제든 떠날 수 있음 |
| 30~69 | 새내기 | 정이 들기 시작함 |
| 70~99 | 동반자 | 오래 머무르려 함 |
| 100 | 토박이 | 마을에 거주 |

| 애착이 오르는 일 | 변화 |
| --- | --- |
| 게시판 의뢰 성공 | +2 |
| 지명(리퀘스트) 성공 | +3 |
| 장식 "화분"이 있을 때 의뢰 성공 | +1 추가 |
| 마스터의 장비 선물 | 등급별 F +1, E +2 … |

- 방문 간격 = 기본 2주 × (1 + (100 − 애착) ÷ 50). 애착 0이면 6주, 100이면 2주마다 옵니다.
- **애착 65 이상인 "정착 모험가"는 매달 마을 인구를 +2** 올립니다. 애착이 경제(인구 → 의뢰 유입)로 이어지는 통로입니다.
- 애착은 전직 수락 확률도 정합니다([전직](jobs.md)).
