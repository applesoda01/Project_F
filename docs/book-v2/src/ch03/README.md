# 모험가

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**모험가는 플레이어가 조작하지 못하는 자율 행동 주체입니다.** 능력치 5개 + 행운, 직업, 성향, 애착도로 정의되고, 이 조합이 "어떤 의뢰를 고르고, 돈을 어떻게 쓰고, 언제 떠나는지"를 정합니다.

모험가 한 명의 행동은 다음 순서로 반복됩니다.

```mermaid
flowchart LR
  V[길드 방문] --> Q[의뢰 고르기]
  Q --> P[정비<br/>장비 · 물약 · 식사]
  P --> X[의뢰 수행]
  X --> R[성공/실패]
  R --> W[보상 받고<br/>다시 방문]
  W --> V
```
