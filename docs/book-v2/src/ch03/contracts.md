# 소속과 정식 계약

> **추가 · ADV-01, ADV-02 · 기획: 제안 / 게임: 미반영**<br>
> 근거: [첨부 3절](../proposal/section-03.md) · [4절](../proposal/section-04.md) · [5절](../proposal/section-05.md)

**자유 모험가 중심의 개방형 길드를 유지하고, 일부와만 정식 계약을 맺습니다.**

| 구분 | 자유 모험가 | 정식 계약원 |
| --- | --- | --- |
| 일반 의뢰 | 자율 선택 | 배치되지 않은 시간에는 자율 선택 |
| 보수 | 정기 보수 없음 | 약정한 정기 보수와 실제 지원 |
| 일반 의뢰 길드 몫 | 일반 중계료 | 개인 배분 기준액에 계약 요율 적용 |
| 지명 | 기존 섭외비·수락/거절 | 계약 범위와 가용 조건 충족 시 우선 배치, 별도 섭외비 없음 |
| 개인 소유 | 장비·지갑·전리품 | 개인 소유 유지, 대여품만 별도 |
| 마왕 토벌 | 후보 가능 | 후보 가능 |

## 소속·관계·거주를 분리

계약(자유/정식), 애착, 실제 거주, 현재 활동, 등급·성장, 창립 이력은 서로 다른 축입니다. 애착이 높거나 상주한다고 자동 고용되지 않습니다. 창립 2명도 상주하는 자유 모험가로 시작하고 별도 동의를 받아 계약합니다. 정식 인원을 전체 정원에 다시 더하지 않습니다.

## 최초 검증 범위

E급 승급 후 관리소에서 표준 계약 1종을 시험합니다. 정원 2명, 후보 애착 30 이상·성공 3회, 기간 12주, 4주 중 지정 업무 최대 2주는 **검증용 수치**입니다. 높은 등급의 정원은 확장 가안입니다.

계약서에는 기간, 보수·지급일, 일반 의뢰 배분율, 지정 업무·위험 한도, 지원 한도, 장비 소유권, 방어 대기, 종료·체납·사망 정산을 명시합니다. 일반 중계료 변경이 기존 계약 조건을 소급 변경하지 않습니다.

## 권한과 책임

- 부상·기존 원정·조건 미달·위험/시간 상한 초과·체납 시 새 배치를 제한합니다. 같은 사람의 호위와 방어를 중복 예약하지 않습니다.
- 전투 직접 조작권·무조건 복종·사망 면역을 주지 않습니다. 범위 밖 임무는 별도 동의 대상입니다.
- 보수는 근무 주수에 비례해 적립하고 월말에 실제 지급합니다. 부상 중 기본 보수와 약정 지원을 유지합니다.
- 체납은 지우지 않고 신규 업무 중지와 경고를 적용합니다. 4주 유예도 검증용입니다.
- 사망 시 발생 보수·약정 위로금을 정산하며 이후 급여를 멈춥니다. 자녀에게 고용 의무·채무를 자동 상속하지 않습니다.
- 지원 예산은 지출 상한이며 실제 사용하지 않은 돈까지 차감하지 않습니다.

개인별 혼성 파티 계산은 [모험가 지갑](../ch09/adventurer.md), 예약 자금은 [장부](../ch09/ledger.md)를 봅니다.
