# 스킬과 성장 경로

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**스킬은 82개이고, 새로 배우는 것은 1차 5개뿐입니다. 나머지 77개는 전직할 때 가진 스킬이 새 직업 모양으로 "진화"한 것입니다.** 어떤 1차를 거쳤느냐에 따라 같은 3차라도 가진 스킬이 다릅니다.

| 항목 | 내용 |
| --- | --- |
| 새 스킬 | 1차 직업마다 1개 (전사 더블 스윙 · 궁수 연사 · 마법사 파이어볼 · 성직자 힐 · 도적 급소 찌르기), 마을 건물에서 구매 |
| 진화 | 2차 · 3차로 오를 때, 스킬의 바탕 능력치가 새 직업 조건에 들어 있으면 그 직업 고유 형태로 바뀜 |
| 진화하지 않을 때 | 바탕 능력치가 없는 직업으로 가면 그 형태로 멈춤 |
| 규모 | 기본 5 + 진화형 77 = 82개. 마을 건물 스킬 약 20개(진화하지 않음) |
| 장착 | 모두 보유, 장착 5칸. 기본은 모험가가 스스로, 마스터가 직접 정할 수도 있음 |
| 구매 · 선물 | 모험가가 소지금으로 사거나, 마스터가 길드 돈으로 선물(애착 상승) |
| 효과 분류 | 판정(충족률 상승) · 생존 · 파티 · 경제 · 침공 |

**진화 예 (파이어볼, 이름은 가칭):** 마도사 플레임 버스트 → 대마도사 메테오, 마검사 화염검, 마궁사 화염 화살.

**전직의 이득:** 레벨 상한 해제, 레벨업 성장치 증가(1차 합 약 3.6 → 2차 약 4.5 → 3차 약 5.5), 스킬 진화, 외형 변화.

## 능력치가 오르는 여섯 가지 길

| 경로 | 내용 |
| --- | --- |
| 레벨업 | 직업별 고정 성장치 |
| 의뢰 | 성공하면 그 유형의 대표 능력치 +2 |
| 훈련장 · 도서관 | 설치한 훈련 아이템에 따라 (D · C급 시설) |
| 장비 · 아이템 · 이벤트 | 보정 |
| 모험가 등급 승급 | 능력치 5개에 각각 +3~+10 |
| 칭호 [제안] | 능력치 보조 +1~+3 |

**알려진 문제:** 조합 직업 12종은 지금 규칙으로는 3년 안에 거의 나오지 않습니다. 보조 능력치를 쌓는 규칙이 2년 차용으로 더 필요합니다.
