# 출발 판단과 성공률

**모험가는 "이길 것 같은 의뢰"만 골라 떠납니다. 그래서 성공률이 95% 가까이 나옵니다.** 이것이 지금 밸런스의 가장 큰 숙제입니다.

## 출발 판단

1. 의뢰마다 예상 성공률을 계산합니다. 전투 의뢰는 고정 씨앗 전투 30회의 승률을 씁니다.
2. 성향의 인식 계수를 곱합니다(신중 ×0.9 · 보통 ×1.0 · 무모 ×1.2).
3. 출발 기준(신중 95% · 보통 85% · 무모 65%)을 넘으면 출발합니다.
4. 모자라면 동료를 찾아 다시 계산하고, 그래도 모자라면 다른 의뢰를 보거나 쉽니다.

## 측정 (게임 규칙 100판 · 48주)

| 구분 | 성공률 |
| --- | --- |
| 전체 | 94.9% (한 판 의뢰 76건) |
| 전투 의뢰 | 98.0% |
| 비전투 의뢰 | 89.6% |
| 파티 대장 신중 / 보통 / 무모 | 98.4% / 97.5% / 91.5% |

- 실패의 대부분은 무모한 모험가가 자기 실력을 높게 보고 고른 비전투 의뢰에서 나옵니다.
- **출발 기준을 낮춰도(85 / 75 / 55%) 95.1%로 그대로였습니다.** 기준보다 쉬운 의뢰가 게시판에 충분히 있기 때문입니다.
- 그래서 능력과 상관없는 실패 원인이 하나 필요하다는 제안이 나와 있습니다. "늦장 실패" 제안서가 그것이고, [부록 C](../appendix/pending.md)에서 다룹니다.
