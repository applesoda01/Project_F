# 습격 · 마인 · 무술 대회

**침공 말고도 전투 장면은 다섯 종류가 더 있고, 모두 "탑뷰 한 화면에서 지켜보기"입니다.** 프로토타입에는 침공만 있고, 나머지는 설계 단계입니다.

## 전투 장면 전체 (15년 기준)

| 장면 | 화면 | 빈도 | 지면 |
| --- | --- | --- | --- |
| 일반 의뢰 전투 | 미니 뷰 | 매주 | 의뢰 실패 |
| 소규모 습격 [제안] | 마을 | 반년에 한 번꼴, 약 30회 | 인구 · 신뢰도 하락 |
| 특별 퀘스트 전투 | 퀘스트별 배경 | 약 25회 | 퀘스트 실패 |
| 승급 침공 | 마을 | 6회 | 승급 실패 |
| 간부 토벌 | 전용 배경 | 3~4회 | 간부 후퇴 |
| 마왕전 | 마왕성 | 1회 이상 | 사망과 계승 |
| 무술 대회 | 투기장 | 투기장을 지은 뒤 1년에 1회 | 기절 (부상 · 사망 없음) |

## 직업별 전투 수치 [가안]

| 1차 직업 | 체력 (레벨당) | 마력 (레벨당) | 공격력 (레벨당) |
| --- | --- | --- | --- |
| 전사 | 100 (+10) | 20 (+2) | 35 (+3) |
| 궁수 | 80 (+8) | 30 (+3) | 30 (+3) |
| 마법사 | 60 (+6) | 60 (+6) | 25 (+2) |
| 성직자 | 70 (+7) | 50 (+5) | 25 (+2) |
| 도적 | 75 (+8) | 30 (+3) | 30 (+3) |

여기에 능력치 환산(힘 1당 체력 3 등)과 장비가 더해집니다.

## 스킬 · 부상 · 사망

| 항목 | 규칙 |
| --- | --- |
| 웨이브 | 한 무리 최대 F 2마리 · E 3마리. 무리를 나눠 차례로, 체력 · 마력은 회복 없이 이어짐 |
| 스킬 | 성직자 외에는 20% 확률로 발동 (설계는 1 · 2 · 3차 20 / 35 / 50%) |
| 부상 | 체력 0이 된 사람. 귀환 뒤 F · E 2주 쉼 (벽난로 −1주) |
| 사망 | 쓰러진 사람만 판정: 등급 사망률 × 위험 성향(0.5 / 1 / 1.5) |

## 소규모 습격 [제안 · 보류]

| 항목 | 내용 |
| --- | --- |
| 빈도 | 개척촌 8개월 · 마을 6개월 · 읍 5개월 · 도시 4개월 · 성채 도시 3개월에 한 번꼴 |
| 규모 | 길드 등급과 같은 몬스터, 1~2웨이브, 보스 없음 |
| 패배 | 인구 −5%, 신뢰도 하락 |
| 플레이어 결정 | 예고 2주 동안 누구를 마을에 남길지, 방어 보상금을 얼마 걸지 |
| 돈 | 보상금이 습격 1번에 평균 439G (시뮬레이터) |

지금 규칙이면 첫해 습격은 0.9번뿐이라 긴장감이 약합니다. 그래서 보류 중입니다.

## 무술 대회

| 항목 | 내용 |
| --- | --- |
| 조건 | 마을에 투기장이 있을 때, 1년에 한 번 |
| 참가 | 모험가가 성향에 따라 스스로 지원 (무모 70% · 보통 40% · 신중 15%, 사교적 +15%p) + 외부 도전자 |
| 방식 | 1대 1 토너먼트, 지면 기절 |
| 등급 | 길드 등급이 오를수록 마을 → 지방 → 왕국 대회 |
| 보상 | 우승자: 상금 · 칭호 · 애착 / 길드: 명성, 외부 강자 방문 / 마을: 축제 기간 인구 증가 |

## 마인 [가안]

**마인은 마왕군에게 죽은 모험가의 2세가 각성하는 전설 직업입니다.** 2세 계승 시스템이 이야기와 만나는 지점입니다.

| 항목 | 내용 |
| --- | --- |
| 생기는 조건 | 마왕군에게 죽은 모험가의 2세가 길드에 있고 2차 이상. 부모가 언데드 간부로 나타남 |
| 각성 | 2세가 있는 파티가 그 간부를 쓰러뜨림 + 주력 능력치 70 + 애착 70 |
| 2세가 없으면 | 8년 차 말까지 없으면 "무너진 봉인 마을 출신" 2세가 1~2명 자동으로 옴 |
| 마왕의 파편 | 장신구. 모든 능력치 +15, 마왕군 대상 피해 증가 |
| 잠식도 (0~100) | 파편을 낀 채 싸우면 오름. 높을수록 강하지만 애착이 서서히 떨어짐. 성당에서 돈으로 정화 |
| 마인이 죽으면 | 파편은 3세에게 (잠식도 0). 3세가 없으면 소멸 |
