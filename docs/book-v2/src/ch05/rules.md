# 전투 규칙

**라운드제 자동 전투이고, 피해는 "공격 − 방어"의 고정 차감입니다.** 회피와 마법 방어는 없앴습니다(2026-11-11). 엔진은 `prototype/js/combat.js` 하나이고, 게임과 시뮬레이터가 같이 씁니다.

| 항목 | 규칙 |
| --- | --- |
| 피해 | (공격 × 배율 × 흔들림 [× 치명타 1.5]) − 방어, 최소 0 |
| 대열 | 한 줄. 전사 · 도적(체력 순) → 궁수 · 마법사 → 성직자, 자동 배치 |
| 대상 | 서로 살아 있는 맨 앞을 공격 |
| 행동 | 기교로 차는 행동 게이지가 100이 되면 행동. 한 라운드에 여러 번도 가능 |
| 최대 라운드 | 30. 넘기면 후퇴(실패) |
| 후퇴 | 파티 전체 체력이 후퇴선(신중 50% / 보통 30% / 무모 10%) 아래로 내려가면 실패 |
| 물약 | 체력이 후퇴선 아래로 떨어지면 자동 사용 |
| 결과 | 적 전멸 = 성공. 잃은 체력 · 물약 · 부상 · 사망이 그대로 결과 |
