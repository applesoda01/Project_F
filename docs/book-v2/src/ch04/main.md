**메인 퀘스트는 길드 등급마다 있고, 깨면 다음 등급으로 승급합니다.** 프로토타입에는 F급 메인 「다리를 지켜라」(침공) 하나가 있습니다.

## F급 메인 「다리를 지켜라」

| 항목 | 내용 |
| --- | --- |
| 등장 | 리퀘스트 8번 해결 → "영주의 전갈" → 리퀘스트 장 맨 위 붉은 카드 (마감 없음) |
| 받기 | 플레이어가 누름 → 2주 뒤 침공 |
| 준비 | 침공 1주 전부터 모든 의뢰 출발 금지 |
| 참가 | 지명 없이 살아 있는 모험가 전원 (의뢰 중 · 부상 중 제외) |
| 승리 | E급 승급 · 모험가 관리소 해금 · 1,000G · 명성 +10 |
| 패배 | 인구 −10% · 신뢰도 −5 · 4주 뒤 재도전 |
| 측정 (100판) | 등장 중앙 31주, 승급 중앙 39주 |

## 메인 퀘스트 16개 [가안]

메인 퀘스트는 "옛 파티는 왜 전멸했는가(원인)"와 "마스터는 어떻게 살아남았는가(생존)" 두 줄기로 진실을 밝혀 갑니다. 굵게 표시한 것은 엔딩을 가르는 분기점입니다.

| 등급 | 줄기 | 제목 (가칭) | 내용 | 연출 |
| --- | --- | --- | --- | --- |
| F | — | 다리를 지켜라 | 침공 방어 (원래 가안 「첫 의뢰」를 대체) | 마을 |
| E | — | 녹슨 문장 | 옛 파티의 문장이 새겨진 장비 조각. 공식 기록과 다른 사고 지점 | 일지 |
| D | 원인 | 맞지 않는 상처 | 마물 발톱이 아닌 무기에 베인 상처 | 일지 |
| D | 생존 | 약초꾼의 기억 | 기절한 마스터를 본 곳이 동굴 입구였다는 증언 | 일지 |
| C | 원인 | **숲속의 석비** | 금이 간 봉인 석비. 분기① 영주에게 보고 / 길드만 앎 | 일지 |
| C | 생존 | 마지막 야영지 | 리나가 오빠의 망토를 알아보고 서로의 정체를 깨달음 | 일지 |
| B | 원인 | 매복의 흔적 | 인위적인 함정과 마왕군 표식 | 일지 |
| B | 생존 | 동료의 일지 | 리나 오빠의 일지. 마스터를 숨긴 사람이 오빠였음 | 일지 |
| B | 정점 | **그날의 숲** | 마왕군 재출현. 분기② 누구를 보내는가 | 탑뷰 |
| A | 원인 | 이름 없는 간부 | 원수 간부의 이름과 목적 | 일지 |
| A | 생존 | 돌아온 이름들 | 동료들의 유품 귀환 | 일지 |
| A | 전환 | **성 아래의 빛** | 영주가 성이 봉인의 핵이라 고백. 분기③ 봉인과 마력을 더 조사함 / 안 함 | 탑뷰 |
| S | 간부 1 | 선봉 | 봉인을 깨려는 첫 간부 | 탑뷰 |
| S | 간부 2 | **지친 왕의 그림자** | "마왕님은 이미 지치셨다". 분기④ 믿고 추적 / 무시 | 탑뷰 |
| S | 간부 3 | 원수 | 원수 간부 토벌 | 탑뷰 |
| S | 마왕 | 덜 풀린 왕 | 마왕전. 승리하면 엔딩 1 | 탑뷰 |

| 분기 | 쌓이는 플래그 | 이어지는 엔딩 |
| --- | --- | --- |
| ① 석비 보고 | 영주와의 신뢰 | 재봉인 |
| ② 정점 파견 | 생존자 기록 | 모든 엔딩의 에필로그 |
| ③ 마력 조사 | 마력의 진실 | 재봉인 |

## 지명 · 실패 · 보상 [가안]

| 유형 | 인원 | 실패하면 | 보상 (같은 등급 의뢰 대비) |
| --- | --- | --- | --- |
| 탐색형 F~C | 1~3명 | 1개월 뒤 재도전, 단서 일부로 다음 성공률 +10%p | 명성 · 금전 ×2, 애착 +10, 경험치 ×1.5 |
| 탐색형 B~A | 2~3명 | 같음 | 같음 |
| 정점 · 전환 | 3~5명 | 2개월 뒤 재도전, 명성 소폭 하락 | 명성 · 금전 ×3, 애착 +15, 경험치 ×2 |
| 간부전 | 4~5명 | 2개월 뒤, 인구 −3% | 같음 + S급 소재 |
| 마왕전 | 고정 파티 | 사망과 계승 | 엔딩 |

- 탐색형 메인은 지명된 모험가의 1인칭 일지로 보여 주고, 성향에 따라 핵심 문장 1~2줄이 바뀝니다.
- 대표 모험가가 죽으면 일지가 문장 중간에 끊긴 채 돌아옵니다.

## 공통 규칙

- 메인 퀘스트는 거절할 수 없고 보류만 됩니다.
- **"언제 받을지"가 첫 번째 결정**입니다. 받자마자 도전하면 절반쯤 지고, 몇 주 더 키우면 이길 확률이 오릅니다. 전투 규칙은 [5장 침공](../ch05/invasion.md)에 있습니다.
- 메인 퀘스트마다 옛 파티 전멸의 진실이 조금씩 드러납니다([11장](../ch11/README.md)).
