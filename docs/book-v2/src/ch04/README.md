# 의뢰와 퀘스트

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**퀘스트는 목적에 따라 세 종류이고, 돈 · 성장의 대부분은 "리소스 퀘스트(게시판 일상 의뢰)"에서 나옵니다.** 리퀘스트(서브)는 마을 이야기와 설비 해금을, 메인 퀘스트는 길드 승급을 맡습니다.

| 종류 | 화면 이름 | 누가 맡나 | 하는 일 | F급 수 |
| --- | --- | --- | --- | --- |
| 리소스 퀘스트 | 의뢰 | 모험가가 스스로 고름 | 돈 · 경험치 · 명성 · 신뢰도 | 매달 5건 유입 |
| 서브 퀘스트 | 리퀘스트 | 플레이어가 지명하거나 돈 · 소재로 해결 | 마을 이야기, 설비 · 건물 해금 | 28개 |
| 메인 퀘스트 | 메인 퀘스트 | 지명 또는 전원 | 길드 승급, 세계관 공개 | 1개 (침공) |
