# 길드 내부 꾸미기

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**장식 8종과 테이블은 길드 1층 바닥 격자에 자유롭게 놓고, 모두 리퀘스트 보상으로 하나씩 열립니다.** 장식은 "의뢰 성공 때 +1" 같은 정수 효과를 줍니다. 첫해의 주된 돈 쓸 곳입니다.

| 장식 | 가격 | 효과 |
| --- | --- | --- |
| 화분 | 150G | 의뢰 성공 시 애착 +1 |
| 의뢰 게시판 장식 | 250G | 의뢰 성공 시 신뢰도 +1 |
| 모험가 사물함 | 300G | 의뢰 성공 시 기본 소재 +1개 |
| 길드 현수막 | 350G | 의뢰 성공 시 명성 +1 |
| 의뢰인 대기 벤치 | 400G | 의뢰 성공 시 +5G |
| 낡은 지도 | 400G | 의뢰 성공 시 경험치 +5 |
| 벽난로 | 500G | 부상 기간 −1주 |
| 트로피 장식장 | 650G | 매달 보상 2배 의뢰 1건 보장 |
| **합계** | **3,000G** | |

| 테이블 | 규칙 |
| --- | --- |
| 가격 | 각 200G, F급 최대 4세트 |
| 처음 | 0세트, 2세트까지 지을 수 있음. 3 · 4세트는 리퀘스트 보상 |
| 효과 | 1세트 = 2석. 앉은 모험가만 음식 주문 → 좌석 수가 식사 수입의 상한 |

- 프로토타입에는 장식 업그레이드가 없습니다.
- **현수막(명성 +1)은 모험가 합류 속도를, 벤치(+5G)는 수입을 직접 올립니다.** 경제 검토 때 장식의 투자 회수 기간을 보시면 좋습니다.
