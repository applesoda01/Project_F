# 원정 미니 뷰

**길드 화면 오른쪽의 원정 현황에서 파티를 누르면, 출발 때 계산된 전투 기록이 SD 캐릭터로 재생됩니다.** 결과는 이미 정해져 있고, 미니 뷰는 보여 주기만 합니다.

| 요소 | 내용 |
| --- | --- |
| 원정 현황 패널 | 평소 반투명, 마우스를 올리면 선명. 나가 있는 파티 목록 |
| 미니 뷰 | 480×203, 가로 스크롤. 의뢰 유형별 배경 5종 |
| 연출 | 이동 → 탐색(머리 위 아이콘) → 조우 → 전투 → 결과 |
| 전투 표시 | 공격할 때만 공격 모션, 데미지 숫자, 행동 게이지, 앞열이 쓰러지면 뒤 열이 앞으로 |
| 캐릭터 | 직업 10종 SD 모션(걷기 · 달리기 · 공격 · 쓰러짐 · 탐색), 몬스터 8종 |
