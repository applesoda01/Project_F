## 버전 관리 원칙

v1 원문은 `docs/book/`, v2 원문은 `docs/book-v2/`에 보관합니다. 원본 규칙을 개정판으로 소급 변경하지 않습니다. 버전은 게임 출시 번호가 아니라 안내서 발행 단위입니다.

[변경 비교표](changes.md)는 기능 ID별 변경 이유와 근거를 기록합니다. [기능 관리](features.md)는 기획 상태와 게임 구현 상태를 따로 기록합니다. 향후 채택·구현·검증 때 해당 칸과 근거 커밋을 갱신합니다. 구현 완료는 코드·검증 근거를 확보한 뒤에만 기록합니다.

안내서 v2의 신규 제안 근거는 [첨부 원문](proposal/README.md)입니다. 원문이 검토한 `bd7e207`과 이번 보존 기준 `6df6325`는 다르므로 원문 코드 분석을 최신 실행 결과로 간주하지 않습니다.
