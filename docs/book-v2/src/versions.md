## 버전 관리

| 작업 | 기록할 것 |
| --- | --- |
| 규칙 수정 | 해당 장 본문 + [변경 비교표](changes.md) |
| 기획 채택 | 결정 날짜·근거, 구현 여부와 별개 |
| 게임 구현 | 코드 커밋·검증 범위·결과 |
| 수치 확정 | 같은 조건의 측정 근거 |
| 이전 규칙 확인 | 우측 V1 선택. 개정 본문에 옛 규칙을 중복 적재하지 않음 |

v1은 `docs/book/`, v2는 `docs/book-v2/`입니다. `docs/design/v2/`는 기존 재분류 묶음으로 별도 버전 체계입니다.
