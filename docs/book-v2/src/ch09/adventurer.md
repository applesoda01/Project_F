# 모험가의 지갑

> 기존 구현·측정 기록은 2026-11-16 기준입니다. V2 신규 설계의 구현·검증 결과가 아니며, 아래 추가·수정 제안과 구분합니다.

**기본 일반 요율 10%일 때 모험가 몫은 90%입니다.** 선택 요율·정식 계약은 개인별로 계산합니다 [제안]. 기존 첫해 평균 지갑 약 230G와 F급 세트 450G의 구매력 문제는 유지합니다.

| 들어오는 돈 | 나가는 돈 |
| --- | --- |
| 개인 배분 기준액 − 개인 길드 몫 [제안] | 장비 (마을 상점) |
| 지명 퀘스트 보수 몫 | 물약 (출발 때) |
| | 식사 · 술 (길드) |

## 소비 성향이 정하는 것

| 성향 | 절약 | 보통 | 낭비 |
| --- | --- | --- | --- |
| 식당 이용 확률 | 30% | 60% | 90% |
| 물약 최대 | 1 | 2 | 3 |
| 장비 사기 전 남겨 두는 돈 | 장비값 × 2 | × 1 | × 0.3 |

## F급 모험가 한 명의 계산 (어림)

| 항목 | 값 |
| --- | --- |
| F급 의뢰 1건 (솔로) | 90G |
| 출발 때 식사 (F) | 25G |
| 출발 때 물약 (F, 보통 2개) | 40G |
| 남는 돈 | 약 25G |
| F급 장비 세트 (무기 150 × 3) | 450G |

이 계산이 첫해 F급 장비 보유율 10~20%의 원인입니다. 식사 · 물약 값이 한 번 나갈 때마다 의뢰 보상의 대부분을 가져갑니다.

> 위 표는 규칙 값으로 계산한 어림입니다. 파티로 가면 보상이 나뉘고, 모든 출발에서 식사 · 물약을 사지는 않습니다.

## V2 추가·수정 규칙 — 제안·미반영

**파티 전체가 아니라, 각자의 배분 기준액에 소속별 요율을 적용합니다.**

## 외부 일반 의뢰 — ECON-01 / 제안·미반영

| 순서 | 규칙 |
| --- | --- |
| ① 기준액 | 총 보상 R을 n명에게 균등 배분 |
| ② 길드 몫 | 자유: 일반 요율 / 계약 모험가: 계약 최종 요율 |
| ③ 실수령 | 개인 기준액 − 개인 길드 몫 |
| ④ 총액 | 길드 몫 합 + 개인 실수령 합 = R |
| ⑤ 잔액 | 기준액 = ⌊R ÷ n⌋, 나머지는 **대장부터 파티 순서로 1G씩**. 개인 길드 몫 = ⌊기준액 × 요율⌋(버림). 예: 101G · 3명 · 10% → 실수령 31 · 31 · 30G + 길드 9G = 101G [결정 2026-11-17] |
| ⑥ 조건 | 출발 때 참가자·요율·계약을 저장. 귀환 시 변경 금지 |

계약 요율은 일반 중계료를 포함합니다. 일반 10% 뒤 계약 20%(F급 기본, 결정 2026-11-17)를 다시 떼지 않습니다.

| 1,000G 혼성 파티 예시 | 기준액 | 길드 몫 | 개인 실수령 |
| --- | ---: | ---: | ---: |
| 자유 A / 일반 10% | 250G | 25G | 225G |
| 자유 B / 일반 10% | 250G | 25G | 225G |
| 계약 C / 계약 20% | 250G | 50G | 200G |
| 계약 D / 계약 20% | 250G | 50G | 200G |
| 합계 | 1,000G | 150G | 850G |

**계산 예시입니다(요율은 F급 기본값, 시험값).** 길드 150G에서 보수·실제 지원은 별도 지출입니다.

## 정식 계약의 유인

> 직접 기여 증가 = (계약 비율 − 일반 비율) × 월 개인 기준액 − 보수 − 실제 지원

| 예시(F급 기본값): 10%→20%, 보수 25G·실제 지원 10G | 자유 길드 기여 | 계약 모험가 길드 기여 |
| --- | ---: | ---: |
| 개인 기준액 100G | 10G | −15G |
| 300G | 30G | 25G |
| 600G | 60G | 85G |

| 모험가의 관점: 기준액 300G | 현금 | 지원 |
| --- | ---: | --- |
| 자유 | 270G | 별도 |
| 계약 모험가 | 의뢰 240G + 보수 25G | 필요할 때 실제 10G 편익 (수락 판단에는 한도의 절반 5G로 셈) |

지원은 개인 현금 지급이 아닙니다. 소득이 높은 인재는 더 좋은 보수·업무 조건을 요구하거나 거절할 수 있습니다(수락 복합식, [계약 화면](../ch03/lifecycle.md)). F급 기본값에서 길드 이득은 돈이 아니라 지명 섭외비 0 · 범위 안 거절 없음입니다(결정 2026-11-17). 지명 비용 절감은 실제 이용 건수만 별도 평가합니다.

## 장기 사업 정산 — 관리비와 수행 보수 분리

| 선수금 300G 예시: 호위 4회 중 3회 완료 | 금액 |
| --- | ---: |
| 완료 3회 수행자 지급 | 180G |
| 미완료 1회 환급 | 60G |
| 실패 배상 | 15G |
| 길드 관리 대가 순수입 | 45G |
| 합계 | 300G |

관리비 60G·수행 보수 240G를 분리한 **산술 예시**입니다. 관리 의무 불이행 시 관리비도 감액합니다. 수행 보수에 일반·계약 요율을 다시 떼지 않고, 길드 45G에서도 급여·지원·직접비를 차감합니다.

## 소비

| 소비 | 처리 |
| --- | --- |
| 장비·물약 | 개인 구매. 계약 지원은 실제 구매액 분담 |
| 식사·술 | 실제 잔액 확인·결제, 길드 지원과 구별 |
| 성향 | 절약·보통·낭비의 기존 구매 성향 유지 |
| 개인 장비·유품 | 계약 종료로 몰수하지 않음 |
