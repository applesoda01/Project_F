# 모험가의 지갑

**파티 전체가 아니라, 각자의 배분 기준액에 소속별 요율을 적용합니다.**

## 외부 일반 의뢰 — ECON-01 / 제안·미반영

| 순서 | 규칙 |
| --- | --- |
| ① 기준액 | 총 보상 R을 n명에게 균등 배분 |
| ② 길드 몫 | 자유: 일반 요율 / 정식: 계약 최종 요율 |
| ③ 실수령 | 개인 기준액 − 개인 길드 몫 |
| ④ 총액 | 길드 몫 합 + 개인 실수령 합 = R |
| ⑤ 잔액 | 정수 잔액의 고정 배분 순서·반올림은 구현 전 확정 |
| ⑥ 조건 | 출발 때 참가자·요율·계약을 저장. 귀환 시 변경 금지 |

정식 요율은 일반 중계료를 포함합니다. 일반 10% 뒤 정식 30%를 다시 떼지 않습니다.

| 1,000G 혼성 파티 예시 | 기준액 | 길드 몫 | 개인 실수령 |
| --- | ---: | ---: | ---: |
| 자유 A / 일반 10% | 250G | 25G | 225G |
| 자유 B / 일반 10% | 250G | 25G | 225G |
| 정식 C / 계약 30% | 250G | 75G | 175G |
| 정식 D / 계약 30% | 250G | 75G | 175G |
| 합계 | 1,000G | 200G | 800G |

**계산 예시이며 요율은 검증용입니다.** 길드 200G에서 보수·실제 지원은 별도 지출입니다.

## 정식 계약의 유인

> 직접 기여 증가 = (정식 비율 − 일반 비율) × 월 개인 기준액 − 보수 − 실제 지원

| 예시: 10%→30%, 보수 40G·실제 지원 20G | 자유 길드 기여 | 정식 길드 기여 |
| --- | ---: | ---: |
| 개인 기준액 100G | 10G | −30G |
| 300G | 30G | 30G |
| 600G | 60G | 120G |

| 모험가의 관점: 기준액 300G | 현금 | 지원 |
| --- | ---: | --- |
| 자유 | 270G | 별도 |
| 정식 | 의뢰 210G + 보수 40G | 필요할 때 실제 20G 편익 |

지원은 개인 현금 지급이 아닙니다. 소득이 높은 인재는 더 좋은 보수·업무 조건을 요구하거나 거절할 수 있습니다. 지명 비용 절감은 실제 이용 건수만 별도 평가합니다.

## 장기 사업 정산 — 관리비와 수행 보수 분리

| 선수금 300G 예시: 호위 4회 중 3회 완료 | 금액 |
| --- | ---: |
| 완료 3회 수행자 지급 | 180G |
| 미완료 1회 환급 | 60G |
| 실패 배상 | 15G |
| 길드 관리 대가 순수입 | 45G |
| 합계 | 300G |

관리비 60G·수행 보수 240G를 분리한 **산술 예시**입니다. 관리 의무 불이행 시 관리비도 감액합니다. 수행 보수에 일반·정식 요율을 다시 떼지 않고, 길드 45G에서도 급여·지원·직접비를 차감합니다.

## 소비

| 소비 | 처리 |
| --- | --- |
| 장비·물약 | 개인 구매. 계약 지원은 실제 구매액 분담 |
| 식사·술 | 실제 잔액 확인·결제, 길드 지원과 구별 |
| 성향 | 절약·보통·낭비의 기존 구매 성향 유지 |
| 개인 장비·유품 | 계약 종료로 몰수하지 않음 |
