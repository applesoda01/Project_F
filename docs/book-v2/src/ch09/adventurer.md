# 모험가의 지갑과 개인별 정산

> **변경 · ECON-01, ADV-01 · 기획: 제안 / 게임: 미반영**<br>
> 근거: [첨부 8절](../proposal/section-08.md)

**파티 전체 보상에 한 사람의 계약 요율을 적용하지 않습니다.**

보상 총액을 먼저 참가자에게 균등 배분한 기준액으로 나눕니다. 자유 모험가는 일반 중계료, 계약원은 계약상 최종 길드 비율을 자신의 기준액에 적용합니다. 계약 비율에 일반 중계료를 다시 더하지 않습니다.

## 혼성 파티 계산 예시

총 1,000G, 자유 2명·정식 2명, 일반 10%·정식 30%를 가정한 산술 예시입니다.

| 참가자 | 개인 기준액 | 길드 몫 | 개인 실수령 |
| --- | ---: | ---: | ---: |
| 자유 A | 250G | 25G | 225G |
| 자유 B | 250G | 25G | 225G |
| 정식 C | 250G | 75G | 175G |
| 정식 D | 250G | 75G | 175G |
| 합계 | 1,000G | 200G | 800G |

정기 보수와 실제 지원은 별도 지출입니다. 200G는 순이익이 아닙니다. 정수 잔액은 재현 가능한 참가자 순서로 배분하고, 반올림 기준은 구현 전 결정합니다. 출발 시 요율·계약 조건을 고정합니다.

## 계약할 이유는 양쪽에 있어야 함

월 개인 기준액 합계 S, 일반 비율 f, 정식 비율 r이면 전환 직접 기여는 **(r − f) × S − 보수 − 실제 지원**입니다.

10%→30%, 보수 40G·실제 지원 20G라는 가정에서는 S=300G가 직접 손익분기점입니다. F급 100G 의뢰를 4명이 네 번 수행한 개인의 S는 100G입니다.

같은 S=300G에서 모험가는 자유 270G와 정식 현금 250G(의뢰 210 + 보수 40)를 비교합니다. 지원 20G는 현금 지급이 아니고, 필요할 때만 편익이 있습니다. 숙련자가 높은 수입을 얻을수록 더 나은 계약을 요구하거나 거절할 수 있습니다.

지명 비용 절감과 가용성은 실제 이용한 만큼 따로 평가합니다. 모든 인원을 정식으로 전환하는 것이 항상 최적이어서는 안 됩니다.
