## V2 추가 안내

> **개정 · 기획: 제안 중심 / 게임: 신규 규칙 미반영**

**누구를 계약하고, 무엇을 지원하며, 그 비용을 감당할지 선택하는 경제를 제안합니다.**

자유 모험가는 의뢰·거래·시설 이용으로 길드 활동을 넓힙니다. 정식 모험가는 보수와 지원을 받으며 합의한 임무에 우선 참여합니다. 계약의 가치는 더 높은 길드 몫뿐 아니라 인력 가용성과 지명 비용 절감입니다.
