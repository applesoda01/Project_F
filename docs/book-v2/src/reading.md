# 이 책을 읽는 법

**각 절은 "결론 한 줄 → 표 → 짧은 설명" 순서로 씁니다.** 굵은 첫 문장만 이어 읽어도 그 장의 요지를 알 수 있습니다.

## 상태 표시

| 표시 | 뜻 |
| --- | --- |
| (표시 없음) | V1에서 이어받은 기존 기록. 새 규칙의 구현 여부는 별도 상태로 확인 |
| **[가안]** | 방향은 정했지만 수치가 바뀔 수 있음 |
| **[제안]** | 아직 결정 전 |
| **[반영 예정]** | 결정은 끝났고 코드 반영만 남음 |
| **[수정 예정]** | 다시 설계할 예정 (경제 구조) |

## 숫자 읽는 법

- 돈 단위는 **G(골드)** 입니다.
- 시간 단위는 **주**입니다. 한 달 = 4주, 1년 = 48주입니다.
- 등급은 **F → E → D → C → B → A → S** 순서로 높아집니다. 길드와 모험가가 각각 등급을 가집니다.
- "100판 평균"은 같은 규칙으로 게임을 자동으로 100번, 48주씩 돌린 평균입니다. 측정은 저장소의 시뮬레이터와 게임 규칙 코드로 합니다.

## 그림

흐름이나 구조는 그림으로 보여 드립니다. 그림이 안 보이면 페이지를 새로 고쳐 주십시오(그림 도구를 인터넷에서 불러옵니다).

## V2 상태와 변경 표시

**본문은 v2의 설계 규칙입니다. 게임 구현 여부는 별도로 읽습니다.**

| 표시 | 의미 |
| --- | --- |
| 유지 | v1 규칙 유지. 이번에 실행 재검증한 것은 아님 |
| 제안 / 미반영 | v2 본문에 반영한 새 설계. 게임에는 아직 없음 |
| 기존 확정 / 코드 차이 | 결정은 있었지만 실제 코드와 차이 기록 |
| 검증용 | 계약 정원·급여·요율 등의 실험 시작값 |
| 미결 | 구현 전에 결정할 항목 |
