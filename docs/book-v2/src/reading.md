# 이 책을 읽는 법

**기획이 정해졌는지와 게임에서 동작하는지는 서로 다른 상태입니다.**

| 기획 상태 | 의미 |
| --- | --- |
| 기존 유지 | v1 규칙·설명을 이어받음. 신규 승인이나 구현 확인을 뜻하지 않음 |
| 기존 확정 | 기존 문서에 결정 기록이 있음. 코드 반영 여부는 별도 |
| 제안 | 개정판에 수록한 검토 대상. 채택 미확정 |
| 검증용 수치 | 계산·실험의 시작값. 밸런스 확정값 아님 |
| 미결 | 근거나 규칙 간 충돌이 남아 있음 |
| 이번 범위 제외 | 이번 최소판에서 도입하지 않는 항목 |

| 게임 구현 상태 | 의미 |
| --- | --- |
| v1 기록 | v1/첨부 기준의 서술. 이번에 실행 재검증하지 않음 |
| 미반영 | 신규 규칙에 대응하는 게임 변경을 이번 작업에서 하지 않음 |
| 기존 코드와 차이 | 기존 확정 기획과 코드가 다르다고 원자료에 기록 |
| 재확인 필요 | 부분 구현·상충 근거 등으로 단정할 수 없음 |
| 적용 대상 아님 | 문서 사이트 기능 또는 제외 항목 |

**아무 표시가 없다고 구현 완료로 해석하지 않습니다.** 이어받은 본문의 ‘현재’, ‘지금’, ‘통과’는 원본 시점 기록입니다. 판별이 필요한 경우 [기능 관리](features.md)와 원문 근거를 먼저 확인합니다.

## 숫자와 범위

- 시간: 한 달 4주, 1년 48주. 돈은 정수 G.
- 계약 정원 2명, 기간 12주, 후보 애착 30·성공 3회, 지정 업무 4주 중 2주, 8주 예산은 검증용입니다.
- 일반 요율 10/15/20%, 정식 길드 몫 30%, 보수 40G·지원비 20G는 설명·시험값입니다.
- v1의 100판 평균은 과거 경제 측정이며, v2 수치는 새로 측정하지 않았습니다.
- 첨부의 구현 예상 파일·시험 목록은 향후 작업 계획입니다. 완료 증거가 아닙니다.

문서 사이트의 버전 선택·비교 기능과 게임 속 업무 일지 UI도 별개입니다.
