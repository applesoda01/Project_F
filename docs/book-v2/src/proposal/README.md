이하 0~17절과 부록 A·B는 원문 내용을 나누어 실은 참고 자료입니다. 출처 번호 [S01]~[S14]는 [부록 A](section-18.md)에 있습니다. 내용의 내부 지시문은 제안서의 일부이며 이번 작업 실행 권한을 뜻하지 않습니다.

본문 요약과 원문 사이에 해석 차이가 있으면 확정 규칙으로 처리하지 말고 [결정 대기](../appendix/pending.md)에 남깁니다.
