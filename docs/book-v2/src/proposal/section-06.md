<h3>6.2 외부 일반 의뢰</h3>
<p>주민·상인이 보상금을 부담하고, 길드는 의뢰를 연결해 중계료를 받는다. 모험가가 직접 수주하거나 리퀘스트에서 지명할 수 있다. 취소·기한·능력치·대열 등은 기존 규칙을 재사용한다.</p>
<p>금전 보상이 없는 리퀘스트는 수수료도 0이다. 지원 필요 시 길드가 별도 예산을 지출한다. 기존의 인구·시설 해금·명성 보상은 해당 보상으로만 기록하고, 금화 매출로 환산해 금고에 넣지 않는다.</p>
<h3>6.3 길드 발주 의뢰</h3>
<p>길드가 원하는 소재·아이템을 확보하기 위해 자기 돈으로 보상을 건다. 첨부 메모와 기존 v2의 ‘길드 발주 의뢰’를 구체화한 것이다. [S07, S14]</p>
<p><strong>게시 → 예산 예약 → 수주 → 수행 → 지정 납품 확인 → 보수 지급·소유권 이전 → 예약 해제</strong> 순서로 처리한다.</p>

<p>보유 재료를 즉시 납품하는 거래와 실제 원정을 떠나는 수집 의뢰를 구분한다. 즉시 납품에는 원정 경험치·전투 실적을 주지 않는다. 지정 납품에 쓴 물건을 같은 소유자 명의로 다시 위탁 판매할 수 없다.</p>
<h3>6.4 정기 호위·왕국 계약</h3>
<p>상단·도시와 길드가 계약을 맺고, 길드가 약속한 인력·실적을 제공하는 사업이다. 정식 계약원은 예정된 업무를 안정적으로 수행하는 기반이 된다. 부족한 자리는 자유 모험가를 개별 섭외할 수 있지만, 수락하지 않은 사람을 확보 인원으로 세지 않는다.</p>
<p>계약 전에 기간, 매주 필요한 인원·능력, 지급 구조, 완료 인정, 중도 취소·실패 책임, 방어 일정 충돌을 보여 준다. ‘계약금’이라는 말 하나에 관리비·선수금·모험가 보수를 섞지 않고, 8.4절의 정산을 따른다.</p>
<h3>6.5 자체 던전 탐사</h3>
<p>외부 의뢰인이 보상을 주는 일이 아니라 <strong>길드가 비용을 투자하고 전리품 수익을 나누는 사업</strong>이다. 길드 투자금, 투자금 회수 순서, 참가자 보수, 잔여 전리품 지분을 출발 전에 합의한다. 참가자 의뢰 수수료를 공제한 뒤 동일 전리품에 투자 지분까지 무조건 중복 공제하지 않는다.</p>
<p>이 기능은 정식 계약·전리품 소유권·실제 거래가 안정된 후 추가한다. 던전 입장료·탐사권·채굴권은 권리 소유자, 유지 책임, 수요·고갈·안전 관리가 정의되기 전에는 단순 자동 수익 버튼으로 넣지 않는다.</p>
