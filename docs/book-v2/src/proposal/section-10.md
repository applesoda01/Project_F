# 10. 시설 수익과 모험가 구매력

<h3>10.1 주점·식당의 실제 거래</h3>
<p>현재 식사는 개인 지갑에서 가격을 차감하고 길드에 마진을 넣으며, 술은 확인한 처리에서 개인 지갑 차감 없이 마진이 발생한다. 업그레이드는 음식·술 마진에 5G를 더한다. [S10, S11]</p>
<p>개선 후에는 <code>판매 가격 − 직접 원가 = 거래 기여</code>가 맞도록 정리한다. 예를 들어 식사 25G, 외부 조달 원가 10G라면 모험가 −25G, 길드 매출 +25G·원가 −10G·기여 +15G다. 기존의 가격 25%·마진 60%와 같은 결과를 내는 설명용 예시다.</p>
<p>술도 구매 가능 잔액을 확인하고 실제 지갑에서 결제한다. 가격은 아직 별도로 정해야 하며, 기존 ‘마진 2G’를 판매가 2G로 오해하지 않는다. 예시로 가격 5G·원가 3G이면 마진 2G다.</p>
<p>업그레이드 후 가격이 그대로인데 이익만 가격을 초과해 늘어나는 일이 없어야 한다. 품질 개선에 따른 판매가·수요 변화 또는 원가 절감으로 설명하고, 원가 절감은 최소 원가 아래로 내려가지 않게 한다. 해당 변경은 기존 +5G 효과와 수입 곡선이 달라질 수 있으므로 회귀 실험 대상이다.</p>
<h3>10.2 정식 모험가 지원과 내부 거래</h3>
<p>길드가 정식 모험가에게 자기 식당 식사를 제공한 경우, 길드 돈을 자기 식당 매출로 돌려 <strong>새 순이익을 만들지 않는다.</strong> 외부 식재료 원가와 실제 개인 부담분만 순현금에 영향을 준다.</p>
<p>외부 물약 상점에서 20G짜리 물약을 50% 지원한다면 길드 −10G, 개인 −10G, 상점 +20G다. 길드가 무료로 물약을 만들어 주거나, 개인 지갑에서 전액을 뺀 뒤 지원비를 또 상점에 지급하지 않는다.</p>
<p>지원 예산은 사용 상한이고 실제 비용이 아니다. 미사용 예산은 비용 처리하지 않는다. 계약원은 ‘지원비 환급’을 반복 청구해 현금을 만들 수 없으며, 구매 영수증·품목·수량과 연결된 지원만 처리한다.</p>
<h3>10.3 요리 발견과 판매 재료는 구분</h3>
<p>기존 요리의 중심은 소재 조합으로 레시피를 <strong>발견</strong>하는 것이다. 이를 갑자기 매 끼니 재료를 수동 수급하는 식당 경영으로 바꾸지 않는다. [S04]</p>
<p>첫 버전은 발견 시 기존 소재 소모를 유지하고, 판매 시 소요 원가는 자동 조달 비용으로 표현한다. 실제 식재료 재고를 매 끼니 차감하는 구조는 선택적 확장이다. 위탁품은 어느 쪽에서도 자동 재료로 사용할 수 없다.</p>
<h3>10.4 훈련·치료·숙박</h3>
<p>훈련장·의무실·숙박 등은 실제로 제공하는 편익과 비용이 정의될 때 선택 서비스로 확장한다. 무료 자연 회복·기본 휴식 경로는 남겨 둔다. 돈이 없는 신입이 회복도 못 하고 의뢰도 못 하는 상태로 고착되지 않아야 한다.</p>
<p>치료비를 냈다고 현재 전투의 부상 규칙을 무시하고 즉시 완전 회복시키는 안은 채택하지 않는다. 기존 치료 시설의 회복 단축 범위에서 서비스를 설계한다. 길드가 아직 운영하지 않는 시설의 수익·비용은 먼저 장부에 추가하지 않는다.</p>
