<h3>9.1 소유권부터 정한다</h3>
<p>자유 모험가가 가져온 물건을 길드가 무료로 자기 창고에 넣은 뒤 전부 판매하면, ‘자유 모험가를 지원하는 중개 조직’과 ‘소재 매입 비용’이 충돌한다. 새 소재 거래는 <strong>물리적 보관 장소와 경제적 소유자</strong>를 분리해야 한다.</p>

<p>정식 계약원이 되었다고 모든 개인 전리품이 길드 소유가 되지는 않는다. 정식 계약의 금전 배분과 소재 지분은 다른 권리다. 첫 버전은 일반 전리품을 개인 소유로 유지하고, 길드 발주·투자 탐사에서만 별도 권리를 정하는 편이 명확하다.</p>
<h3>9.2 두 가지 거래</h3>
<p><strong>즉시 매입:</strong> 길드가 모험가에게 매입 대금을 지급하고 물건의 소유권을 얻는다. 이후 더 높은 가격에 팔면 차익을 얻지만 팔리지 않거나 가격이 내려가면 손실을 부담한다.</p>
<p><strong>위탁 판매:</strong> 길드는 물건을 보관하고 판매를 대행한다. 판매 대금에서 수수료만 얻으며, 나머지를 소유자에게 준다. 판매되기 전에 위탁품을 요리·제작·선물·납품에 쓸 수 없다.</p>

<p>한 물건이 동시에 매입 재고와 위탁품이 되어서는 안 된다. 매입 판매액 100G와 차익 30G를 둘 다 수입 합계에 더하지 않는다. 파티 공동 전리품은 보관 묶음에 지분을 기록하고, 판매 때 대금을 배분하면 소재 1개를 억지로 여러 조각으로 나누지 않아도 된다.</p>
<h3>9.3 처음부터 시세 시뮬레이터를 크게 만들지 않는다</h3>
<p>최초 버전은 기존 등급별 판매가(F 6G, E 9G 등)를 기준 가격으로 사용하고, 매입가·위탁 수수료·판매 가능한 수량만 검증한다. 복잡한 가격 변동은 후순위다. [S07]</p>
<p>현금이 부족하면 매입 대신 위탁을 권할 수 있어야 한다. 매입 예산 상한, 보관 한도, 최소 예비금을 둔다. 길드에 팔지 않아도 모험가가 외부 상인에게 판매하는 기본 경로를 두어, 길드의 자금 부족 때문에 모험가 경제까지 멈추지 않게 한다.</p>
<p>실제 판매 방식이 적용되는 시점에 자동 차익 <code>resaleRate = 0.08</code>을 해당 거래에서 끈다. 먼저 자동 수입을 제거하고 대체 수입은 미구현인 상태로 배포하지 않는다.</p>
<h3>9.4 소재를 ‘팔까, 쓸까’</h3>
<p>길드 소유 소재는 즉시 판매, 요리 발견, 길드 시설 개방, 대장간 납품, 정식 모험가 장비 지원, 이야기 리퀘스트 제출에 사용할 수 있다. 같은 재료가 여러 용도를 가지는 것이 핵심이다.</p>
<p>대장간·물약 상점의 완제품 매출은 기존대로 해당 상점의 수입이다. 길드는 <strong>소재 납품 대금 또는 별도로 맺은 위탁·서비스 계약의 수수료</strong>만 번다. ‘길드가 해금시켜 준 가게이므로 모든 매출이 길드 돈’이라는 규칙으로 바꾸지 않는다. [S04, S07]</p>
<h3>9.5 제작·가공의 범위</h3>
<p>초기에는 기존 대장간과 공급 계약·주문 제작을 연결한다. 길드가 자체 제작소까지 동시에 운영하게 하지 않는다. B급 해체장 등의 기존 시설에 가공 수수료·고급 재료 생산을 붙이는 것은 후속 확장으로 둔다. 신규 목욕탕·경매장·던전 입장 사업도 기존 15종 시설에 필요한 역할이 없는지 먼저 검토한다.</p>
