<p>정식 계약이 전직 성공률·전투 명중률·사망 면역을 자동으로 높이지 않는다. 성장 이점은 실제 시설·장비·치료·시간 지원으로 발생해야 한다.</p>
<h3>4.2 정식 계약의 권한 한계</h3>
<p>정식 계약은 전투 직접 조작권이나 무조건 복종권이 아니다. 계약이 보장하는 것은 <strong>합의한 종류·위험·시간 범위에서 우선적으로 일을 맡기는 권리</strong>다.</p>
<p>부상, 기존 원정, 충족하지 못한 임무 조건, 계약상 위험 상한 초과, 업무 시간 초과, 급여 체납 상태에는 배치할 수 없다. 범위 밖 임무는 별도 동의를 받으며 자유 모험가와 같은 거절 가능성을 남긴다. 기존 전투·후퇴·대열 규칙은 그대로 적용한다.</p>
<p>계약 범위 내 배치는 매번 애착 확률을 굴려 거절시키지 않는 안을 추천한다. 안정적인 인력 확보라는 대가가 분명해야 하기 때문이다. 애착과 성향은 <strong>영입·재계약·업무 선호·범위 밖 요청</strong>에 계속 작용한다.</p>
<h3>4.3 배치 시간과 자율성</h3>
<p>첫 시험에서는 계약원 1명당 <strong>4주 중 최대 2주를 길드 지정 업무에 예약</strong>하고 나머지를 일반 의뢰·회복·개인 활동에 남기는 값을 검토한다. [검증용 수치]</p>
<p>장기 의뢰는 실제 점유 주수만큼 계산하고, 같은 사람을 호위·소재 수집·방어 대기에 중복 예약하지 않는다. 방어 대기도 인력 점유다. 일정상 쉴 시간이 남는다고 피로도가 이미 구현된 것으로 취급하지 않으며, 피로 시스템을 넣기 전에는 예약 시간 제한과 기존 부상 규칙으로 과로를 제한한다.</p>
<p>침공 준비는 기존의 출발 제한을 우선 적용한다. 계약 임무를 수락하기 전에 예상 충돌을 안내하고, 이미 외부에 약속한 호위가 있다면 대체 인원·일정 변경·위약금 중 하나가 필요하다. 같은 모험가가 양쪽에 동시에 나타나서는 안 된다.</p>
