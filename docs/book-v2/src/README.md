## 유지하는 게임의 정체성

플레이어는 직접 전투하지 않는 길드 마스터입니다. 자유 모험가의 의뢰 선택·장비 구매·파티 결성과 간접 육성은 유지합니다. 정식 계약은 일부 인재와 상호 책임을 약속하는 선택지이며 전원 고용을 요구하지 않습니다.

F급은 시작 500G와 창립 2명을 기준으로 기존 리퀘스트 8회 → 「다리를 지켜라」 → E급 흐름을 유지하는 제안입니다. 계약은 E급 이후 관리소에서 시험하며, 계약하지 않아도 승급할 수 있어야 합니다.

## 원본과 개정판

상단의 v1/v2 링크로 같은 장을 비교할 수 있습니다. 해당 장이 없는 판은 첫 페이지로 이동합니다. v1 본문은 수정하지 않았습니다. v2의 유지된 장에는 원본 기록임을 표시했고, 바뀐 규칙에는 제안임을 표시했습니다.

저장소의 `docs/design/v2/`는 과거 기획서의 **재분류 묶음**입니다. 이 사이트의 **안내서 v2**와 같은 버전 번호 체계가 아닙니다. 과거 측정인 월 573G·성공률 94.9%는 새 계약 경제의 결과가 아닙니다.
