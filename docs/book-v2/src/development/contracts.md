# 2. 계약·지원·배치

**1단계의 저장·정산 검증을 통과한 뒤 계약을 연결합니다.**

## 2단계 — 제안과 체결

| 작업 | 구현 내용 | 완료 조건 |
| --- | --- | --- |
| 해금·후보 | E급+관리소, 정식 정원·가용 상태·후보 조건 | 미충족 사유 표시, 정식 0명 허용 |
| 조건 편집 | 전직제안 아래 계약제안 탭, 기본값·직접 선택·복원 | 범위 밖 입력 차단, 비용 즉시 재계산 |
| 제안·수락 | 상담 조건·결과 저장, 체결 시 예산 확보 | 같은 조건 반복 재추첨 금지, 중복 체결 없음 |
| 명부 표시 | 소속·애착·거주·계약 기간을 구분 | 기존 명부·경력·전직 기능 유지 |

- [ ] 제안 범위·예산 부족·정원 초과 사례를 먼저 작성한다.
- [ ] 계약 상태와 조건별 수락 처리를 구현한다.
- [ ] `prototype/js/ui.js`와 기존 책 UI 스타일에 계약제안 탭을 연결한다.
- [ ] 기본값 변경·복원·저장 후 재개·중복 클릭을 확인한다.

## 3단계 — 급여·지원·예약·종료

| 작업 | 규칙 | 필수 검증 |
| --- | --- | --- |
| 보수 | 주별 발생, 월말 1회 지급 | 월중 영입·종료·귀환 지연 |
| 실비 지원 | 약정 한도와 실제 사용액만 부담 | 현금 부족·내부 식사 지원 중복 수입 |
| 배치 | 약정 종류·위험·기간·업무 상한, 별도 섭외비 없음 | 부상·원정·호위·침공 중복, 귀환 주 예외 |
| 혼성 정산 | 자유/정식 개인별 요율, 총액 보존 | 계약률에 일반 요율을 이중 부과하지 않음 |
| 종료·체납·사망 | 발생 보수 정산, 신규 배치 제한, 대여품 반환 | 채무 삭제·개인 물품 몰수·자녀 자동 고용 없음 |

- [ ] 종료 경계·체납·부상·사망의 실패 사례를 작성한다.
- [ ] `game_core.js`의 주간/월간 처리와 `sim_engine.js`를 함께 수정한다.
- [ ] 기존 지명·전직·침공 흐름에 회귀가 없는지 확인한다.
- [ ] 계약 카드·장부에서 실제 처리 결과와 불가 이유를 확인한다.

**완료 조건:** 자유 모험가와 정식 0명 플레이를 유지하고, 소수 계약이 실제 비용과 가용성의 선택으로 작동합니다. 근거·시안: [계약](../ch03/lifecycle.md) · [지명](../ch04/nomination.md) · [정산](../ch09/adventurer.md).
