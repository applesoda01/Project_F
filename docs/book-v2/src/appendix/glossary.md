# 부록 A. 용어집

| 용어 | 뜻 |
| --- | --- |
| 길드 마스터 | 플레이어 |
| 리나 | 접수원. 보고 · 제안 · 힌트를 전하는 안내 캐릭터 |
| 의뢰 | 게시판에 걸리는 일상 일(리소스 퀘스트). 모험가가 스스로 고름 |
| 리퀘스트 | 의뢰인이 가져오는 부탁(서브 퀘스트). 지명 · 납품 · 돈 내기 등으로 해결 |
| 메인 퀘스트 | 등급마다 있는 승급 퀘스트. F급은 침공 「다리를 지켜라」 |
| 지명 | 마스터가 모험가를 골라 보내는 것 |
| 섭외비 | 지명할 때마다 내는 돈. 모험가 등급별 고정, 거절당해도 나감 |
| 의뢰 배분 | 게시판 칸을 등급별로 나누는 설정(없음 · 적게 · 보통 · 우선) |
| 중계료 | 의뢰 보상에서 길드가 가져가는 몫. 기본 10% |
| 왕국 보조금 | 왕국(길드 연합)이 주는 돈. 지금 코드는 등급별 매달 고정 |
| 소재 자동 차익 | 의뢰 성공 때 보상의 8%가 저절로 길드에 들어오는 규칙. 폐지 예정 |
| 운영 순이익 | 수입 − 지출, 단 건설 · 투자 지출은 뺌. 관문 1의 기준 |
| 관문 1 | 첫해 경제 · 성공률을 게임과 시뮬레이터로 함께 검증하는 단계 |
| 시뮬레이터 | 게임 규칙을 단순하게 옮긴 밸런스 측정 코드(`sim_engine.js`) |
| 신뢰도 | 의뢰인의 신뢰(0~100). 의뢰 유입량을 정함 |
| 명성 | 길드의 이름값. 10마다 모험가 1명 합류 |
| 애착도 | 모험가가 길드에 정든 정도(0~100). 방문 빈도 · 전직 수락 · 인구 |
| 정착 모험가 | 애착 65 이상. 매달 인구 +2 |
| 성향 | 모험가의 판단 기준. 위험(모험심) · 소비 · 사교 3축 |
| 창립 멤버 | 시작 모험가 2명. 늘 길드에 있음 |
| 미니 뷰 | 원정 중인 파티의 전투 재생 창 |
| 침공 | 마을을 지키는 방어전. F급 메인 퀘스트 |
| 2세 | 사망한 모험가의 자녀. 6개월 뒤 등장 |

## 계약·정산 용어

| 용어 | 뜻 |
| --- | --- |
| 정식 계약원 | 기간·보수·지원·업무를 약정한 모험가 |
| 개인 배분 기준액 | 전체 보상을 인원별로 나눈 수수료 차감 전 금액 |
| 지급 예약액 | 이미 약속해 다른 곳에 쓸 수 없는 길드 자금 |
| 외부 예치금 | 위탁 소유자 돈·미이행 선수금 등 길드 소유가 아닌 돈 |
| 위탁품 | 길드가 보관·판매만 대행하는 타인 물품 |
| 지역 활동 기여 | 인구 효과 계산. 실제 주택 거주·고용과 별개 |
