## 1. 늦장 실패 (추천: A안)

**모험가가 늦장을 부려 기한을 넘기면 의뢰가 실패하게 하자는 제안입니다.** 능력과 상관없는 실패 원인을 넣어 성공률을 목표 범위 가운데로 내립니다.

| 안 | 늦장 결과 | 성공률 | 월 순이익 |
| --- | --- | ---: | ---: |
| 지금 | — | 94.9% | 573G |
| **A 늦장 = 실패 (기본 3%)** | 기한 초과 실패 | **87.6%** | **535G** |
| A2 늦장 = 실패 (기본 5%) | 기한 초과 실패 | 85.6% | 518G |
| B 늦게 성공 | +1주 · 보수 절반 | 95.4% | 560G |
| C 출발 기준 낮춤 | — | 95.1% | 591G |
| D = A + 출발 기준 약간 낮춤 | 실패 | 87.8% | 548G |

늦장 확률은 파티원 한 명당 기본 3% + 성격 보정(낭비 +4%, 사교적 +3%, 무모 +2%)입니다.

## 2. 마스터 중재

**모험가끼리 다툼 같은 사건이 생기면 카드가 뜨고, 마스터가 중재 · 방관 · 방출 중 하나를 고르는 제안입니다.** 사건은 한 달에 평균 1건입니다.

| 선택 | 비용 | 결과 |
| --- | --- | --- |
| 중재 | 10G (제안) | 두 사람 애착 +2, 3개월 동안 같은 사건 없음 |
| 방관 | 없음 | 70% 저절로 풀림 / 30% 애착 −3 |
| 방출 | 명성 −5, 동료 애착 −5 | 원인 모험가를 내보냄 |

매번 중재하면 연 120G로, 첫해 월 순이익의 약 2%입니다.
