# 플랫폼과 로드맵

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**출시 플랫폼은 스팀(PC)으로 확정했고, 지금은 첫해(F → E급)를 다듬는 프로토타입 단계입니다.** 프로토타입을 마친 뒤 장비 시스템, D급 이상 콘텐츠로 넓힙니다.

## 플랫폼

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | 스팀(PC) 확정 |
| 해상도 [가안] | 16:9 1920×1080 기준, 1280×720에서도 읽히게 |
| 조작 [가안] | 마우스 중심 + 단축키(일시정지 · 배속 · 화면 전환) |
| 스팀 덱 | 프로토타입 이후 검토 (글자를 처음부터 크게) |
| 도전 과제 후보 | 직업 도감, 전설 직업, 멀티엔딩, 2세 · 3세 계승 |
| 체험판 후보 | F~C급, C급 메인 「마지막 야영지」에서 종료 |
| 게임 제목 | 가칭 「이세계 모험가 길드」. "이세계"가 전생 · 전이물로 읽힐 수 있어 출시 전 재검토 |

## 제작 환경

| 항목 | 내용 |
| --- | --- |
| 프로토타입 | 빌드 도구 없이 브라우저에서 바로 열리는 웹 (HTML UI + 1920×1080 캔버스) |
| 데이터 | `prototype/data/*.csv` → 도구로 `data_gen.js` 생성. 웹에서 CSV만 고쳐 올려도 자동 반영 |
| 검증 | GitHub에 올릴 때마다 데이터 검사 + 관문 1 자동 실행 |
| 저장 | 브라우저 저장, 저장 칸 3개 |
| 그림 | SD 캐릭터 모션은 생성 도구 + 수작업 보정, 배경은 계절 · 시간대 판을 따로 만들어 덧씌움 |

## 로드맵 (2026-11-16)

```mermaid
flowchart LR
  A[지금<br/>프로토타입 다듬기] --> B[프로토타입 마무리<br/>F→E 첫해 완성]
  B --> C[프로토타입 뒤<br/>장비 · D급 이상]
  C --> D[출시 준비<br/>스팀]
```

| 단계 | 주요 일 |
| --- | --- |
| 지금 (동료 피드백 반영) | 목표 안내판, 하단 메뉴 · UX 정리, 음식 장 재배치, 기록창 길이, 리퀘스트 수락 · 완료 연출 |
| 결정됨 · 구현 남음 | 모험가 부상 표시 · 방출, 반기 실적 보조금, 소재 자동 차익 정리, 마을 인구 남은 규칙 |
| 제안서 단계 | 늦장 실패, 마스터 중재, 긴장감 아이디어 묶음 |
| 경제 | 시니어 기획자 검토 뒤 구조 개편 ([9장](../ch09/README.md)) |
| 프로토타입 뒤 | 장비(강화 · 보조효과 · 드랍 · 길드 인벤토리), 퀘스트 종류 늘리기, 마을 건물 F · E 효과, D급 이상 몬스터, 후열을 노리는 적, 장식 교체 방식 · E급 장식 6종 |
