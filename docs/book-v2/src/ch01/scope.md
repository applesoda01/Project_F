# 프로토타입 범위와 현재 상태

**v1 프로토타입의 범위와 v2에서 구현할 범위를 분리합니다.**

## 현재 기준 — 기존 기록, 이번에 재실행하지 않음

| 기존 플레이 범위 | 상태 |
| --- | --- |
| F급 시작 → 리퀘스트 8회 → 「다리를 지켜라」 → E급 | v1 플레이 가능 기록 |
| 게시판·F급 리퀘스트 28개·지명·전투 계산 | v1 기록 |
| 시설 6종·장식·요리·마을·미니 뷰 | v1 기록 |
| 월 운영 순이익 573G·성공률 94.9% | 2026-11-16, 게임 규칙 100판 |
| E급 승급 중앙 39주 | 같은 과거 측정 |
| 신규 계약·소유권·예산·장부 | v2 설계만 반영, 게임 미구현 |

## 적용 순서 — SCOPE-01

| 단계 | 구현할 것 | 확인할 것 |
| --- | --- | --- |
| P0 | 정산·소유·예약·관계 용어, 기준 측정 | 기존 금고 변화를 설명 가능 |
| P1 | E급 소수 계약·보수·실비·지명·혼성 정산·종료 | 자유 유지와 계약의 장단점 |
| P2 | 매입·위탁·요율 정책·길드 발주 | 중복 지급·자가 실적·소유권 오류 없음 |
| P3 | 상단 호위·예치·관리비·실패 책임·예약 | 외부 사업과 방어 간 선택 |
| P4 | 도시·왕국 계약, 투자 탐사·정보·가공 | 기존 경제와 연결될 때만 확장 |

반기 보조금은 독립 설정으로 시험한 뒤 P1·P2와 결합합니다.

## 저장 호환 — COMPAT-01 / 제안·미반영

| 기존 상태 | 전환 규칙 |
| --- | --- |
| 기존 인물 | 자유 유지. 강제 고용·소급 급여 없음 |
| 상주 혜택 | 보존. 상주 값만 보고 창립·정식으로 추정하지 않음 |
| 진행 의뢰 | 기존 출발 조건으로 완료 |
| 공용 재고 | 길드 기존 보유분으로 1회 이관 |
| 원가 없는 재고 | 원가 미상 표식, 정밀 이익을 꾸며내지 않음 |
| 이탈·사망 | 별도 원인·상태로 구분. 해지를 사망으로 취급하지 않음 |
| 반복 불러오기 | 거래·급여·재고 이관 중복 없음 |
