## 적용 순서 — SCOPE-01

| 단계 | 구현할 것 | 확인할 것 |
| --- | --- | --- |
| P0 | 정산·소유·예약·관계 용어, 기준 측정 | 기존 금고 변화를 설명 가능 |
| P1 | F급 소수 계약(집무실 · 정원 1명)·보수·실비·지명·혼성 정산·종료·금고 마이너스(자동 지급만) | 자유 유지와 계약의 장단점 |
| P2 | 매입·위탁·요율 정책·길드 발주 | 중복 지급·자가 실적·소유권 오류 없음 |
| P3 | 상단 호위·예치·관리비·실패 책임·예약 | 외부 사업과 방어 간 선택 |
| P4 | 도시·왕국 계약, 투자 탐사·정보·가공 | 기존 경제와 연결될 때만 확장 |

반기 보조금은 독립 설정으로 시험한 뒤 P1·P2와 결합합니다.

## 저장 호환 — COMPAT-01 / 제안·미반영

| 기존 상태 | 전환 규칙 |
| --- | --- |
| 기존 인물 | 자유 유지. 강제 고용·소급 급여 없음 |
| 상주 혜택 | 보존. 상주 값만 보고 창립·계약으로 추정하지 않음 |
| 진행 의뢰 | 기존 출발 조건으로 완료 |
| 공용 재고 | 길드 기존 보유분으로 1회 이관 |
| 원가 없는 재고 | 원가 미상 표식, 정밀 이익을 꾸며내지 않음 |
| 이탈·사망 | 별도 원인·상태로 구분. 해지를 사망으로 취급하지 않음 |
| 반복 불러오기 | 거래·급여·재고 이관 중복 없음 |
