## 영주

**봉인을 대대로 비밀리에 지켜 온 가문입니다.** 처음에는 외부인 길드를 경계하다가, 마을이 커질수록 마음을 엽니다.

| 마을 단계 | 영주의 태도 |
| --- | --- |
| 개척촌 | 경계 |
| 마을 | 관망 (첫 방어전 승리 뒤 인정하기 시작) |
| 읍 | 협력 |
| 도시 | 신뢰 |
| 성채 도시 | 동반자 → 봉인의 비밀을 털어놓음 |

C급 메인 「숲속의 석비」에서 영주에게 보고하면 태도가 한 단계 오르고, A급 「성 아래의 빛」에서 성이 봉인의 핵이라고 고백합니다.

## 옛 용사의 방패 (전설급 방어구)

| 항목 | 내용 |
| --- | --- |
| 첫 주인 | 선택 간부를 토벌한 파티의 전위 (여럿이면 힘이 가장 높은 사람) |
| 그 뒤 | 첫 주인이 죽거나 떠나면 길드 소유. 마스터가 원하는 모험가에게 빌려줌 |
| 특징 | 직업 제한 없음. 검 · 지팡이와 달리 스스로 주인을 고르지 않음 |

## 프롤로그

새 게임을 시작하면 101.6초짜리 프롤로그 영상(1920×1080)이 나옵니다.

## 서브 스토리

마을 핵심 건물 11종마다 의뢰인의 이야기가 있습니다. 기본 건물 9개는 2편씩(사연 소개 → 건물 완성), 상위 건물 2개는 후속편 1편씩, 모두 20편입니다. 의뢰인은 건물이 완성되면 그 스킬 상점의 주인이 됩니다.
