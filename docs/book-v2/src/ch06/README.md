# 아이템

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**아이템은 장비 · 물약 · 소재 · 요리 네 가지이고, 장비와 물약은 모험가가 자기 돈으로 삽니다.** 길드는 요리 발견과 소재 판매 창구로만 아이템 경제에 들어갑니다.

| 아이템 | 누가 사나 | 어디서 | 길드 수입이 되나 |
| --- | --- | --- | --- |
| 장비 | 모험가 | 마을 상점 · 대장간 | 아니요 |
| 물약 | 모험가 (침공 때는 길드) | 마을 물약 상점 / 침공 정비 창 | 침공 때만 지출 |
| 소재 | 의뢰에서 얻음 | 소재 판매 창구에서 팖 | 예 (소재 판매) |
| 요리 | 모험가가 사 먹음 | 길드 식당 | 예 (식사 판매) |
