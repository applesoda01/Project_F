# 요리

## v2 변경 — 식사 결제와 지원

> **ECON-04 · 기획: 제안(유지 사항 별도 명시) / 게임: 신규 규칙 미반영**

식사 판매는 실제 결제액·직접 원가·개인 구매력·길드 지원을 구분합니다. 길드가 자체 식당 이용을 지원할 때 내부 자금 이동만으로 순이익을 만들지 않습니다. 위탁 소재는 요리에 사용할 수 없습니다.

[상세 규칙과 근거](../proposal/section-10.md)

## v1에서 이어받은 설명

> **v1에서 유지한 설명.** 이 본문은 기존 문서의 기록이며 이번에 게임 구현을 재확인한 결과가 아닙니다. 새 제안은 별도 표시합니다. [상태 읽는 법](../reading.md) · [변경 비교표](../changes.md)

**요리는 식당 조리대에서 소재 1~3개를 조합해 "발견"하고, 발견한 요리가 많을수록 모든 모험가가 강해집니다.** 요리는 길드의 식사 판매 수입원이기도 합니다.

| 항목 | 규칙 |
| --- | --- |
| 발견 | 조리대에 소재를 넣어 맞히면 발견. 틀리면 소재가 사라지고 리나가 힌트를 줌 |
| 요리 수 | 16종, F · E 6종 확정 |
| 효과 ① | 발견한 요리 1개당 +2% (비전투 성공 확률, 전투 공격력) |
| 효과 ② | 먹은 요리의 능력치 보너스 (예: 힘 · 기교 +3%), 먹은 사람만 |
| 가격 | 요리 등급 의뢰 보상의 25% (F 25G), 길드 마진 60% |
| 먹는 확률 | 소비 성향: 절약 30% · 보통 60% · 낭비 90% |
| 좌석 | 테이블에 **앉은 모험가만** 주문 (테이블 1세트 = 2석) |

- 16개를 다 발견하면 효과 ①만 +32%입니다. 후반 상한은 아직 정하지 않았습니다.
- 첫해 식사 판매는 월 평균 71G입니다([9장](../ch09/measure.md)).

## 모험가는 어떤 요리를 먹나

출발 전, 발견한 요리 중 **의뢰 등급 이하**에서 그 의뢰의 요구 능력치와 가장 많이 겹치는 것을 고릅니다. 같으면 높은 등급, 높은 수치 순입니다. 발견한 요리가 없으면 먹지 않습니다.
