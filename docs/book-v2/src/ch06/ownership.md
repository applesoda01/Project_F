# 소유권·매입·위탁

> **변경 · ITEM-01 · 기획: 제안 / 게임: 미반영**<br>
> 근거: [첨부 9절](../proposal/section-09.md)

**보관 장소와 소유자를 분리합니다. 정식 계약원이라는 이유로 개인 물품을 길드 소유로 바꾸지 않습니다.**

| 물품 | 소유·사용 규칙 |
| --- | --- |
| 일반 전리품 | 개인 또는 파티 공동 소유 |
| 의뢰인 납품품 | 의뢰 조건에 따라 인도, 임의 판매 불가 |
| 길드 발주 납품품 | 보수 지급·인도 후 길드 소유 |
| 길드 매입품 | 길드 소유, 판매·요리·지원 등 선택 가능 |
| 위탁품 | 판매 전까지 원소유자 소유, 제작·선물·납품 불가 |
| 장비 선물 / 대여 | 선물은 개인 소유, 명시한 대여품만 회수 |
| 기존 저장 재고 | 기존 길드 재고로 보존, 원가 미상은 그대로 표시 |

## 거래 예시 — 검증된 밸런스가 아닌 산술 예시

| 거래 | 지급·현금 | 길드 이익 |
| --- | --- | --- |
| 70G 매입 → 100G 판매 | 매입 때 개인 +70G·길드 −70G, 판매 때 길드 +100G | 30G, 부대비용 전 |
| 100G 위탁, 수수료 10% | 소유자 90G, 길드 10G | 10G, 부대비용 전 |

매출 100G와 차익 30G를 모두 수입에 더하지 않습니다. 위탁 판매대금 전체를 길드 자금으로 쓰지 않습니다. 공동 소유는 지분을 기록합니다.

실제 거래를 도입할 때 대응하는 자동 소재 차익 8%를 대체합니다. 새 거래와 자동 차익을 중복 지급하거나, 대체 수입 없이 먼저 제거하지 않습니다.

마을 대장간·물약 상점의 매출은 해당 상점 수입입니다. 길드는 소재 납품이나 별도 서비스 계약으로만 수익을 얻습니다. 큰 시세 변동·자체 제작소·독점 탐사권은 최초 범위에서 제외합니다.
