## 5. 원인 메모 (기록용 · 고칠 때 참고)

- **1 타이틀 BGM (Pages)**
  - 곡 파일은 정상: `assets/audio/title_loop.ogg` · Ogg Opus 2.9MB · 200 응답
  - `audio.js`는 첫 `pointerdown` / `keydown`에서 `Snd.unlock()` → 타이틀 곡 시작. 타이틀 iframe은 `postMessage({act:'touch'})`로 알림
  - 즉, 누르기 전에는 브라우저 정책상 소리가 안 나는 구조. "화면이 나오자마자" 나오게 하려면 누르는 단계가 하나 필요함 → 시안
  - 주의: 개발자 도구에서 누르지 않고 `Snd.unlock()`을 먼저 부르면 소리 엔진이 멈춘 채로 만들어져, 그 뒤에 눌러도 소리가 안 남 → 확인할 때는 새로고침
- **2 암전 깜빡임:** `tutorial.js` `dimPaint()`가 매 프레임 "밝힌 칸 가운데를 찍어 실제로 눌리는가"를 검사함 → 책이 펼쳐지는 동안 결과가 오가며 켜짐 · 꺼짐 반복
  - 재현: `prototype/tools/qa/qa_dim.js` (누를 때마다 60프레임 기록, 예: `001010111…`)
  - 의뢰 장 · 시설 장 · 리퀘스트 장을 열 때 2~4번 바뀜
- **3 BGM 루프:** `audio.js`는 intro 한 번 + loop 파일 반복 구조
  - 사용자 요청: 페이드 없이, 곡 전체(intro + loop)가 끝나면 처음부터
- **5 테이블:** `ui.js` 놓기 확정 뒤 `d.max > 1 && pmCanBuy(d)`이면 이어서 놓기 모드로 들어감 → 튜토리얼에서 2개째를 사게 됨
