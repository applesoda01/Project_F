# 길드 시설 효과 초안 v0.1 — 이세계 모험가 길드 (가칭)

모든 이름과 수치는 [가안]입니다. 수치는 시뮬레이터로 검증합니다.

## 공통 규칙

| 항목 | 내용 |
| --- | --- |
| 구조 | 시설에는 레벨이 없고, 소재를 소모해 효과를 하나씩 개방 (기존 규칙) |
| 효과 수 | 시설마다 3개 (1 → 2 → 3 순서). 정보실만 5개 (기존 확정). 집무실은 효과 없음. 총 44개 |
| 공개 | 소문 → 근접(필요 소재 일부 공개) → 개방. 필요 소재를 모두 한 번씩 얻으면 근접 단계 |
| 비용 | 효과 1은 시설 등급 소재 3개, 효과 2는 한 등급 위 소재 4개, 효과 3은 두 등급 위 소재 5개 (S급이 상한) + 금전 |
| 소재 계열 | 시설마다 정해진 의뢰 유형의 소재 |
