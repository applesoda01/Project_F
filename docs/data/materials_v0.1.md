# 소재 목록 초안 v0.1 — 이세계 모험가 길드 (가칭)

모든 이름과 수치는 [가안]입니다.

## 뼈대

소재는 **의뢰 등급**(어느 등급의 장비를 만들 수 있는가)과 **의뢰 유형**(어떤 종류의 장비를 만들 수 있는가) 두 축에 연결됩니다.

| 의뢰 유형 (대표 능력치) | 소재 계열 | 주로 쓰이는 장비 |
| --- | --- | --- |
| 토벌 (힘) | 마물 부산물 (뼈, 뿔, 비늘) | 검, 중갑, 반지 |
| 사냥·채집 (민첩) | 동식물 (가죽, 목재, 깃털) | 활, 경갑, 발찌 |
| 조사 (지력) | 마력 결정 (마석류) | 지팡이, 목걸이 |
| 호위·구호 (정신) | 의뢰인의 사례품 (천, 성물) | 성구, 로브, 묵주 |
| 탐사 (기교) | 광석 (금속) | 모든 장비의 재질 (E급부터), 단검, 장갑 |

## 등급별 소재 (35종)

| 등급 | 토벌 | 사냥·채집 | 조사 | 호위·구호 | 탐사 |
| --- | --- | --- | --- | --- | --- |
| F | 슬라임 점액 | 참나무 가지 | 희미한 마석 | 무명천 | 고철 조각 |
| E | 고블린 뼈 | 사슴 가죽 | 마석 조각 | 문양 천 | 구리 원석 |
| D | 오크 엄니 | 흑곰 가죽 | 마정석 | 마직 천 | 철광석 |
| C | 트롤 뿔 | 그리폰 깃털 | 고급 마정석 | 축복받은 천 | 흑철광 |
| B | 와이번 비늘* | 세계수 가지* | 정령석* | 은빛 실타래* | 미스릴 원석* |
| A | 키메라 뿔* | 불사조 깃털* | 성좌석* | 성은 실타래* | 아다만 원석* |
| S | 용의 유해* | 용근* | 용안석* | 용익막* | 운철* |

\* B급 이상은 해체장에서 가공해야 제작에 쓸 수 있음 (기존 규칙)

## 복원 재료 (기존 규칙 구체화)

| 등급 | 이름 | 획득 |
| --- | --- | --- |
| F~C | 수선 숫돌 | 모든 의뢰에서 5% 확률 |
| B~S | 고대 복원석 | 주기적인 특별 의뢰 (리소스 퀘스트) |

손상된 장비와 유품을 복원할 때 씁니다.

## 레시피 규칙

| 등급 | 레시피 |
| --- | --- |
| F | 해당 계열 소재 2개 (금속 없음, 견습 장비) |
| E~S | 같은 등급 탐사 금속 1개 + 해당 계열 소재 2개 + 금전 |

| 장비 종류 | 계열 소재 |
| --- | --- |
| 검, 중갑, 반지 | 토벌 |
| 활, 경갑, 발찌 | 사냥·채집 |
| 지팡이, 목걸이 | 조사 |
| 성구, 로브, 묵주 | 호위·구호 |
| 단검, 장갑 | 탐사 (금속 1 + 금속 2 = 같은 금속 3개) |

예: D급 「철심 장궁」 = 철광석 1 + 흑곰 가죽 2 + 금전

## 획득 규칙

| 항목 | 내용 |
| --- | --- |
| 주 소재 | 의뢰를 성공하면 그 등급·유형의 소재를 얻음 |
| 부 소재 | 30% 확률로 한 단계 아래 등급의 다른 계열 소재 |
| 복원 재료 | 위 표 참고 |
| 보정 | 짐꾼은 획득량 증가, 괴도의 그림자 습격은 추가 획득 |
| 메인 보상 | 간부전은 S급 소재 (간부의 유해) |

## 사용처 (기존 규칙)

| 사용처 | 내용 |
| --- | --- |
| 장비 제작 | 대장간 레시피 |
| 대장간 납품 | 납품한 최고 등급까지 상점 진열 |
| 길드 시설 효과 | 소재를 소모해 효과를 하나씩 개방 (다음 주제) |
| 판매 | 소재 판매 창구에서 되팔기 (길드 수입) |
| 주문 제작 | 선물용 장비 |
