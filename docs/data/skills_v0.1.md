# 스킬 목록 초안 v0.1 — 이세계 모험가 길드 (가칭)

모든 이름과 효과는 [가안]입니다.

## 공통 규칙

| 항목 | 내용 |
| --- | --- |
| 구성 | 5개 계열(바탕 능력치) × 직업별 형태 = 82개 (1차 5 + 2차 25 + 3차 심화 22 + 3차 확장 30) |
| 진화 | 2차·3차로 오를 때, 바탕 능력치가 새 직업 조건에 들어 있으면 그 직업의 형태로 진화. 없으면 현재 형태로 멈춤 |
| 단계 | 1차 = 1단계, 2차 = 2단계, 3차(심화·확장) = 3단계 |
| 발동 확률 | 1단계 10%, 2단계 18%, 3단계 28%. 높은 단계부터 판정, 공격당 1개, 마나 필요, 재사용 대기 있음 |
| 발동 시점 | 공격형·디버프형: 공격할 때 / 회복형·보호형: 아군이 피해를 받을 때 / 버프형: 전투 시작 시와 주기적으로 |
| 판정 보너스 | 의뢰 성공 판정에서 바탕 능력치의 충족률 +3% / +6% / +10% (1 / 2 / 3단계) |
