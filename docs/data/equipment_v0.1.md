# 장비 목록 초안 v0.1 — 이세계 모험가 길드 (가칭)

모든 이름과 수치는 [가안]입니다. 수치는 시뮬레이터로 검증합니다.

## 공통 규칙

| 항목 | 내용 |
| --- | --- |
| 구성 | 계열 기준. 무기 5종 + 방어구 3종 + 장신구 5종 = 등급당 13개 × 7등급(F~S) = 91개 |
| 슬롯 | 무기, 방어구, 장신구 각 1칸 |
| 수치 적용 | 장비는 최종 능력치만 올림 (기본 능력치 상한 100과 무관) |
| 개방 | 의뢰 등급 → 소재 등급 → 레시피·상점 진열 (기존 규칙) |
| 제작 | 마을 대장간. 레시피는 필요 소재를 모두 한 번씩 얻으면 개방 (기존 규칙) |
| 강화 | +1~+10. +1당 기본 수치 +8% (최대 +80%). +3까지 안전, 이후 실패 시 손상 (기존 규칙) |
| 재질 | 등급마다 재질 하나: F 견습(나무·가죽·천) / E 청동 / D 철 / C 강철 / B 미스릴 / A 아다만 / S 용 |
| 해체장 | B급 이상 원재료(미스릴, 아다만, 용 소재)는 해체장에서 가공해야 제작 가능 (기존 규칙) |

- 방어구의 "주력 / 보조": 중갑은 방어가 주력, 로브는 마법 방어가 주력, 경갑은 둘 다 중간값(주력과 보조의 평균)입니다.
- 참고로 의뢰 판정 기준치는 F15 ~ S90입니다. 같은 등급 무기 하나가 기준치의 약 20~30%를 채워 주는 수준입니다.
