1. 목적

  • 사용자 보고 (11-24 18:12): 「모험가가 3명이 되었는데 2명만 계속 나가고 있어서, 노는 애들은 뭘 어떻게 시켜야 하는지 모르겠다」.
  • 노는 까닭을 먼저 보이게 하고, 그다음에 할 일을 준다. todo1124 3번을 기획서로 옮긴 문서.

2. 지금 (측정)

  • 원인 ① 짝이 없음: 혼자 갈 승산이 낮으면 길드에 있는 동료를 모으는데 필요한 만큼만 모음 → 2명이 짝을 지으면 셋째가 남음. 창립 멤버가 첫 12주에 길드에 있으면서 못 나간 주 22%.
  • 나중 합류자가 길드에 왔는데 못 나간 주: 65% 「동료 부족」, 31% 「맞는 의뢰 없음」.
  • 원인 ② 시킬 방법이 없음: 플레이어가 직접 보낼 수 있는 것은 리퀘스트 지명과 던전(12주 뒤)뿐.
  • 2년 차 이후에는 「맞는 의뢰 없음」이 주원인 (모험가-주의 33 → 57%) — 14.
