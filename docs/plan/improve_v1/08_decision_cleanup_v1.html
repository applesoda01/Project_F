결정 정리

고를 이유가 없는 선택지를 숨기고 묶고 E급 뒤로 미루기

1. 목적

  • 결정의 수를 줄여 남은 결정에 무게가 실리게 한다 (P3 · P4). 효과가 없는 결정이 같은 무게로 화면을 차지하면, 「이건 해도 그만」을 깨닫는 순간 책 12쪽이 부담이 된다 (보고서 1-6 · 4-3).
  • 보고서 A1 · B6, 대화 M5를 한 문서로 모은다.

2. 지금 (측정)

E급 승급(약 40주)까지 만나는 결정 종류 약 20가지. 효과를 잰 13가지 가운데 7가지가 ±20G 안쪽이고, 20G를 넘는 6가지는 모두 「하지 않으면 손해」 쪽 (보고서 1-1).

4. 숨기는 방법

  • 메뉴 잠금(메뉴_잠금_설계.md)을 넓혀 씁니다: 숨긴 결정은 E급 승급 때 「새로 열림」으로 한 번에 소개.
  • 「자세히」 안으로 넣는 것은 지우지 않고 접어 둠 (테스트하는 사람이 찾을 수는 있게).
  • 규칙 코드(game_core.js)는 그대로 두고 화면에서만 숨기는 것이 기본 — 수치 변경 없음. 삭제 항목(준비량 · 가격)은 02가 결정될 때 규칙과 함께 바뀜.

5. 연동

  • 02 · 04 · 05가 결정되기 전에도 「숨김 · E급 뒤로」 줄은 먼저 할 수 있음.
  • 튜토리얼(튜토리얼.md) · 상황별 안내 26개 중 숨긴 결정을 가르치는 안내는 E급 뒤로 옮김.

6. 검증

  • 숨긴 뒤 기준 봇 수치가 그대로인지 (관문 1).
  • 시안을 1280×720에서 캡처해 화면당 누르는 것 수가 줄었는지 (지금 12~32개).

7. 미결 사항

  • 의뢰 떼기: 「자세히」 안으로 / 규칙을 고쳐 살림
  • F급 수수료를 숨길 때 기본값 10% 고정 문구를 어디에 보여 줄지
  • 숨긴 결정이 E급에 열리는 순서 (한 번에 / 하나씩)
  • 상단 · 대장간 · 물약을 측정한 뒤 이 표에 넣을지
