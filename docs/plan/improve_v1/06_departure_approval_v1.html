06이세계 모험가 길드 · 개선 기획서v1제안수치: 작음초안 2026-11-24

출발 승인

승산이 낮은 출발에만 뜨는 카드: 보낸다 / 같이 보낸다 / 말린다

1. 목적

  • 실패를 「날씨」가 아니라 내 결정의 결과로 만든다. 지금은 실패의 30%가 주사위(늦장)이고 나머지도 미리 막을 수단이 없다 (보고서 1-5).
  • 메인 퀘스트에서 이미 작동하는 「준비 → 판정 → 값」을 평소 플레이로 옮긴다.
  • 설계서 핵심 루프의 「승인 · 지명 결정」을 채운다. 모험가가 고른 것을 마스터가 승인하는 것이라 「모험가는 스스로 판단」(P7)을 넘지 않는다.

2. 지금

  • 모험가가 의뢰를 고르고 혼자 가거나 길드에 있는 동료를 모아 떠남. 플레이어는 볼 수만 있음.
  • 예상 성공률 80% 미만 출발은 72주에 약 6건, 90% 미만은 약 22건 (보고서 6장 B1).
  • 예상과 실제의 어긋남: 예상 96% 이상이 실제 93.4%, 60~70%가 55.5% (보고서 1-5).
  • 돈으로 본 상한: 막을 수 있는 실패 약 5.3건 × 약 70G = 월 +31G (대화 5-1). 카드만으로는 판별 편차(75G)를 넘지 못합니다. 판돈은 05 계약 · 10 신입과 묶여서 생깁니다.

3. 규칙 (안)

3-1. 카드가 뜨는 때

  • 모험가(또는 파티)가 의뢰를 맡았는데 예상 성공률이 85% 미만 [임시]일 때, 출발 직전에 카드가 뜹니다. 목표 빈도는 한 달 1~2장.
  • 보호 구간(튜토리얼 뒤 12주)에는 뜨지 않습니다 (P8).
  • 자동 진행 중에도 잠깐 멈춥니다. 「다음부터 이 모험가는 알아서」 같은 끄기는 두지 않음 (빈도가 낮으므로).

3-2. 세 가지 선택

선택결과 [임시]값
보낸다그대로 출발. 성공하면 「마스터가 믿어 줬다」 애착 +2실패 위험을 그대로 짐
같이 보낸다길드에 있는 모험가 1명을 골라 붙임(파티 상한 안). 예상 성공률이 바로 다시 계산되어 카드에 보임보수가 나뉨 · 붙인 사람은 이번 주에 다른 의뢰를 못 맡음. 신입을 붙이면 경험치 (10)
말린다이번 주 출발 취소. 의뢰는 게시판에 남음 (기한은 흐름)그 모험가 애착 −1 · 의뢰가 만료될 수 있음

3-3. 카드에 보이는 것

  • 의뢰 · 모험가 초상 · 승산 칩(리퀘스트와 같은 「여유 · 보통 · 팽팽 · 위험」) · 이번 주 길드에 있는 모험가.
  • 성향 한 줄: 「브루노는 요즘 들떠 있어요」처럼 늦장 성향을 말로 보여 줌 (제미나이 의견: 확률 계산기 놀이 방지). 새 수치는 만들지 않고 이미 있는 성향 · 늦장 규칙을 읽어 씀 (P10).
  • 의뢰 변주 태그(07)가 들어오면 「야간」 같은 태그가 판단 거리가 됨.

3-4. 돈이 걸리게 하는 방법

  • 05 신뢰 계약(성공률 90% 이상)일 때 말리거나 같이 보내는 것이 보너스를 지킴.
  • 의뢰 실패 시 의뢰인 신뢰도 −2는 그대로. 위약금 같은 새 벌점은 두지 않음.

4. 화면

  • 사건 카드(중재, proposal_master_mediation_v1.md)와 같은 크림색 카드 틀. 단추 3개, 「같이 보낸다」는 누르면 초상 줄이 펼쳐짐.
  • 결과는 귀환 보고에 한 줄: 「마스터 말씀대로 토빈과 같이 가길 잘했어요」 / 「말려 주셔서 다행이었어요」(같은 의뢰를 다른 사람이 실패했을 때).

5. 연동

  • todo1124 3번 C안(플레이어가 의뢰를 권함)과 한 묶음 — 이 카드가 「시킬 방법」의 첫 단계 (11).
  • 중재 사건 카드와 틀을 같이 씀. 다른 점은 걸린 것의 크기(애착 ±2~3 대 실패 · 부상 · 보상).
  • 예전의 「출발 전 작전 고르기」와 달리 모든 출발이 아니라 승산이 낮은 출발에만.

6. 검증

  • 늘 보냄 · 늘 말림 · 늘 같이 보냄 · 잘 고르는 봇 넷을 짝 비교. 05 계약이 있을 때와 없을 때 각각.
  • 카드 빈도: 한 판 첫해 6~15장 안 [임시].
  • 「잘 고르는 봇」 대 「늘 보냄」 차이가 75G에 못 미치면, 05와 묶지 않은 단독 도입은 하지 않음.

7. 미결 사항

  • 플레이어의 개입 선 (목록 갈림길 5번)
  • 카드 문턱 (85% / 80% / 90%)
  • 말린다의 값 (애착 −1이 맞는지, 값이 없어도 되는지)
  • 같이 보낸다의 보수 나눔 · 붙인 사람이 거절할 수 있는지 (지명처럼 수락 확률)
  • 늦장 성향을 카드에 보여 줄지, 보여 주면 얼마나 직접적으로
  • 파티(2명 이상)가 출발할 때도 같은 카드인지
