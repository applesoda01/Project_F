# 접수원 리나 파츠 분리 모션 시험 계획

상태: 계획 (측정 완료, 제작 전) · 대상: 대화창 상반신 초상 340×640

## 1. 목표

- 리나 상반신 초상에 **머리카락 흔들림 + 숨쉬기 + 표정 교체**를 넣는다.
- 완성 그림을 억지로 쪼개는 방식이 아니라, **처음부터 파츠 분리를 전제로 한 그림**으로 만든다.
- 하체는 쓰지 않는다 (상체만 보임).

## 2. 방식 결정

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 표정 | 눈·눈썹·입을 **표정마다 한 세트로 그려 덮어 씌움** (변형 아님) | 일그러짐 없음, 그린 표정 품질 유지 |
| 눈 깜박임 | 표정마다 3단계(뜸·반쯤·감음) | 변형 없이 교체만 |
| 머리카락 | 8~12덩어리로 분리해 흔들림 | 움직임의 대부분 |
| 몸 | 머리 베이스 / 목 / 몸통 / 팔 좌·우 | 숨쉬기용 |
| 시선 이동 | 이번 시험에서는 제외 (필요하면 홍채만 분리) | 범위 축소 |

## 3. 측정 결과 (기존 전신 6장)

대상: `art_source/illustrations/receptionist/` 의 최종확정 1장 + 표정 5종 (진지·웃음·걱정·곤란·놀람).
최종확정은 1024×1536, 표정 5종은 1684×2528 이라 최종확정을 1684×2528 로 키워 비교했다.

| 항목 | 값 |
| --- | --- |
| 인물 바깥 테두리 위치 차이 | 최대 1~2px (6장 모두) |
| 머리 위치 이동량 (최적 정렬) | 0px |
| 얼굴 밖 실제 변화 (블러 후, 머리+상체 영역 대비) | 0.005 ~ 0.021% |
| 표정 차이가 모이는 영역 (얼굴 상자) | x 678~1022, y 226~559 (344×333px, 1684×2528 기준) |
| 얼굴 상자 밖 차이 픽셀 | 38~47%, 모두 1~2px 윤곽 떨림 (내용 변화 아님) |

해석: **머리·몸은 6장이 사실상 동일하고 얼굴만 다르다.** 기존 그림으로 표정 교체 시험이 바로 가능하다.
비교 이미지: `docs/art/images/lina_expression_diff.jpg` (붉은 부분이 차이).

주의: 1~2px 윤곽 떨림 때문에 얼굴 상자를 그대로 덮으면 상자 경계에서 선이 어긋나 보일 수 있다. 가장자리를 약 8px 번지게(페더) 합치고, 베이스 윤곽을 우선한다.

## 4. 초상 잘라내기

- 대화창 규격 340×640 (비율 0.531)에 맞춰 1684×2528 원본에서 **x 560~1120, y 100~1154** (560×1054)를 상체로 쓴다.
- 허리 아래는 사용하지 않는다. 아래 경계는 대화창 틀에서 자연스럽게 잘리는 구도로 정한다.

## 5. 파츠 목록 (목표 약 20개 안팎)

레이어 순서 (뒤 → 앞):

1. 뒷머리
2. 몸통(몸+옷, 책 포함) · 팔 좌 · 팔 우
3. 목
4. 머리 베이스 (얼굴 피부, 귀, 이마까지 — 눈·입 없음)
5. 표정 세트 6종 (눈·눈썹·입, 이마 쪽 눈썹 위까지 포함) × 깜박임 3단계 × 입 2종
6. 옆머리 좌·우
7. 앞머리
8. 장식 (묶은 머리 끝 등)

필수 규칙:
- 표정 세트는 머리 베이스와 **위치·크기·각도가 완전히 같게** 그린다.
- 앞머리가 올라가는 층 아래의 이마·눈썹 위쪽은 표정 세트에 이미 그려져 있어야 한다 (흔들릴 때 드러남).
- 옆머리 아래의 목·귀·어깨는 몸 파츠에 미리 그려 둔다.
- 각 머리카락 덩어리는 아래 파츠 밑으로 20~30px 더 이어 그린다.

## 6. 단계

| 순서 | 내용 | 산출물 |
| --- | --- | --- |
| 1 | 기존 6장으로 표정 교체 시험 (최종확정 베이스 + 얼굴 상자 덮기) | 표정 교체 시험 영상 |
| 2 | 머리카락 덩어리 분리와 가려진 부분 보충 (파츠 분리 시험) | 머리카락 파츠 PNG |
| 3 | 숨쉬기 + 머리카락 흔들림 시험 | 움직이는 초상 시험본 |
| 4 | 결과가 좋으면 표정 깜박임 3단계와 입 2종 확장 | 표정 세트 완성본 |
| 5 | 직업 캐릭터 확대 여부 판단 | 결정 |

## 7. 아직 정할 것

- 베이스를 1024×1536(최종확정)로 할지 1684×2528(표정 5종)로 할지 — 해상도가 높은 쪽을 권장하나, 최종확정과 윤곽이 다르다.
- 시선 이동 포함 여부
- 시험 결과를 평가할 기준 (눈에 띄는 어긋남 없음, 흔들림 폭 등)
