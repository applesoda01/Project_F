## 1. 달리기 프레임 정리 (Real-ESRGAN)

**대상 (9세트 205장):** 전사 남 41 · 궁수 여 24 · 궁수 남 18 · 마법사 남 17 · 마법사 여 26 · 성직자 남 20 · 성직자 여 19 · 도적 남 20 · 도적 여 20 (전사 여 16장은 시험으로 완료 → `run_final/warrior_f_esr/`)

**방법 (전사 여 시험과 동일):**
1. 작업 공간에서 투명 부분 색을 가까운 캐릭터 색으로 채움(`bleed`) → RGB PNG로 ComfyUI `input/pf_runfix/`에 넣음.
2. ComfyUI: `LoadImage` → `RealESRGAN_x4plus_anime_6B` ×4 → `ImageScale` lanczos 640×800 → `pf/runfix/<직업>_run_NN` 저장. 장당 약 22초.
3. 작업 공간으로 가져와 **원래 알파(투명도)를 그대로** 씌움 → `run_final/<직업>_esr/` (프레임 · `run.gif` · `run.json`).
4. 확인 그림: 직업마다 확대 비교 1장 + 나란히 움직이는 GIF 1개.

**입력 기준:** 저장소 `archive/art_source/sd_sprites/run/<직업>/` (2026-11-14 10세트 반영 완료, 최근 5세트는 자홍 테두리 · 윤곽 색 정리본)

**알려진 특성:** 압축 노이즈 · 번진 선이 정리되고 윤곽이 또렷해짐. 갑옷 반사광 같은 잔 명암은 조금 단순해짐 (원본은 그대로 보관).

## 3 · 4. 앉기 · 대기 프레임 정리 (Real-ESRGAN, 2026-11-14 추가)

**방법:** 1번 달리기와 같음 (`bleed` → ComfyUI ×4 → 원래 크기로 축소 → 원래 알파 그대로). 크기만 다름.

| | 앉기 | 대기 |
| --- | --- | --- |
| 입력 | 저장소 `archive/art_source/sd_sprites/sit/<직업>/sit_NN.png` (720×700) — 보간 보정본 포함 | `idle/<직업>/idle_NN.png` (640×800) — 보간 보정본 포함 |
| 장수 | 궁수 여 35 · 궁수 남 43 · 성직자 여 38 · 성직자 남 48 · 마법사 여 46 · 마법사 남 44 · 도적 여 49 · 도적 남 43 · 전사 여 38 · 전사 남 35 = **419장** | 10명 × 72 = **720장**. 게임 시트는 2장마다 1장(짝수 번호)만 쓰므로 **짝수 360장 먼저** |
| 결과 | 작업 공간 `sit_esr/<직업>/` | `idle_esr/<직업>/` |
| 확인 그림 | 직업마다 확대 비교 1장 + 앉기 GIF | 직업마다 확대 비교 1장 + 숨쉬기 GIF |

- **주의:** 대기는 숨쉬기처럼 움직임이 아주 작아서, 정리하면서 장마다 선이 미세하게 달라지면 **가만히 있는데 선이 떨려 보일 수** 있음 → 아침 보고에 떨림 측정값(장 사이 변화가 정리 전보다 커졌는지)을 함께 남김. 커졌으면 대기는 반영하지 않는 것을 제안.
- 게임 시트(`*_sit.webp` · `*_idle.webp`)는 "반영해줘" 때 다시 만듦.
