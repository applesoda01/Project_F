## 목표와 범위

2차의 목표는 1차의 표·목록 화면을 **1층 로비를 정면에서 바라보는 한 화면**으로 바꾸고, 육성(레벨·전직·장비·식사)과 식당 하우징을 화면으로 만드는 것입니다. 플레이 시간 대부분을 보내는 곳이 1층 로비이므로, 층 이동과 다른 층·별관은 이번 범위에서 뺍니다. 규칙은 1차의 `game_core.js`를 그대로 쓰고 확장하며, 리소스는 직접 제작하고 그 전까지 같은 규격의 임시 그래픽을 넣습니다.

| 구분 | 만드는 것 | 만들지 않는 것 (나중에) |
| --- | --- | --- |
| M2 로비 화면 | 정면 3/4 시점 로비 한 화면, 리나가 오가는 긴 카운터(주방 창구·접수·소재 매입), 모험가 출입과 행동, 리나 대화·월간 보고, 일러스트 위에 겹치는 화면 UI(상·하단 바 없음) | 층 이동, 2층 이상·지하·별관, 마을 탑뷰 |
| M3 육성과 하우징 | 모험가 상세창, 레벨업·전직 제안과 수락, 장비 F\~D와 대장간, 요리 F\~D, 식당 테이블 업그레이드 | 3차 전직, 강화·복원, 선물, 자유 배치 하우징 |
| 규칙 | 1차 규칙 + 레벨별 성장, 1→2차 전직, 장비 구매, 스킬 1·2단계, 테이블 효과(좌석·매출·애착) | 승급·전투·사망 (M4\~M5), 리나 대기로 인한 수익 손실 |

**관문 2 기준:** 개입 없이 10분간 지켜보기만 해도 모험가가 무엇을 하는지 화면에서 읽히고, 테스터가 키운 모험가 한 명을 이름으로 기억하며, 첫 2차 전직이 Lv 18 전후에 일어난다.

## 화면 구성

메인 화면은 1층 로비를 정면에서 비스듬히 내려다보는 한 화면(3/4 시점)이고, 나머지는 팝업입니다. 시점은 고정이며 카메라 이동은 없습니다. 기준 해상도는 1920×1080이며, 1280×720에서도 글자가 읽혀야 합니다.

**로비 화면 배치**

| 영역 | y 범위 (px) | 내용 |
| --- | --- | --- |
| 뒤쪽 벽 | 0 \~ 472 | 벽 거의 전체를 차지하는 의뢰 게시판(x 150\~1770, y 70\~400). 의뢰서 자리 24칸, 가운데 2열은 리나 자리라 비움. 주방 창과 소재 선반은 화면에 그리지 않음 |
| 카운터 뒤 통로 | 330 \~ 470 | 리나가 오가는 길 (카운터 위로 허리 위만 보임) |
| 긴 카운터 | 440 \~ 550 | 화면 폭 약 1,720px, 명패 3개(주방 창구·접수·소재 매입) |
| 앞쪽 식당 | 540 \~ 1080 | 고정된 테이블 자리 4칸(앞뒤 2줄 × 좌우 2칸), 의자, 앉아 있는 모험가, 화면 아래 입구 |
| 화면 UI (겹침) | 네 모서리 | 왼쪽 위 날짜·속도, 오른쪽 위 등급·금고·신뢰도·인구·모험가 수, 왼쪽 아래 일지 알림(잠시 뒤 사라짐), 오른쪽 아래 원형 메뉴 6개. 모두 반투명 바탕 위에 표시 |

**카운터 세 구역 (리나 혼자 담당)**

| 구역 | 위치 | 하는 일 | 화면 표시 |
| --- | --- | --- | --- |
| 주방 창구 | 왼쪽 | 출발 전 식사, 술 | 카운터 명패, 접시·맥주잔 소품 |
| 접수 | 가운데 | 의뢰 수주(리나가 뒤 게시판에서 의뢰서를 떼어 건넴), 정산, 월간 보고 | 카운터 명패, 서류 소품, 뒤쪽 게시판 |
| 소재 매입 | 오른쪽 | 소재 감정과 매입 | 카운터 명패, 저울·소재 자루 소품 |

**동선:** 모험가는 화면 아래쪽(플레이어 쪽)에서 들어와 카운터로 간 뒤, 테이블에 앉거나 다시 아래로 나갑니다. 출발은 접수(수주) → 주방 창구(식사) → 퇴장, 귀환은 소재 매입 → 접수(정산) → 테이블 → 휴식 또는 퇴장입니다. 리나가 바쁜 동안 모험가는 줄을 서지만, 수익에는 영향이 없습니다(연출만).

**팝업 화면**

| 화면 | 열리는 방법 | 요소 | 단계 |
| --- | --- | --- | --- |
| 게시판 팝업 | 뒤 벽 게시판을 누름 | 의뢰서 카드(코르크보드에 핀으로 꽂힌 형태), 필터 슬라이더, 떼기 | M2 |
| 리나 대화 | 리나를 누름, 월초 자동 | 리나 상반신, 대화창, 월간 보고 수치 | M2 |
| 장부 팝업 | 하단 메뉴 | 이번 달·지난달 수지, 최근 12개월 그래프 | M2 |
| 모험가 목록 | 하단 메뉴 | 초상 아이콘, 이름, 직업, 등급, Lv, 상태, 애착 | M3 |
| 모험가 상세창 | 모험가를 누름 | 초상, 능력치 오각형, 장비 3칸, 스킬, 경력, 애착 칭호 | M3 |
| 전직 제안창 | 조건 충족 시 리나가 제안 | 현재 직업 → 후보 직업, 조건, 수락 확률, 승인·보류 | M3 |
| 전직 연출 | 수락 시 | 빛 효과, 새 외형, 스킬 진화 알림 | M3 |
| 대장간·상점 | 하단 메뉴 | 장비 목록, 레시피(소문·근접·개방), 제작 | M3 |
| 식당 메뉴판 | 주방 창구를 누름 | 요리 카드 6종(F\~D), 잠긴 요리는 실루엣 | M3 |
| 테이블 하우징 | 테이블 자리를 누름 | 현재 단계, 다음 단계 미리보기, 효과(좌석·매출·애착), 비용(금전 + 소재), 교체 연출 | M3 |

**식당 하우징 \[가안\]:** 테이블 자리는 고정이고, 자리마다 테이블 세트를 사서 바꿉니다. 처음에는 2칸만 채워져 있습니다.

| 단계 | 테이블 세트 | 좌석 (뒤+앞+옆) | 매출 | 애착 상승 | 비용 |
| --- | --- | --- | --- | --- | --- |
| 1 | 낡은 나무 (둥근) | 2 (1+1+0) | +0% | +0% | 기본 제공 |
| 2 | 튼튼한 나무 (둥근) | 4 (2+2+0) | +5% | +5% | 300G + 참나무 가지 2 |
| 3 | 참나무 (가로 타원) | 5 (2+2+1) — 5인 파티 한 테이블 | +10% | +10% | 900G + 사슴 가죽 2 |
| 4 | 장식 테이블 (가로 타원) | 6 (2+2+2) | +15% | +15% | 2,500G + 흑곰 가죽 2 |

테이블 자리 수는 시안 v0.3에 따라 4칸으로 정합니다. 6칸은 가운데 러그 자리를 써야 해서 화면이 복잡해집니다. 세트 효과용 테마는 데모 이후로 미룹니다.

좌석 배치 규칙: 자리는 테이블의 뒤쪽(먼 쪽), 앞쪽(가까운 쪽), 양 끝(옆)에 둡니다. 뒤쪽은 앞모습 의자에 앞모습으로(의자 → 모험가 → 테이블), 앞쪽은 뒷모습 의자에 등을 보이며(테이블 → 모험가 → 의자), 옆자리는 옆모습 의자에 옆모습으로 앉고 테이블과 같은 깊이로 정렬합니다. 옆모습 의자는 한쪽만 그리고 반대쪽은 코드가 좌우 반전합니다. 앞쪽 모험가가 음식을 가려도 괜찮습니다. 최대 파티 5인이 한 테이블에 앉는 것은 Lv3부터입니다. 좌석 수는 식사 매출에 영향을 주므로 M3-8에서 시뮬레이터와 숫자를 다시 맞춥니다. 프로토타입에서 Lv3·4 가구는 임시 그래픽으로 두고 리소스는 나중에 만듭니다.

작업은 M2 11개, M3 10개입니다. 모두 리소스 없이 임시 그래픽으로 먼저 돌아가게 만들고, 리소스가 도착하면 파일만 교체합니다.

| 번호 | 작업 | 완료 기준 |

| M2-1 | 리소스 로더와 매니페스트 | 파일이 없으면 임시 그래픽, 있으면 그 파일을 표시 |
| M2-2 | 화면 구조 (캔버스 로비 + HTML UI 층) | 1920×1080 기준, 창 크기에 맞춰 비율 유지 축소 |

| M2-7 | 규칙 연결 | 1차 규칙의 출발·귀환·식사·소재 판매가 화면 행동으로 보임 |

| M2-9 | 겹침 UI(모서리 4곳)·팝업 틀 | 공통 창 프레임, 버튼, 알림 |

| M3-5 | 장비 3칸 분리 | 1차의 장비 세트를 무기·방어구·장신구로 나눔 |

## 리소스 제작 목록과 규격

M2에 꼭 필요한 것(P1)은 로비 레이어 5장, 테이블·의자 기본 단계, 캐릭터 5종(3방향), 리나 동작 시트, UI 기본 세트입니다. 모두 PNG(투명 배경, sRGB)로, 아래 크기는 1920×1080 화면 기준 1배 크기입니다. 2배로 그리면 더 선명하며, 코드가 자동으로 줄여 씁니다.

화면 좌표 기준: 화면 고정 1920×1080, 위에서 비스듬히 내려다보는 3/4 시점입니다. 배경이 화면 끝까지 채워지고 UI는 그 위에 겹칩니다. 카운터 앞면 아래선은 y=550, 식당 바닥은 y=540\~1080입니다. 멀리 있는 인물일수록 작게 보이도록 코드가 크기를 줄입니다(카운터 앞 0.85배 → 화면 아래 1.0배 \[가안\]).

### 레이어 구성 (시안 v0.3 기준)

로비는 아래 순서로 겹쳐 그립니다(번호가 클수록 앞). 원본은 1920×1080 캔버스 하나에서 레이어를 나눠 그리고, 레이어마다 필요한 부분만 잘라 PNG로 내보내면 됩니다. 잘라낸 위치(왼쪽 위 x, y)는 매니페스트에 적습니다.

| 순서 | 레이어 | 파일 | 움직임 | 따로 그리는 이유 |
| --- | --- | --- | --- | --- |
| 0 | 벽 | lobby\_wall | 고정 | 맨 뒤 배경 |
| 1 | 바닥 | lobby\_floor | 고정 | 러그 포함, 카운터가 아래쪽 끝을 덮음 |
| 2 | 게시판 판 | lobby\_board | 고정 | 의뢰서가 그 위에 붙음 |
| 3 | 의뢰서 | lobby\_quest\_paper, lobby\_board\_slot\_empty | 붙고 떼어짐 | 의뢰 수가 변함. 등급·유형·보상 글자는 코드가 씀 |
| 4 | 리나 | npc\_lina\_sheet | 카운터 뒤를 좌우로 이동 | 게시판 앞, 카운터 뒤에 있어야 함 |
| 5 | 카운터 | lobby\_counter | 고정 | 리나의 허리 아래를 가림. 명패 글자는 코드가 씀 |
| 6 | 카운터 소품 | prop\_\* | 생기고 사라짐 | 음식 내기, 저울질 연출 |
| 7 | 앞뒤 정렬 묶음 | chr\_*, table\_*, chair\_\*\_back·\_front, table\_slot\_empty | 발 위치(y)로 매 프레임 정렬 | 모험가가 테이블 앞뒤를 지나가고, 줄 선 모험가가 카운터를 가림 |
| 8 | 효과 | fx\_\*, ui\_bubble | 잠깐 표시 | 항상 인물 위 |
| 9 | 조명 덮개 | lobby\_light\_dusk, \_night | 시간대별 | 화면 전체에 색을 입힘 (P3) |
| 10 | 화면 UI | ui\_*, ic\_* | 고정 | 네 모서리에서 일러스트 위에 겹침 |

- 글자는 그림에 넣지 않습니다. 게시판 제목, 카운터 명패, 의뢰서 내용은 바탕만 그리고 글자는 코드가 씁니다. 그래야 문구를 고치거나 번역할 때 그림을 다시 만들지 않아도 됩니다.
- 인물·가구의 기준점은 발(다리) 바닥 가운데입니다. 앞뒤 정렬이 이 점의 y로 정해집니다.
- 발밑 그림자는 그리지 않습니다. 코드가 반투명 타원으로 그립니다.
- 의자는 앞·뒤 두 장입니다. 테이블 뒤쪽 의자는 앉은 모험가 뒤에, 앞쪽 의자는 앞에 그려져야 하기 때문입니다.
- 화면 UI 안전 영역: 왼쪽 위·오른쪽 위 높이 약 90px, 아래쪽 약 130px 안에는 중요한 그림 요소를 두지 않습니다.

## 파일 규칙과 교체 구조

리소스는 **정해진 파일명으로 주시기만 하면** 임시 그래픽 대신 표시됩니다. 코드는 매니페스트(`assets/manifest.json`)에서 파일을 찾고, 파일이 없으면 같은 크기의 임시 그래픽을 그립니다.

1. 파일명은 영문 소문자와 밑줄만 씁니다 (예: `chr_warrior_sheet.png`).
2. 폴더는 `assets/bg`, `assets/rooms`, `assets/chr`, `assets/ui`, `assets/icons`, `assets/fx` 여섯 개입니다.
3. 크기는 규격표의 1배 또는 정확히 2배로 맞춥니다. 다른 크기는 비율을 유지해 맞추지만 흐릿해질 수 있습니다.
4. 스프라이트 시트는 프레임을 간격 없이 가로로 붙이고, 발끝이 프레임 바닥에서 8px 위에 오게 합니다.
5. 리소스는 이 대화에 첨부해 주시면 제가 폴더에 넣고 게임 페이지를 다시 게시합니다. 한 번에 여러 개를 묶어 주셔도 됩니다.

## 진행 순서

코드는 임시 그래픽으로 먼저 달리고, 그동안 같은 단계에 필요한 리소스를 만드는 병행 방식입니다. 단계마다 끝나면 플레이해 보고 다음으로 넘어갑니다.

1. **2-A 로비와 이동** (M2-1\~M2-7) — 코드: 리소스 로더, 로비 렌더링과 앞뒤 정렬, 게시판 표시, 모험가 이동, 리나 행동. 리소스: lobby\_wall, lobby\_board, lobby\_quest\_paper, lobby\_counter, lobby\_floor, table·chair lv1, table\_slot\_empty, chr 1차 5종, npc\_lina\_sheet.
2. **2-B 화면 틀과 대화** (M2-8\~M2-11) — 코드: 말풍선, HUD, 하단 바, 팝업, 게시판·장부, 리나 대화. 리소스: UI 기본 세트, 아이콘 P1, lina 표정 6종.
3. **관문 2 중간 점검** — 10분 지켜보기 테스트. 모험가와 리나의 행동이 화면에서 읽히는지 확인.
4. **3-A 성장과 전직** (M3-1\~M3-4) — 코드: 성장·전직 규칙, 제안창, 모험가 상세창. 리소스: chr 2차 15종, pt 20종, fx\_levelup, fx\_classchange.
5. **3-B 장비·식당·하우징** (M3-5\~M3-10) — 코드: 장비 3칸, 대장간, 식당 메뉴판, 테이블 하우징, 저장. 리소스: table·chair lv2\~4, prop 4종, ic\_equip 13종, ic\_meal 6종, ui\_corkboard.
6. **관문 2** — 내부 플레이테스트. 통과하면 3차(M4\~M6: 승급·전투·사망·메인)로.

어느 단계든 리소스가 늦어도 코드는 멈추지 않습니다. 도착한 리소스는 다음 게시 때 한꺼번에 반영합니다.
