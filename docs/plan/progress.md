2-1. **탁자 4석 배치 — 앉는 모션 작업(나중에, 사용자 제작 후 공유 예정)** — (10-26 확정) 탁자 확정안(둥근 상판+기둥)·의자 확정안(앞·옆·뒤) 적용, 탁자 하나에 4석: 위쪽 2석(정면 의자) + 왼쪽·오른쪽 1석씩(옆모습 의자). 좌표는 `lobby.js` 의자 그림과 `actors.js` 의 `D.layout` 이 같은 숫자를 씀. 남은 일: ① 앉는 모션 그림 받아 적용(위쪽 자리=정면 앉기, 옆자리=옆모습 앉기, 지금은 옆자리도 임시로 정면) ② 옆자리 `side` 값(`left`/`right`)으로 방향 분기 ③ 의자·탁자 Lv2 새 그림(지금은 Lv1과 같은 그림) ④ 의자 색상 B·C ⑤ 좌석 접근 위치(`ap`)와 겹침 확인, 좌석 16석(탁자 4개) 수용 인원 영향 점검

4. 리나 눈 깜빡임을 대화 초상에 연결할지, 깜빡임 2배속 반영 여부 결정 (24fps에서 반쯤 칸이 1프레임보다 짧아짐 → 화면 확인 후)
