> 작성: Claude, 2026-11-13 · 사용자 요청 "지금까지 만든 도구들 한번 정리"
> 위치는 모두 `prototype/tools/` 기준입니다. HTML 도구는 **크롬에서 파일을 바로 열면** 됩니다(서버 · 설치 없음). Python 도구는 `pip install pillow numpy scipy` 정도가 필요합니다.

## 1. 대사 · 데이터 편집

| 도구 | 파일 | 하는 일 | 저장되는 곳 |
| --- | --- | --- | --- |
| 대화씬 편집기 | `dialogue_editor/index.html` | 프롤로그 · 대화씬 · 메인 퀘스트 대사(화자 · 표정 · 배경 · BGM · 박스 효과). 대본 붙여넣기, 재생, 점검 | `data/dialogue/*.json` (사용법 `dialogue_editor/README.md`) |
| **모험가 대화 편집기** | `talk_editor.html` | 모험가끼리 대화(`talk.csv`) 상황 12가지 × 말 걸기 · 대답 · 맺음 × 말투 5 + 공통. 줄 추가 · 삭제, 관계(단짝만 · 서먹만), 말투 조합 미리 보기, 빈 말투 · 길이 초과(전투 12자 / 그 밖 28자) 점검. Ctrl+S 저장 | `prototype/data/talk.csv` → 아래 데이터 빌드 실행 |
| 소재 편집기 | `material_editor/index.html` | 소재 · 음식 · 장비 · 물약 · 퀘스트 정의, 아이콘 | `collegium_data.json` (사용법 `material_editor/README.md`) |
| 데이터 빌드 | `data_build.py` | `data/*.csv` + `collegium_data.json` → `js/data_gen.js` (게임 · 시뮬레이터가 함께 읽음). 표 내용 검사 후 오류 줄 번호 표시 | `python prototype/tools/data_build.py` |

- 밸런스 수치 표(`data/balance.csv`)의 열 설명은 `balance_schema.json`.
