# 한 판의 흐름

**게임은 주 단위로 흘러가고, 한 주에 "의뢰 게시 → 모험가 선택 · 출발 → 귀환 · 정산"이 한 바퀴 돕니다.** 한 달(4주)마다 결산이 있고, 1년(48주) 동안 F급 길드를 E급으로 올리는 것이 첫해 목표입니다.
