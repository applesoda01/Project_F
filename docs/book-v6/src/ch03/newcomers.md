## 3. 섭외 — 손잡이 셋

플레이어가 「어떤 사람을 데려올지」에 손을 대는 길입니다. 새 장치를 만들지 않고, 이미 정한 셋을 묶었습니다.

| 손잡이 | 하는 일 | 얻는 곳 |
| --- | --- | --- |
| 구인 현수막 | **더 자주** — 놓여 있는 동안 인구 25명마다가 20명마다로 [임시] | 한스가 만듦 ([07](../ch07/placement.md)) |
| 소개장 | **원하는 직업** — 다음에 오는 사람의 직업을 고름 | 보스의 보상 ([17](../ch04/quest-material-map.md)) |
| 명성 | **좋은 사람** — 경험자가 올 확률 | 의뢰 성공 |

- 막힘에 풀 길이 붙습니다: 「성직자가 없어요」 → 소개장 · 「받을 사람이 없어요」 → 구인 현수막.
- 「정든 모험가가 아는 사람을 데려온다」는 지금은 넣지 않습니다.

## 4. 방출한 뒤 · 자리가 찼을 때

| 때 | 일어나는 일 |
| --- | --- |
| 자리가 있을 때 | 찾아온 사람이 바로 합류 (지금 그대로 · 기본값) |
| 방출한 뒤 | 바로 오지 않음. 다음 인구 칸(일곱 주쯤 뒤)에서 옴 |
| 자리가 찼을 때 | 찾아온 사람이 한 주 머물다 감. 받으려면 지금 있는 누군가를 방출해 자리를 냄 |

**되풀이해서 뽑기(어뷰징)가 막히는 까닭**

| | 까닭 |
| --- | --- |
| 칸 하나에 한 사람 | 지나간 인구 칸은 다시 오지 않음 |
| 다시 뽑는 값 | 그 자리가 일곱 주쯤 빔. 그 사람이 벌어 줄 수수료와 시설 수입을 잃음 |
| 쌓은 것 | 애착 · 칭호 · 시설에서 붙은 몫이 사라짐 |
| 다음 사람 | 무작위. 마음에 든다는 보장이 없음 |

**찾아온 사람의 정보**

| | 정한 것 |
| --- | --- |
| 보이는 곳 | 로비에 「손님」으로 한 주 동안 서 있음 |
