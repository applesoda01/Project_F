# 프롤로그 3번 일러스트 (레이어)
배경 2304x1296(중앙 1920x1080 표시, 좌우 192px·상하 108px 여분), 봉인진·빛은 검은 바탕 가산(screen) 합성, 나머지는 알파 PNG. 위치는 layout.json(1920x1080 기준).
## 애니메이션 사양(미리보기 GIF 기준)
- 구름: 배경을 가로 ±70px 이동(사인), 여분 영역 안에서만 이동
- 봉인진: 회전(게임에서는 60초 1바퀴 권장) + 밝기 0.7~1.0 맥동(1.5초)
- 칼날: 금빛 선(굵기 15/흰 심 5, 글로우)을 hand→entry는 밝게, entry→exit는 28% 밝기, exit 직전 70px는 다시 밝게. 맥동 동기
- 마왕: ±2px 떨림. 칼 꽂힌 자리 빛(light_add) 크기 맥동, 금빛 입자 위로 상승
- 용사 망토: hero_cape_big(진폭 18px), hero_cape_small(진폭 11px). 어깨 고정, 끝으로 갈수록 사인 변위, 끝은 위상 지연. 4초에 2회
