# R&D: 옆모습 SD 마네킹과 부위 애니메이션

## 목표
- 옆모습 SD 캐릭터를 **공용 마네킹(뼈대) + 의상·헤어·표정 교체** 구조로 만든다.
- 마네킹은 참고 구조와 **95% 이상 일치**(관절 위치와 겹침 순서는 100%)하도록 설계한다.
- 움직임의 부드러움, 선 굵기의 일관성, 음영 품질을 "참고 수준"에 가깝게 만든다. 참고 그림은 베끼지 않고, 그림은 우리 캐릭터로 새로 만든다.
- 비상업 프로토타입이며, **참고 자료의 이미지·파일은 저장소에 넣지 않는다(숫자만 기록)**.

## 구성
- `reference_spec.md`: 참고 구조 수치표
- `mannequin/`: 마네킹 설계(숫자 파일)와 검증 결과
- `experiments/`: 시험별 기록(입력, 설정, 수치, 실패 원인)

## 기록 규칙
- **(2026-11-05 사용자 지시)** 논의 내용은 기록·커밋하지 않는다. **결과물이 생성되거나 실험 결과가 나오면** 그때 `experiments/` 등에 기록하고 커밋·푸시한다. 이 절차는 사용자에게 묻지 않고 자동으로 진행한다(커밋은 별도 브랜치 `rnd/*`, `main` 반영은 사용자가 말할 때).
- 시험할 때마다 `experiments/`에 날짜·입력·설정·결과 수치·결론을 남긴다. (이전 Gemini 실험이 저장되지 않아 결과를 되살리지 못한 경험에서 만든 규칙)
- 실패도 기록한다.

## 합의된 단계
1. 마네킹 설계(숫자 파일) → 2. 마네킹으로 동작 제작(대기, 걷기) → 3. 마네킹 그림 입히기 → 4. 캐릭터 1명(골든 샘플)으로 의상·헤어·표정 시험 → 5. 나머지 확장
