# 참고 수치표 초안: 옆모습 SD 뼈대 구조 (2026-11-05 측정)

> 목적: 마네킹 설계의 구조 기준값. **숫자와 구조만** 기록한다. 그림과 파일은 저장하지 않는다.
> 측정 대상: 참고 페이지(공개 팬 사이트)에서 재생 중이던 SD 캐릭터 1명(100111)의 뼈대·슬롯·동작 데이터를 화면에서 읽음.
> 한계: 1명만 측정함. 단위는 뼈대 좌표 단위(스파인 단위)이며 픽셀과의 환산은 아직 확인하지 않음.

## 2. 뼈 계층 (핵심 몸 뼈대)
```
root
├─ shadow
└─ body (root 기준 x 11, y 160.9)
   ├─ head (body 기준 x -8.1, y 89.7)
   │   ├─ face
   │   ├─ hairF, hairB, hairSideF, hairSideB, hairTail, hairTwinF, hairTwinB  (머리카락 체인)
   │   └─ acce01, acce02
   ├─ armF → handF          (팔은 2마디: 팔꿈치 없이 팔 + 손)
   ├─ armB → handB
   ├─ thighF → legF         (다리는 2마디: 허벅지 + 다리)
   ├─ thighB → legB
   ├─ skirtF → skirtB
   ├─ tail, wing, acce03
   └─ weapon 계열(무기 쥐는 뼈는 handF/handB 아래에 별도)
```

## 3. 관절 위치 (바닥 root = 0 기준, 단위: 뼈대 좌표)

|---|---|---|---|

환산 메모: 다리 두 마디 합이 약 130 단위, 몸통(허벅지~어깨) 약 90, 머리 관절 높이 250.6.
→ 머리 영역이 전체 키에서 차지하는 비율이 매우 큼(SD 비율). 정확한 등신은 부위 이미지 크기로 별도 계산 필요.

## 4. 그리기 순서 (뒤 → 앞, 핵심 부위만)
shadow → (tail, hairB, wing) → headB → hairTwinB → hairSideB → **armB → handB** → shoulderB → skirtB → hipB → **legB → thighB → legF → thighF** → **body** → hipF → crotch → skirtF → grip → **head** → **armF** → shoulderF → hairSideF → **hairF** → face → (무기류) → **handF**

특징: 뒤쪽 팔·다리가 몸 뒤에, 앞쪽 팔·다리가 앞에 오는 전형적 옆모습 순서. 머리카락은 앞(hairF)과 뒤(hairB)가 머리를 사이에 둠.

## 6. 마네킹 설계에 쓸 결론 (초안)
1. 팔·다리는 2마디면 충분하다(팔꿈치 3마디 불필요).
2. 머리카락·치마·꼬리는 별도 체인으로 두어 보조 동작을 만든다.
3. 핵심 부위 14개: head, hairF, hairB, headB, body, hipF, armF, handF, armB, handB, thighF, legF, thighB, legB.
4. 표정은 face 슬롯에서 교체(7종 이미지).
5. 그리기 순서는 위 4번을 그대로 따른다.
