# 소재 편집기

소재·음식·장비·물약을 정의하는 단일 HTML 도구입니다. 설치 없이 `index.html`을 Chrome으로 열면 됩니다(인터넷이 없으면 글꼴만 기본 글꼴로 보입니다).

## 하는 일

| 탭 | 내용 |
| --- | --- |
| 소재 | 코어 35종(5계열 × F~S)은 이름·아이콘·설명만 수정, 삭제 불가. 추가 소재는 등급·계열 변경과 삭제 가능. 조합법에서 쓰는 소재는 삭제가 막힘 |
| 퀘스트 | 의뢰 유형 × 등급 35칸(삭제 불가)과 직접 추가하는 메인·서브·승급·리소스 퀘스트. 오른쪽 상세는 하위 탭 4개로 나뉨(아래 표). 소재 상세에는 "얻는 퀘스트"가 표시됨 |
| 음식·장비·물약 | 이름, 등급, 효과 설명, 오버 메모, 아이콘, 조합법(소재 최대 3종 × 수량. 음식은 각 1개) |

- 처음 열면 `docs/data/materials_v0.1.md`의 코어 35종, 복원 재료 2종, 음식 14종, 의뢰 35칸(주 소재 100%, 한 단계 아래 다른 계열 소재 7.5%씩 합계 30%, F~C는 수선 숫돌 5%. 모두 가안)(재료는 식재료 12종을 추가 소재로 만들어 연결)이 들어 있습니다. 식재료 소재는 가안이니 필요 없으면 삭제하세요.
- 추가 소재는 정렬(추가한 순·이름·등급·계열·쓰이는 곳 수, 오름·내림차순)을 고를 수 있고, 고른 정렬은 이 브라우저에 기억됩니다.
- 원본은 `data/collegium_data.json` 파일 하나입니다(아래 "저장과 불러오기"). 브라우저에는 창을 닫아도 복원되도록 임시 보관만 합니다.
- 아이콘은 긴 변 512px 이하로 줄여 보관합니다. 게임용 크기는 정해지면 내보낼 때 맞춥니다.

### 요리·오버 메모 (2026-11-05)

> **먼저 "불러오기"를 누르세요.** 브라우저에 임시 보관된 예전 작업이 열려 있으면, 그대로 저장할 때 새 소재 4종(소금·향신료·신선한 물·밀가루)과 요리 레시피를 예전 값으로 덮어쓸 수 있습니다.

- **요리 조합 규칙**(`docs/design/cooking.md`): 소재 **각 1개, 1~3종**. 요리 탭에서는 수량 칸이 없고 목록 카드에도 ×n이 나오지 않습니다.
- 요리 상세 경고: 같은 소재 두 칸 · **다른 요리와 조합법이 같음** · **어느 퀘스트 보상에도 없는 소재**(게임에서 못 얻음).
- **효과 = 게임 원본**: 요리 '효과' 칸이 게임 식사 효과에 바로 쓰입니다(비면 `data/meals.csv`). 아래에 해석 결과가 보입니다. 예: `힘·기교 +3%` → 힘·기교 ×1.03 (먹은 사람만). 능력치 이름은 힘·민첩·지력·정신·기교, `모든 능력치` = 다섯 개 모두. 수치 없는 효과(사망 확률 −20% 등)는 발견 수 보너스(요리당 +2%)만 적용.
- `meals.csv`는 메뉴 순서·등급 확인용으로만 남습니다.
- **오버 메모**(`tip`): 음식·장비·물약·몬스터·퀘스트 상세에 있는 자유 메모 칸. 나중에 게임에서 마우스를 올리면 보일 글입니다(아직 게임에 표시 안 됨). 효과·설명·기획 메모와 따로 저장됩니다.
- `tools/data_build.py`도 같은 규칙을 검사합니다(중복 재료·조합 중복은 오류, 퀘스트 없는 재료·해석 안 되는 효과는 경고).

### 장비 (2026-11-03)

- 장비마다 **종류**(검·활·지팡이·성구·단검 / 중갑·경갑·로브 / 반지·발찌·목걸이·묵주·장갑)를 고르면 그 등급의 **기본값**이 채워집니다(장비 초안 v0.1, 전투 수치는 5배). "○급 기본값으로" 버튼으로 다시 채울 수 있습니다.
- 칸: 판정 능력치(힘·민첩·지력·정신·기교, 의뢰 판정에 더해짐), 전투 수치(공격력·방어·마법방어·체력·마력·행운, 전투 장면에서만), 가격, 고유 효과.
- **착용 가능 직업**은 종류의 착용 계열로 자동 표시합니다: 무기는 주 능력치, 방어구는 두 능력치 중 하나, 장신구는 전체.
- **강화 결과 표**(+0~+10)가 자동으로 보입니다. 값 = 기본값 + 반올림(기본값 × 누적 상승률). 소수점 없음.
- 장비 탭 위 **강화 곡선**에서 +1~+10 누적 상승률(%)을 조절합니다. 기본 4·8·13·20·28·39·53·70·88·110.
- 저장할 때 이 편집기가 마지막으로 저장·불러온 뒤 파일이 바뀌었으면(다른 PC나 다른 도구) **덮어쓰기 전에 확인 창**이 뜹니다.

### 몬스터 (2026-11-03)

- **몬스터 탭**에서 퀘스트 미니 뷰에 나올 적을 정의합니다: 이름, 처음 등장 등급, 종류(짐승·마물·사람), **체력·공격력**(장비와 같은 5배 단위), 그림 파일(비우면 네모 상자), 그림 크기(%, 보스는 크게), 떨어뜨리는 소재(설명용), 설명.
- 등급 기준값(보통 몬스터)은 F급 체력 150·공격력 20에 등급 배수(그 등급 무기 공격력 ÷ F급)를 곱한 값입니다. "○급 기준값으로" 버튼으로 채우고, 기준 대비 %가 표시됩니다.
- 퀘스트 → 2. 미니 뷰 연출 탭의 적 목록은 **몬스터를 골라서** 씁니다(수·보스 여부는 퀘스트별). 그 기간의 적 전체 체력·공격력 합이 표시됩니다.
- 몬스터 상세에 "나오는 퀘스트"가 보이고, 쓰는 퀘스트가 있으면 삭제할 수 없습니다.
- 예전 파일의 적(이름만 적힌 것)은 불러올 때 같은 이름의 몬스터로 자동 연결됩니다.

### 게시판 의뢰 칸 (2026-11-03)

- 유형 × 등급 칸마다 퀘스트를 **여러 개** 둘 수 있습니다. 칸 아래 **+ 추가**를 누르면 그 칸의 기본 의뢰를 복사(보상 소재 포함)해 새 퀘스트를 만듭니다. id는 `q_<유형>_<등급>_<번호>`, 분류는 리소스.
- 게임은 게시판에 의뢰를 올릴 때 그 칸의 퀘스트 중 **하나를 무작위로** 고릅니다. 칸에 1개뿐이면 예전과 똑같습니다.
- 원칙 (2026-11-03 변경): **칸의 퀘스트끼리 서로의 주 소재를 부 소재 70%로 줍니다.** 예: 토벌 F 1줄 = 짐승 뼛조각 100% + 짐승 가죽 70%, 2줄 = 짐승 가죽 100% + 짐승 뼛조각 70%. 어느 퀘스트가 뽑혀도 칸의 두 소재가 함께 들어옵니다. (예전의 "같은 칸은 주 소재를 같게" 경고는 없앰)
- 점검 경고:
  - 부 소재가 게시판 퀘스트 한 곳에서만 나옴 (공급처 2곳 이상 권장). **식재료는 제외**(한 번 얻으면 요리가 영구 해금)
- 칸 퀘스트의 분류를 메인·서브·승급으로 바꾸면 칸에서 빠져 아래 "추가 퀘스트"로 옮겨집니다. 반대로 추가 퀘스트를 분류 리소스 + 유형으로 두면 칸으로 들어갑니다.

### 기간 규칙 계수 (퀘스트 탭 맨 위)

기본 기간보다 1주 늘거나 줄 때 적용하는 계수입니다. 바꾸면 아래 표와 모든 퀘스트의 자동 계산이 바로 바뀝니다.

| 계수 | 기본값 [가안] |
| --- | --- |
| 보상 배수 (주마다) | ×2 |
| 몬스터 수 배수 (주마다, 보스 제외, 반올림) | ×1.5 |
| 판정 기준치 (주마다) | +5% |
| 기간 범위 | −1주 ~ +2주 (1주 미만 불가) |
| 주당 보상 상한 | 켬: 한 등급 위 기본 주당 보상까지 |

**등급별 기본 보상 (2026-11-03 추가):** 계수 아래 F~S 7칸에서 등급별 기본 보상(G)을 바꿀 수 있습니다. 바꾼 칸은 주황 테두리와 "원래 값"이 표시되고, 모든 자동 계산·시뮬레이션 표에 바로 반영됩니다. **저장**을 누르면 `data/balance.csv`의 `quest,reward` 줄 값만 바꿔 씁니다(다른 줄·설명·BOM·줄바꿈은 그대로). "원래 값으로"를 누르면 balance.csv 값으로 되돌립니다. 한 등급 위인데 주당 보상이 더 낮아지면 경고합니다.

- 판정·보상 탭에서 직접 입력한 값은 계수보다 우선합니다(✎ 표시). 계수를 바꿔도 직접 입력한 값은 그대로입니다.
- 사망률은 기간에만 비례합니다: 1 − (1 − 등급 사망률)^(기간 ÷ 기본 기간).
- 등급 기본값(보상·기간·기준치·사망률)은 `data/balance.csv`의 quest 항목을 옮겨 적은 것입니다. balance.csv를 바꾸면 편집기 코드의 `BAL`도 맞춰야 합니다(게임 연결 단계에서 자동으로 읽게 바꿀 예정).
- 시뮬레이션 표: 등급 7 × 기간 변화별로 보상·주당 보상·몬스터 수·기준치·사망률 중 하나를 골라 봅니다. 주황 글자는 상한에 걸린 값입니다.

- 고른 하위 탭은 이 브라우저에 기억됩니다. 예전 작업(브라우저 저장·`backup.json`)을 열면 새 항목은 빈 값으로 채워집니다.

## 저장과 불러오기 (2026-11-03 변경)

**원본 = `Project_F/prototype/data/collegium_data.json` 한 파일.** 소재·음식·장비·물약·퀘스트(적·대사·조건 포함)·기간 규칙 계수가 모두 들어 있습니다. 아이콘 그림만 당분간 `data/icons/<id>.png`로 따로 둡니다(나중에 통합 예정).

| 버튼 | 하는 일 |
| --- | --- |
| **저장** (Ctrl+S) | 고른 폴더에 `collegium_data.json`과 아이콘을 씀. 처음 한 번만 폴더(`Project_F/prototype/data`)를 고르면 다음부터 바로 저장 |
| **불러오기** | 그 폴더의 `collegium_data.json`을 읽음. 바꾸기 전에 지금 작업과 개수를 비교해 보여 주고, 저장 안 된 변경이 있으면 경고 |
| **폴더** | 저장·불러오기할 폴더를 고르거나 바꿈 |
| 처음 상태로 | 가안 데이터로 되돌림 (두 번 눌러야 실행) |

- 오른쪽 위 상태: **● 저장 안 된 변경 있음**(주황) / **✓ 저장됨·불러옴 시각**(초록)과 파일 위치. 저장 안 된 변경이 있으면 창을 닫을 때 브라우저가 묻습니다.
- 브라우저 임시 보관은 실수로 창을 닫았을 때 복원용입니다. 다른 PC·다른 사람과 주고받는 것은 항상 `collegium_data.json`입니다.
- 폴더에 `collegium_data.json`이 없고 예전 `backup.json`만 있으면 그것을 읽습니다(예전 형식은 아이콘 그림이 파일 안에 들어 있음). 불러온 뒤 저장하면 새 형식으로 바뀝니다.
- 폴더 저장을 지원하지 않는 브라우저(Firefox·Safari)는 저장 시 JSON 파일을 내려받고, 불러오기는 파일 하나를 고릅니다(아이콘 제외). Chrome·Edge를 권장합니다.
- **CSV 7종과 zip 내보내기는 없앴습니다.** 표로 보는 기능이 필요하면 나중에 "엑셀용 내보내기"를 따로 추가합니다.

## 파일 형식 (`collegium_data.json`, version 3)

키 순서와 들여쓰기(2칸)가 고정이라 Git에서 바뀐 줄만 보입니다.

```
format: "collegium-data", version: 3, savedAt: 저장 시각
rules:     기간 규칙 계수 { rMul, mMul, refPct, dMin, dMax, cap }
seq:       새 id 번호
materials: [{ id, name, grade, line, core, desc, icon }]          icon = "icons/<id>.png" 또는 ""
items:     [{ id, kind(food/gear/potion), name, grade, desc, recipe[{m, n}], icon,
              장비만: gtype, slot(weapon/armor/acc), stats{0~4: 값}, atk, def, mdef, hp, mp, luck, price, effect }]
enhance:   강화 누적 상승률(%) 10개 (+1~+10)
monsters:  [{ id, name, grade, kind, hp, atk, img, scale, drops[소재 id], desc }]
quests:    [{ id, name, cat, grade, line, core, client, notice, desc,
              view  { region, delta, enemies[{ mon(몬스터 id), count, boss }] },
              judge { smode, stats[], boss, ref, death, reward, fameS, fameF, trustS, trustF }  (null = 자동값),
              cond  { route, minGrade, prereq[], fame, trust, hidden, rumor, near, reappear },
              talk  { appear|accept|hold|success|fail: { mode(none/line/scene), face, text, scene } },
              rewards[{ m, role, p }] }]
```

- id: `mat_<계열>_<등급>`(코어 소재), `mat_xNNN`(추가 소재), `food_NN` / `gear_NN` / `pot_NN`, `q_<유형>_<등급>`(기본 의뢰 35칸), `q_xNNN`(추가 퀘스트).
